# 全站检索

本知识库采用 **MkDocs Material 内置全文检索**，支持中文与英文关键词搜索，覆盖全部 200+ 篇文档。

## 如何使用

点击页面右上角的 **搜索图标**（或按快捷键 `/` `f` `s`），在弹出的搜索框中输入关键词即可。

- 支持多关键词组合（空格分隔）

- 实时高亮匹配片段

- 按相关度排序，点击结果直达原文
