# GB/T 50966-2024《电动汽车充电站设计标准》换版记录

## 1. 版本信息

| 项目 | 内容 |
|---|---|
| 旧版 | GB 50966-2014《电动汽车充电站设计规范》（同时废止） |
| 新版 | GB/T 50966-2024，2024 年发布 |
| 强制性 | 推荐性（GB/T） |
| 属性变化 | **GB（强制）→ GB/T（推荐）**；名称"规范"→"标准"；充电技术形态由 2014 年代"慢充为主"升级为"快充/超充/V2G 多形态" |

## 2. 主要技术变化（逐条）

| # | 变化内容 | 影响的工程环节 | 关联知识条目 |
|---|---|---|---|
| 1 | 充电站分级与供配电系统要求更新（充电主机站/群充群控等新形态） | 站区电气主接线 | L 域（充电设施）条目 |
| 2 | 大功率充电（超充）配电预留与谐波治理要求（与 GB/T 14549、MAP-G 联动） | 负荷计算、无功与谐波 | CALC-LD、PQ 域条目 |
| 3 | 与新版 GB/T 18487.1-2023、GB/T 27930-2023 接口/通信标准体系全面对齐 | 充电设备选型 | L 域条目；MAP-O 对照 |
| 4 | V2G（双向充放电）预留条款 | 并网/计量设计 | L 域条目；MAP-Q |
| 5 | 消防要求细化（与 GB 50016-2014、GB 55037-2022 协调），充电区与站界布置 | 总图、消防 | PR 域条目 |
| 6 | 防雷与接地按 GB/T 50065/GB 50057 体系更新 | 防雷接地设计 | GR 域条目 |

## 3. 对本知识库的影响

- 需复审条目：cn-04 标准包充电节、MAP-O 对照表
- 需新建条目：充电站供配电设计要点（PR/L 域）、超充站谐波专项（PQ 域）
- 注意：车库内分散充电设施仍执行 GB/T 51313-2018，**两者适用边界勿混淆**（独立充电站 vs 车库分散桩）

## 4. 过渡期衔接

- 新建独立充电站按 2024 版执行；既有站增容改造以改造设计文件审查日期为界；
- 分散充电设施（车库/停车场）走 GB/T 51313-2018 路线，标准引用错位是校审常见错误。
