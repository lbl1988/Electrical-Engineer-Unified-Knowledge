# 接地故障电流精确计算

## 1. 算例背景

单相接地故障（LG）和两相接地故障（LLG）是电力系统最常见的短路类型，其故障电流**取决于零序网络**。工程设计必须根据接地方式精确计算，否则会导致：
- 保护灵敏度不够（TN 系统 RCD 30 mA 未动作）
- 保护误动（IT 系统过流保护因电容电流误动）
- 设备热稳定不足（接地点电弧持续燃烧）

## 2. 核心公式

### 2.1 对称分量法（通用）

不对称短路故障的故障相电流（相量）：

| 故障类型 | 故障相电流 | 零序电流 |
|---|---|---|
| **单相接地（LG）** | $\dot{I}_f = \dot{I}_1 = \dot{I}_2 = \dot{I}_0 = \frac{\dot{E}_a}{Z_1 + Z_2 + Z_0 + 3 Z_f}$ | $\dot{I}_0 = \dot{I}_f$ |
| **两相接地（LLG）** | $\dot{I}_b = a^2 \dot{I}_1 + a \dot{I}_2 + \dot{I}_0$；$\dot{I}_c = a \dot{I}_1 + a^2 \dot{I}_2 + \dot{I}_0$ | $\dot{I}_0 = -\dot{I}_1 Z_2/(Z_2 + Z_0 + 3Z_f)$ |

其中：
- $\dot{I}_1 = (\dot{E}_b - \dot{E}_c)/(Z_1 + (Z_2+Z_0+3Z_f) \parallel (Z_1+Z_f))$（LLG 简化）
- $Z_1, Z_2, Z_0$ = 正/负/零序总阻抗
- $Z_f$ = 故障点过渡电阻（电弧 $Z_f \approx 0.1 \sim 1 \Omega$，金属短路 $Z_f = 0$）

### 2.2 变压器接地方式对 $Z_0$ 的影响

| 接地方式 | $Z_0$ 特点 | 单相接地电流 |
|---|---|---|
| **YNyn0**（直接接地） | $Z_0 \approx Z_{0,\text{line}} + Z_{T,0}$（较小） | 大，接近三相短路 |
| **YNyn0 + NGR（消弧线圈/电阻）** | $Z_0$ 被 NGR 限制 | 由 NGR 阻值决定，小 |
| **Yy**（不接地） | $Z_0 \approx \infty$（理想） | 很小（仅系统对地电容电流） |
| **ΔYn**（低压侧直接接地） | 从高压侧看 $Z_0$ 取决于低压侧接地 | 高压侧单相接地电流取决于两侧耦合 |

## 3. 完整算例

### 3.1 已知条件（220 kV 变电站 110 kV 侧单相接地）

| 参数 | 值 | 说明 |
|---|---|---|
| 系统 | 220/110 kV，YNyn0 直接接地变压器 | 主变 240 MVA |
| 主变 $Z_{T,1} = Z_{T,2}$ | 0.10 pu | |
| 主变 $Z_{T,0}$ | 0.15 pu | YNyn0 零序电抗比正序大 |
| 110 kV 线路 $Z_{L,1}$ | 0.03 + j0.10 pu | |
| 110 kV 线路 $Z_{L,0}$ | 0.10 + j0.25 pu | 零序比正序大 2~3 倍 |
| 故障类型 | 单相金属性接地（$Z_f = 0$） | 110 kV 母线 |
| $S_{\mathrm{base}}$ | 100 MVA | |
| $U_{\mathrm{base}}$ | 115 kV（110 kV 侧） | |

### 3.2 计算步骤

**步骤 1：归算到故障点电压等级（110 kV），合并各序阻抗**

| 序 | 计算 | 结果（pu） |
|---|---|---|
| 正序 $Z_1$ | $Z_{T,1} + Z_{L,1} = 0.10 + 0.03 + j0.10$ | $0.13 + j0.10 = 0.164 \angle 37.6°$ |
| 负序 $Z_2$ | 同正序（旋转电机 $Z_2 \approx Z_1$；线路变压器 $Z_2 = Z_1$） | $0.164 \angle 37.6°$ |
| 零序 $Z_0$ | $Z_{T,0} + Z_{L,0} = 0.15 + 0.10 + j0.25$ | $0.25 + j0.25 = 0.354 \angle 45°$ |

**步骤 2：单相接地故障电流**

$$Z_{\Sigma} = Z_1 + Z_2 + Z_0 = (0.13+0.13+0.25) + j(0.10+0.10+0.25) = 0.51 + j0.45 = 0.680 \angle 41.3°$$

$$\dot{I}_f = \frac{\dot{E}_a}{Z_{\Sigma}} = \frac{1.1 \angle 0°}{0.680 \angle 41.3°} = 1.62 \angle -41.3° \text{ pu}$$

**步骤 3：有名值**

$$I_{\mathrm{base}} = \frac{S_{\mathrm{base}}}{\sqrt{3} U_{\mathrm{base}}} = \frac{100}{\sqrt{3} \times 115} = 0.501 \text{ kA}$$

$$I_f = 1.62 \times 0.501 = 0.812 \text{ kA} = 812 \text{ A}$$

**步骤 4：三相短路对比**

$$I''_{\text{三相}} = \frac{1.1}{\sqrt{3} \times |Z_1|} I_{\mathrm{base}} = \frac{1.1}{1.732 \times 0.164} \times 0.501 = 1.91 \text{ kA}$$

**结论**：直接接地系统单相接地电流（0.81 kA）约为三相短路电流（1.91 kA）的 42%——足够使过流保护动作。

### 3.3 IT 系统对比（中性点不接地）

若同一 110 kV 侧改为 **IT 系统（中性点不接地）**：

$$Z_0 \approx j \infty \text{（理想，只有对地电容）}$$

$$I_f = \sqrt{3} \omega C_{\Sigma} U_{\mathrm{ph}}$$

典型值：110 kV 系统对地电容 $C_{\Sigma} \approx 0.5 \sim 2 \mu$F/km，50 km 线路：

$$I_f = \sqrt{3} \times 314 \times 1 \times 10^{-6} \times 50 \times \frac{115}{\sqrt{3}} = 314 \times 10^{-6} \times 50 \times 115 = 1.80 \text{ A}$$

**结论**：IT 系统单相接地电流仅 1~5 A（电容电流），保护不动作，允许带故障运行 2 小时内必须找到故障点。

## 5. 工程注意点

| 要点 | 说明 |
|---|---|
| 过渡电阻 $Z_f$ 取值 | 金属短路 0 Ω，电弧 0.1~1 Ω，高阻故障（树枝等）可达数十 Ω |
| $Z_2 \approx Z_1$ 假设 | 对同步机近似成立，对逆变器侧（电力电子）需单独计算 $Z_2$ |
| 变压器 $Z_0$ 方向 | YNyn0 变压器从高压侧看低压侧接地时，$Z_0$ 取决于低压侧中性点阻抗 |
| IT 系统电容电流 | 电缆比架空线大 2~3 倍，长线路可能超 10 A → 需装消弧线圈 |
