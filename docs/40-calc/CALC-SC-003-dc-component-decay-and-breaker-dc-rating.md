# 短路电流直流分量衰减计算

## 1. 算例背景

三相短路发生时，短路电流包含**交流分量（周期分量）**和**直流分量（非周期分量）**。直流分量的大小和衰减时间对**断路器开断能力校验**至关重要：开断瞬间直流分量过高会导致断路器**开断失败**（弧重燃或触头熔焊）。

**设计要求**：断路器开断能力必须包含直流分量。标准 GB 1984 规定：额定短路开断电流的峰值系数 **1.7（纯交流）→ 2.0（直流分量 50%）**，开断时刻直流分量不得超过额定值。

## 2. 核心公式

### 2.1 短路电流完整表达式（派克方程形式）

三相瞬时短路电流（a 相）：

$$i_a(t) = \sqrt{2} I''_{k} \left[\sin(\omega t - \frac{\pi}{2} + \theta) - e^{-t/T_a} \sin(\theta - \frac{\pi}{2})\right] + \sqrt{2} I_{dc} e^{-t/T_a}$$

简化工程表达式：

$$i_k(t) = \sqrt{2} I''_{k} \sin(\omega t + \alpha) + \sqrt{2} I_{dc}(t) e^{-t/T_a}$$

其中：
- $I''_{k}$ = 次暂态短路电流交流分量（有效值）
- $I_{dc}(t) = I''_{k} \sin(\alpha)$ — 直流分量初始值
- $\alpha$ = 短路瞬间的电压相位（决定直流分量大小，最恶劣 $\alpha = 90°$）
- $T_a = L_{\Sigma}/R_{\Sigma}$ — 直流分量衰减时间常数（秒）
- $\omega = 2\pi \times 50 = 314$ rad/s

### 2.2 直流分量时间常数 $T_a$

$$T_a = \frac{X_{R\Sigma} + X''_{d,\mathrm{gen}}}{\omega (R_{\Sigma} + R_{a,\mathrm{gen}})}$$

| 系统类型 | $T_a$ 典型值 | 备注 |
|---|---|---|
| 低压配电网（变压器短路） | 0.05 ~ 0.1 s | 衰减快（R 大） |
| 中压 10/20 kV 系统 | 0.1 ~ 0.2 s | |
| 高压 110 kV 及以上 | 0.2 ~ 0.8 s | 发电机占主导（$X/R$ 大） |
| 特高压系统 | 0.5 ~ 1.0 s | |

### 2.3 断路器开断时刻直流分量计算

断路器在 **$t_{\mathrm{break}}$** 时刻开断（通常是短路后的第 1~3 个工频周波，即 $0.02 \sim 0.06$ s）：

$$I_{dc, \mathrm{break}} = I''_{k} \sin(\alpha) e^{-t_{\mathrm{break}}/T_a}$$

直流分量百分比（标准定义）：

$$\frac{I_{dc, \mathrm{break}}}{\sqrt{2} I''_{k}} \times 100\% = \frac{1}{\sqrt{2}} \sin(\alpha) e^{-t_{\mathrm{break}}/T_a} \times 100\%$$

## 3. 完整算例

### 3.1 已知条件

| 参数 | 值 | 说明 |
|---|---|---|
| 系统 | 220 kV 高压，100 km 线路末端三相短路 | |
| $S_{\mathrm{base}}$ | 100 MVA | 基准容量 |
| $U_{\mathrm{base}}$ | 220 kV | 基准电压 |
| 电源侧 $X_d''$ | 0.15 pu | 发电机次暂态电抗 |
| 电源侧 $R_a$ | 0.003 pu | 发电机电枢电阻 |
| 线路 $X_L$ | 0.08 pu | |
| 线路 $R_L$ | 0.012 pu | |
| 断路器动作时间 | 0.04 s（2 周波） | 典型速动保护 |
| 短路相位 | $\alpha = 90°$（最恶劣） | 直流分量最大 |

### 3.2 计算步骤

**步骤 1：总阻抗**

$$X_{\Sigma} = X_d'' + X_L = 0.15 + 0.08 = 0.23 \text{ pu}$$

$$R_{\Sigma} = R_a + R_L = 0.003 + 0.012 = 0.015 \text{ pu}$$

**步骤 2：次暂态短路电流**

$$I''_{k} = \frac{U_{f}}{\sqrt{3} Z_{\Sigma}} I_{\mathrm{base}} = \frac{1.1}{\sqrt{3} \times 0.23} \times \frac{100}{\sqrt{3} \times 220} = 2.81 \text{ kA}$$

（$U_f = 1.1$ pu 故障前电压，$c = 1.1$ 高压系数）

**步骤 3：直流分量时间常数**

$$T_a = \frac{X_{\Sigma}}{\omega R_{\Sigma}} = \frac{0.23}{314 \times 0.015} = 0.0487 \text{ s}$$

**步骤 4：断路器开断时刻直流分量**

$$I_{dc,0} = I''_{k} \sin(90°) = 2.81 \text{ kA}$$

$$I_{dc,\mathrm{break}} = 2.81 \times e^{-0.04/0.0487} = 2.81 \times e^{-0.821} = 2.81 \times 0.440 = 1.24 \text{ kA}$$

直流分量百分比：

$$\frac{I_{dc,\mathrm{break}}}{\sqrt{2} I''_{k}} = \frac{1.24}{\sqrt{2} \times 2.81} = 31.2\%$$

**步骤 5：断路器开断能力校验**

选额定开断电流 $I_{r} = 40$ kA 的 220 kV 断路器（典型）。

断路器直流分量耐受（GB 1984）：额定值通常为 50%（即开断时刻 $I_{dc}/(\sqrt{2}I_r) \leq 50\%$）。

实际：$1.24/(\sqrt{2} \times 40) = 2.2\%$ ✓ 远低于额定值。

**峰值校验**（开断瞬间短路电流峰值）：

$$i_{\max} = \sqrt{2} I''_{k} \times 1.8 = 1.414 \times 2.81 \times 1.8 = 7.16 \text{ kA}$$

1.8 倍峰值系数（含直流分量）。断路器额定峰值耐受电流通常为 $2.5 \times I_r = 100$ kA ✓。

### 3.3 结果表

| 量 | 计算值 | 说明 |
|---|---|---|
| $I''_{k}$ | 2.81 kA | 次暂态短路电流 |
| $T_a$ | 0.0487 s | 直流分量衰减时间常数 |
| $I_{dc,0}$ | 2.81 kA | 直流分量初始值 |
| $I_{dc,\mathrm{break}}$ | 1.24 kA | 开断时刻直流分量 |
| 直流分量% | 31.2% | 小于断路器额定 50% |
| $i_{\max}$ | 7.16 kA | 峰值电流 |

## 5. 工程注意点

| 要点 | 说明 |
|---|---|
| 最恶劣相位 | $\alpha = 90°$（电压峰值时短路），直流分量初始值最大 |
| $T_a$ 近似 | 简化计算可近似 $T_a \approx T_d'$（d 轴暂态时间常数），误差 < 20% |
| 发电机贡献 | 发电机距离短路点越近，$T_a$ 越大（衰减越慢），直流分量越高 |
| 断路器开断相位 | 选相断路器可在小直流分量相位开断，降低对断路器的要求 |
