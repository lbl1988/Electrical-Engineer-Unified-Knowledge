# 低压系统三相短路电流计算（等效电压源法）

## 1. 摘要

本条目给出 10/0.4kV、1000kVA（uk=6%）配变低压系统在三相短路下的初始对称短路电流 $I_k''$、峰值（冲击）电流 $i_p$ 与热稳定校验的完整计算流程，依据 GB/T 15544.1-2013（idt IEC 60909-0）等效电压源法。算例双短路点（变压器低压端子 d1、电缆末端 d2）实测演示：**d1 处 $I_k''\approx 23.3$ kA、$i_p\approx 53.6$ kA；d2 处 $I_k''\approx 21.5$ kA、$i_p\approx 46.5$ kA**。结论直接用于低压电器分断/动稳定选型与电缆热稳定校验。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 初始对称短路电流 $I_k''$ | 短路发生瞬间（t=0）的对称交流分量有效值，不计衰减 | GB/T 15544.1-2013 |
| 峰值短路电流 $i_p$ | 预期短路电流最大可能瞬时值（含直流分量） | 同上 |
| 等效电压源法 | 在短路点施加唯一理想电压源 $c \cdot U_n/\sqrt{3}$，其余电源置零的计算模型 | 同上 |
| 电压系数 $c$ | 计入系统电压偏差/波动的等效电压修正系数；400V 低压取 1.05 | 同上，表 1 |
| 峰值系数 $\kappa$ | $i_p$ 与 $\sqrt{2}I_k''$ 的比值，由短路点 $R/X$ 决定 | 同上 |
| 远端短路（far from generator） | 短路期间交流分量基本不衰减（MV/LV 电网绝大多数工况） | 同上 |

## 3. 原理与公式

**总模型**：短路点唯一电压源 $c \cdot U_n/\sqrt{3}$，网络阻抗串联叠加。

$$I_k'' = \frac{c \cdot U_n}{\sqrt{3} \cdot Z_k}, \quad Z_k = \sqrt{R_k^2 + X_k^2}$$

$$i_p = \kappa \cdot \sqrt{2} \cdot I_k'', \quad \kappa = 1.02 + 0.98\,e^{-3R_k/X_k}$$

**各阻抗归算**（归算至短路点电压级 $U_n=400$ V）：

| 环节 | 公式 | 说明 |
|---|---|---|
| 上级系统 | $X_Q = U_{nQ}^2 / S_{scQ}$ | $S_{scQ}$ 为上级母线短路容量；$R_Q$ 通常可忽略（见 §6 争议 2） |
| 变压器 | $Z_T = \dfrac{u_k}{100}\cdot\dfrac{U_{nT}^2}{S_{rT}}$；$R_T = \dfrac{P_{krT}}{3 I_{rT}^2}$；$X_T=\sqrt{Z_T^2-R_T^2}$ | $P_{krT}$ 为负载损耗，取产品样本 |
| 线路 | $R_L = r\cdot l,\ \ X_L = x\cdot l$ | 电缆/母线单位长度阻抗 × 长度，多根并联除以根数 |
| 低压电缆热稳定 | $S \ge I_k''\sqrt{t}/k$ | GB/T 16895.5 表 43A：XLPE 铜芯 k=143 |

**符号表**：

| 符号 | 含义 | 单位 |
|---|---|---|
| $U_n$ | 短路点标称线电压（400 V） | V |
| $S_{scQ}$ | 上级系统短路容量 | MVA |
| $u_k$ | 变压器短路阻抗百分数 | % |
| $S_{rT}, P_{krT}, I_{rT}$ | 变压器额定容量、负载损耗、额定电流 | kVA, kW, A |
| $t$ | 短路切除时间（保护动作＋分断） | s |

**适用边界**：① 远端短路（不含发电机直供）；② 三相对称短路（单相/两相另见 CALC-SC-002，待建）；③ 阻抗归算采用标称电压 400V，变压器变比按标称值。

## 5. 设计/选型要点（校审清单）

- [ ] 上级系统参数取值口径确认：供电协议给出的 $S_{scQ}$ 是否含电压系数（见 §6-2）
- [ ] 变压器 $P_{krT}$ 用**实际订货样本值**，方案阶段可用典型值并在计算书标注"待厂家确认"
- [ ] 两个短路点必须分别算：**d1（主进线柜）校验 ACB 的 Icu/Icw/Ipk；d2（馈线末端）决定 MCCB 降档选型**——末端按全 50kA 选是常见浪费
- [ ] $i_p$ 校验动稳定（母排支持件应力、电器 Ipk、成套设备峰值耐受）
- [ ] 电缆热稳定校验用**末端最小短路电流对应的保护动作时间**（与灵敏度校验联动）
- [ ] 计算书须注明方法依据（GB/T 15544.1）与 c、κ 取值，杜绝"来源不明的查表值"

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| ① c 系数双重计入（$X_Q$ 与电流公式分子都乘 c） | $I_k''$ 偏小约 5% | $X_Q=U_n^2/S_{scQ}$（协议容量按标称口径）＋分子统一乘 c=1.05；若供电方明确 $S_{scQ}$ 已按 c 电压折算，则改用 $cU_n^2/S_{scQ}$ 并在计算书注明 | GB/T 15544.1 表 1 及条文说明 |
| ② 系统阻抗 $R_Q$ 计入与否 | 影响很小但口径混乱 | 上级 MV/HV 系统 $X/R\gg1$，$R_Q$ 可忽略（ip 略偏保守，可接受） | 同上 |
| ③ κ 直接取 1.8 或查错表 | $i_p$ 虚大 10%~20%，浪费设备 | 变压器近端按实际 R/X 算 κ（本例 1.63）；仅当 R/X 未知且为远端低压网络时可用 κ=1.3 简化 | GB/T 15544.1 |
| ④ 忽略母线/电缆阻抗只算变压器 | 末端断路器选级过高（成本）或误判选择性 | 按短路点逐段累加阻抗（本例 d2 演示） | 工程惯例＋§5 |
| ⑤ 热稳定校验用变压器端子电流＋末端切除时间 | 电缆截面虚大 | 电流与时间必须同点同工况：末端电流＋末端时间 | GB/T 16895.5 |

## 7. 完整算例

### 7.1 已知条件

| 参数 | 数值 | 来源 |
|---|---|---|
| 系统 | 10kV 母线短路容量 $S_{scQ}=200$ MVA | 供电协议（按标称电压口径） |
| 变压器 | $S_{rT}=1000$ kVA，10/0.4 kV，Dyn11，$u_k=6\%$，$P_{krT}=10.3$ kW | 产品样本（SC(B)13 级典型值） |
| 低压母线 | 变压器—主进线柜母排忽略阻抗 | 距离短（<3m），偏保守 |
| 馈线 d2 | 4×(1×185) YJV 铜芯并联 ×30 m，$r=0.098\ \Omega/km$，$x=0.10\ \Omega/km$（单芯） | 电缆样本 |
| 电压系数 | $c=1.05$（400V） | GB/T 15544.1 表 1 |

**短路点**：d1＝低压主进线柜母线；d2＝馈线电缆末端动力箱。

### 7.2 阻抗归算（400V 级，单位 mΩ）

**变压器：**

$$I_{rT} = \frac{1000}{\sqrt{3}\times0.4} = 1443.4\ \text{A}$$

$$Z_T = \frac{6}{100}\cdot\frac{400^2}{1000\times10^3} = 9.60\ \text{m}\Omega$$

$$R_T = \frac{10\,300}{3\times1443.4^2} = 1.648\ \text{m}\Omega,\quad X_T = \sqrt{9.60^2-1.648^2} = 9.458\ \text{m}\Omega$$

**上级系统**（$R_Q$ 忽略，见 §6-②）：

$$X_Q = \frac{400^2}{200\times10^6} = 0.80\ \text{m}\Omega$$

### 7.3 短路点 d1（主进线柜母线）

$$R_{k1}=1.648,\quad X_{k1}=0.80+9.458=10.258\ \text{m}\Omega,\quad Z_{k1}=\sqrt{1.648^2+10.258^2}=10.39\ \text{m}\Omega$$

$$\boxed{I_{k1}'' = \frac{1.05\times400}{\sqrt{3}\times10.39\times10^{-3}} = 23.3\ \text{kA}}$$

$$R/X = 0.161 \Rightarrow \kappa_1 = 1.02+0.98\,e^{-3\times0.161} = 1.63$$

$$\boxed{i_{p1} = 1.63\times\sqrt{2}\times23.3 = 53.6\ \text{kA}}$$

**选型动作**：主进线 ACB 选 $I_{cu}\ge$23.3 kA（取 42/50 kA 档）、$I_{pk}\ge$53.6 kA、母线动稳定按 53.6 kA 校验。

### 7.4 短路点 d2（馈线电缆末端）

电缆（4 根并联）：$R_L = 0.098\times30/4 = 0.735$，$X_L = 0.10\times30/4 = 0.75$ mΩ

$$R_{k2}=1.648+0.735=2.383,\quad X_{k2}=10.258+0.75=11.008\ \text{m}\Omega,\quad Z_{k2}=11.26\ \text{m}\Omega$$

$$\boxed{I_{k2}'' = \frac{1.05\times400}{\sqrt{3}\times11.26\times10^{-3}} = 21.5\ \text{kA}}$$

$$R/X=0.217 \Rightarrow \kappa_2 = 1.02+0.98\,e^{-0.650} = 1.53 \Rightarrow \boxed{i_{p2}=46.5\ \text{kA}}$$

**κ=1.3 简化对照**（R/X 未知时）：$i_{p2}' = 1.3\times\sqrt{2}\times21.5 = 39.5$ kA ＜ 精确值 46.5 kA——简化值偏保守方向，可用于动稳校验的下限估计但**不宜用于电器铭牌对比的精确论证**。

### 7.5 电缆热稳定校验（d2 处）

末端保护（MCCB 瞬动）切除时间取 $t=0.4$ s（含燃弧时间）：

$$S_{min} = \frac{I_{k2}''\sqrt{t}}{k} = \frac{21\,500\times\sqrt{0.4}}{143} = \frac{21\,500\times0.632}{143} = 95\ \text{mm}^2 < 185\ \text{mm}^2\ \checkmark$$

（校验通过；若改用更长延时或更小截面电缆，须重算。）

### 7.6 结果汇总

| 短路点 | $I_k''$ (kA) | $\kappa$ | $i_p$ (kA) | 用途 |
|---|---|---|---|---|
| d1 主进线柜 | 23.3 | 1.63 | 53.6 | ACB 选型、母线动稳定 |
| d2 电缆末端 | 21.5 | 1.53 | 46.5 | MCCB 选型、电缆热稳定 |
