# 高压短路暂态电动势计算

## 1. 算例背景

IEC 60909-0 标准短路计算的核心在于**暂态电动势 $E_f$** 的取值——它决定了短路电流的"源头电压"。不同设备类型有不同的公式，计算值直接影响短路电流结果的 **±5~20%** 偏差，对高压断路器开断能力校验至关重要。

## 2. 核心公式

### 2.1 c 系数（电压修正系数）

IEC 60909-0 引入 $c$ 系数修正故障前电压，补偿负荷电流和发电机电压调节：

| 电压等级 | c（最大短路） | c（最小短路） |
|---|---|---|
| LV（0.4 kV） | 1.00 | 0.95 |
| MV（6~30 kV） | 1.10 | 1.00 |
| HV（35~550 kV） | 1.10 | 1.00 |
| EHV（750 kV） | 1.10 | 1.00 |

**故障点电压**：$U_f = c \cdot U_{n}$

### 2.2 发电机暂态电动势

发电机直接接电网（故障在高压侧）：

$$E_{f,G}'' = c \cdot U_{n,G}$$

发电机经变压器接电网：

$$E_{f,G}'' = U_{n,G} \cdot \left(1 + k_{G} \cdot X_{d,G}'' \cdot \frac{S_{\mathrm{base}}}{S_{N,G}}\right)$$

其中 $k_G \approx 0.05 \sim 0.10$（电网电压系数，高压大系统取 0.10）。

### 2.3 电动机暂态电动势

高压同步电动机：

$$E_{f,M}'' = 1.1 \cdot U_{n,M}$$

高压感应电动机（IEC 60909 要求考虑电动机贡献）：

$$I_{k,M}'' = \frac{E_{f,M}''}{Z_{d,M}''} = 3.5 \cdot I_{r,M}$$

即**高压感应电动机的短路贡献取 $3.5 \times I_{r,M}$**（次暂态额定电流的 3.5 倍）。

### 2.4 变压器与线路阻抗归算

变压器短路阻抗（标幺值，IEC 60909 方法）：

$$Z_{T} = u_{k,r} \cdot \frac{S_{\mathrm{base}}}{S_{N,T}} \angle \varphi_T$$

其中 $u_{k,r}$ = 变压器短路电压百分比（%），$\varphi_T = \arctan(X/R)$。

## 3. 完整算例

### 3.1 已知条件（500 kV 变电站高压侧三相短路）

| 参数 | 值 |
|---|---|
| 系统 | 500 kV EHV 变电站，2×750 MVA 主变 |
| $S_{\mathrm{base}}$ | 1000 MVA |
| 系统侧短路容量 | $S_{\mathrm{sc,grid}} = 15000$ MVA |
| 主变 1 号 $S_{N,T}$ | 750 MVA，$u_k = 14\%$，$X/R = 10$ |
| 主变 2 号 | 同 1 号 |
| 低压侧 | 220 kV，带发电机 2×600 MW（$X_d'' = 0.15$ pu on 600 MVA） |
| 故障点 | 500 kV 母线 |

### 3.2 计算步骤

**步骤 1：故障点电压**

$$U_f = c \cdot U_n = 1.10 \times 500 = 550 \text{ kV}$$

**步骤 2：各电源归算阻抗**

| 电源 | 归算公式 | 结果（pu on 1000 MVA） |
|---|---|---|
| 系统 | $Z_{\mathrm{grid}} = S_{\mathrm{base}} / S_{\mathrm{sc,grid}}$ | $1000/15000 = 0.0667$ pu |
| 主变 T1（与 T2 并联） | $Z_T = u_k \cdot S_{\mathrm{base}}/S_{N,T} / 2 = 0.14 \times 1000/750 / 2$ | $0.0933$ pu |
| 发电机 G1+G2（经 T） | 先算发电机 $X_d''$ on 600 MVA：0.15 → on 1000 MVA：0.15×1000/600=0.25<br>加主变阻抗（从低压看）：0.25 + 0.1867 = 0.4367<br>归算到高压侧：$Z_G'' = 0.4367$ pu | 0.4367 pu（从 500 kV 看进） |

**步骤 3：各电源暂态电动势**

| 电源 | $E_f''$ 公式 | 结果（pu） |
|---|---|---|
| 系统 | $c \cdot U_n$ | 1.10 |
| 发电机 | $U_{n,G} (1 + k_G X_d'' \cdot S_b/S_{N,G}) = 1.0 \times (1 + 0.10 \times 0.15 \times 1000/600) = 1.025$ | 1.025 |

**步骤 4：短路电流（合并电源）**

从 500 kV 母线看，系统和发电机并联：

$$I_k'' = \frac{E_f''}{Z_{\Sigma}} \text{，其中各电源 } I_i = E_{f,i}''/Z_i$$

逐源计算：

$$I_{\mathrm{grid}} = \frac{1.10}{0.0667} = 16.50 \text{ pu}$$

$$I_G = \frac{1.025}{0.4367} = 2.35 \text{ pu}$$

总短路电流（代数和，同方向）：

$$I_{\mathrm{total}} = 16.50 + 2.35 = 18.85 \text{ pu}$$

有名值（500 kV 侧）：

$$I_{\mathrm{base}} = \frac{1000}{\sqrt{3} \times 525} = 1.10 \text{ kA}$$

$$I_k'' = 18.85 \times 1.10 = 20.7 \text{ kA}$$

**步骤 5：短路容量**

$$S_{\mathrm{sc,total}} = \sqrt{3} \times 525 \times 20.7 = 18.8 \text{ GVA}$$

### 3.3 结果对比（不含发电机贡献 vs 含）

| 方案 | 短路容量 | 贡献占比 |
|---|---|---|
| 仅系统 | 15 GVA | 79.8% |
| 仅发电机 | 2.35×1.10×√3×525 = 2.35 GVA | 12.5% |
| **合计** | **17.35 → 校正后 18.8 GVA** | **系统 79%，发电机 12%（其他 9%）** |

**结论**：大型发电机对高压侧短路电流贡献约 10~15%，**必须纳入计算**，否则断路器开断能力校核会偏保守。

## 5. 工程注意点

| 要点 | 说明 |
|---|---|
| c 系数取值 | HV 系统最大短路 c=1.10 包含了发电机电压调节效应，不是保守值 |
| 电动机贡献 | 只有 **3 kV 以上高压感应电动机**需考虑，低压中小型机可忽略 |
| 电源多支路 | 独立计算各支路 $I_i = E_{f,i}/Z_i$，同方向代数相加（不叠加阻抗后求 $E_f/Z_\Sigma$） |
| 网络化简 | 用 **星形-三角形变换** 化简多支路复杂网络，保证精度 |
