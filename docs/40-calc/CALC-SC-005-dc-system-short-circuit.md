# 直流系统短路电流计算

## 1. 算例背景

直流侧短路是 UPS、电力工程直流操作电源、储能 PCS 直流母线的关键校验工况。与交流短路不同，**直流短路无自然过零点**，短路电流不存在周期分量，而是由**电源内阻与回路电阻/电感**决定的准稳态上升与衰减过程。算错会导致：

- 直流断路器开断能力不足 → 烧毁甚至火灾（CASE-052 蓄电池组起火即源于此）；

- 直流馈线选择错误 → 保护拒动或越级跳闸；

- UPS 直流母线电压跌落 → 服务器/医疗设备掉电。

**本条目解决**：蓄电池组 / UPS 直流母线 / 储能 PCS 直流侧三类典型场景的短路电流计算与直流断路器选型，统一遵循 IEC 61660 逼近法（GB/T 22589 等同采用）。

## 2. 核心公式

### 2.1 直流短路电流的电源分类

IEC 61660 将直流短路电源分为四类，每类电流波形与计算方法不同：

| 电源        | 稳态短路电流                                               | 峰值短路电流                                   | 典型衰减时间常数                   |
| --------- | ---------------------------------------------------- | ---------------------------------------- | -------------------------- |
| **蓄电池组**  | $I\_{k,B} = U\_{B0}/(R\_B + R\_L)$                   | $i\_{p,B} = \kappa\_B \cdot I\_{k,B}$    | $T\_B = L/(R\_B + R\_L)$   |
| 静止整流器（电网） | $I\_{k,R} = k\_R \cdot I\_{r,R}$                     | $i\_{p,R} = 1.1 \cdot I\_{k,R}$          | $T\_R \approx 10\~15$ ms   |
| 直流电机（反馈）  | $I\_{k,M} = (U\_{M0}-E)/(R\_M+R\_L)$                 | $i\_{p,M} = \kappa\_M \cdot I\_{k,M}$    | $T\_M = L/R\_M$（30\~50 ms） |
| 电容器（放电）   | $i\_{p,C} = U\_{C0}/\sqrt{L/R \cdot C \cdot \ldots}$ | $i\_{p,C} = U\_{C0}/\sqrt{L\_C \cdot C}$ | $T\_C = L\_C/R\_C$         |

**UPS 与储能场景以蓄电池为主**，整流器在电网侧短路时短时贡献有限；电容器放电瞬时但能量小；直流电机反馈仅在传统电站直流系统需考虑。

### 2.2 蓄电池组短路电流（核心）

#### 稳态短路电流 $I\_{k,B}$

$$I\_{k,B} = \frac{U\_{B0}}{R\_{B} + R\_L}$$

| 符号         | 含义                          | 单位 |
| ---------- | --------------------------- | -- |
| $U\_{B0}$  | 蓄电池开路电压（满充，2.20 V/cell × N） | V  |
| $R\_B$     | 蓄电池内阻（总内阻 = 单体内阻 × 单体数）     | mΩ |
| $R\_L$     | 回路电阻（电缆 + 接触电阻 + 熔断器）       | mΩ |
| $I\_{k,B}$ | 稳态短路电流（准稳态）                 | A  |

#### 峰值短路电流 $i\_{p,B}$

$$i\_{p,B} = \kappa\_B \cdot I\_{k,B}$$

其中峰值系数 $\kappa\_B$ 由时间常数比决定：

$$\kappa\_B = 1 + e^{-\frac{0.3 \cdot \pi}{\sqrt{T\_B/RC - 0.3^2}}}$$

工程实用逼近（GB/T 22589 §4.2）：

$$\kappa\_B \approx 1.0 + 0.5 \cdot \frac{T\_B}{T\_B + 0.4}$$

简化查表法：

| $T\_B = L/(R\_B+R\_L)$ | $\kappa\_B$（典型） |
| ---------------------- | --------------- |
| < 5 ms                 | 1.10            |
| 5\~20 ms               | 1.20\~1.30      |
| 20\~50 ms              | 1.30\~1.40      |
| > 50 ms                | 1.40\~1.45      |

### 2.3 整流器短路电流（UPS AC/DC 变换侧）

$$I\_{k,R} = k\_R \cdot I\_{r,R}, \quad i\_{p,R} = 1.1 \cdot I\_{k,R}$$

- $I\_{r,R}$ = 整流器额定电流（A）

- $k\_R$ = 整流器短路系数（GB/T 22589 §5）：取值 $5 \sim 10$（取决于整流变压器阻抗与电网容量）

- 衰减时间常数 $T\_R \approx 10\~15$ ms

### 2.4 总短路电流合成

多电源并联直流母线短路（如 UPS 直流母线同时连蓄电池 + 整流器 + 电容）：

$$i\_{p,total} = \sum i\_{p,i} \quad (\text{峰值代数相加，保守})$$

$$I\_{k,total} = \sum I\_{k,i} \quad (\text{稳态代数相加})$$

> 注：IEC 61660 §4 规定不同电源峰值时间不同，合成时取最恶劣组合（保守叠加）。

## 4. 完整算例

### 算例 A：UPS 蓄电池组短路（48 V/100 Ah 通信电源）

#### 已知条件

| 参数          | 值                      | 说明                                     |
| ----------- | ---------------------- | -------------------------------------- |
| 蓄电池组        | 48 V，24 单体 × 2 V（铅酸阀控） | 满充 $U\_{B0} = 2.20 \times 24 = 52.8$ V |
| 单体内阻 $r\_B$ | 0.5 mΩ                 | GB/T 22264 典型值                         |
| 组内阻 $R\_B$  | 24 × 0.5 = 12 mΩ       | 串联                                     |
| 电缆电阻 $R\_L$ | 3.0 mΩ                 | 35 mm² × 5 m 铜电缆                       |
| 电缆电感 $L$    | 5 μH                   | 单根 5 m 近似                              |
| 直流断路器       | 待选                     | 开断能力 ≥ ?                               |

#### 步骤 1：稳态短路电流

$$I\_{k,B} = \frac{52.8}{0.012 + 0.003} = \frac{52.8}{0.015} = 3520 \text{ A}$$

#### 步骤 2：时间常数与峰值系数

$$T\_B = \frac{L}{R\_B + R\_L} = \frac{5 \times 10^{-6}}{0.015} = 0.333 \text{ ms}$$

查表：$T\_B < 5$ ms → $\kappa\_B \approx 1.10$

#### 步骤 3：峰值短路电流

$$i\_{p,B} = 1.10 \times 3520 = 3872 \text{ A} \approx 3.87 \text{ kA}$$

#### 步骤 4：直流断路器选型

- 额定电压 ≥ 60 VDC

- 额定电流 ≥ UPS 满载放电电流（取 100 A）

- **额定短路开断能力 ≥ 4 kA**（峰值）

- 时间常数 $L/R = T\_B = 0.33$ ms（断路器选 $L/R = 3$ ms 档即可，裕量充足）

选 **GB/T 14048.2 直流断路器：100 A / 60 VDC / 6 kA（L/R = 3 ms）** ✓

### 算例 B：储能 PCS 直流侧短路（1500 V / 5 MWh 锂电舱）

#### 已知条件

| 参数          | 值               | 说明                                                |
| ----------- | --------------- | ------------------------------------------------- |
| 电池簇         | 1500 VDC，400 Ah | 三元锂电，满充 $U\_{B0} = 4.2 \times 357 \approx 1500$ V |
| 簇内阻 $R\_B$  | 25 mΩ           | 357 单体串联 × 0.07 mΩ                                |
| 直流电缆 $R\_L$ | 8 mΩ            | 240 mm² × 20 m                                    |
| 直流电缆电感 $L$  | 18 μH           | 20 m 近似                                           |
| PCS 直流断路器   | 待选              | 需配合 GB/T 42288                                    |

#### 步骤 1：稳态短路电流

$$I\_{k,B} = \frac{1500}{0.025 + 0.008} = \frac{1500}{0.033} = 45455 \text{ A} \approx 45.5 \text{ kA}$$

#### 步骤 2：时间常数与峰值系数

$$T\_B = \frac{18 \times 10^{-6}}{0.033} = 0.545 \text{ ms}$$

查表 $\kappa\_B \approx 1.10$。

#### 步骤 3：峰值短路电流

$$i\_{p,B} = 1.10 \times 45.5 = 50.0 \text{ kA}$$

#### 步骤 4：PCS 直流断路器选型

- 额定电压 ≥ 1500 VDC

- 额定电流 ≥ 400 A（PCS 额定）

- **额定短路开断能力 ≥ 50 kA**（峰值）

- 时间常数 $L/R = 0.55$ ms，选 $L/R = 3$ ms 档

选 **1500 VDC 直流断路器：400 A / 65 kA（L/R = 3 ms）** ✓

> 注：储能舱实际多在电池簇与 PCS 间加装**快速熔断器**（GB/T 42288 §7.4），直流断路器作为后备保护，分断能力裕量取 1.3 倍。

### 算例 C：电力工程 220 V 直流操作电源（DL/T 5044）

#### 已知条件

| 参数          | 值                    | 说明                  |
| ----------- | -------------------- | ------------------- |
| 蓄电池组        | 220 V，104 单体 × 2.2 V | $U\_{B0} = 228.8$ V |
| 单体内阻 $r\_B$ | 0.45 mΩ              | 阀控铅酸                |
| 组内阻 $R\_B$  | 104 × 0.45 = 46.8 mΩ | 串联                  |
| 电缆 $R\_L$   | 12 mΩ                | 70 mm² × 30 m       |
| 电缆 $L$      | 25 μH                | 30 m                |

#### 步骤 1：稳态短路电流

$$I\_{k,B} = \frac{228.8}{0.0468 + 0.012} = \frac{228.8}{0.0588} = 3891 \text{ A} \approx 3.89 \text{ kA}$$

#### 步骤 2：时间常数与峰值系数

$$T\_B = \frac{25 \times 10^{-6}}{0.0588} = 0.425 \text{ ms}$$

查表 $\kappa\_B \approx 1.10$。

#### 步骤 3：峰值短路电流

$$i\_{p,B} = 1.10 \times 3891 = 4280 \text{ A} \approx 4.28 \text{ kA}$$

#### 步骤 4：直流断路器选型

DL/T 5044 §6.2 要求直流断路器分断能力 ≥ 蓄电池组短路电流 1.3 倍裕量：

$$I\_{cu} \geq 1.3 \times 3.89 = 5.06 \text{ kA}$$

选 **250 VDC 直流断路器：100 A / 6 kA（L/R = 3 ms）** ✓

## 7. 工程注意点

| 要点            | 说明                                                            |
| ------------- | ------------------------------------------------------------- |
| **无自然过零点**    | 直流短路电流无周期分量，断路器灭弧靠磁场吹断或栅片分割，**L/R 时间常数**必须匹配断路器额定 $L/R$       |
| **蓄电池内阻温度系数** | 铅酸电池 -10℃ 内阻升高 1.5\~2 倍，短路电流反而降低；高温内阻下降，短路电流升高，按 +25℃ 典型值校验   |
| **锂电内阻非线性**   | 锂电池内阻随 SOC 与温度剧烈变化，应取**满充 + 高温**（最恶劣工况）校验短路电流                 |
| **多簇并联储能**    | 储能舱多簇并联时短路电流代数叠加，峰值可能超 60 kA，必须加装**簇级快速熔断器**隔离故障簇             |
| **整流器限流**     | 现代 UPS 整流器多带限流保护（$k\_R < 3$），实际贡献短路电流远小于理论值，但蓄电池短路不受限流保护      |
| **保护选择性**     | 蓄电池总熔断器与馈线直流断路器必须满足**阶梯时限 + 电流级差**配合，避免越级跳全站失电（CASE-052 事故教训） |
| **电弧能量**      | 直流电弧不自然熄灭，开断能量高于交流，GB/T 14048.2 直流断路器灭弧室容量必须≥实际 $L/R$ 下的电弧能量  |
