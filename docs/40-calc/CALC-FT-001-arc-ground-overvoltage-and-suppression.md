# 弧光接地过电压计算

## 1. 算例背景

IT 系统（中性点不接地）发生单相接地时，故障点可能出现**间歇电弧**——电弧每半周波自熄重燃。每次重燃都会在非故障相产生**操作过电压**，倍数可达 $3 U_{\mathrm{ph}} \sim 3.5 U_{\mathrm{ph}}$（额定相电压的 3~3.5 倍）。反复过电压是 **IT 系统绝缘劣化和损坏的主要原因**。

**抑制手段**：消弧线圈（L）或接地电阻（R）+ 消弧线圈。现代配电网多采用**小电阻接地 + 零序保护跳闸**替代传统 IT 系统。

## 2. 核心公式

### 2.1 弧光重燃过电压倍数

弧光重燃时非故障相的过电压倍数 $k$：

$$k = \frac{\text{重燃后非故障相对地电压峰值}}{\text{系统相电压峰值 } U_{\mathrm{ph,m}}}$$

| 重燃条件 | $k$ 最大值 |
|---|---|
| 电弧在电流自然过零点熄灭，电压过峰时重燃（最恶劣） | $k = 3.0 \sim 3.5$ |
| 电弧在任意时刻熄灭重燃 | $k = 2.0 \sim 2.5$ |
| 消弧线圈抑制后 | $k \leq 1.8$ |

### 2.2 消弧线圈选型

消弧线圈电感 $L$ 的计算（要求补偿度 $\nu$ = 5~10% 过补偿）：

$$I_C = 3 \omega C_{\Sigma} U_{\mathrm{ph}}$$

$$I_L = \frac{U_{\mathrm{ph}}}{\omega L} = (1 + \nu) I_C$$

$$L = \frac{U_{\mathrm{ph}}}{\omega (1 + \nu) I_C} = \frac{1}{3 \omega^2 (1 + \nu) C_{\Sigma}}$$

其中：
- $I_C$ = 系统对地总电容电流（见 CALC-GR-002 IT 系统部分）
- $I_L$ = 消弧线圈电感电流
- $C_{\Sigma}$ = 全系统对地总电容
- $\nu = (I_L - I_C)/I_C$ = 过补偿度（通常 +5~+10%）

### 2.3 小电阻接地选型

小电阻阻值计算（通常要求单相接地电流 $I_f = 100 \sim 400$ A）：

$$R_N = \frac{U_{\mathrm{ph}}}{I_f}$$

| $U_{\mathrm{ph}}$ | 目标 $I_f$ | $R_N$ 取值 |
|---|---|---|
| 10/√3 = 5.77 kV | 400 A | $14.4 \Omega$ |
| 20/√3 = 11.55 kV | 400 A | $28.9 \Omega$ |
| 35/√3 = 20.2 kV | 400 A | $50.5 \Omega$ |

## 3. 完整算例

### 3.1 已知条件

| 参数 | 值 |
|---|---|
| 系统 | 10 kV IT 配电网（原中性点不接地） |
| 线路 | 电缆，总长度 100 km |
| 对地电容 | 电缆 0.3~0.5 μF/km，取中间值 0.4 μF/km |
| 故障 | 单相金属性接地 + 间歇电弧 |

### 3.2 计算步骤

**步骤 1：总对地电容**

$$C_{\Sigma} = 3 \times 0.4 \times 100 = 120 \mu\text{F}$$

**步骤 2：系统电容电流**

$$I_C = 3 \omega C_{\Sigma} U_{\mathrm{ph}} = 3 \times 314 \times 120 \times 10^{-6} \times \frac{10}{\sqrt{3}} = 1.94 \text{ A}$$

（10 kV IT 系统 100 km 电缆的电容电流约 1.5~2 A，在此量级）

**步骤 3：无抑制时过电压**

弧光重燃倍数 $k = 3.0$（最恶劣），非故障相过电压：

$$U_{\mathrm{over}} = k \cdot U_{\mathrm{ph,m}} = 3.0 \times \frac{10}{\sqrt{3}} \times \sqrt{2} = 3.0 \times 8.16 = 24.5 \text{ kV（峰值）}$$

**额定雷电冲击耐受电压**：10 kV 设备 BIL = 75 kV，**3p.u. 过电压远低于 BIL**，但**反复过电压**累积效应会导致绝缘老化加速。

**步骤 4：消弧线圈抑制方案**

要求 $\nu = 10\%$ 过补偿：

$$I_L = 1.1 \times I_C = 2.13 \text{ A}$$

$$L = \frac{U_{\mathrm{ph}}}{\omega I_L} = \frac{5774}{314 \times 2.13} = 8.61 \text{ H}$$

过电压抑制后 $k \leq 1.5$：

$$U_{\mathrm{over, supp}} \leq 1.5 \times 8.16 = 12.2 \text{ kV}$$

**步骤 5：小电阻接地方案**

目标接地电流 $I_f = 400$ A（常规保护可动作）：

$$R_N = \frac{5774}{400} = 14.4 \Omega$$

过电压被抑制到 $k \approx 1.0$（近似金属性短路，无电弧），但**单相接地跳闸**，失去 IT 系统允许带故障运行的优点。

### 3.3 方案对比

| 方案 | 单相接地电流 | 过电压倍数 | 带故障运行 | 优缺点 |
|---|---|---|---|---|
| IT 无抑制 | 1.94 A | 3.0 | ✓ 2 h | 过电压风险高 |
| IT + 消弧线圈 | 1.94 A（$I_L - I_C = 0.19$ A） | ≤ 1.5 | ✓ 2 h | 保护灵敏度降低，需加装接地点定位 |
| IT + 小电阻 | 400 A | ≤ 1.0 | ✗ 立即跳闸 | 保护可靠，损失带故障运行 |

## 5. 工程注意点

| 要点 | 说明 |
|---|---|
| 电缆 vs 架空线 | 电缆电容电流 2~5 倍架空线，长电缆网电容电流大 → 消弧线圈容量需加大 |
| 过补偿 vs 欠补偿 | 传统推荐过补偿（5~10%），避免"串联谐振"；但过补偿时高阻故障检测需特殊技术 |
| 小电阻接地电流 | 通常 200~1000 A，需配合零序过流保护（I₀ ≥ 10~20 A） |
| 现代趋势 | 新建 10 kV 配网普遍采用**小电阻接地**，过电压问题从根源上消除 |
