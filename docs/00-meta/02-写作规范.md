# 写作规范（L0 元数据 · KB-WRITING-SPEC）

**文档编号**：META-002 ｜ **版本**：1.0 ｜ **适用范围**：全库条目

---

## 1. 通用规则

1. **语言与单位**：简体中文；物理量一律使用法定计量单位（SI），数值与单位间加空格（如 `400 V`、`1000 kVA`、`23.3 kA`）；
2. **术语锚点**：首次出现的专业术语链接至 `00-术语表.md` 锚点：`[断路器](00-术语表.md#断路器)`；
3. **标准引用**：遵循 META-001 §7（标准号-年份 + 条款号）；
4. **公式**：行内 `$...$`，独立公式块 `$$...$$`；公式后必须附符号表（符号、含义、单位）；
5. **禁止事项**：
   - 禁止出现"一般而言""大概""通常没问题"等模糊结论——要么给出标准依据，要么标注 `[经验条目]` 并写明适用边界；
   - 禁止摘录标准原文超过单句必要的转述需求（版权红线），一律"要点转述 + 条款号"；
   - 禁止使用未经 §权威数据源清单 核验的标准版本号。

## 2. 数字与算例规范

- 算例必须**从头算到尾**：已知条件 → 逐步计算（含中间量与单位换算）→ 结果 → 与标准限值/设备参数对照校验；
- 中间量保留 3~4 位有效数字，最终结果按工程惯例圆整；
- 每个计算步骤标注依据（公式出处或标准条款）；
- 图表编号：图 X-Y、表 X-Y（X=条目序号）。

## 3. 篇幅指引

| 条目类型 | 目标篇幅 | 上限 |
|---|---|---|
| 实践类（九段式） | 1500~3000 字 | 4500 字 |
| 理论类（五段式） | 800~1500 字 | 2500 字 |
| CALC 计算方法 | 2000~3500 字（含算例） | 5000 字 |
| changelog | 300~800 字 | 1200 字 |

超限应拆分为多个条目并互相链接。

## 4. 评审要点（评审人自查清单）

- [ ] 所有工程结论是否挂了标准条款？
- [ ] 算例数字是否可复算（第三方按步骤能算出同样结果）？
- [ ] 引用的标准是否仍在 `20-standards/` 现行索引中？
- [ ] 是否存在与已发布条目冲突的表述？（冲突须在评审意见中显式处理）
- [ ] 术语、符号、单位是否符合本规范？

## 5. Git 提交规范

- 分支：`main`（发布）/ `draft/{条目ID}`（撰写）；
- 提交信息：`{条目ID}: {动作} {一句话说明}`，如 `CALC-SC-001: 新增 IEC 60909 系数法完整算例`；
- 状态变更为 `published` 必须经双人复核并在 commit message 中注明复核人。
