## 2. 文件命名

```
{域码}-{三位序号}-{英文短名}.md
```

- 示例：`DD-012-load-calculation-demand-factor.md`、`CALC-SC-001-low-voltage-3phase-short-circuit.md`
- 英文短名：全小写、连字符分隔、≤6 个单词；
- 子域缩写可选嵌入序号前（如 CALC-**SC**-001，SC=短路计算，见 §3）；
- changelog 条目：`CHG-{四位序号}-{标准号}.md`，如 `CHG-001-GBT50034-2024.md`。

## 6. 条目状态机

```
草稿(draft) → 评审中(review) → 已发布(published) → 存档(archived)
                                     ↘ 驳回(rejected) → 修改后重投
```

- 状态变更必须留痕（写入正文"变更记录"节 + Git commit）；
- `archived` 仅因标准换版淘汰时使用，必须链接替代条目。

## 7. 标准引用写法（强制）

- 格式：`标准号-年份 + 条款号`，如 `GB 50054-2011 第 6.2.4 条`、`IEC 60909-0:2016 Clause 4.0`；
- front matter `standards` 字段为**数组**，每项至少含 `code / clause`；
- 禁止只写标准号不写条款号（溯源红线的机器可校验形式）；
- 每个引用的标准必须存在于 `20-standards/` 索引中（校验脚本检查）。

## 8. ID 分配规则

- 序号在域内全局唯一、只增不复用；
- 条目拆分产生新 ID，原 ID 保留跳号并在新条目中注明来源；
- 示范条目从 `001` 起。
