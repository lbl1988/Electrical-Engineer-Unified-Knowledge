# 综合案例：海上风电场升压站电气-结构-海工多专业协同设计

## 1. 摘要

本案例以某 200MW 海上风电场（50 台 4MW 风机，66kV 集电海缆 + 220kV 送出海缆）升压站设计为载体，覆盖**集电系统选型、升压变压器配置、短路电流校验、海上接地、防腐与消防、继电保护**六大专业接口。关键结论：2 台 150MVA 66/220kV 变压器分列运行（互为备投）；66kV 母线三相短路 9.64kA，选用 31.5kA 开关柜满足；海上平台钢桩自然接地电阻约 0.01Ω，远优于陆上；环氧富锌涂层 + 牺牲阳极联合防腐设计寿命 25 年。教训：**海上风电升压站须跨电气-结构-海工-防腐-暖通五专业协同，关键接口在电缆穿越甲板防火密封、变压器消防海水-泡沫系统、平台防雷利用钢桩接地。**

## 2. 背景

### 2.1 工程概况（脱敏）

某近海风电场（代号"某 OF 工程"），装机 200MW，50 台 4MW 风机分 5 组并联接入海上升压站：

| 参数 | 取值 | 说明 |
|---|---|---|
| 风机台数 | 50 台 × 4MW | 200MW 总容量 |
| 集电电压 | 66 kV | 风机出口 |
| 升压 | 66/220kV, 2×150MVA | 分列运行 |
| 送出海缆 | 3×500mm² 220kV, 25km | 至陆上集控中心 |
| 海上平台 | 4 腿导管架, 45m×25m | 含甲板层、设备层、底层 |
| 水深 | ~22m | 钢桩入泥 35m |

  │ 变压器布置        │ 设备重量/重心     │ 冲刷防护
  │ 短路电流          │ 抗震校验          │ 电缆敷设张力
  │ 接地              │ 桩基入泥深度      │ 登乘栈桥
  ├───────────────────┼──────────────────┤
  │   消防专业        │ 暖通专业          │ 防腐专业
  │ 变压器泡沫系统    │ 盐雾防护通风      │ 富锌涂层
  │ 电缆穿舱密封      │ 设备散热           │ 牺牲阳极

## 3. 方案

### 3.1 集电系统拓扑

```
风机 1~10 ─→ 66kV 汇集电缆 ─┐
风机 11~20 ─→ 66kV 汇集电缆 ─┤
风机 21~30 ─→ 66kV 汇集电缆 ─┼─→ 66kV 母线（单母线分段）─→ T1 66/220kV ─→ 220kV 海缆
风机 31~40 ─→ 66kV 汇集电缆 ─┤                                        ─→ T2 66/220kV ─┐
风机 41~50 ─→ 66kV 汇集电缆 ─┘                                                          ├→ 220kV 母线 ─→ 送出
```

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|

| $L_{export}$ | 送出海缆长度 | 25 km | 设计 |
| $\rho_{seawater}$ | 海水电阻率 | 0.25 Ω·m | 实测 |

## 4. 计算

### 4.1 集电海缆截面选择

每组 10 台风机（40MW），功率因数 $\cos\varphi$=0.95：

$$I_{string}=\frac{S_{string}}{\sqrt{3}\cdot U_{cable}\cdot\cos\varphi}=\frac{40}{\sqrt{3}\times 66\times 0.95}=\frac{40}{108.5}=0.369\ \text{kA}=369\ \text{A}$$

按 GB 50217-2018 海缆选型（三芯交联聚乙烯, 66kV, 海底敷设, 土壤温度 15°C）：

| 截面 (mm²) | 载流量 (A, 15°C) | 是否满足 369A |
|---|---|---|
| 185 | 310 | ✗ |
| 240 | 360 | ✗（边界值） |
| 300 | 410 | ✓ |
| 400 | 470 | ✓（有裕量） |

选 **3×300mm², 66kV 三芯海缆**（裕量约 11%）。海缆路由 J 型管（直径 250mm）穿入平台底层。

### 4.2 短路电流校验（引自 [CALC-SC-002](../40-calc/CALC-SC-002-hv-short-circuit-iec60909.md) §3 IEC 60909）

**66kV 母线三相短路**（最大运行方式）：

**（A）220kV 系统阻抗（归算至 66kV）**：

$$Z_{s,66}=\frac{U_{n,66}^2}{S_{cc,onshore}}=\frac{66^2}{5000}=\frac{4356}{5000}=0.871\ \Omega$$

**（B）升压变压器阻抗（150MVA，归算至 66kV）**：

$$Z_T=\frac{u_k\%\cdot U_{n,66}^2}{100\cdot S_T}=\frac{12\times 66^2}{100\times 150}=\frac{52272}{15000}=3.485\ \Omega$$

**（C）总阻抗（两台变压器并联运行）**：

$$Z_{\Sigma}=\frac{Z_{s,66}\times Z_T}{Z_{s,66}+Z_T}$$

分列运行（单台）：

$$Z_{\Sigma,1}=Z_{s,66}+Z_T=0.871+3.485=4.356\ \Omega$$

$$I_{k3,66}''=\frac{c\cdot U_{n,66}}{\sqrt{3}\cdot Z_{\Sigma,1}}=\frac{1.10\times 66}{\sqrt{3}\times 4.356}=\frac{72.6}{7.543}=9.63\ \text{kA}$$

**（D）风机贡献短路电流**（引自 [TH-011](../10-theory/TH-011-synchronous-machine-subtransient-reactance.md) §3 异步发电机次暂态）：

风机变流器为电流源型（全功率变流器），故障电流贡献限于额定 1.1~1.5 倍：

$$I_{k,WF}''\approx 1.1\times\frac{S_{WF}}{\sqrt{3}\cdot U_{n,66}}=1.1\times\frac{200}{\sqrt{3}\times 66}=1.1\times 1.75=1.93\ \text{kA}$$

**（E）总短路电流**：

$$I_{k,total}''=I_{k3,66}''+I_{k,WF}''=9.63+1.93=11.56\ \text{kA}$$

| 项 | 计算值 | 设备选型 | 是否满足 |
|---|---|---|---|
| 66kV 母线三相短路 | 11.56 kA | GIS 31.5kA | ✓ |
| 峰值短路 $i_p$ | 26.3 kA ($\kappa$=1.8) | GIS 80kA | ✓ |

### 4.3 海上接地电阻校算（引自 [CALC-GR-001](../40-calc/CALC-GR-001-grounding-grid-design.md) §4 自然接地体 + GB/T 50065）

海上平台钢桩（4 腿，直径 $d$=2m，入泥 $L$=35m）作为自然接地极，海水电阻率 $\rho$=0.25Ω·m：

**单桩接地电阻**（垂直管/桩公式，IEEE 80 附录B）：

$$R_{pile}=\frac{\rho}{2\pi L}\ln\frac{4L}{d}=\frac{0.25}{2\pi\times 35}\ln\frac{4\times 35}{2}$$

$$=\frac{0.25}{219.9}\times\ln 70=0.00114\times 4.248=0.00484\ \Omega$$

**4 桩并联**（间距 45m，屏蔽系数 $\eta$=0.9）：

$$R_{g,total}=\frac{R_{pile}}{4\times\eta}=\frac{0.00484}{4\times 0.9}=\frac{0.00484}{3.6}=0.00135\ \Omega\approx 0.001\ \Omega$$

| 项 | 计算 | 要求 | 结论 |
|---|---|---|---|
| 平台接地电阻 | ~0.001 Ω | ≤4Ω（GB/T 50065 大接地） | ✓ 远优于陆上 |
| 接触电压 | <0.1V | ≤80V（GB/T 50065） | ✓ |
| 跨步电压 | <0.01V | ≤50V | ✓ |

**防腐与接地联合**：钢桩外壁环氧涂层（1000μm）+ 牺牲阳极（锌铝合金 50kg/桩），设计寿命 25 年。涂层破损后阳极保护接管。

### 4.4 多专业接口校算

**（A）变压器消防——水雾-泡沫系统（引自 [PR-CM-001](../30-practice/PR-CM-001-fire-protection-interlocking.md) §3 + GB 50229-2019 §7）**

| 项 | 设计 | GB 50229 要求 |
|---|---|---|
| 变压器消防型式 | 水喷雾 + 泡沫 | 水雾或泡沫（海上无淡水） |
| 喷雾强度 | 20 L/(min·m²) | ≥20（GB 50229 §7.1.3） |
| 供水 | 海水+精过滤器 | 海水须过滤 ≥0.5mm |
| 持续时间 | 30 min | ≥30min |
| 排油 | 事故油柜 50m³/台 | ≥单台油量+20% |

**（B）电缆穿舱防火密封（引自 GB 50229-2019 §7.4 + GB 50016-2014 §10）**

海缆穿越甲板处须设**电缆贯穿密封堵料**（MCT 型模块）：

| 穿越点 | 封堵型式 | 防火等级 | 水密等级 |
|---|---|---|---|
| 底层甲板→设备层 | MCT-BR 金属模块 | 3h | IP68 (50m水头) |
| 设备层→甲板层 | MCT-W 轻型 | 1.5h | IP67 |

**（C）平台防雷（引自 [PR-GR-001](../30-practice/PR-GR-001-lightning-protection-design.md) §4 + IEC 61400-24）**

海上平台金属体直接利用钢桩接地（$R_g$≈0.001Ω），无需独立接地装置。直升机甲板设航空警示灯与避雷针，接地引下线利用平台钢柱（截面≥50mm²铜当量）。

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 66kV 母线分段运行时未校验单台变压短路 | GB/T 14285 §5 | 分列时短路 9.63kA, 须校验单母分段开关 |
| 2 | 送出海缆 25km 须核算电容电流与充电功率 | NB/T 31003 §6 | 海缆 I_C 可能触发空载过电压 |
| 3 | 变压器消防须双电源（海上无市电备投） | GB 50229 §7.1 | 消防泵须由平台柴油发电机直供 |
| 4 | 电缆穿舱密封未明确防水密等级 | NB/T 31003 §8 | 水密失效致设备层进水 |

## 6. 整改

### 6.1 送出海缆充电功率核算

$$I_C=U_n\cdot\omega\cdot C\cdot L=220\times 314\times 0.18\times 10^{-6}\times 25=0.311\ \text{kA}=311\ \text{A}$$

$$Q_C=U_n\cdot I_C=220\times 0.311=68.4\ \text{Mvar}$$

充电功率 68.4Mvar > 变压器容量 150MVA 的 45% → **须配高压电抗器补偿**（3×25Mvar, 220kV 并联电抗器，补偿度 50%）。

### 6.2 消防双电源

平台设 1 台 500kW 柴油发电机（独立于风机变流器），直供消防泵+应急照明+通讯：

```
平台柴发 500kW → 消防控制柜 → 水雾泵组 + 泡沫泵组
                    → 应急照明+EPS
```

### 6.3 电缆穿舱密封

所有海缆穿越甲板处改用 MCT-BR 金属密封模块（水密 IP68/50m + 防火 3h），穿透清单逐条核对。

## 7. 经验教训

- [ ] **海上升压站 66kV 短路须叠加风机变流器贡献**（约 2kA），总短路 ≥11.6kA，选 31.5kA 开关柜有裕量
- [ ] **海上接地利用钢桩自然接地**，$R_g$≈0.001Ω，无需人工接地网——陆上经验不可直接迁移
- [ ] **220kV 送出海缆电容功率须核算**：25km 海缆充电功率可达 68Mvar，须配并联电抗器补偿
- [ ] **变压器消防用海水+精过滤**，须配 500kW 柴发独立双电源——海上无市电备投
- [ ] **电缆穿舱密封须防水密+防火双等级**，MCT-BR 金属模块（IP68 + 3h）
- [ ] 防腐设计须与接地设计联合：涂层破损后牺牲阳极保护接管，设计寿命须与平台一致（25年）
