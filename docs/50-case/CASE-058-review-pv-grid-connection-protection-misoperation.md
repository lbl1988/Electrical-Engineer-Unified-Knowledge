# 校审意见：光伏并网联络线保护三项隐患

## 1. 摘要

某工业园区 10 kV 光伏并网项目（20 MW）保护整定校审中发现 3 项常见错误：①过流保护未考虑光伏 PCS 短路贡献导致整定值偏小误动、②方向过流保护方向极性接反（DG 在故障点下游时拒动）、③防孤岛保护只有被动检测没有主动注入。涉及 3 个标准条款，全部整改。**教训：DG 接入配电网保护整定必须纳入 PCS 短路贡献、方向极性、孤岛检测双判据。**

## 2. 校审意见清单

### 错误 1：过流保护未考虑 PCS 短路贡献

| 项目 | 图纸设计 | 规范要求 | 违反标准 |
|---|---|---|---|
| 整定计算 | 仅考虑电网侧短路电流（$I''_{k} = 12$ kA） | 必须叠加 PCS 贡献 | DL/T 584-2017 §3.4 |
| 整定值 | $I_{\mathrm{set}} = 1.3 \times I''_k = 15.6$ kA | 需重新计算 | GB/T 40567-2021 §9.2 |

**实际情况**：光伏 PCS 短路贡献按 GB/T 15544 取 $1.1 \times I_N = 1.1 \times (20000 / \sqrt{3} / 10) = 1.1 \times 1155 = 1270$ A ≈ 1.27 kA。

总短路电流：$I''_{k, \text{total}} = 12 + 1.27 = 13.27$ kA。

**原来整定 15.6 kA** → 已偏大，不是问题。**问题出在**：PCS 接入后短路阻抗下降，最小运行方式下短路电流比无 DG 时**增大 10~15%**，原来按最小运行方式整定的灵敏度裕度不足 1.2（要求 ≥ 1.5）。

**整改**：重新整定：

$$I_{\mathrm{set, new}} = \frac{I''_{k, \min} \text{（含 DG）}}{K_{\mathrm{sen}} \times K_{\mathrm{rel}}} = \frac{13.27}{1.5 \times 1.2} = 7.37 \text{ kA}$$

整定时间 $t = 0.6$ s（与下一级配合）。

### 错误 2：方向过流保护极性接反

| 项目 | 图纸设计 | 规范要求 | 违反标准 |
|---|---|---|---|
| 方向极性 | 电流极性从母线流向线路为正 | 光伏 DG 在故障点**下游**时，短路电流从 DG 流向故障点（反方向！） | GB/T 14285-2006 §7.2 |

**物理图像**：

```
电网 ──── 断路器A（方向从电网→线路） ──── 光伏DG
                │                    │
           故障点（DG下游单相接地）
```

单相接地故障时，电网侧和 DG 侧都向故障点供电，但**方向相反**：
- 电网→故障点（断路器 A 正方向，保护会动）✓
- DG→故障点（断路器 A **反方向**，方向元件闭锁）→ 拒动！

**整改**：在联络线**两侧**都装方向过流保护，极性分别指向母线（电网侧）和指向线路（DG 侧），形成**双侧方向保护**。

### 错误 3：防孤岛保护缺失主动检测

| 项目 | 图纸设计 | 规范要求 | 违反标准 |
|---|---|---|---|
| 检测方式 | 仅被动检测（频率/电压突变） | 必须被动 + 主动双判据 | GB/T 40567-2021 §9.5 |
| 检测时间 | < 2 s（被动） | < 0.2 s（主动注入） | GB/T 40567-2021 §9.5 |

**漏检测场景**：电网停电后，光伏 + 储能继续给本地负荷供电形成**孤岛**。被动检测在负荷匹配时（功率平衡）不触发频率/电压突变 → **孤岛检测失败**。

**整改**：加装**主动频率偏移法（AFD）**：PCS 输出频率注入微小偏移（±0.1 Hz），电网正常时被电网频率"钳位"看不出偏移，孤岛时频率自由漂移触发保护。检测时间 < 100 ms。

## 3. 整改清单

| 整改项 | 整改方式 | 优先级 |
|---|---|---|
| 过流保护重整定 | 纳入 PCS 贡献 + 灵敏度 ≥ 1.5 | 高 |
| 方向保护加装 | 联络线加装双侧方向过流 | 高 |
| 孤岛保护升级 | 加装主动频率偏移检测 | 高 |
