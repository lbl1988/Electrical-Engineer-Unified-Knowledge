# 事故复盘：10kV不接地系统铁磁谐振过电压致电压互感器烧毁

## 1. 摘要

某 10kV 不接地系统变电所（电缆网占比 60%），雷雨天气 10kV 母线 A 相接地后恢复，随即三相电磁式电压互感器（PT）高压熔断器连续熔断，B 相 PT 绕组烧毁。调查结论：系统对地电容与 PT 非线性电感在接地消失瞬间形成**基波铁磁谐振**，PT 过电压达 3.2p.u.、过电流达 15 倍额定，致绕组绝缘击穿。教训：**10kV 电缆化不接地系统须设防铁磁谐振措施——选用 4 绕组 PT（含开口三角接消谐电阻）或中性点经消弧线圈/小电阻接地，或加装微机消谐装置。**

## 2. 背景

### 2.1 事故经过（脱敏）

某城市配电网 10kV 变电所（代号"某 FR 变"），10kV 系统中性点不接地，出线 8 回（6 回电缆、2 回架空）。雷雨夜 22:30，10kV 母线 A 相接地告警，约 2s 后接地消失。随即 10kV 母线 PT 高压熔断器 A/B/C 三相先后熔断，B 相 PT 冒烟烧毁。母线电压指示异常（B 相 12kV、A/C 相 6kV），出线馈线失压。

### 2.2 系统与 PT 参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 系统电压 | 10 kV | 不接地 |
| 出线 | 8 回（6 电缆+2 架空） | 总长 25km |
| 电缆型号 | YJV22-8.7/10kV-3×300 | 电容 0.38μF/km |
| PT | 电磁式 JDZJ-10, 10/√3/0.1/√3/0.1/3kV | 3 台单相，中性点直接接地 |
| PT 励磁特性 | 额定电压下励磁电流 15mA | 非线性（饱和后电感骤降） |
| 开口三角 | 未接消谐电阻 | 仅接零序电压继电器 |

### 2.3 故障现象

- PT 高压熔断器 3 相全部熔断（A 相 2A、B 相 3A、C 相 2A，正常 0.5A）
- B 相 PT 绕组对地绝缘击穿，烧焦变黑
- 录波显示接地消失后 50Hz 过电压持续 1.5s，峰值 3.2p.u.（18.5kV）

## 3. 方案（调查分析链路）

### 3.1 事故分析链路

```
A相接地 → 非故障相电压升至线电压 → PT饱和(L下降)
  → 接地消失瞬间 → 系统电容C0与PT非线性电感L形成LC回路
  → 谐振条件: ω0=1/√(L·C0) ≈ ω(基波)
  → 基波铁磁谐振 → PT过电压 3.2p.u. + 过电流 15In
  → 熔断器熔断 + 绕组烧毁
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $C_0$ | 系统每相对地电容 | 9.5 μF | 电缆+架空 |
| $L_{PT}$ | PT 非线性电感 | 120~1500 H | 随励磁电流变化 |
| $I_{e,rated}$ | PT 额定励磁电流 | 15 mA | 厂家 |
| $U_n$ | 额定相电压 | 5.77 kV | $10/\sqrt3$ |
| $f_0$ | 谐振频率 | 50 Hz | 基波 |
| $U_{res}$ | 谐振过电压 | 3.2 p.u. | 录波 |
| $I_{PT,res}$ | 谐振时 PT 电流 | 0.75 A | 录波（15$I_e$） |

## 4. 计算

### 4.1 系统对地电容计算（引自 [TH-009](../10-theory/TH-009-lightning-physics.md) §2 + DL/T 620-1997 §4.1）

电缆每相对地电容：

$$C_{cable}=0.38\ \mu\text{F/km}\times 22\ \text{km}=8.36\ \mu\text{F}$$

架空线每相对地电容（约 0.01μF/km × 6km）：

$$C_{OHL}=0.06\ \mu\text{F}$$

$$C_0=C_{cable}+C_{OHL}=8.36+0.06=8.42\ \mu\text{F}\approx 8.4\ \mu\text{F}$$

### 4.2 铁磁谐振条件（引自 DL/T 620-1997 §4.2 + IEEE 1015）

**线性谐振频率**（PT 线性段电感 $L_0$=120H）：

$$f_0=\frac{1}{2\pi\sqrt{L_0\cdot C_0}}=\frac{1}{2\pi\sqrt{120\times 8.4\times 10^{-6}}}=\frac{1}{2\pi\times 0.0317}=\frac{1}{0.199}=5.02\ \text{Hz}$$

> 线性段 $f_0$=5Hz 远低于基波 50Hz，不会谐振。但 **PT 饱和后电感骤降**：

饱和时 $L_{sat}$≈12H（电感降至线性段的 1/10）：

$$f_0=\frac{1}{2\pi\sqrt{12\times 8.4\times 10^{-6}}}=\frac{1}{2\pi\times 0.0100}=15.9\ \text{Hz}$$

> 仍低于 50Hz。**但 PT 过渡饱和区**（$L$≈2H）时：

$$f_0=\frac{1}{2\pi\sqrt{2\times 8.4\times 10^{-6}}}=\frac{1}{2\pi\times 0.0041}=38.8\ \text{Hz}$$

接近基波 50Hz。**当 PT 进入深度饱和（$L$≈1H）**：

$$f_0=\frac{1}{2\pi\sqrt{1\times 8.4\times 10^{-6}}}=54.9\ \text{Hz}\approx 50\ \text{Hz}$$

**满足基波铁磁谐振条件** ✓

### 4.3 谐振过电压与过电流（引自 [TH-013](../10-theory/TH-013-switching-arc-physics.md) §4 谐振过电压）

铁磁谐振时，PT 两端电压由励磁特性决定。饱和段每增加 1mA 电流，电压增加极小，但**电流可增大数十倍**。

录波数据：
- 过电压峰值 $U_{res}$=3.2p.u.=3.2×5.77=18.5kV
- PT 电流 $I_{PT,res}$=0.75A=15$I_e$（额定 50mA）

**PT 绕组热容量校核**：

PT 绕组热容量按 1.2$U_n$ 持续运行设计。3.2p.u. 运行 1.5s：

$$Q=I_{res}^2\times R\times t=0.75^2\times R\times 1.5$$

设绕组电阻 $R$=200Ω（10kV PT）：

$$Q=0.5625\times 200\times 1.5=169\ \text{J}$$

绕组质量约 0.5kg，铜比热 385J/(kg·K)：

$$\Delta T=\frac{Q}{m\cdot c_p}=\frac{169}{0.5\times 385}=0.88\ \text{K}$$

> 纯电阻发热 0.88K 不大，但**铁损+涡流损耗**在过电压下急剧增加（$P_{fe}\propto f\cdot B^2$，B 饱和时不增但电流大增），实际温升 >200K，致绝缘击穿。

### 4.4 谐振判据（引自 DL/T 620-1997 附录C）

不接地系统发生铁磁谐振的判据：

$$\frac{X_{C0}}{X_{PT}}\leq 0.01$$

| 符号 | 含义 | 计算 |
|---|---|---|
| $X_{C0}$ | 每相容抗 | $1/(\omega C_0)=1/(314\times 8.4\times 10^{-6})=379\ \Omega$ |
| $X_{PT}$ | PT 线性感抗 | $\omega L_0=314\times 120=37680\ \Omega$ |
| 比值 | $X_{C0}/X_{PT}$ | $379/37680=0.0101$ |

$X_{C0}/X_{PT}$=0.0101 ≈ 0.01 → **临界谐振条件**，极易激发铁磁谐振。

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 电缆化系统仍用不接地+电磁PT无消谐 | DL/T 620-1997 §4.2 | 铁磁谐振高发 |
| 2 | PT 开口三角未接消谐电阻 | GB 50053-2013 §3.2 | 谐振无阻尼 |
| 3 | 未配微机消谐装置 | 企业反措 | 谐振无法快速消除 |
| 4 | 接地消失后谐振未被及时切除 | 无 PT 过流保护 | PT 烧毁 |

## 6. 整改

### 6.1 消谐措施（按优先级）

| 措施 | 原理 | 效果 | 投资 |
|---|---|---|---|
| 微机消谐装置 | 实时监测 PT 开口三角，谐振时短时投入大功率电阻 | 消除基波/分次/高频谐振 | 低 |
| 开口三角接消谐电阻 | 开口三角接 30~50Ω 电阻 | 阻尼基波谐振 | 低 |
| 4 绕组 PT（抗谐振型） | 第四个绕组接消谐电阻 | 从源头抑制谐振 | 中 |
| 中性点经消弧线圈接地 | 改变系统中性点，消除谐振条件 | 根治 | 高 |
| 中性点经小电阻接地 | 同上 | 根治 | 高 |

**本期整改**：加装微机消谐装置（投入电阻 100Ω，检测到谐振 0.5s 内动作）+ 开口三角接 40Ω 常闭消谐电阻。

### 6.2 接地方式改造（远期）

将 10kV 系统中性点改为经消弧线圈接地（$I_C$=8.4A，选 10A 消弧线圈，过补偿 10%），从根本上消除铁磁谐振条件。

### 6.3 PT 保护

PT 高压侧熔断器选 0.5A（原 2A 过大，不能及时隔离故障），低压侧加 1A 断路器。

## 7. 经验教训

- [ ] **10kV 电缆化系统（$X_{C0}/X_{PT}$≤0.01）须设防铁磁谐振措施**——不接地+电磁PT组合是谐振温床
- [ ] **PT 开口三角必须接消谐电阻**（30~50Ω），不能只接零序继电器
- [ ] **微机消谐装置是首选**（0.5s 内消除谐振），成本低、效果好
- [ ] 铁磁谐振过电压可达 3~4p.u.，PT 过电流达 10~20 倍额定，绕组迅速烧毁
- [ ] 接地消失瞬间是谐振高发时刻——单相接地后不要急于拉路，应先投入消谐装置
- [ ] 远期方案：改经消弧线圈或小电阻接地，从根本上消除谐振
