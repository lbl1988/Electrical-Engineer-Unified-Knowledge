# 事故复盘：台风 + 负荷高峰 + 继电保护越级 → 配电网大面积停电

## 1. 摘要

某沿海城市配电网（35 kV 环网 + 10 kV 辐射）遭遇超强台风（17 级，风速 58 m/s）：**2 条 35 kV 进线瞬时故障 → 环网自动切换但切换断路器拒动 → 上级 110 kV 变电站 10 kV 配变过流保护越级跳闸（时限未配合） → 8 座 10 kV 开关站全站停电**，影响 21 万用户，恢复时间 8 小时 12 分。**根因**：配网保护时限配合错误（10 kV 配变过流时限 0.3 s，下级 10 kV 出线保护 0.5 s，越级）；环网切换断路器弹簧操动机构欠压（储能电机未储能）；预案中台风登陆期间负荷预测偏低 15%（实际达 95% 额定容量）。

## 2. 事故时序

| 时间 | 事件 | 关键参数 |
|---|---|---|
| 14:38 | 台风登陆，风速 52 m/s | 阵风 58 m/s |
| 14:41 | 35 kV L1 进线瞬时故障（树木倒伏） | 故障持续 120 ms |
| 14:41 | 35 kV 环网切换断路器 CLOSE 命令发出 | 断路器拒动 |
| 14:41 | 35 kV L2 进线同时故障 | 同一片林区 |
| 14:42 | 上级 110 kV 变电站 10 kV 配变过流保护跳闸 | 时限 0.3 s（越级下级 0.5 s） |
| 14:42 | 8 座 10 kV 开关站全站停电 | 影响 21 万用户 |
| 15:05 | 巡线发现 L1/L2 故障点 | 树木倒伏压双线 |
| 15:40 | 人工合闸环网切换 | 弹簧机构手动储能耗时 18 min |
| 16:20 | L1 修复，恢复 50% 负荷 | |
| 18:53 | L2 修复，全部恢复 | 8 h 12 min 后 |

## 3. 直接损失

| 项目 | 数量 | 说明 |
|---|---|---|
| 停电用户 | 21 万户 | 含医院 1 家、数据中心 2 家 |
| 停电容量 | 126 MW | 峰值 145 MW |
| 经济损失 | 约 860 万元 | 工业停产 + 商业停业 |
| 抢修成本 | 128 万元 | 含临时发电车 |
| **合计** | | **约 988 万元** |

## 4. 原因分析

### 4.1 直接原因

台风倒伏树木压断 35 kV 双回线 → 配网失去进线电源。

### 4.2 间接原因（可避免）

| 漏洞 | 根因 | 标准要求 |
|---|---|---|
| **环网切换断路器拒动** | 弹簧机构储能电机因负荷高峰电压低（342 V，额定 380 V）未储能 | 应配 UPS 保障操动机构供电 |
| **继电保护越级** | 10 kV 配变过流时限 0.3 s < 下级出线 0.5 s，反向配合 | GB/T 14285-2023 要求上级时限 ≥ 下级 + Δt（0.2 s） |
| **负荷预测偏低** | 预案预测 125 MW，实际 145 MW（+16%），配变过载 15% | 预案应按 95% 分位负荷 |
| **树木清障不足** | 线路走廊 5 m 内有高大乔木，台风季节未清理 | 应台风前 1 个月清障 |

## 5. 整改措施

| 措施 | 费用 | 工期 |
|---|---|---|
| 环网切换断路器加装 UPS（8 台） | 约 48 万 | 3 天 |
| 继电保护时限重新整定：配变 0.7 s，出线 0.5 s | 约 8 万 | 1 天 |
| 负荷预测模型升级（引入气象参数） | 约 22 万 | 30 天 |
| 配网走廊树木清障专项（台风季前） | 约 18 万/季 | 每季 |
| **合计** | **约 96 万** | |

## 6. 经验教训

1. **配网保护时限配合方向不能搞反**——上级必须比下级慢，这是 GB/T 14285 的基本要求，实测时必须逐级验证
2. **弹簧操动机构必须配 UPS**——台风期间电压跌落 10% 是常态，储能电机欠压拒动=失去恢复能力
3. **负荷预测必须考虑气象 + 场景**——工业用户 + 高温 + 台风停电 = 叠加峰值，不能用年平均负荷
4. **树木清障是最低成本的防灾措施**——倒伏树障占台风期间配网故障的 70% 以上
