# 校审驳回：应急照明仅配双电源未设蓄电池

## 1. 摘要

本案例复盘某8层办公楼消防应急照明设计的典型校审驳回项：设计单位仅配双电源切换（市电＋柴发），未设蓄电池，被审查以"不符合GB 51309-2018"驳回。教训：**双电源切换不等于应急照明合格——蓄电池是标配，集中电源或自带电源不可省。**

## 2. 背景

**工程概况**（脱敏代号：某8层办公楼，地址隐去）：办公塔楼8层，建筑高度32m（＜100m），设消防控制室。原设计消防应急照明系统采用双电源切换方案：主电源引自市电＋备用电源引自柴发（[CALC-DG-001](../40-calc/CALC-DG-001-diesel-generator-capacity.md) 应急电源），未设蓄电池组。校审阶段被审查驳回，要求整改。

## 3. 方案

### 3.1 原设计要点

- 系统类型：非集中控制型（无控制器，由开关/接触器就地控制）
- 灯具类型：B型（高于DC36V）
- 供电方式：双电源切换（市电＋柴发），**无蓄电池**
- 持续时间：未标注（设计默认市电/柴发持续供电）
- 联动：火灾确认后本地强制点亮

### 3.2 原设计参数

| 项目 | 原设计取值 |
|---|---|
| 应急照明灯具数 | 100只×10W=1000W |
| 供电方式 | 双电源切换（市电＋柴发） |
| 蓄电池 | 无 |
| 持续时间 | 未标注 |
| 灯具类型 | B型 |

## 4. 计算

### 4.1 蓄电池容量校算（引自 [CALC-BT-001](../40-calc/CALC-BT-001-battery-capacity.md) §7.1 体系一）

**输入**：A型应急照明灯具100只×10W，共 $P$=1000W；持续时间 $t$=0.5h（一般民用建筑档）；集中电源输出DC36V；$\eta$=0.9；$K$=1.25。

$$C_d=\frac{K\,P\,t}{U_{dc}\,\eta}=\frac{1.25\times1000\times0.5}{36\times0.9}=\frac{625}{32.4}=19.3\ \text{Ah}$$

**选型**：30Ah磷酸铁锂电池组（DC36V输出，配BMS），裕度再放宽（$K$=1.4时 $C_d$=21.6Ah → 30Ah更稳）。

### 4.2 双电源切换时间校验

柴发自启动≈15s，而GB 51309-2018要求应急照明**≤5s进入点亮状态**——双电源切换时间窗口存在10s黑暗间隙，须蓄电池在线缓冲。

## 5. 审查意见

| 序号 | 意见/结论 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 应急照明须设蓄电池（自带电源或集中电源） | GB 51309-2018 第3章 | 市电全停（含柴发失效窗口）时黑暗 |
| 2 | 持续时间须按建筑类别查档（0.5/1.0/1.5h） | GB 51309-2018 第3章 | 持续时间不足 |
| 3 | 双电源切换时间＞5s，须蓄电池缓冲 | GB 51309-2018 | 切换窗口黑暗 |
| 4 | 车库/潮湿场所应优先A型灯具（DC36V及以下） | GB 51309-2018 第3章 | 触电风险 |
| 5 | 集中控制型须设应急照明控制器 | GB 51309-2018 第3章 | 无统一监视 |

## 6. 整改

### 6.1 整改后方案

- 系统类型：**集中控制型**（设消控室，配应急照明控制器）
- 灯具类型：**A型**（DC36V及以下，车库与办公地面安装优先）
- 供电方式：**自带电源型**为主，公共区出入口设A型集中电源补强
- 持续时间：0.5h档（一般民用建筑，建筑高度＜100m）
- 蓄电池：集中电源30Ah/DC36V（计算见§4.1），自带电源型按灯具内置电池（每灯标注应急时间）

### 6.2 验收复查

- 火灾工况模拟验收：切除主电源＋断开柴发（双失电）检验蓄电池持续0.5h（带照度计记录最低值）。
- 联动：火灾确认后控制器强制全楼点亮，5s内到位（详见 [PR-CM-001](../30-practice/PR-CM-001-fire-protection-interlocking.md) 联动逻辑表）。

## 7. 经验教训

- [ ] 双电源切换**不等于**应急照明合格——蓄电池是标配（自带电源或集中电源）
- [ ] 持续时间按建筑类别查档（一般0.5h；医疗/超高层1.0/1.5h），勿一刀切
- [ ] 蓄电池初装容量按"老化末期仍满足持续时间"校验（$K$取1.2~1.5裕度）
- [ ] 双电源切换时间＞5s时须蓄电池在线缓冲
- [ ] 车库/潮湿/金属构件密集场所优先A型灯具（安全电压）
