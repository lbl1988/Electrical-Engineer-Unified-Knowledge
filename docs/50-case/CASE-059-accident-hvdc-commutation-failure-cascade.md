# 事故复盘：HVDC 换相失败连锁导致受端母线失压

## 1. 摘要

某 500 kV 受端变电站发生双回 220 kV 线路瞬时性故障 → 两条 HVDC（LCC 型，共 3200 MW）**同时换相失败** → 直流功率瞬降 → 500 kV 母线电压骤降 → 站内 220 kV 母线受端失压 → 影响 12 座下级变电站，停电负荷约 800 MW，持续 12 min 恢复。**根因**：受端交流系统电压跌落 ≥ 15% 导致换相角不足（换相电压时间面积不足）；两条 LCC-HVDC 相距仅 15 km 且同属一个 500 kV 母线供电，故障同时冲击；缺乏换相失败预测控制（CFC）。

## 2. 事故时序

| 时间 | 事件 | 关键参数 |
|---|---|---|
| 14:23:15 | 220 kV L1 线路瞬时接地故障 | 故障持续 80 ms |
| 14:23:15 | 220 kV L2 线路同时接地故障 | 故障持续 80 ms |
| 14:23:15 | 500 kV 受端母线电压跌落至 0.85 pu | ΔU = 15% |
| 14:23:16 | HVDC-1 换相失败 | γ = 3.2°（换相裕度 < 5° 阈值） |
| 14:23:16 | HVDC-2 换相失败 | 同上 |
| 14:23:17 | 直流功率从 3200 MW 降至 0 | 功率瞬降 100% |
| 14:23:18 | 500 kV 母线电压继续跌落至 0.72 pu | 触发低压减载 |
| 14:23:20 | 站内 220 kV 母线受端失压 | 12 座下级变全站停电 |
| 14:23:25 | HVDC-1 尝试重启（3 次尝试） | 均失败 |
| 14:30:00 | 人工切换到备用回路 | 开始恢复 |
| 14:35:00 | 全部恢复供电 | 停电 12 min |

## 3. 根因分析

### 3.1 换相失败机理

LCC（晶闸管）换流器的换相依赖**交流侧换相电压的时间面积**。换相裕度 $\gamma$（熄弧角）：

$$\gamma = \arccos\left(2 \frac{d}{U_{L-L}}\right) - \frac{\mu}{2}$$

其中 $d$ 为换相电抗对应的电压降，$\mu$ 为换相重叠角。

当受端电压跌落 15% 时：
- $U_{L-L}$ 降低 → $\gamma$ 减小
- 同时直流电流 $I_d$ 可能增大（定功率控制调整）→ $\mu$ 增大
- $\gamma$ 降至 < 5° → **换相失败**（晶闸管无法自然关断）

### 3.2 连锁放大机制

```
220 kV 瞬时故障（外部）
    │
    ├── 500 kV 母线电压跌落 15%
    │       │
    │       ├── HVDC-1 换相失败 → 功率 0 MW
    │       ├── HVDC-2 换相失败 → 功率 0 MW  （双路同时！）
    │       │
    │       └── 瞬间减少 3200 MW 受端有功
    │               │
    │               ├── 500 kV 母线电压继续跌落
    │               ├── 频率跌落 RoCoF > 0.1 Hz/s
    │               └── 220 kV 母线受端失压
    │                       │
    │                       └── 12 座下级变全站停电（800 MW）
```

**关键放大因素**：
1. **双路 HVDC 同母线供电** → 一个故障同时冲击两条
2. **LCC 型无故障穿越能力**（对比 VSC-HVDC 具备 LVRT）
3. **换相失败后无快速恢复预案**（3 次自动重启都失败，未及时切换）

## 4. 整改措施

### 4.1 短期（1 年内）

| 措施 | 原理 | 效果 |
|---|---|---|
| **增加换相失败预测控制（CFC）** | 实时监测 $U_{L-L}$，跌落 > 8% 时提前触发直流降额 | 换相失败概率降低 60% |
| **两条 HVDC 母线解耦** | 从同一 500 kV 母线改为分接相邻两个 500 kV 站 | 一条故障不影响另一条 |
| **快速重启策略优化** | 换相失败后重启间隔从 300 ms 缩短到 100 ms，同时降低触发阈值 | 自动重启成功率提升 20% |
| **220 kV 线路重合闸与直流配合** | 交流重合闸前通知直流降功率，避免再次冲击 | 避免重合闸后二次失败 |

### 4.2 长期（3 年内）

| 措施 | 原理 | 效果 |
|---|---|---|
| **受端加装 STATCOM** | 动态无功支撑，电压跌落时快速补偿 | 电压跌落降低 50% |
| **后续 HVDC 工程采用 VSC 型** | VSC 具备 LVRT/无换相失败 | 从根源消除 |
| **HVDC 分层接入（1000 kV + 500 kV）** | 多电压等级降低故障耦合 | 故障影响范围缩小 |
