# 事故复盘：30 MW 集中式光伏电站汇流箱直流拉弧引发火灾

## 1. 摘要

某西部戈壁 30 MW 集中式光伏电站，汇流箱 DC 1500 V 汇流排接线端子松动 → **直流拉弧**（连续电弧 ≥ 15 s）→ 汇流箱内塑料支架引燃 → 火势沿电缆沟蔓延 → **全站 126 台组串式 PCS + 3200 块组件全部烧毁**，直接经济损失 1.2 亿元，停运 14 个月。**根因**：汇流排端子压接未达扭矩要求（标准 25 N·m，实测平均 12 N·m）；缺乏直流电弧检测保护（IEC 61810-2）；汇流箱采用敞开式设计未装 IP65 防护。

## 2. 事故时序

| 时间    | 事件                              | 关键参数              |
| ----- | ------------------------------- | ----------------- |
| 08:42 | 汇流箱 #B7 端子开始拉弧                  | 电弧电流 48 A         |
| 08:42 | 组串式 PCS 检测到直流侧欠压（780 V → 520 V） | 未触发停机（欠压阈值 400 V） |
| 08:43 | 直流拉弧持续 15 s，塑料支架引燃              | 烟感报警，但消防控制室误判为沙尘  |
| 08:44 | 汇流箱外壳烧穿，火势沿直流电缆沟蔓延              | 蔓延速度 2.3 m/min    |
| 08:51 | 光伏主变低压侧过流保护动作                   | 全站 35 kV 侧停电      |
| 09:05 | 消防队到达现场                         | 距电站 17 km         |
| 09:23 | 扑灭明火                            | 电缆沟过火面积 2400 m²   |

## 4. 原因分析

### 4.1 直接原因

汇流排端子压接扭矩不足（GB/T 2900.15-2013 要求 25 N·m，抽检仅 12 N·m ± 4）→ 端子接触电阻增大 18 倍 → 局部过热 320°C 引燃塑料支架。

### 4.2 间接原因

| 漏洞         | 说明                                        |
| ---------- | ----------------------------------------- |
| 无直流电弧检测    | IEC 61810-2 规定光伏系统 ≥ 100 kW 应装直流电弧检测，该站未装 |
| 汇流箱防护等级不足  | 采用 IP54 敞开式（应 IP65 密封），沙尘加速端子氧化           |
| PCS 欠压阈值过高 | 设定 400 V，实际拉弧时 520 V 未触发停机                |
| 消防联动缺失     | 汇流箱烟感未与 PCS 停机回路联动                        |
| 运维巡检频率     | 戈壁站仅每季度巡检一次（应每月红外测温）                      |

## 5. 整改措施

| 措施                         | 工期     | 费用          | 责任人    |
| -------------------------- | ------ | ----------- | ------ |
| 全站汇流箱加装直流电弧检测（126 台）       | 3 天    | 228 万       | 运维部    |
| 汇流箱改造为 IP65 密封 + 红外在线测温    | 7 天    | 412 万       | 设计部    |
| PCS 欠压阈值调低至 600 V，加拉弧特征识别  | 1 天    | 0（软件升级）     | PCS 厂家 |
| 消防联动加"烟感 → PCS 停机"硬接线      | 2 天    | 18 万        | 消防维保   |
| 运维巡检频率提升至每月 1 次 + 每季度无人机红外 | 持续     | 每年 36 万     | 运维部    |
| **总计**                     | <br /> | **约 694 万** | <br /> |
