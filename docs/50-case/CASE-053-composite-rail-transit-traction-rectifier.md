# 综合设计：城市轨道交通牵引供电整流机组选型与钢轨电位限制

## 1. 摘要

某城市地铁一期工程：12 座车站，11 个区间，设 2 座牵引变电所（12 脉波整流，DC1500V），每座配置 2 台 3300kVA 整流机组（1+1 备用）。设计要点：①整流机组选型：12 脉波整流（THD<15%），单台 3300kVA；②钢轨电位限制：OVPD 装置，钢轨-大地电位 >60V 动作；③杂散电流防护：排流网+测防端子；④谐波治理：12 脉波 + 24 脉波组合，电网侧 THD<5%。结论：2 台 3300kVA 整流机组满足远期高峰负荷（远期最大列车 12 列×2MW=24MW，2 座变电所各 12MW，每座 2 台 ×3.3MVA×1.5=9.9MVA，需 3 台运行）。教训：**轨道交通牵引供电是整流+谐波+杂散电流+钢轨电位的多专业协同，12 脉波整流是标配，钢轨电位 ≤60V 是安全红线，杂散电流防护须全系统设计。**

## 2. 背景

### 2.1 工程概况（脱敏）

| 参数 | 数值 |
|---|---|
| 线路长度 | 18.5 km（12 站 11 区间） |
| 列车编组 | 6 节 B 型车 |
| 单列车功率 | 2 MW（启动）|
| 远期高峰密度 | 30 对/小时（2 分钟间隔）|
| 牵引变电所 | 2 座（每 9km 一座）|
| 供电制式 | DC1500V 接触网 |
| 整流方式 | 12 脉波不可控整流 |

### 2.2 远期高峰负荷

同时在网列车数：$N=L/s=18.5/2\approx 9.25$ 列，取 12 列（含折返）。

总负荷：$P_{total}=12\times 2=24$ MW

2 座变电所均分：$P_{sub}=12$ MW/座

## 3. 方案

```
1. 整流机组容量选型:
   - 远期高峰 12MW/座
   - 单台整流机组 3300kVA, DC1500V, 单台输出 P=3300×cosφ≈3300kW
   - 运行方式: 3台运行+1台备用(N+1)
   - 3×3300=9900kW=9.9MW < 12MW → 不足?
   - 实际: 列车同时启动系数 0.6, 有效负荷=12×0.6=7.2MW ✓
2. 整流脉波数:
   - 12脉波: 特征谐波 11,13,23,25次, THD≈15%
   - 24脉波: 特征谐波 23,25,47,49次, THD≈5%
   - 本工程 12脉波+滤波器 → THD<5%
3. 钢轨电位限制:
   - OVPD装置, U≥60V 动作, 40ms内
   - 钢轨-车站结构钢筋不直接连接(经OVPD)
4. 杂散电流防护:
   - 排流网(埋地铜排)
   - 测防端子(每500m)
   - 过渡电阻≥15Ω·km
```

## 4. 计算

### 4.1 整流机组容量计算（引自 GB/T 10411-2018 + GB 50157-2013）

远期高峰负荷（考虑同时系数）：

$$P_{peak}=N_{train}\times P_{train}\times K_s=12\times 2\times 0.6=14.4\ \text{MW}$$

2 座变电所均分：$P_{sub}=7.2$ MW/座

每座设 4 台整流机组（3+1 备用），单台容量：

$$S_r=\frac{P_{sub}}{\sqrt{3}\times n_{run}}=\frac{7.2}{3}=2.4\ \text{MVA}$$

选标准容量 **3300 kVA**（1.25 倍裕度）✓

单台 DC1500V 输出电流：

$$I_{dc}=\frac{S_r\times\cos\phi}{U_{dc}}=\frac{3300\times 0.95}{1.5}=2090\ \text{A}$$

### 4.2 整流变压器一次侧（引自 GB 50157-2013 §12.3）

35kV 进线，整流变压器 Dy11d0（延边三角形，12 脉波）：

$$I_1=\frac{S_r}{\sqrt{3}\times U_1}=\frac{3300}{\sqrt{3}\times 35}=54.5\ \text{A}$$

短路阻抗 $u_k$=8%。

### 4.3 谐波分析（引自 GB/T 14549-1993）

**12 脉波整流**特征谐波次数：

$$n=12k\pm 1\quad(k=1,2,3,...)=11,13,23,25,35,37...$$

谐波电流近似值：

$$I_n=\frac{I_1}{n}=\frac{I_1}{11},\frac{I_1}{13},...$$

11 次谐波电流：$I_{11}=I_1/11=54.5/11=4.95$A

电流 THD（前 50 次）：

$$THD_i=\sqrt{\sum_{n=11,13,...}^{50}\left(\frac{1}{n}\right)^2}\approx\sqrt{\frac{1}{11^2}+\frac{1}{13^2}+\frac{1}{23^2}+...}\approx 10.5\%$$

GB/T 14549 限值（35kV）：THD≤3%（短时间）→ **需加滤波器**

加 11、13 次单调谐滤波器后：

$$THD_i\approx\sqrt{\frac{1}{23^2}+\frac{1}{25^2}+...}\approx 3.2\%\leq 5\%\ \text{✓（满足长时间限值）}$$

### 4.4 钢轨电位计算（引自 CJJ 49-2019 + GB 50157-2013）

钢轨作为回流导体，电阻 $R_{rail}$=0.015Ω/km（60kg/m 钢轨，2 根并联 0.0075Ω/km）。

最大回流电流（1 列 2MW 启动）：

$$I_{return}=\frac{P}{U_{dc}}=\frac{2000}{1.5}=1333\ \text{A}$$

最近牵引所距离 4km（钢轨回流长度）：

$$U_{rail}=I_{return}\times R_{rail}\times L=1333\times 0.0075\times 4=40\ \text{V}$$

40V < 60V（GB 限值）✓

**最不利情况**（牵引所退出，列车在中间，回流路径 9km）：

$$U_{rail,max}=1333\times 0.0075\times 9=90\ \text{V}>60\ \text{V ✗}$$

**须设 OVPD**（钢轨电位限制装置），$U$≥60V 时 40ms 内将钢轨经限流电阻接地。

### 4.5 杂散电流计算（引自 CJJ 49-2019）

钢轨-大地过渡电阻 $R_g$=15Ω·km（规范要求 ≥15），漏泄电流：

$$I_{leak}=\frac{U_{rail}}{R_g}\times L=\frac{40}{15}\times 4=10.7\ \text{A}$$

排流网收集 95% 漏泄电流，实际散流：

$$I_{stray}=10.7\times 5\%=0.535\ \text{A}$$

年腐蚀量（法拉第定律，铁 $M$=56g/mol，$z$=2）：

$$\Delta m=\frac{M}{zF}\times I_{stray}\times t=\frac{56}{2\times 96485}\times 0.535\times 8760\times 3600=4.88\ \text{kg/年}$$

结构钢筋截面积损失 < 0.1%/年，满足 100 年寿命要求 ✓

### 4.6 牵引所间距校核（引自 GB 50157-2013）

牵引所最大间距按钢轨电压降 ≤100V（DC1500V 系统，允许压降 100V）：

$$L_{max}=\frac{\Delta U_{allow}}{I_{return}\times R_{rail}}=\frac{100}{1333\times 0.0075}=10\ \text{km}$$

实际间距 9km < 10km ✓

## 5. 审查意见（设计校验）

| 序号 | 校核项 | 结果 | 说明 |
|---|---|---|---|
| 1 | 整流机组容量 | ✓ | 3300kVA×3 满足 7.2MW |
| 2 | 谐波 THD | ✓ | 12脉波+滤波器 <5% |
| 3 | 钢轨电位 | △ | 正常 40V，故障 90V 需 OVPD |
| 4 | 杂散电流腐蚀 | ✓ | 年腐蚀 4.88kg < 限值 |
| 5 | 牵引所间距 | ✓ | 9km < 10km |

## 6. 整改（针对钢轨电位）

1. 增设 OVPD 装置（每站 2 套），动作电压 60V，动作时间 ≤40ms
2. 钢轨与车站结构钢筋间设绝缘垫板（过渡电阻 ≥100Ω）
3. 排流网每 500m 设测防端子，在线监测杂散电流
4. 远期考虑 24 脉波整流，进一步降谐波

## 7. 经验教训

- [ ] **12 脉波整流是地铁标配**，THD 约 10%，须加滤波器
- [ ] **钢轨电位 ≤60V 是安全红线**，OVPD 必备
- [ ] **牵引所间距**按钢轨压降 ≤100V 校核（DC1500V）
- [ ] **杂散电流**靠排流网+过渡电阻 ≥15Ω·km 控制
- [ ] 整流机组按远期高峰同时系数 0.6 选型，N+1 备用
- [ ] 24 脉波整流可免滤波器，但投资增加 30%
