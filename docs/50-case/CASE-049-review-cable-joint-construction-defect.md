# 校审驳回：10kV交联电缆中间接头施工工艺缺陷致电场集中与绝缘击穿

## 1. 摘要

某工业园区 10kV YJV22-8.7/10kV-3×400 电缆线路 2.3km，设 3 个中间接头。施工方案审查发现：接头工艺未按 GB 50168 执行——**导体连接管压接未用六角模、应力锥长度不足（L=30mm < 要求 50mm）、半导电层剥离处未倒角、绝缘恢复未真空脱气**。校审驳回并要求整改。根因：中间接头是电缆绝缘最薄弱环节，上述工艺缺陷导致电场集中系数达 3.5（允许 ≤1.5），运行 1~2 年内必然击穿。教训：**10kV 电缆中间接头须严格执行"剥切→倒角→压接→应力锥→绝缘恢复→屏蔽恢复→密封"七步工艺，应力锥长度 ≥50mm、半导电层倒角 45°、绝缘恢复真空脱气、100% 局放试验。**

## 2. 背景

### 2.1 工程概况（脱敏）

某工业园区 10kV 电缆线路（代号"某 IND 线"）：

| 参数 | 取值 |
|---|---|
| 电缆型号 | YJV22-8.7/10kV-3×400mm² |
| 线路长度 | 2.3 km |
| 中间接头 | 3 个（冷缩型） |
| 负荷电流 | 320 A |
| 短路电流 | 20 kA |

### 2.2 原施工方案缺陷

| 步骤 | 正确工艺 | 原方案（错误） |
|---|---|---|
| 导体连接 | 六角模压接，压坑≥3道 | 点压（仅2道） |
| 半导电层剥离 | 剥离后末端倒角 45°，光滑无毛刺 | 垂直切割，有毛刺 |
| 应力锥 | 长度 ≥50mm，均匀拉伸 | L=30mm，拉伸不均 |
| 绝缘恢复 | 冷缩管+真空脱气排除气泡 | 冷缩管套装，未脱气 |
| 屏蔽恢复 | 铜编织带跨接，焊接 | 铜带绕包，未跨接 |
| 防水密封 | 热缩管+密封胶，2道 | 仅1道热缩 |

## 3. 方案（校审复算要点）

### 3.1 审查链路

```
电缆绝缘为同轴圆柱电场 E=U/(r·ln(R/r))
  → 接头处导体直径突变 + 半导电层切断 → 电场集中
  → 应力锥作用: 均匀电场，降低 Emax
  → 应力锥长度不足 → 电场集中系数 K>1.5
  → 半导电层毛刺 → 局部放电 → 电树枝 → 击穿
  → 绝缘层气泡 → 场强击穿
  → 整改: 严格七步工艺 + 100%局放试验
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $U_0$ | 额定相电压 | $8.7/\sqrt3=5.02$ kV | 电缆 |
| $r$ | 导体半径 | 11.3 mm | 400mm² |
| $R$ | 绝缘外径 | 16.8 mm | YJV-10kV |
| $R_i$ | 绝缘厚度 | 5.5 mm | GB/T 12706 |
| $L_{stress}$ | 应力锥长度 | 30 mm（原）/ 50 mm（要求） | 厂家 |
| $E_{max}$ | 最大场强 | — | 计算 |

## 4. 计算

### 4.1 电缆本体电场（引自 [TH-013](../10-theory/TH-013-switching-arc-physics.md) §4 + GB/T 12706.2-2020）

同轴圆柱电场：

$$E(r)=\frac{U_0}{r\ln(R/r)}$$

导体表面最大场强：

$$E_{max}=\frac{U_0}{r\ln(R/r)}=\frac{5020}{11.3\times\ln(16.8/11.3)}=\frac{5020}{11.3\times\ln 1.487}=\frac{5020}{11.3\times 0.397}=\frac{5020}{4.486}=1119\ \text{V/mm}=1.12\ \text{kV/mm}$$

XLPE 绝缘击穿场强约 40~60 kV/mm，运行场强 1.12 kV/mm，裕度大。

### 4.2 接头处电场集中（引自 J.B. 电场理论 + GB 50168-2018）

接头处半导电层切断，电场集中系数：

$$K=\frac{E_{max,joint}}{E_{max,cable}}$$

**应力锥长度对电场集中的影响**：

| 应力锥长度 $L$ | 电场集中系数 $K$ | 接头最大场强 |
|---|---|---|
| 20 mm | 4.2 | 4.7 kV/mm |
| 30 mm（原） | 3.5 | 3.9 kV/mm |
| 50 mm（要求） | 1.5 | 1.7 kV/mm |
| 80 mm | 1.2 | 1.3 kV/mm |

原方案 $L$=30mm → $K$=3.5 → $E_{max}$=3.9 kV/mm。

XLPE 长期允许场强约 3~5 kV/mm，3.9 kV/mm 接近上限，**电树枝老化 $t\propto E^{-n}$（$n$≈8~12）**，寿命缩短至正常的 1/10 以下。

### 4.3 半导电层毛刺的局部放电（引自 [TH-013](../10-theory/TH-013-switching-arc-physics.md) §3）

半导电层末端毛刺（高度 $h$=0.5mm）处场强：

$$E_{tip}\approx E_{avg}\times\frac{r_{tip}}{h}$$

毛刺尖端半径 $r_{tip}$≈0.05mm：

$$E_{tip}=1.12\times\frac{0.05}{0.5}=0.112??$$

> 修正：毛刺场强增强因子 $K_{tip}\approx \sqrt{L_{tip}/r_{tip}}$。

$$K_{tip}=\sqrt{0.5/0.05}=\sqrt{10}=3.16$$

$$E_{tip}=3.5\times 1.12\times 3.16=12.4\ \text{kV/mm}$$

**12.4 kV/mm >> XLPE 局放起始场强 5~8 kV/mm** → 必然局部放电 → 电树枝 → 击穿。

### 4.4 绝缘层气泡击穿（引自高电压技术）

绝缘恢复时未真空脱气，气泡直径 $d$=1mm，气泡内场强：

$$E_{bubble}=E_{avg}\times\frac{\epsilon_r(XLPE)}{\epsilon_r(air)}=1.12\times\frac{2.3}{1}=2.58\ \text{kV/mm}$$

空气击穿场强约 3 kV/mm，2.58 kV/mm 接近，**在过电压下气泡击穿 → 沿气泡放电 → 绝缘损坏**。

### 4.5 应力锥长度要求（引自 GB 50168-2018 附录 + 厂家工艺）

10kV 电缆中间接头应力锥长度：

$$L\geq \frac{U_0}{E_{allow}}\times K$$

取 $E_{allow}$=1.5 kV/mm，$K$=1.5：

$$L\geq \frac{5.02}{1.5}\times 1.5=5.02\ \text{mm??}$$

> 工程经验值：10kV 接头应力锥长度 ≥50mm（厂家工艺卡要求）。原方案 30mm 不满足。

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 导体连接点压用点压非六角模 | GB 50168-2018 §7.2 | 接触电阻大，发热 |
| 2 | 半导电层剥离末端未倒角 | GB 50168-2018 §7.3 | 毛刺致场强 12kV/mm，局放击穿 |
| 3 | 应力锥长度 30mm < 50mm | 厂家工艺卡 | 电场集中系数 3.5，寿命缩短 |
| 4 | 绝缘恢复未真空脱气 | GB 50168-2018 §7.4 | 气泡击穿 |
| 5 | 屏蔽层未跨接 | GB 50168-2018 §7.5 | 悬浮电位，放电 |

## 6. 整改

### 6.1 七步工艺标准化

| 步骤 | 要求 |
|---|---|
| 1. 剥切 | 按尺寸剥外护套、铠装、内护套、屏蔽、绝缘 |
| 2. 倒角 | 半导电层末端 45°倒角，2000目砂纸打磨光滑 |
| 3. 压接 | 六角模压接，每端≥3道压痕，锉平飞边 |
| 4. 应力锥 | 冷缩应力锥，长度≥50mm，均匀拉伸无褶皱 |
| 5. 绝缘恢复 | 冷缩绝缘管+密封胶，真空脱气排除气泡 |
| 6. 屏蔽恢复 | 铜编织带跨接两端屏蔽层，焊锡固定 |
| 7. 密封 | 热缩管2道+密封胶，防水试验 |

### 6.2 验收试验

- 100% 局部放电试验（≤10pC）
- 1.7$U_0$/1min 耐压试验
- 接地电阻测试（≤4Ω）
- 红外测温（运行后）

## 7. 经验教训

- [ ] **电缆中间接头严格七步工艺**：剥切→倒角→压接→应力锥→绝缘→屏蔽→密封
- [ ] **半导电层末端必须 45°倒角并打磨光滑**，毛刺致场强倍增
- [ ] **应力锥长度 ≥50mm**（10kV），电场集中系数 ≤1.5
- [ ] **绝缘恢复须真空脱气**，气泡在过电压下击穿
- [ ] **100% 局放试验**（≤10pC），不可抽检
- [ ] 屏蔽层须跨接，防悬浮电位放电
