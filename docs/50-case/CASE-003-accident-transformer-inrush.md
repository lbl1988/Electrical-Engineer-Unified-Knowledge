# 事故复盘：10kV变压器空投涌流致差动保护误动

## 1. 摘要

本案例复盘某10kV配电变压器空载投运时差动保护误动跳闸的典型事故。变压器空投励磁涌流可达额定8~10倍，含显著2/3次谐波，原差动保护未投2次谐波闭锁，导致合闸瞬间误判为区内故障跳闸。教训：**变压器差动保护必须投2次谐波制动闭锁，CT变比与励磁涌流校核是配置前提。**

## 2. 背景

**事故经过**（公开通报类事故，去项目名）：某10kV用户配电站，SCB13-630kVA干式变压器（Dyn11，$u_k$=6%）检修后空载投运。合闸瞬间差动保护动作跳闸，变压器本体无故障。运维检查发现差动保护装置2次谐波闭锁功能未投入（厂家默认关闭），合闸涌流被误判为区内故障。

**调查依据**：公开事故调查报告，涉及继电保护配置不当（[TH-012 继保四性](../10-theory/TH-012-protection-four-properties.md) §3）与磁路饱和机理（[TH-014 磁路饱和](../10-theory/TH-014-magnetic-circuit-saturation.md) §3.1）。

## 3. 方案

### 3.1 原保护配置

| 项目 | 原配置 |
|---|---|
| 变压器 | SCB13-630kVA，Dyn11，$u_k$=6%，10/0.4kV |
| 差动保护 | 微机比率制动差动，2次谐波闭锁**未投** |
| CT变比 | 一次侧 75/5（10kV侧），二次侧 1500/5（0.4kV侧） |
| 谐波闭锁 | 厂家默认关闭（2次谐波制动系数 $K_2$ 未设置） |
| 速断 | 按躲过涌流整定（$I_{set}=8I_N$） |

### 3.2 原整定参数

差动动作电流 $I_{op}=0.5I_N$（额定二次电流），比率制动斜率0.4，2次谐波闭锁阈值 $K_2$=0（即闭锁功能无效）。

## 4. 计算

### 4.1 励磁涌流估算（引自 [TH-014](../10-theory/TH-014-magnetic-circuit-saturation.md) §3.1）

变压器空投时铁芯剩磁与合闸相角共同作用，磁通峰值可达稳态2倍以上，铁芯深度饱和，励磁电流尖顶波含显著2/3次谐波：

$$I_{inrush}\approx(6\sim10)\times I_N$$

10kV侧额定电流：$I_{N,10}=S_N/(\sqrt3\times U_{10})=630/(\sqrt3\times10)=36.4$A

空投涌流峰值：$I_{inrush}\approx8\times36.4=291$A（10kV侧），折合二次侧 $291/15=19.4$A（CT变比75/5）。

### 4.2 差动保护误动校验

差动保护比较变压器一二次侧电流，正常空载时一次侧有涌流、二次侧无电流，差流 $I_d=I_{inrush}$（折合标幺值约8倍），远超动作门槛 $0.5I_N$ → **保护误动跳闸**。

### 4.3 2次谐波闭锁应动作校验

涌流含2次谐波约15%~30%（基波百分比），应触发谐波闭锁：

$$K_2 = \frac{I_{2nd}}{I_{1st}}\times100\% \approx 15\%\sim30\%$$

典型闭锁阈值 $K_{2,set}=15\%$~20%，实测 $K_2$ 应大于阈值 → **闭锁应动作，差动应不跳闸**。

## 5. 审查意见

| 序号 | 意见/结论 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 变压器差动保护必须投2次谐波闭锁 | GB/T 14285-2006 §3.1 | 空投涌流误动 |
| 2 | CT变比须校核涌流不致饱和 | GB/T 20840-2014 §4.2 | CT饱和畸变二次电流 |
| 3 | 保护装置投运前须校验全部功能参数 | DL/T 587-2016 §4.1 | 厂家默认关闭未发现 |

## 6. 整改

### 6.1 整改措施

1. **投入2次谐波闭锁**：设置 $K_{2,set}=15\%$~20%，空投时闭锁差动出口。
2. **增设间断角闭锁**（可选）：涌流波形有间断角（>60°），故障电流接近正弦无间断角，作为谐波闭锁的冗余判据。
3. **CT校核**：按涌流8~10倍校核CT准确限值系数，避免饱和（详见 [TH-014](../10-theory/TH-014-magnetic-circuit-saturation.md) §3.2）。
4. **保护装置投运校验**：按DL/T 587-2016校验全部功能参数，不得沿用厂家默认值。

### 6.2 复查结论

投入2次谐波闭锁后，空载合闸试验3次，差动保护均未误动，涌流被正确识别。

## 7. 经验教训

- [ ] 变压器差动保护**必须投2次谐波闭锁**（$K_{2,set}$=15%~20%），厂家默认值不可信
- [ ] 空投涌流可达8~10倍额定，含显著2/3次谐波（[TH-014](../10-theory/TH-014-magnetic-circuit-saturation.md) §3.1）
- [ ] CT变比须按涌流校核准确限值系数，避免饱和畸变二次电流
- [ ] 保护装置投运前按DL/T 587校验全部功能参数，不得沿用默认
- [ ] 新型电源（逆变器并网）故障电流受限幅，传统过流保护灵敏性退化（[TH-012](../10-theory/TH-012-protection-four-properties.md) §4 失效边界）
