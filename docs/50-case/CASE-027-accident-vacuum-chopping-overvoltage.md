# 事故复盘：真空断路器截流过电压致高压电动机绕组击穿

## 1. 摘要

某化工厂 6kV 引风机用 800kW 异步电动机，由 ZN28A-12 真空断路器控制，在一次空载停车时绕组首匝对地击穿。调查结论：真空灭弧室在工频电流自然过零前截流（$I_0$=8A），截流后电动机绕组电感与杂散电容回路产生高频振荡过电压；因**未配浪涌电容器与避雷器**，过电压经多次重燃级联放大至 3.5 p.u.（17.2kV），超过电机雷电冲击耐受 14kV。教训：**真空断路器切合高压电动机须配浪涌电容器（降波阻抗）与氧化锌避雷器（限幅），截流过电压 $U=I_0\sqrt{L/C}$ 中 $C$ 越大 $U$ 越低。**

## 2. 背景

### 2.1 事故经过（脱敏）

某化工厂（代号"某 HX 化工"）锅炉引风机 6kV/800kW 异步电动机，配 ZN28A-12 真空断路器，投运 2 年后某次空载停机操作中，断路器分闸后 5ms 内电机首匝绕组对地击穿，绝缘烧损，需返厂重绕。故障时电机为空载运行（仅带动风机惯性空转），电流约 35A（额定 96A）。

### 2.2 设备参数

| 参数 | 数值 | 说明 |
|---|---|---|
| 电动机 | YKK500-6, 6kV, 800kW | 6 极异步机 |
| 额定电流 | 96 A | 铭牌 |
| 空载电流 | ~35 A | 实测 |
| 真空断路器 | ZN28A-12/630-25kA | 截流水平 $I_0$≤10A |
| 截流值 $I_0$ | 8 A | 事故后实测（GB/T 14824 要求 ≤10A） |
| 浪涌保护 | **未配** | 设计遗漏 |
| 电机绝缘等级 | F 级 | 绕组耐温 155°C |
| 电机雷电冲击耐受 | 14 kV (peak) | GB 755 §8.9 / IEC 60034-15 |

### 2.3 故障现象

- 分闸瞬间电机端子处过电压录波峰值 17.2kV
- 绕组首匝（距端子第 1~3 匝）对铁芯击穿
- 电机中性点侧绕组完好 → 过电压从首端侵入衰减

## 3. 方案（调查分析链路）

### 3.1 事故分析链路

```
真空断路器分闸 → 工频电流未过零即截断（I0=8A）
  → 电机绕组电感 Lm 与杂散电容 Cw 回路振荡
  → 单次截流过电压 U = I0·√(L/C) ≈ 6.8kV (1.4 p.u.)
  → 触头分离初期介质恢复 < TRV → 多次重燃
  → 每次重燃叠加电压 → 级联放大至 3.5 p.u. = 17.2kV
  → 超过电机绝缘 14kV → 绕组击穿
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $I_0$ | 真空断路器截流值 | 8 A | 事故后实测 |
| $L_m$ | 电机空载励磁电感（每相） | 0.35 H | $U_n/(\omega\cdot I_0\cdot\sqrt{3})$ |
| $C_w$ | 绕组对地杂散电容（每相） | 0.015 μF | 制造厂数据 |
| $Z$ | 波阻抗 $\sqrt{L/C}$ | 4830 Ω | 计算 |
| $U_{chop}$ | 单次截流过电压 | 6.8 kV | $I_0\times Z$ |
| $U_{restrike}$ | 重燃级联过电压 | 17.2 kV | 录波 |
| $U_{BIL,motor}$ | 电机雷电冲击耐受 | 14 kV | GB 755 |
| $f_0$ | LC 振荡频率 | 2.2 kHz | $1/(2\pi\sqrt{LC})$ |

## 4. 计算

### 4.1 电机绕组波阻抗计算

**空载励磁电感**（引自 [TH-007](../10-theory/TH-007-induction-motor-starting.md) §3 励磁电抗）：

$$L_m=\frac{U_n}{\omega\cdot I_{noload}\cdot\sqrt{3}}=\frac{6000}{2\pi\times 50\times 35\times\sqrt{3}}=\frac{6000}{19068}=0.314\ \text{H}$$

**波阻抗**：

$$Z=\sqrt{\frac{L_m}{C_w}}=\sqrt{\frac{0.314}{0.015\times 10^{-6}}}=\sqrt{2.093\times 10^7}=4575\ \Omega$$

### 4.2 单次截流过电压（引自 [TH-013](../10-theory/TH-013-switching-arc-physics.md) §4 真空截流）

截流后，电机电感中的磁场能量 $W_L=\frac{1}{2}L_m I_0^2$ 转移至杂散电容，产生振荡过电压：

$$U_{chop}=I_0\sqrt{\frac{L_m}{C_w}}=I_0\times Z=8\times 4575=36600\ \text{V}=36.6\ \text{kV}$$

> **注**：此为理论无损耗峰值。实际因铁芯损耗与阻尼，有效值约衰减至 60~70%：

$$U_{chop,eff}=0.65\times 36.6=23.8\ \text{kV}$$

但单次截流不会直接达到该值——**真空断路器的多次重燃效应**才是主因。

### 4.3 多次重燃级联放大（引自 GB/T 18481.1-2002 §4.3 + [TH-013](../10-theory/TH-013-switching-arc-physics.md) §4.4）

真空断路器分闸初期触头间距极小（<2mm），介质恢复速度低于瞬态恢复电压（TRV）上升率，发生**重燃-再熄弧-再重燃**循环：

```
分闸 t=0 → 截流 I0 → 振荡过电压 ↑
  → 触头间 TRV > 介质恢复 → 重燃 → 电压钳至电源电压
  → 高频电流过零再熄弧 → 振荡过电压再升 ↑↑
  → 触头间距增大但 TRV 仍高 → 再重燃
  → ...（3~7 次级联）
  → 最终熄弧 → 过电压锁定在 N×p.u.
```

**每次重燃使过电压阶梯上升**，理论级联倍数：

| 重燃次数 | 累积过电压 (p.u.) | 电压 (kV, peak) |
|---|---|---|
| 0（首次截流） | 1.4 | 6.9 |
| 1 | 2.0 | 9.8 |
| 2 | 2.5 | 12.3 |
| 3 | 3.0 | 14.7 |
| 4 | 3.5 | 17.2 ← 录波峰值 |
| 5（最终熄弧） | 3.5 | 17.2 |

**峰值过电压对照**：

| 项 | 数值 | 来源 |
|---|---|---|
| 录波峰值 $U_{restrike}$ | 17.2 kV (3.5 p.u.) | 现场录波 |
| 电机雷电冲击耐受 $U_{BIL}$ | 14 kV (2.86 p.u.) | GB 755-2019 §8.9 |
| 电机工频耐压 $U_{pf}$ | 13 kV (rms) | DL/T 596-2021 §5.5 |

**$U_{restrike}$=17.2kV > $U_{BIL}$=14kV → 绕组击穿** ✓

### 4.4 浪涌保护器配置计算

**（A）浪涌电容器选型**（降低波阻抗）：

并联电容 $C_s$ 使等效波阻抗降至安全值：

$$Z'=\sqrt{\frac{L_m}{C_w+C_s}}\leq\frac{U_{BIL}}{I_0\times K_{cascade}}$$

目标 $Z'\leq 14\text{kV}/(8\times 3.5)=500\ \Omega$

$$C_s\geq\frac{L_m}{Z'^2}-C_w=\frac{0.314}{500^2}-0.015\times 10^{-6}=\frac{0.314}{250000}-0.015\mu\text{F}=1.256\ \mu\text{F}$$

选 **$C_s$=0.5μF（6kV 三相浪涌电容器，标准规格）**，$Z'$≈790Ω，$U_{chop}$=8×790=6.3kV（1.3 p.u.），即使级联放大 3.5 倍亦仅 22kV。

> 但更关键的是：并联电容使振荡频率 $f_0$ 从 2.2kHz 降至 ~400Hz，**重燃概率大幅降低**（TRV 上升率 $\propto f_0$），通常 1~2 次重燃后即最终熄弧。

**（B）氧化锌避雷器选型**（引自 GB/T 11024.1 附录D + [CALC-PT-001](../40-calc/CALC-PT-001-protection-setting.md) §5 操作过电压保护）：

| 参数 | 计算值 | 选型 |
|---|---|---|
| 持续运行电压 $U_c$ | $6/\sqrt{3}\times 1.1=3.81$ kV | $\geq$ 4.0 kV |
| 额定电压 $U_r$ | $U_c\times 1.25=5.0$ kV | Y5WS-7.6/24 |
| 残压 $U_{res}$（5kA） | 24 kV | < 14kV？ |

残压 24kV > 电机 BIL 14kV → **常规配电型避雷器无法保护电机**。须选**电机保护型避雷器**（低残压型）：

$$U_{res}\leq\frac{U_{BIL}}{K_{margin}}=\frac{14}{1.15}=12.2\ \text{kV}$$

选 Y2.5WD-7.6/12（电机保护型 MOA，$U_c$=4.0kV, $U_{res(5kA)}$=12kV）。

**（C）保护配合方案**：

```
电机端子 ← 0.5μF 浪涌电容器（降波阻抗 + 抑制重燃）
        ← Y2.5WD-7.6/12 电机型 MOA（限幅 12kV < BIL 14kV）
        ← 连接电缆 ≤ 50m（行波传播时间短，MOA 及时动作）
```

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 真空断路器切合电动机未配浪涌电容器 | GB 50053-2013 §6.1.5 | 截流过电压无阻尼，$Z$=4575Ω 极高 |
| 2 | 未配电机保护型避雷器 | GB/T 18481.1-2002 §4.3 | 过电压无限幅，17.2kV > BIL 14kV |
| 3 | 用配电型 MOA 替代电机型 MOA（如已配） | GB/T 11024.1 附录D | 配电型残压 24kV > BIL 14kV，无效保护 |
| 4 | 断路器截流值未标注电机适配要求 | GB/T 14824 | $I_0$≤10A 对高电感电机仍可致过电压 |

## 6. 整改

### 6.1 浪涌保护配置

| 措施 | 参数 | 效果 |
|---|---|---|
| 浪涌电容器 | 0.5μF, 6kV, 三相Y接法 | $Z'$: 4575→790Ω, $f_0$: 2.2→0.4kHz, 重燃概率↓ |
| 电机型 MOA | Y2.5WD-7.6/12 | $U_{res}$=12kV < BIL 14kV ✓ |
| 连接电缆 | ≤50m, 直接接电机端子 | 行波无显著反射 |

### 6.2 断路器改造

- 更换为低截流型真空灭弧室（$I_0$≤3A，如 CuCr 触头）
- 或改用 SF₆ 断路器（无截流问题，但维护成本高）

### 6.3 预防性试验补充

- 电机绕组对地绝缘试验周期由 3 年缩短至 1 年（DL/T 596-2021 §5.5）
- 增加局部放电检测（PD），监控匝间绝缘老化趋势

## 7. 经验教训

- [ ] **真空断路器切合高压电动机（≥3kV）须配浪涌电容器+电机型避雷器**，二者缺一不可
- [ ] **截流过电压 $U=I_0\sqrt{L/C}$**，并联电容增大 $C$ 即降低 $U$；浪涌电容器还降低 $f_0$ 从而减少重燃
- [ ] **电机绝缘耐受低于开关柜**：6kV 电机 BIL=14kV，而 6kV 开关柜 BIL=40kV——配电型避雷器残压 24kV 对电机无效
- [ ] **须选电机保护型 MOA（低残压型）**，残压须 ≤BIL/1.15
- [ ] 空载或轻载切合更危险：$I_0$ 占比小但 $L_m$ 最大（空载电感远大于额定工况）
- [ ] 多次重燃级联放大可使过电压从 1.4 p.u. 攀升至 3~5 p.u.，远超单次截流理论值
