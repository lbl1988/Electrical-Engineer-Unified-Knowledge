# 校审驳回：变电所直流操作电源系统未设绝缘监测装置

## 1. 摘要

某 110kV 变电所直流操作系统采用 220V 阀控铅酸蓄电池组（200Ah）+ 高频开关充电模块，设计文件未配置直流系统绝缘监测装置，仅在蓄电池组出口设一套电压巡检。校审驳回：直流系统一点接地时若无监测，第二点接地将导致保护误动或拒动（CASE-011 同源事故）。须装设**在线绝缘监测装置**，监测正/负极对地绝缘电阻，当任极对地电阻 ≤25kΩ（220V 系统）时发告警，并具备**接地故障选线定位**功能。教训：**直流操作系统绝缘监测是继电保护可靠动作的前提，DL/T 5044-2014 §7.3 强制要求，不可省略。**

## 2. 背景

### 2.1 工程概况（脱敏）

某工业园区 110kV 变电所（代号"某 SS 变"），1 台 50MVA 主变，110kV 进线 1 回、10kV 出线 12 回。直流操作系统供继电保护、断路器分合闸、信号、事故照明等负荷。

### 2.2 原设计直流系统参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 直流电压 | 220 V | 控制+动力合一 |
| 蓄电池 | GFM-200, 104 节×2V | 阀控铅酸 |
| 充电模块 | 220V/20A × 3 台（N+1） | 高频开关 |
| 直流馈线 | 约 30 回 | 保护/控制/信号/合闸 |
| 绝缘监测 | **未设** | 设计遗漏 |
| 电压巡检 | 1 套（蓄电池出口） | 仅电压 |

### 2.3 事故隐患

直流系统电缆敷设于电缆沟，与交流电缆共沟（间距 0.2m），存在受潮、绝缘老化风险。一点接地时无法发现，发展为两点接地可能导致：
- 保护出口继电器误动（正电源接地+跳闸回路接地）
- 保护拒动（负电源接地使跳闸线圈失去电源）
- 直流母线短路烧毁熔断器

## 3. 方案（校审复算要点）

### 3.1 审查链路

```
DL/T 5044-2014 §7.3 要求设绝缘监测
  → 监测正/负极对地绝缘电阻 R+、R-
  → 220V 系统告警阈值 R ≤ 25kΩ (DL/T 5044 表7.3.1)
  → 须具备接地故障选线（支路定位）
  → 原设计无 → 驳回
  → 选线原理：低频信号注入法 / 直流漏电流法
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $U_{dc}$ | 直流系统电压 | 220 V | 设计 |
| $R_{alarm}$ | 绝缘告警阈值 | 25 kΩ | DL/T 5044-2014 表7.3.1 |
| $R_{total}$ | 正+负极总对地电阻 | ≥50 kΩ | 正常 |
| $I_{leak,max}$ | 最大允许对地泄漏电流 | $U_{dc}/R_{alarm}$=8.8 mA | 计算 |
| $N_{feeder}$ | 直流馈线数 | 30 回 | 设计 |

## 4. 计算

### 4.1 绝缘监测阈值校算（引自 DL/T 5044-2014 §7.3 + 表 7.3.1）

DL/T 5044-2014 表 7.3.1 直流系统绝缘监测告警整定值：

| 直流电压 | 绝缘电阻告警值 $R_{alarm}$ |
|---|---|
| 110 V | 10 kΩ |
| 220 V | 25 kΩ |
| 48 V | 5 kΩ |

本系统 $U_{dc}$=220V → **$R_{alarm}$=25 kΩ**。

**对地泄漏电流告警阈值**：

$$I_{leak,alarm}=\frac{U_{dc}}{R_{alarm}}=\frac{220}{25000}=0.0088\ \text{A}=8.8\ \text{mA}$$

### 4.2 一点接地风险分析（引自 [CASE-011](../50-case/CASE-011-accident-dc-ground-fault.md) 同源机理）

假设正极经 $R_f$=50kΩ 接地（未达告警值），此时系统无告警。若负极某跳闸回路再经 $R_f'$=10kΩ 接地：

**跳闸线圈电流**：

$$I_{trip}=\frac{U_{dc}}{R_f+R_f'+R_{coil}}$$

设跳闸线圈电阻 $R_{coil}$=200Ω：

$$I_{trip}=\frac{220}{50000+10000+200}=\frac{220}{60200}=3.65\ \text{mA}$$

> 若 $R_f'$ 更小（如 2kΩ，金属性接地趋势）：
> $$I_{trip}=\frac{220}{50000+2000+200}=\frac{220}{52200}=4.21\ \text{mA}$$

跳闸线圈动作电流通常 0.5~2A，3.65mA 不足以动作。但**若 $R_f$ 降至 2kΩ**（接地发展）：

$$I_{trip}=\frac{220}{2000+2000+200}=\frac{220}{4200}=52.4\ \text{mA}$$

仍不动作。但**若 $R_f$→0（金属性接地）**：

$$I_{trip}=\frac{220}{0+2000+200}=\frac{220}{2200}=0.1\ \text{A}=100\ \text{mA}$$

部分灵敏跳闸线圈（动作电流 50~100mA）**可能误动**。

**关键**：一点接地不可怕，可怕的是**无监测导致第二点接地时无法预警**。

### 4.3 绝缘监测装置选型（引自 DL/T 5044-2014 §7.3.2）

| 功能 | 要求 | 原设计 | 整改 |
|---|---|---|---|
| 在线监测正/负极对地电阻 | 连续监测 | ✗ | ✓ |
| 绝缘电阻越限告警 | $R$≤25kΩ 发信 | ✗ | ✓ |
| 接地故障选线 | 定位到具体馈线支路 | ✗ | ✓ |
| 直流母线电压监测 | 过/欠压告警 | ✓（电压巡检） | ✓（集成） |
| 蓄电池电压巡检 | 逐节电压 | ✓ | ✓（集成） |

**选线原理对比**：

| 原理 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 低频信号注入法 | 不影响正常运行 | 受分布电容影响 | 220V 系统 |
| 直流漏电流法（霍尔） | 不受电容影响 | 须每回路装传感器 | 大系统 |
| 不平衡桥法 | 简单 | 无法选线 | 仅监测不定位 |

选**低频信号注入+直流漏电流组合型**（30 回馈线，每回装霍尔传感器）。

### 4.4 告警与联动逻辑

```
正常: R+ > 25kΩ 且 R- > 25kΩ → 无告警
一点接地: R+ ≤ 25kΩ 或 R- ≤ 25kΩ → 发"直流接地"告警 + 选线定位
两点接地: R+ ≤ 10kΩ 且 R- ≤ 10kΩ → 发"直流两点接地"紧急告警 + 闭锁相关保护出口
```

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 直流系统未设绝缘监测装置 | DL/T 5044-2014 §7.3.1 | 一点接地无法发现，发展为两点接地致保护误/拒动 |
| 2 | 仅有蓄电池电压巡检，无对地电阻监测 | DL/T 5044-2014 §7.3.2 | 电压正常不代表绝缘正常 |
| 3 | 直流电缆与交流电缆共沟间距 0.2m < 0.5m | GB 50217-2018 §5.1.11 | 交流故障窜入直流，绝缘劣化加速 |
| 4 | 未设接地故障选线 | DL/T 5044-2014 §7.3.3 | 接地后无法定位支路，停电查找扩大范围 |

## 6. 整改

### 6.1 增设绝缘监测装置

| 项 | 参数 |
|---|---|
| 型号 | 直流系统绝缘监测装置（低频注入+漏电流选线） |
| 监测电压 | 220V 直流 |
| 告警阈值 | $R_{alarm}$=25kΩ |
| 选线回路 | 32 路（覆盖 30 回馈线+2 路备用） |
| 通信 | RS485/以太网接入变电所监控系统 |
| 安装位置 | 直流主屏内 |

### 6.2 电缆敷设整改

直流电缆与交流电缆分沟敷设，或同沟时直流在上、交流在下，间距 ≥0.5m（GB 50217-2018 §5.1.11）。

### 6.3 运行规程补充

- 每日检查绝缘监测装置告警信息
- 每月记录正/负极对地绝缘电阻趋势
- 接地告警后 2 小时内定位处理（DL/T 724-2000 §5.3）

## 7. 经验教训

- [ ] **直流操作系统必须设绝缘监测装置**（DL/T 5044-2014 §7.3 强制），不可仅靠电压巡检
- [ ] **220V 系统绝缘告警阈值 $R_{alarm}$=25kΩ**，110V 为 10kΩ
- [ ] **须具备接地故障选线功能**，定位到具体馈线支路，否则接地后停电查找范围大
- [ ] 一点接地本身不直接致事故，但**发展为两点接地可致保护误动/拒动**——监测的目的是在第二点接地前发现第一点
- [ ] 直流电缆与交流电缆**间距 ≥0.5m**，防止交流窜入直流
