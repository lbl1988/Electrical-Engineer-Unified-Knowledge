# 事故复盘：100 MWh 电化学储能电站 PACK 级热失控级联爆炸

## 1. 摘要

某工业园区 100 MWh 磷酸铁锂储能电站（50 MW / 100 MWh，2022 年并网），**#2 BESS 电池簇 PACK-17 电芯内部短路 → 单体热失控 → 同簇 24 颗电芯级联 → 热蔓延至相邻 #1 BESS → 两个集装箱相继爆炸**，造成 2 人死亡、1 人重伤，直接经济损失 3.4 亿元。**根因**：BMS 热失控预警阈值设得过高（电芯 68°C 才报警，实际 62°C 已开始产气）；PACK 级无独立隔离阀；集装箱消防采用全氟己酮（Novec 1230）但浓度仅 7%（标准 9%~11%），不足以抑制级联。

## 2. 事故时序

| 时间 | 事件 | 关键参数 |
|---|---|---|
| 09:02:18 | PACK-17 Cell-12 内部短路 | 电芯电压 2.8 V → 0 V，温度 61°C |
| 09:02:22 | BMS 采集到过温，但未达 68°C 报警阈值 | 触发"预警"但未停机 |
| 09:03:05 | Cell-12 触发热失控（SEI 分解） | 温度 210°C，释放 H₂/CO |
| 09:03:12 | PACK 内 24 颗电芯级联热失控 | 温度 > 600°C |
| 09:03:28 | PACK 防爆阀打开，喷射高温烟气 | 烟气温度 480°C |
| 09:03:42 | 同集装箱 PACK-18 被引燃（热蔓延） | 蔓延时间 14 s |
| 09:04:15 | #2 BESS 集装箱内气体爆炸 | TNT 当量约 45 kg |
| 09:04:33 | 相邻 #1 BESS 被辐射热引燃 | 间距 3.2 m（应 ≥ 5 m） |
| 09:05:18 | #1 BESS 爆炸 | TNT 当量约 38 kg |
| 09:08:00 | 消防启动全氟己酮灭火 | 浓度实测 7.2%（标准 ≥ 9%） |
| 09:12:00 | 明火基本扑灭 | 集装箱外壳已熔穿 |

## 3. 直接损失

| 项目 | 损失 |
|---|---|
| 储能系统（2 × 50 MW / 100 MWh） | 3.2 亿元 |
| 周边建筑及设备 | 0.2 亿元 |
| 人员伤亡 | 2 死 1 重伤 |
| 停运时间 | 恢复需 18 个月 |

## 4. 原因分析

### 4.1 直接原因

电芯制造缺陷（极耳毛刺 → 刺穿隔膜 → 内部短路），在 95% SOC 满充状态下触发热失控。

### 4.2 间接原因

| 漏洞 | 详情 | 标准 |
|---|---|---|
| BMS 预警阈值设置错误 | 电芯过温报警 68°C，实际 62°C 已产气 | GB/T 40427-2021 要求 60°C |
| PACK 级无隔离 | 24 颗电芯串联无独立熔断隔离 | GB/T 40427-2021 第 6.3 条 |
| 集装箱间距不足 | 3.2 m（应 ≥ 5 m，NFPA 855） | NFPA 855 第 10.4.3 |
| 消防浓度不达标 | 全氟己酮 7.2%（应 ≥ 9%） | NFPA 855 附录 B |
| 热蔓延方向无阻挡 | 集装箱间无防火墙/水幕 | GB/T 51048-2025 第 7.2 条 |

## 5. 整改措施

| 措施 | 标准依据 | 费用 |
|---|---|---|
| 全站 BMS 阈值调低：60°C 预报警 / 65°C 强制停机 | GB/T 40427-2021 | 0（软件） |
| 每个 PACK 加独立直流熔断器（100 A） | GB/T 51048-2025 | 约 120 万 |
| 集装箱间距扩至 5 m，加防火墙 + 水幕 | NFPA 855 | 约 380 万 |
| 全氟己酮浓度复检 + 补药至 ≥ 10% | NFPA 855 | 约 45 万 |
| 加舱外红外测温 + H₂/CO 浓度在线监测 | — | 约 90 万 |
| 运维规程加"满充后静置 2 小时再并网" | 厂家推荐 | 0 |

## 6. 经验教训

1. **BMS 预警阈值是储能安全最后一道防线**——62°C vs 68°C 的 6°C 差就是"提前停机"和"爆炸"的区别
2. **PACK 级隔离熔断器是必须项**——24 颗电芯串联必须每 6~8 颗加一个 100 A 熔断器，否则一颗失控全部炸
3. **集装箱间距 5 m 不是摆设**——热辐射在 3.5 m 处仍达 800°C，足以引燃相邻舱
4. **全氟己酮浓度必须 ≥ 9%**——7.2% 的灭火剂在密闭空间里不足以抑制级联，尤其是氢气已充满舱内的情况下
