# 标准变更跟踪日志

> 维护期日常更新记录。跟踪 GB/T、DL/T、IEC、IEEE、NFPA 等标准的新发布、修订、废止动态，以及对知识库条目的回填影响。
> 更新频率：每月至少 1 次，或标准公告发布后即时更新。

## 跟踪方法

1. 国家标准公告：[std.samr.gov.cn](https://std.samr.gov.cn) 按月检索
2. 电力行业标准：中国电力企业联合会 / 国家能源局公告
3. IEC/IEEE：官网标准目录按季度检索
4. 考纲变动：注册电气工程师管委会年度公告（通常 12 月~1 月）
