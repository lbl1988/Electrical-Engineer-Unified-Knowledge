## 一、项目概述

### 1.1 建设目标

建设一个面向注册电气工程师（供配电 + 发输变电）考试的**纯静态知识库**，覆盖"理论→计算→实践→案例"四层闭环，支持：

- 考试备考（真题 + 校审 + 考纲映射）
- 工程参考（设备选型 + 行业场景 + 事故复盘）
- 快速检索（MkDocs 全文搜索 + 术语表 + 标准索引）

### 1.2 技术选型

| 组件 | 选型 | 理由 |
|---|---|---|
| 静态站点生成器 | MkDocs + Material 主题 | Markdown 原生、Mermaid 图谱、搜索、暗色模式 |
| 版本控制 | GitHub（lbl1988/Electrical-Engineer-Unified-Knowledge） | 免费、自动部署 |
| CI/CD | GitHub Actions | push → 自动 build → 自动发布到 Pages |
| 镜像站 | Render Static Site | 备用地址 |
| 字体/CDN | 系统字体栈 + BootCDN | 国内访问优化 |

## 九、经验教训

1. **front matter 格式一致性是最大隐患**——`***`（Markdown 分割线）与 `---`（YAML 分隔符）肉眼难辨，但构建行为完全不同。10 个文件踩坑，占全部 bug 的 40%。
2. **文件名重命名必须同步全库链接**——`git mv` 后正文里的 `![](old-name.md)` 不会自动更新，需要全库 grep 替换。
3. **Render Static Site 不读 `render.yaml`**——`render.yaml` 只给 Blueprint 用，Static Site 必须在 Dashboard Settings 手动配置 Build Command。
4. **MkDocs 目录页需要 `README.md`**——MkDocs 不自动生成目录索引，缺 `README.md` 的目录点击 404。
5. **Mermaid 图谱节点超过 30 个渲染变慢**——大型图谱拆分为独立文档 + 索引页，比单页 6 张图更清晰。
