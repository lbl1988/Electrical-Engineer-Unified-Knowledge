## 更新节奏

| 文件 | 更新方式 | 触发条件 |
|---|---|---|
| 权威数据源清单（GOV-001） | 按监控节奏 | 月度：强制规范/考纲相关标准 → 季度：全量盘点 → 半年：国际标准 |
| 盘点记录（GOV-002） | 季度产出 | 每季度末执行白名单核验后产出 `YYYYQ{n}-盘点记录.md` |
| 交接报告（GOV-003，即本 HANDOVER） | **每次大批量开发后手动更新** | 四层核心条目累计完成后同步修订统计数字、路线图、交接确认表 |
| 标准变更跟踪日志（GOV-STD） | 月度/即时 | 标准公告发布后即时回填影响条目 |
