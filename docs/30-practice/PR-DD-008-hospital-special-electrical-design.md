# 医院供配电与医用特殊系统设计

## 1. 负荷分级（GB 51348）

医院负荷按**断电后果严重性**分三级：

| 等级 | 典型场所 | 断电时间要求 | 供电方案 |
|---|---|---|---|
| **特级** | 手术室、ICU、CCU、产房 | ≤ 0.5 ms | 双路市电 + 医用 UPS（双套） |
| **一级** | 电梯、消防泵、排烟、应急照明 | ≤ 5 s | 双路市电 + 柴油发电机 |
| **二级** | 普通病房、检查科室 | ≤ 30 min | 双路市电，柴发备用 |
| **三级** | 辅助、行政 | 无 | 单路市电 |

**核心原则**：特级负荷的**断电时间 ≤ 0.5 ms**，只能靠**医用 UPS（双套冗余）**，柴发启动需 10~30 s 赶不上。

## 2. 核心特殊系统

### 2.1 医用 IT 系统（绝缘监测 + 报警）

手术室/ICU 等**生命安全区**采用**医用 IT 系统**（中性点不接地），防止一点接地即跳闸导致手术中断。

| 指标 | 要求 | 标准依据 |
|---|---|---|
| 对地绝缘 | ≥ 50 kΩ（正常） | GB 51348 §16.3 |
| 绝缘监测 | **实时监测 + 声/光报警** | 绝缘降至 50 kΩ 报警，≥ 10 s 提示检修 |
| 一点接地 | 仅报警不跳闸 | 允许带故障运行，检修排障后恢复 |
| 隔离变压器 | 每手术室 1 台，容量 ≥ 8 kVA | 医用隔离变压器 |

**关键设备**：医用隔离变压器 + 绝缘监测仪 + 过/欠压保护。

### 2.2 医用接地（低电阻 + 等电位）

医院接地系统比常规建筑更严格：

| 项目 | 要求 | 说明 |
|---|---|---|
| **接地电阻** | ≤ 4 Ω（综合接地） | 含保护接地 + 医用功能性接地 |
| **等电位联结** | 手术室/ICU 所有金属部件 | 防止不同设备外壳电位差引发微电击（< 10 μA） |
| **PE 线截面** | S ≥ 保护线，且 ≥ 16 mm² | 比常规建筑要求高 |
| 防触电压 | ≤ 10 mV（手术台附近） | YY/T 0709 |

**等电位联结范围**：手术台金属部件、医疗设备外壳、灯具、风口、水管、护栏 → 全部联结到**局部等电位箱**（LEB）。

### 2.3 医用 UPS（双套 2N）

手术室/ICU 的 UPS 必须**双套冗余 2N**：

```
市电 A ─── UPS A（50%）─── 手术室 A 侧
市电 B ─── UPS B（50%）─── 手术室 B 侧

正常：两套并联各供一半
故障：一套故障另一套 100% 顶上，切换时间 < 0.1 ms
```

**参数要求**：
- 切换时间 < 0.1 ms（比常规 2N 更快）
- 电池后备：**30~60 min**（柴发启动备用 + 手术应急）
- 谐波失真 THD < 2%（医用设备对电能质量敏感）
- 电池舱防泄漏 + 气体灭火（GB 44240）

## 3. 算例：三甲医院 1000 床设计

### 3.1 负荷计算

| 区域 | 面积/数量 | 单位负荷 | 计算负荷 |
|---|---|---|---|
| 手术室 | 20 间（25 m²/间） | 350 VA/m² | 175 kVA |
| ICU/CCU | 50 床 | 2 kW/床 | 100 kVA |
| 病房 | 1000 床 | 150 W/床 | 150 kW |
| 辅助 + 空调 | 40,000 m² | 60 W/m² | 2400 kW |
| 照明 | 40,000 m² | 15 W/m² | 600 kW |
| 消防 | — | — | 500 kW |
| **合计** | | | **4025 kVA ≈ 4.1 MVA** |

### 3.2 变压器选型

双路 10 kV 市电，2 台主变：

$$S_T = \frac{4.1 \times 1.25}{2} = 2.56 \text{ MVA/台}$$

选 **10/0.4 kV，2.5 MVA Dyn11 × 2 台**，一用一备，自动切换 ATS（切换时间 ≤ 0.2 s）。

### 3.3 柴油发电机

**柴发数量**：2 台（N+1 冗余），单台容量 ≥ 100% 特级 + 一级负荷 = 2.5 MVA。

**启动时间**：≤ 10 s（应急负荷自动接通）。

### 3.4 医用 UPS

20 间手术室 + 50 床 ICU，UPS 总容量：

$$P_{\mathrm{UPS}} = (175 + 100) \times 1.25 = 344 \text{ kVA}$$

选 **500 kVA × 2（2N 冗余）**，电池 60 min。

### 3.5 IT 系统配置

20 间手术室 × 1 台医用隔离变压器（8 kVA）+ 绝缘监测仪 = 20 套。

## 5. 工程注意点

| 要点 | 说明 |
|---|---|
| **断电时间硬指标** | 特级 ≤ 0.5 ms（UPS），一级 ≤ 5 s（柴发）；柴发赶不上特级负荷，必须配 UPS |
| **医用 IT vs 常规 IT** | 医用 IT 系统必须带**绝缘监测仪**，常规 IT 系统仅电容电流监测 |
| **电池泄漏防护** | 医用 UPS 电池舱必须有**酸液/电解液泄漏收集系统**（ICU 洁净区不能被污染） |
| **等电位联结** | 手术室 LEB 箱与接地网联结电阻 ≤ 0.01 Ω |
| **消防优先** | 柴发优先启动消防泵 > 空调 > 照明（ATS 分级） |
| **洁净区电气** | ICU 洁净区（10 万级）电器 IP ≥ IP54，线缆穿墙密封 |
