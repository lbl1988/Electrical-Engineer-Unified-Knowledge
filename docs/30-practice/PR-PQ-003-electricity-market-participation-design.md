# 工商业用户电力市场参与方案设计

## 1. 电力市场格局（2024）

中国电力市场已进入**现货市场 + 辅助服务市场 + 绿色电力交易**三市场并行的格局，工商业用户（≥ 10 kV 或年用电量 ≥ 100 万 kWh）可自主选择售电公司或直接参与市场。

| 市场类型 | 交易周期 | 价格波动 | 用户参与方式 |
|---|---|---|---|
| **中长期合约** | 年/月 | 低（锁价） | 与售电公司签合同，价差返还 |
| **现货市场** | 日前（D-1）/实时 | 高（峰谷 3~5 倍） | 直接参与或委托售电 |
| **辅助服务市场** | 15 min | 中 | 用户侧储能/可中断负荷 |
| **绿电交易** | 年/月 | 略高于现货 | 购买绿电证书，满足 ESG |
| **容量市场**（试点） | 年 | 固定 | 承诺可中断负荷容量获补贴 |

## 2. 用户侧可参与的服务

| 用户侧资源 | 可参与市场 | 技术要求 | 典型收益 |
|---|---|---|---|
| **分布式光伏** | 自发自用 + 余电上网 + 现货 | 计量关口表 + 反孤岛 | 余电上网 0.3~0.8 元/kWh |
| **电化学储能** | 峰谷套利 + 辅助服务（一次/二次调频） | EMS + 调频控制 | 峰谷套利 0.5~1.0 元/kWh；调频 30~100 元/MWh |
| **可中断负荷** | 辅助服务（备用/黑启动） | EMS 远程控制 + 快速响应 | 100~300 元/kW·年 + 响应收益 |
| **电动汽车换电站** | V2G（车到电网）+ 峰谷套利 | 双向 PCS + EMS | 峰谷套利 0.5~1.0 元/kWh |
| **余热/余压发电** | 分布式发电上网 | 并网验收 + 计量 | 上网电价 0.4~0.6 元/kWh |
| **绿电消费** | 绿色电力证书（GEC） | 购买 GEC 或直接签绿电合约 | 满足 ESG 披露，无直接收益 |

## 3. 设计要点

### 3.1 中长期合约策略

**核心**：锁价 + 价差返还。

```
用户电价构成：
电网代理购电价（现货市场加权均价）± 中长期价差 ± 输配电价 ± 税费

中长期合约（与售电公司）：
├── 签订"价差合约"（差价合约）
│   合约价 F（如 0.5 元/kWh）vs 实际现货价 S
│   结算：用户付给售电公司 (S - F) × Q
│   实际电价 = S + (F - S) = F（固定）
│   效果：锁价，现货涨了赚，跌了不亏
│
└── 签订"捆绑合约"（现货 + 辅助服务）
    售电公司打包服务，用户支付一个综合价格
```

**策略**：
- **保守策略**：100% 合约锁定电价，避免现货波动
- **激进策略**：60% 合约 + 40% 现货，现货低时多买
- **储能配合**：合约买谷电（便宜），储能充电；现货峰价时放电

### 3.2 现货市场参与

**门槛**：年用电量 ≥ 400 万 kWh（广东/山东），或委托售电公司代理。

```
日前市场（D-1，提前一天 10:00 前报价）
├── 报价：每小时申报买入/卖出价格和电量
├── 出清：按社会福利最大化排序，统一出清价格 MCP
├── 结算：实际用电量 × MCP

实时市场（D，每 15 min 滚动）
├── 超短期（15 min 前）
├── 超超短期（5 min 前）
└── 结算调整
```

**用户侧套利**：
- 储能 D-1 申报：谷价时段（23:00~7:00）买入充电
- 储能 T 日：峰价时段（9:00~11:00, 18:00~21:00）放电卖出

### 3.3 辅助服务市场

用户侧可提供的辅助服务：

| 服务 | 提供方式 | 补偿标准（典型） | 技术要求 |
|---|---|---|---|
| **一次调频（AGC）** | 储能 PCS 快速响应（< 3 s） | 30~100 元/MWh | 储能 PCS 必须具备一次调频能力 |
| **二次调频** | 储能慢速响应（< 10 min） | 15~50 元/MWh | EMS 调度 |
| **备用（备用容量）** | 储能待命 + 可中断负荷 | 100~300 元/kW·年 | 可中断负荷必须能在 5 min 内切断 |
| **黑启动** | 储能 + VSG 提供启动电源 | 50~150 元/kW | 必须具备离网启动能力 |
| **无功补偿** | SVG + 储能 PCS 无功调节 | 20~50 元/kvar·年 | 电网调度自动指令 |

### 3.4 算例：50,000 m² 办公园区电力市场收益

**已知条件**：年用电量约 800 万 kWh，园区有 2 MW 光伏 + 2 MWh 储能。

**收益项**：

| 项目 | 年收益（万元） |
|---|---|
| 光伏自发自用（省电费） | 160 |
| 光伏余电上网 | 40 |
| 储能峰谷套利（现货市场） | 525 |
| 储能一次调频（辅助服务） | 80 |
| 储能备用容量补贴 | 100 |
| 可中断负荷补贴 | 50 |
| 绿电证书（减碳 ESG） | 0（无直接收益，但助力 ESG 评级） |
| **合计** | **955** |

**年化收益率**（光伏 + 储能 + EMS 投资 1300 万）：955 / 1300 = **73.5%**。

## 5. 工程注意点

| 要点 | 说明 |
|---|---|
| **现货价格波动** | 广东现货 2023 年峰谷比达 4~5 倍，储能套利空间大 |
| **结算流程** | 现货市场 T+1 结算，偏差考核 < ±5%（超量考核价格 1.5 倍） |
| **计量** | 必须装**关口智能电表**（双向计量 + 数据加密），由电网公司/交易中心认证 |
| **绿电 vs 现货** | 绿电合约价格略高于现货（0.05~0.1 元/kWh），但可用于 ESG 减碳披露 |
| **需求响应** | 用户主动削减负荷（≥ 10% 额定）可获额外补贴，上海约 0.5 元/kWh |
| **政策风险** | 各省市场细则每年调整，需每年更新参与方案 |
