# 智慧园区能源管理系统（EMS）设计

## 1. 系统概述

智慧园区能源管理系统（Energy Management System, EMS）是**将园区内电/气/冷/热/光伏/储能/充电桩等多元能源统一监测、调度、优化**的数字化平台。目标是实现：

| 目标 | 量化指标 |
|---|---|
| **节能** | 综合能耗降低 15~30% |
| **降本** | 电费降低 10~20%（峰谷套利 + 需量控制） |
| **减碳** | 园区自消纳新能源占比 > 30% |
| **可靠** | 供电可靠性提升至 99.99% |

## 2. 系统架构

### 2.1 五层架构

```
┌─────────────────────────────────────────────┐
│  应用层 (Application)                         │
│  ├── EMS 主界面（能耗驾驶舱）                  │
│  ├── 光伏/储能/充电桩管理                      │
│  ├── 需量管理 + 峰谷套利调度                   │
│  ├── 碳排放核算                               │
│  └── 报表 + 运维工单                          │
├─────────────────────────────────────────────┤
│  平台层 (Platform)                            │
│  ├── 数据中台（时序数据库 TimescaleDB）         │
│  ├── 实时调度引擎（规则引擎 + AI 优化）          │
│  ├── 微电网管理（并离网切换）                   │
│  └── 边缘计算网关（本地快速响应）                │
├─────────────────────────────────────────────┤
│  网络层 (Network)                             │
│  ├── 5G/光纤主干                              │
│  ├── LoRa/RS485/Modbus 边缘                   │
│  └── 能源路由器（多协议转换）                    │
├─────────────────────────────────────────────┤
│  边缘层 (Edge)                                │
│  ├── 边缘网关（每变配电室 1 台）                │
│  ├── 本地保护（防孤岛/反送电）                   │
│  └── 本地微源调度                              │
├─────────────────────────────────────────────┤
│  感知层 (Perception)                          │
│  ├── 电能质量监测（电压/电流/谐波/功率）          │
│  ├── 光伏 PCS 数据                             │
│  ├── 储能 BMS/PCS 数据                         │
│  ├── 充电桩数据                                │
│  ├── 空调/冷水机组能耗                          │
│  └── 燃气/水/冷量表具                           │
└─────────────────────────────────────────────┘
```

## 3. 核心功能设计

### 3.1 能耗监测与计量

| 监测点 | 频率 | 数据 |
|---|---|---|
| 10 kV 进线 | 1 s | 三相电压/电流/有功/无功/谐波 |
| 0.4 kV 馈线（按功能区） | 1 s | 同上 |
| 光伏/储能/充电桩 | 1 s | 功率/能量/状态 |
| 燃气/水/冷量 | 1 min | 流量/累计量 |

**计量颗粒度**：按楼栋/楼层/部门/设备分类计量，实现"谁用能、谁买单"。

### 3.2 需量管理

**最大需量**：变压器或园区进线的最大 15 min 平均有功功率（电费按此计费）。

| 控制手段 | 效果 |
|---|---|
| **储能削峰** | 储能在用电高峰放电，降低最大需量 |
| **错峰用电** | 将非生产性负荷（空调/热水/充电桩）移到谷电时段 |
| **光伏自发自用优先** | 光伏电力优先供给本地负荷，减少从电网购电 |

**算例**：园区最大需量 8 MW，储能 2 MW 放电可将最大需量降至 6 MW → 年节约需量电费约 200 万元（上海 40 元/kW/月 × 2 MW × 12 月）。

### 3.3 峰谷套利调度

| 时段 | 电价（元/kWh） | 储能操作 | 光伏操作 |
|---|---|---|---|
| 谷时（0:00~6:00） | 0.3 | **充电**（2 MW × 6 h = 12 MWh） | 无 |
| 平时（6:00~8:00, 11:00~18:00, 21:00~24:00） | 0.8 | 待机 | 自发自用优先 |
| 峰时（8:00~11:00, 18:00~21:00） | 1.5 | **放电**（2 MW × 6 h = 12 MWh） | 自发自用 + 余电上网 |

**年峰谷套利收益**：12 MWh × (1.5 - 0.3) × 365 天 = **525.6 万元**。

### 3.4 微电网并离网

当园区光伏 + 储能容量足够时，配置**构网型 PCS（VSG）**实现：

| 模式 | 条件 | 动作 |
|---|---|---|
| **并网模式** | 电网正常 | 光伏/储能优先供给本地，余电上网 |
| **离网模式** | 电网故障/计划检修 | VSG 构建独立电网，光伏 + 储能维持重要负荷（应急照明/安防/数据中心） |
| **无缝切换** | 并离网切换 < 10 ms | 对重要负荷供电无中断 |

## 6. 工程注意点

| 要点 | 说明 |
|---|---|
| **储能选型** | 园区储能优先选**磷酸铁锂**（循环寿命 3000~6000 次，安全），不选三元锂 |
| **PCS 必须 GFM** | 储能 PCS 必须具备**构网型（GFM/VSG）**能力，才能支撑离网运行 |
| **数据安全** | 能源数据涉及商业机密，必须**本地边缘计算 + 云端加密**，不对外暴露 |
| **AI 调度** | 用 LSTM 预测园区负荷（精度 > 90%），优化储能充放策略 |
| **消防** | 储能舱必须**全氟己酮气体灭火 + 热蔓延阻隔**（见 TH-055） |
| **反送电** | 分布式光伏禁止向电网倒送（除非有上网许可），EMS 必须实时监测并切断 |
