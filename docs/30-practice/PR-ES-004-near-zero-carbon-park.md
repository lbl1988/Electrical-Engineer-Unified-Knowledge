# 碳中和园区综合能源设计

## 1. 碳中和目标定义

**零碳园区**（ISO 50001 / GB/T 41197）：年园区净碳排放量 **≤ 1 kgCO₂e/m²·年**（或 100% 绿电 + 其他排放抵消）。

**近零碳园区**：年碳排放强度 **≤ 10 kgCO₂e/m²·年**（约传统园区 1/5）。

| 园区类型 | 建筑面积 | 年耗电 | 碳排放强度 |
|---|---|---|---|
| 传统办公 | 50,000 m² | 500 万 kWh | 30~50 kgCO₂e/m² |
| 近零碳 | 50,000 m² | 350 万 kWh | ≤ 10 kgCO₂e/m² |
| **零碳** | 50,000 m² | 350 万 kWh | **≤ 1 kgCO₂e/m²** |

## 2. 综合能源架构

### 2.1 光储直柔系统

```
光伏 10 MWp（屋顶 + 车棚 + BIPV）
    │
    ├── DC 母线（750 V 柔性直流）
    │       │
    │       ├── 储能 PCS GFM（5 MWh × 2）
    │       ├── 直流充电桩（V2G 双向）
    │       ├── 数据中心 HVDC 直供
    │       └── DC/AC 逆变（380 V 交流负荷）
    │
    └── 10 kV 并网变压器 + SVG 无功补偿
            │
            └── 市电（现货/中长期合约）
```

**关键技术**：
- **直流（柔）**：核心是 **柔性直流母线（DC 750 V）**，光伏/储能/充电桩/数据中心直接挂 DC 母线，减少 AC↔DC 转换损耗（PUE 从 1.2 降到 1.05）
- **柔（Flexibility）**：储能/负荷可 EMS 调度响应电网需求

### 2.2 绿电消纳与碳排核算

| 能源 | 年供能量 | 碳因子（kgCO₂e/kWh） | 年碳排放 |
|---|---|---|---|
| 光伏（自发自用） | 10 MW × 1200 h = 1200 万 kWh | 0（绿电） | 0 |
| 光伏余电上网 | 1200 万 kWh - 350 万 = 850 万 kWh | 0 | 0 |
| 储能峰谷套利 | 谷电买入 5 MWh × 300 天 | 0.585（电网） | 877 kg |
| **年度净排放** | | | **877 kg ≈ 1 kgCO₂e/m² ✓** |

> 注：电网碳因子 0.585 kgCO₂e/kWh（GB/T 41197 默认值），光伏碳因子计入全生命周期约 0.04 kgCO₂e/kWh，但绿电交易按 0 计。

### 2.3 V2G（车到网）

园区电动汽车配**双向充电桩（V2G）**，参与辅助服务：

| 项目 | 数值 | 收益 |
|---|---|---|
| 园区 EV 数量 | 200 台 | |
| 参与 V2G 比例 | 50% | 100 台 |
| 单车电池 | 70 kWh | |
| V2G 总容量 | 100 × 70 × 50%（SOC 可调度）= 3500 kWh = 3.5 MWh | |
| 调频收益 | 30 元/MWh × 365 天 × 3.5 MW × 4 h = | 15.3 万 |

## 3. 算例：5 万 m² 零碳园区设计

### 3.1 能源平衡

| 项目 | 年能量 | 来源 | 碳因子 |
|---|---|---|---|
| 园区总用电 | 350 万 kWh | | |
| 光伏供给 | -1200 万 kWh（> 总用电） | 自发自用 350 万 + 上网 850 万 | 0 |
| **年度净排放** | | | **≈ 877 kg** |
| **排放强度** | | | **0.018 kgCO₂e/m² ✓（≤ 1）** |

### 3.2 光伏容量配置

$$P_{\mathrm{PV}} = \frac{350}{1200 \times 0.7 \text{（自用率）}} \approx 4.2 \text{ MWp}$$

选 **5 MWp**（屋顶 3 MW + 车棚 1.5 MW + BIPV 0.5 MW），余电上网卖电。

### 3.3 储能配置

$$E_{\mathrm{ESS}} = 5 \text{ MWh（2 × 2.5 MWh 舱）}$$

储能作为：
1. **削峰填谷**：谷电充电（0.3 元）→ 峰电放电（1.5 元）
2. **电网备用**：并网时作为惯量支撑（VSG）
3. **离网备用**：电网故障时维持园区重要负荷

### 3.4 EMS 调度策略

```
EMS 运行模式（日调度）
├── 夜间谷电（0:00~6:00）
│   ├── 储能充电（2 MW × 6 h = 12 MWh）
│   ├── V2G 低谷充电（电价引导）
│   └── 园区 HVAC 制冷机组（谷电储能冷）
│
├── 白天（6:00~18:00）
│   ├── 光伏优先自用 → 储能补充
│   ├── V2G 可调度（电网调频指令）
│   └── 余电自动上网（预测 15 min 前申报）
│
├── 峰电（18:00~21:00）
│   ├── 储能放电（2 MW × 3 h = 6 MWh）
│   └── 园区高能耗负荷避峰（通知式削减 20%）
│
└── 夜间（21:00~24:00）
    └── 待储能充电至 SOC ≥ 70% 待机
```

### 3.5 投资回报

| 项目 | 投资 | 年收益 | 回收期 |
|---|---|---|---|
| 光伏 5 MWp | 1750 万（3.5 元/W） | 自发自用 350 万 + 上网 425 万 | 2.4 年 |
| 储能 5 MWh | 750 万（1500 元/kWh） | 峰谷套利 600 万 | 1.3 年 |
| V2G 桩 100 台 | 200 万（2 万/台） | 调频 15 万 + 桩费 120 万 | 1.5 年 |
| EMS + 其他 | 500 万 | — | 并入整体 |
| **合计** | **3200 万** | **≈ 1510 万** | **2.1 年** |

> 注：储能+V2G 收益可观是因为峰谷价差（1.2 元/kWh）和调频补贴（30 元/MWh）双轨收入。

## 5. 工程注意点

| 要点 | 说明 |
|---|---|
| **碳排放因子** | 电网碳排放因子各省份不同（华北 ~0.9，南方 ~0.5），碳核算必须用最新公布值 |
| **BIPV 适配** | 建筑一体化光伏需与建筑设计同步（不能事后加装），效率比组件低 3~5% |
| **储能舱消防** | 全氟己酮气体灭火 + 热蔓延阻隔（见 TH-055） |
| **V2G 双向计量** | 必须装关口双向智能电表（正向购电 + 反向卖电） |
| **绿电交易** | 直接交易（用户→新能源场站）比现货市场价格低，签约 3~5 年长期合约 |
| **PUE 硬性约束** | 园区 PUE ≤ 1.2（零碳园区要求），采用自然冷却 + 液冷 + HVDC 直供 |
