# 航空港航站楼供配电设计

## 1. 负荷分级

航站楼负荷**以一级负荷为主**，断电影响机场运行导致航班延误：

| 等级 | 典型场所 | 断电后果 | 恢复时间要求 |
|---|---|---|---|
| **特级** | ATS 自动值机、安检系统、航班信息显示（FIDS） | 航班混乱，旅客滞留 | ≤ 0.5 ms |
| **一级** | 登机桥、行李系统、消防泵、应急照明 | 航班延误、安全风险 | ≤ 15 s |
| **一级特别重要** | 助航灯光（跑道/滑行道） | **飞机无法起降**，航空安全 | ≤ 1 s（UPS 过渡） |
| **二级** | 办公、商业、餐饮 | 影响服务 | ≤ 30 min |

## 2. 核心系统

### 2.1 双路市电 + 应急电源架构

```
市电 A（机场高压 35 kV 环网）
市电 B（另一独立电源）
    │
    ├── 母线 A ─── 柴发 A（100% 特级 + 一级）
    ├── 母线 B ─── 柴发 B（N+1 冗余）
    └── 母联 CB（正常闭合均衡负载）

特级负荷：
  └── UPS 2N 冗余（同医院手术室）

助航灯光（机场专用）：
  └── 专用变压器 + 柴油 + 直流应急母线（GB 50061）
```

### 2.2 不间断照明（疏散 + 应急）

**应急照明规范**：GB 50016 要求航站楼疏散通道照度 ≥ 10 lux，且**自带蓄电池应急灯具**（≥ 90 min 持续时间）。

**关键设计**：

| 区域 | 照度（lx） | 应急方式 | 持续时间 |
|---|---|---|---|
| 疏散走道 | ≥ 10 | 自带蓄电池 + 柴发 | ≥ 90 min |
| 楼梯间 | ≥ 30 | 同上 | ≥ 90 min |
| 登机桥口 | ≥ 50 | 双电源 + 柴发 | ≥ 120 min |
| 行李提取厅 | ≥ 200 | 双路市电 + 柴发 | ≥ 120 min |
| 安检 | ≥ 300 | 双路市电 + UPS | ≥ 30 min |
| 登机口 | ≥ 200 | 双路市电 + 柴发 | ≥ 120 min |

### 2.3 行李输送系统供电

航站楼行李处理系统（BHS）耗电大户，占总负荷 **15~20%**：

| 部分 | 功率 | 供电方式 |
|---|---|---|
| 值机岛行李输送 | ~20 kW × N 岛 | 双路市电 + 柴发 |
| 安检 X 射线 | ~10 kW × N 台 | UPS 过渡（≤ 0.5 s） |
| 离港行李分拣机 | ~50 kW | 双路市电 |
| 到港提取转盘 | ~30 kW × N 个 | 双路市电 |

## 3. 算例：5 万 m² 中型航站楼

### 3.1 负荷计算

| 区域 | 面积/数量 | 单位负荷 | 计算负荷 |
|---|---|---|---|
| 公共区域（值机/安检/登机） | 25,000 m² | 80 VA/m² | 2000 kVA |
| 商业餐饮 | 10,000 m² | 100 VA/m² | 1000 kVA |
| 行李系统 | 1 套 | | 250 kVA |
| 消防 + 应急 | | | 300 kVA |
| 空调 | 50,000 m² | 60 W/m² | 3000 kW |
| **合计** | | | **6550 kVA ≈ 6.7 MVA** |

### 3.2 变压器

双路 35 kV，3 台主变（N+1 冗余）：

$$S_T = \frac{6.7 \times 1.1}{2} = 3.69 \text{ MVA/台}$$

选 **35/0.4 kV，4 MVA Dyn11 × 3 台**。

### 3.3 柴油发电机

2 台（N+1 冗余），单台容量 ≥ 6 MVA，启动时间 ≤ 10 s。

### 3.4 UPS

- 助航灯光 FIDS：50 kVA × 2（2N）
- 安检 X 射线：20 kVA（1N + 柴发）
- ATS 自动值机：30 kVA × 2

## 5. 工程注意点

| 要点 | 说明 |
|---|---|
| **助航灯光优先级最高** | 属于航空安全级，断电影响飞机起降，UPS + 柴发双保险 |
| **柴发位置** | 航站楼柴发布置在地下或屋顶，排烟管道独立，不能被行李/安检系统影响 |
| **疏散照明 90 min** | GB 50016 强制，自带蓄电池的灯具不能仅依赖柴发 |
| **行李系统柴发裕量** | 行李系统启动电流大（2~3 $I_N$），柴发选型时要考虑同时启动 |
| **民航专用标准** | MH/T 5012 比 GB 更严格，机场项目优先执行民航标准 |
| **谐波治理** | 安检 X 射线、LED 大屏产生大量谐波，需加装 LCL 滤波器 |
