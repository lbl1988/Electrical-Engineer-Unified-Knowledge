# SPD 选型与级间配合设计

## 1. 摘要

SPD 配置＝**防护区划分 → 试验等级选择（Type 1/2/3）→ $U_p$ 校核 → 级间能量配合 → 前端保护 → 接线与接地**六步。本条给出 Type 1/2/3 SPD 适用矩阵、$U_p\le U_{w}$（设备耐压）校核公式、级间配合判据（退耦距离/触发型 SPD）；算例为综合楼三级 SPD 配置（10/350μs 直击雷与 8/20μs 感应雷防护），衔接 [PR-GR-001](PR-GR-001-lightning-protection-design.md) 防雷设计。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| SPD | 电涌保护器，限制瞬态过电压与泄放浪涌电流 | GB/T 18802.1 |
| Type 1（I 级） | 可泄放直击雷电流（10/350μs，$I_{imp}$） | GB/T 18802.1 |
| Type 2（II 级） | 限制感应雷与操作过电压（8/20μs，$I_n$/$I_{max}$） | GB/T 18802.1 |
| Type 3（III 级） | 末端精细保护（1.2/50μs+8/20μs 混合波，$U_{oc}$） | GB/T 18802.1 |
| $U_p$ | 电压保护水平（SPD 残压） | GB/T 18802.1 |
| $U_w$ | 设备绝缘耐压（ withstand voltage） | GB/T 16935 |
| 防护区（LPZ） | 雷电防护区域划分（LPZ 0/1/2/3） | GB 50057 |

## 3. 原理与公式

### 3.1 SPD 试验等级与适用

| SPD 类型 | 波形 | 关键参数 | 适用位置 | 防护区 |
|---|---|---|---|---|
| Type 1 | 10/350μs（直击雷） | $I_{imp}$（12.5kA 典型） | 总进线/主配电 | LPZ 0→1 |
| Type 2 | 8/20μs（感应雷） | $I_n$（20kA）/ $I_{max}$（40kA） | 楼层配电 | LPZ 1→2 |
| Type 3 | 混合波 | $U_{oc}$（10kV）/ $I_{sc}$ | 末端设备 | LPZ 2→3 |

### 3.2 电压保护水平校核

$$U_p \le U_w \cdot K$$

$K$ 为安全裕度系数（通常 0.8），$U_w$ 为设备耐压（380V 级设备 $U_w=4$kV，IT 设备 $U_w=1.5\sim2.5$kV）。

| SPD 位置 | $U_p$ (kV) | 设备 $U_w$ (kV) | $U_p \le 0.8 U_w$？ | 结论 |
|---|---|---|---|---|
| 总进线 Type 1 | $\le2.5$ | 4.0（配电设备） | $2.5\le3.2$ ✓ | OK |
| 楼层 Type 2 | $\le1.5$ | 4.0（配电） | ✓ | OK |
| 末端 Type 2/3 | $\le1.2$ | 1.5（IT） | $1.2\le1.2$ ⚠ | 临界，需 Type 3 |

### 3.3 级间能量配合

SPD 级间配合判据：前级 SPD 泄放大部分电流，后级承受残压不超过 $U_w$。

**退耦距离法**：

$$L_{decouple} \ge \frac{U_{p1} - U_{p2}}{di/dt}$$

| 场景 | $U_{p1}$ (kV) | $U_{p2}$ (kV) | $di/dt$ (kA/μs) | $L_{decouple}$ (m) |
|---|---|---|---|---|
| Type 1→Type 2 | 2.5 | 1.5 | 1 | 10 |
| Type 2→Type 3 | 1.5 | 1.0 | 0.5 | 10 |

实际线路长度不足时：配退耦电感或选触发型 SPD（ ignition SPD）。

### 3.4 前端保护（后备保护）

SPD 前端保护器件须满足：
- 正常工况不误动（$I_n$ 下不跳）
- 短路工况速动（SPD 短路时切除）
- 雷电冲击不熔断（8/20μs 或 10/350μs 下不熔断）

| 前端器件 | 适用 SPD | 特点 |
|---|---|---|
| 专用 SPD 后备熔断器 | Type 1/2 | 雷电不熔+短路速动 |
| MCB（C 型） | Type 2（小容量） | 须校验雷电流耐受 |
| Type 1 专用脱离器 | Type 1 | 雷电流下不脱扣 |

## 5. 设计/选型要点（校审清单）

- [ ] 防护区划分：LPZ 0（直击雷暴露）/1（主进线）/2（楼层）/3（末端设备）
- [ ] Type 1 SPD：仅在建筑物有避雷装置或架空进线时设置；$I_{imp}\ge12.5$kA（10/350μs）
- [ ] Type 2 SPD：楼层/区域配电柜标配；$I_n\ge20$kA，$I_{max}\ge40$kA（8/20μs）
- [ ] Type 3 SPD：末端敏感设备（IT/医疗/控制）近距离安装
- [ ] $U_p \le 0.8\,U_w$（设备耐压裕度）
- [ ] 级间退耦距离：Type 1→Type 2 ≥10m；Type 2→Type 3 ≥5m（线缆电气距离）
- [ ] 距离不足时：退耦电感或触发型 SPD
- [ ] 前端保护：专用 SPD 后备熔断器，校验 $I_n$ 下不跳+雷电不熔+短路速动
- [ ] 接线：V 型接线（减少残压）；SPD 接线长度 ≤0.5m
- [ ] 接地：SPD 接地端子与等电位母排短直连接（阻抗最小）
- [ ] 状态指示：失效指示（机械/远程遥信），纳入监测系统

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| Type 1 用于无避雷装置建筑 | 浪费（无直击雷风险） | 按防护区选择 Type 级别 | GB 50057 |
| $U_p > U_w$ | 设备绝缘击穿 | 选低 $U_p$ SPD 或加级 | GB 50057 |
| 级间无退耦距离 | 后级承压过大失效 | 保证 ≥10m 或退耦电感 | GB 51348 |
| 前端 MC 选型不当 | 雷电流熔断或短路不跳 | 专用 SPD 后备熔断器 | GB/T 18802 |
| SPD 接线过长 | 残压叠加超标 | V 型接线+ ≤0.5m | GB 51348 |
| SPD 失效无指示 | 过压无保护 | 状态指示+遥信+定期巡检 | GB/T 18802 |
| N-PE 间漏装 SPD | 雷电共模过电压未限 | N-PE 配 Type 1/2 SPD | GB 50057 |

## 7. 完整算例（综合楼三级 SPD 配置）

### 7.1 背景

综合楼（二类防雷），有避雷带+架空进线改电缆引入。变压器 1600kVA，10kV/0.4kV。IT 机房 2 层。

### 7.2 第一级（总进线配电柜，LPZ 0→1）

- 直击雷风险（架空引入段）→ 选 Type 1 SPD
- $I_{imp}=12.5$kA（10/350μs），$U_p\le2.5$kV
- 前端保护：专用 SPD 后备熔断器（100A gG）
- N-PE 间配 Type 1 SPD（3+1 模式）

### 7.3 第二级（楼层配电箱，LPZ 1→2）

- Type 2 SPD：$I_n=20$kA，$I_{max}=40$kA（8/20μs），$U_p\le1.5$kV
- 与第一级电气距离 30m（满足退耦 ≥10m）
- 前端保护：MCB C32（校验 8/20μs 20kA 不熔）

### 7.4 第三级（IT 机房 PDU，LPZ 2→3）

- Type 3 SPD 或精细 Type 2：$U_p\le1.0$kV
- 与第二级电气距离 15m（满足退耦 ≥5m）
- IT 设备 $U_w=1.5$kV → $U_p=1.0 \le 0.8\times1.5=1.2$ ✓

### 7.5 校核汇总

| 级别 | SPD 类型 | $U_p$ (kV) | 设备 $U_w$ (kV) | $U_p\le0.8 U_w$ | 退耦距离 |
|---|---|---|---|---|---|
| 第一级 | Type 1 | 2.5 | 4.0（配电） | ✓ | — |
| 第二级 | Type 2 | 1.5 | 4.0（楼层） | ✓ | 30m ≥10m ✓ |
| 第三级 | Type 3 | 1.0 | 1.5（IT） | ✓ | 15m ≥5m ✓ |
