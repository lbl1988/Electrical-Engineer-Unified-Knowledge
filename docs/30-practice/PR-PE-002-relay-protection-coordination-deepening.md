# 继电保护整定配合深化（阶梯时限/零序方向/距离保护与重合闸配合）

## 1. 摘要

保护整定配合＝**阶梯时限配合 → 灵敏度校验 → 上下级选择性 → 动态校核（重合闸/故障转换）→ 失效边界分析**五步。本条深化 [PR-PE-001](PR-PE-001-relay-protection-config.md) 的基础配置，给出三段式电流/距离保护的 $\Delta t$ 阶梯配合、零序方向过流灵敏系数 $K_{sen}$ 校验、单相重合闸与保护配合的时序图、DG 接入后保护适应性调整；算例衔接 [CALC-PT-001](../40-calc/CALC-PT-001-protection-setting.md) 与 [CALC-SC-002](../40-calc/CALC-SC-002-hv-short-circuit-iec60909.md)。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 阶梯时限 $\Delta t$ | 上下级保护时间级差（0.3~0.5s） | DL/T 553 |
| 三段式电流保护 | 瞬时/限时电流速断/定时限过流三段 | DL/T 553 |
| 距离保护 | 阻抗继电器，按线路阻抗整定 | GB/T 14285 |
| 零序方向过流 | 接地短路保护（方向元件消除死区） | GB/T 14285 |
| 灵敏系数 $K_{sen}$ | 最小故障电流与整定值之比（≥1.3~1.5） | DL/T 553 |
| 重合闸 ARC | 自动重合闸装置（三相/单相/综合） | GB/T 14285 |

## 3. 原理与公式

### 3.1 阶梯时限配合

上下级保护时间级差：

$$\Delta t = t_{上级} - t_{下级} \ge 0.3\,\text{s}$$

时间级差组成：

$$\Delta t = t_{断路器} + t_{继电器误差} + t{裕度} = 0.06 + 0.10 + 0.14 = 0.30\,\text{s}$$

| 断路器分闸时间 | 继电器误差 | 裕度 | $\Delta t$ |
|---|---|---|---|
| 40 ms（GIS） | 50 ms | 110 ms | 0.20 s（紧凑级） |
| 60 ms（常规） | 100 ms | 140 ms | 0.30 s（标准） |
| 80 ms（老旧） | 150 ms | 170 ms | 0.40 s（保守） |

### 3.2 三段式电流保护整定

| 段别 | 整定原则 | 公式 | 时限 |
|---|---|---|---|
| I 段（瞬时速断） | 躲本线路末端短路 | $I_{set}^I = K_{rel}\,I_{k,max}^{末端}$ | 0~0.1s |
| II 段（限时速断） | 与下级 I 段配合 | $I_{set}^{II} = K_{rel}\,I_{k,max}^{下级末端}$ | $\Delta t$ |
| III 段（定时限过流） | 躲最大负荷+自启动 | $I_{set}^{III} = K_{rel}\,K_{ss}\,I_{load,max}/K_r$ | $\ge\Delta t$ |

$K_{rel}$ 可靠系数（1.2~1.3），$K_{ss}$ 自启动系数（1.5~3），$K_r$ 返回系数（0.85~0.95）。

### 3.3 灵敏系数校验

$$K_{sen} = \frac{I_{k,min}}{I_{set}}$$

| 保护段 | $K_{sen}$ 要求 | 备注 |
|---|---|---|
| I 段（速断） | 不要求（保护区 15~85%） | 短线路可能无保护区 |
| II 段（限时速断） | $\ge1.3\sim1.5$ | 末端短路最小电流 |
| III 段（过流） | $\ge1.5$（近后备）/ $\ge1.2$（远后备） | 长线路末端 |

### 3.4 距离保护整定

| 段别 | 阻抗整定 | 保护范围 | 时限 |
|---|---|---|---|
| I 段 | $Z_{set}^I = 0.85\,Z_{line}$ | 本线路 85% | 0s |
| II 段 | $Z_{set}^{II} = 0.8(Z_{line}+0.85\,Z_{下级})$ | 本线全+下级末端 | $\Delta t$ |
| III 段 | 躲最小负荷阻抗 $Z_{load,min}$ | 远后备 | $\ge2\Delta t$ |

### 3.5 重合闸与保护配合

| 故障类型 | 重合闸方式 | 保护配合 | 时序 |
|---|---|---|---|
| 单相接地 | 单相 ARC | 选相跳单相→无电间隔→重合 | 0.8~1.0s |
| 相间短路 | 三相 ARC | 三相跳闸→无电间隔→三相重合 | 0.3~0.5s |
| 永久故障 | 后加速跳闸 | 重合后速动跳闸（不延时速断） | $<0.1$s |

## 5. 设计/选型要点（校审清单）

- [ ] $\Delta t$ 按断路器/继电器/裕度选取，常规 0.3s，GIS 可取 0.2s
- [ ] I 段保护区校核：$15\%\sim85\%$ 线路长度（短线路 I 段可能无保护区，退 II 段）
- [ ] II 段灵敏度 $K_{sen}\ge1.3$，不满足时延伸至下级 II 段配合（时限增加）
- [ ] III 段躲负荷+自启动：$K_{ss}=1.5$（一般）/ $2\sim3$（电动机集中）
- [ ] 零序方向过流：方向元件消除死区（中性点直接接地系统必须）
- [ ] 距离保护：短线用全阻抗继电器，长线用方向/四边形特性
- [ ] CT 选配：保护级 10P10/5P30（短路倍数≥最大短路电流/额定）
- [ ] 重合闸：架空线必配，电缆线路不配（永久故障概率高）
- [ ] DG 接入：双向潮流下保护需加方向元件，重合闸需检无压/同期
- [ ] 保护联调：CT 极性/方向元件动作区/重合闸逻辑现场校验

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| $\Delta t$ 过小 | 选择性失效 | 常规 0.3s，GIS 可 0.2s | DL/T 553 |
| I 段整定不躲末端 | 误动下级 | $I_{set}^I \ge K_{rel}\,I_{k,max}^{末端}$ | DL/T 553 |
| III 段未计自启动 | 负荷恢复时误动 | $K_{ss}=1.5\sim3$ | DL/T 553 |
| CT 选型短路倍数不足 | 饱和致保护拒动 | 10P10/5P30 校验 | DL/T 5222 |
| 重合闸与保护无配合 | 永久故障重合后慢跳 | 后加速跳闸 | GB/T 14285 |
| DG 双向潮流保护无方向 | 误动/拒动 | 加方向元件+检无压重合闸 | TH-030 |
| 距离保护弧光电阻 | 阻抗测量偏大 | 四边形特性+电抗分量整定 | GB/T 14285 |

## 7. 完整算例（10kV 馈线三段式保护整定）

### 7.1 已知

10kV 架空馈线 $L=8$km，$Z_1=0.4$Ω/km，最大负荷 $I_{load,max}=300$A，自启动系数 $K_{ss}=1.8$。末端三相短路 $I_{k,max}^{末端}=3500$A（大方式），最小两相短路 $I_{k,min}^{末端}=1800$A。

### 7.2 I 段整定

$$I_{set}^I = 1.3 \times 3500 = 4550\,\text{A}$$

保护区：$l_{protect} = \frac{U_N/\sqrt3 - I_{set}^I \times Z_1\times l}{I_{set}^I \times Z_1} \approx \frac{10000/\sqrt3 - 4550\times0.4\times8}{4550\times0.4} \approx 20\%$（满足 ≥15%）

### 7.3 II 段整定

与下级 I 段配合：$I_{set}^{II} = 1.1 \times I_{set,下级}^I = 1.1\times 3500 = 3850$A

时限 $t^{II} = 0.3+0.1 = 0.4$s

灵敏度：$K_{sen} = I_{k,min}^{末端}/I_{set}^{II} = 1800/3850 = 0.47 < 1.3$ → **不满足**，延伸至下级 II 段配合，时限 $t^{II} = 0.7$s

### 7.4 III 段整定

$$I_{set}^{III} = \frac{1.2\times1.8\times300}{0.85} = 762\,\text{A}$$

时限 $t^{III} = 1.0$s

近后备灵敏度：$K_{sen} = 1800/762 = 2.4 > 1.5$ ✓

### 7.5 重合闸

架空线配三相 ARC，无电间隔 0.5s，后加速跳闸。
