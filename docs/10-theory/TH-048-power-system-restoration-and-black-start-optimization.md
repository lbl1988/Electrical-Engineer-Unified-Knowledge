# 电力系统恢复控制与黑启动优化

## 1. 定义

黑启动（Black Start）是电力系统**全停或部分停电后**，利用**自启动电源**（Black Start Resource, BSR）在无外部电源支撑下，逐步恢复供电的过程。黑启动是电力系统自愈能力的终极考验，其目标是**以最小代价、最快速度恢复最大范围的供电**。

| 阶段 | 时长 | 核心任务 | 关键约束 |
|---|---|---|---|
| **黑启动阶段** | 0~30 min | BSR 自启动 → 建立第一个稳定电压源 → 恢复关键负荷 | 自启动能力（无辅机电源）、空载线路/变压器零起升压过电压 |
| **网架重构阶段** | 30 min ~ 4 h | 恢复主干网架 → 分区并列 → 恢复区域变电站 | 过电压限制、继电保护配合、稳定裕度 |
| **负荷恢复阶段** | 4~24 h | 恢复重要用户 → 逐步恢复一般负荷 → 全系统恢复 | 负荷恢复速率（≤ 5%/10 min）、频率稳定（RoCoF 约束） |
| **正常运行阶段** | 24 h+ | 系统重新调度、潮流调整、稳定裕度恢复 | 经济调度、辅助服务恢复 |

**关键概念**：

| 概念 | 定义 | 工程意义 |
|---|---|---|
| **黑启动电源（BSR）** | 具备自启动能力的电源，无需外部辅助电源即可启动 | 燃机/水轮发电机（快速自启动）、构网型储能 |
| **恢复路径** | 从 BSR 到目标变电站的带电顺序 | 优化恢复时间、减少过电压 |
| **分区恢复** | 大系统停电后按区域并行恢复再并网 | 缩短总恢复时间 |
| **过载预警** | 恢复过程中避免过载/电压越限 | 热稳定、暂态稳定约束 |

## 2. 物理图像

黑启动的关键物理约束——**自启动能力与零起升压过电压**：

```
BSR 自启动能力
├── 燃气轮机：辅机由蓄电池/柴油发电机供电，10~30 min 启动
├── 水轮发电机：自启动，5~15 min 启动（抽水蓄能可反向发电）
├── 构网型储能（电化学/飞轮/超导）：秒级启动，但容量有限（MW 级）
└── 火力发电机组：无法自启动（依赖厂用辅机），不是 BSR

零起升压过电压风险（恢复路径带电时）
├── 空载变压器合闸：可能产生 2~4 p.u. 操作过电压（见 TH-013 开关电弧）
├── 空载长线合闸：工频过电压可达 1.3~1.8 p.u.（见 TH-022 过电压机理）
└── 抑制措施：合闸电阻/选相合闸/逐步升压
```

恢复过程的时间尺度（以 500 kV 省级电网为例）：

```
0 min     │ 系统全停（全部机组脱网，电压=0）
          │
5 min     │ BSR 自启动完成（典型：燃机/水轮机组）
10 min    │ BSR 厂用电恢复
15 min    │ 从 BSR 对附近变电站零起升压（抑制过电压）
          │
20 min    │ 恢复第一个 500 kV 变电站（分区起点）
30 min    │ 建立第一个稳定电压源，开始分区恢复
          │
30~120 min│ 分区并行恢复网架（每个分区独立操作）
120 min   │ 分区完成，开始跨区并列（同期校核）
          │
120~480 min│ 重要负荷恢复（医院、数据中心、交通枢纽、政府机关）
480 min   │ 一般负荷逐步恢复（住宅、商业、工业）
          │
24 h+     │ 全系统恢复，转入正常调度
```

## 3. 推导

### 3.1 黑启动恢复路径优化

黑启动的数学模型可形式化为**最短路径 + 多约束**问题：

$$\min \quad T_{\mathrm{total}} = \sum_{k=1}^{N} t_k$$

其中 $t_k$ 是第 $k$ 步操作耗时（启动、合闸、升压等）。

约束：
1. **过电压约束**：每步操作后 $U_{\max} \leq 1.3$ p.u.
2. **频率约束**：黑启动初期 $f \pm 0.5$ Hz 范围
3. **热稳定约束**：恢复负荷不超过线路/变压器额定容量
4. **保护配合**：恢复路径上的保护定值不被触发
5. **自启动约束**：只有 BSR 可作为起点

### 3.2 零起升压过电压计算

空载变压器零起升压时的操作过电压倍数：

$$\frac{U_{\mathrm{over}}}{U_{\mathrm{rated}}} \approx 2 \cdot \frac{X_{\mathrm{open}}}{X_{\mathrm{close}}}$$

其中 $X_{\mathrm{open}} = X_d$（开路电抗，约 1.0~2.0 p.u.），$X_{\mathrm{close}} = X_d'$（短路电抗，约 0.1~0.3 p.u.），倍数约 6~20 倍——这显然超过了绝缘水平（2.5~3.0 p.u.）。

**工程抑制**：
- 合闸前先合并联电阻（$R \approx 100~500\ \Omega$）降低倍数至 2~3 p.u.
- 选相合闸：在电压过零点附近合闸，避免直流分量叠加
- 逐步升压：从 25% → 50% → 75% → 100%，每级稳定 3~5 min

### 3.3 恢复时序优化：启发式算法

实用的恢复时序优化采用**贪心 + 约束检查 + 回溯**：

```
1. 从 BSR 开始，按距离最近原则选择第一个目标变电站
2. 带电路径（考虑过电压抑制措施）
3. 检查约束：过电压 ✓  → 继续；✗ → 加抑制措施或换路径
4. 每完成一个节点带电，记录已恢复集合
5. 重复 1~4 直到所有关键负荷恢复
6. 冲突（如分区间潮流反转）→ 回溯到上一步换路径
```

### 3.4 电力电子化系统的黑启动特殊性

高比例电力电子电源（跟网型为主）的黑启动面临**无稳定电压源**问题：

| 阶段 | 传统同步机系统 | 电力电子化系统 |
|---|---|---|
| 电压源 | 同步发电机天然构网 | 跟网型 PCS 依赖电网电压，必须有**至少一台构网型 PCS** 或同步机 |
| 频率 | 同步机转子天然稳定 | 需构网型 PCS 提供频率支撑 |
| 黑启动电源 | 燃机/水轮/抽水蓄能 | 构网型储能（电池/飞轮）/微型燃机 |
| 恢复速度 | 分钟级启动 | 储能 PCS 秒级启动，但容量有限需逐步扩展 |

**构网型 PCS 作为黑启动电源的关键**：必须具备**独立电压/频率控制**（无 PLL 依赖）和**自启动能力**（无源预充电或小电源辅助）。

### 4.2 失效边界

| 边界条件 | 后果 | 工程速记 |
|---|---|---|
| 系统全停后无 BSR（全部机组失去自启动能力） | 陷入黑启动"死锁"，只能靠外部电网送电恢复 | 保证**至少 5% 装机容量**为 BSR（燃机/构网储能） |
| 恢复路径过电压未抑制 | 变压器/避雷器损坏，反而扩大故障 | 恢复路径必须选相合闸 + 逐步升压 |
| 电力电子化系统全停且跟网型占比 100% | 无稳定电压源，无法自启动 | 强制要求**至少一台构网型设备**（同步机/PCS）作为 BSR |
| 恢复负荷速率过快（> 5%/10 min） | 频率失稳（RoCoF 超限） | 严格控制恢复节奏 |

### 4.3 工程速记

> **黑启动三要素**：BSR + 恢复路径 + 时序。电力电子化系统额外需要**构网型设备**作为第一电压源。负荷恢复速率不超过 5%/10 min。
