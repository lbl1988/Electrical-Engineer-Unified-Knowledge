# 主动配电网故障定位与隔离

## 1. 定义

主动配电网（Active Distribution Network, ADN）是指**接有分布式电源（DG）和可控负荷**的配电网。传统配电网是**单电源、辐射状**，短路电流始终从主电源流向故障点；接入 DG 后，短路电流可以从**两个方向**流动，传统保护（过流）可能**拒动或误动**，故障定位和隔离也从一维搜索变成二维。

| 特征 | 传统配电网 | 主动配电网（ADN） |
|---|---|---|
| 短路电流方向 | 单向（主电源→故障点） | 双向（主电源 + DG → 故障点） |
| 故障定位 | 过流 + 时间级差 | 需要方向元件 + 多源融合 |
| 故障隔离 | 单段开关动作 | 可能需要 DG 先脱网 |
| 恢复 | 单侧供电恢复 | 可重构网络拓扑，恢复更多负荷 |

## 2. 物理图像

DG 接入后短路电流方向的三种典型场景：

```
场景 A：DG 在故障点上游（传统单向）
    │
    │  主电源 ───── 断路器 ───── DG ───── 故障点
    │  I_gen →      I_DG →        I_fault = I_gen + I_DG（增大）
    │
    │  断路器正确动作：过流 + 方向（正向）

场景 B：DG 在故障点下游（反方向！）
    │
    │  主电源 ───── 故障点 ───── DG
    │  I_gen →      ← I_DG
    │
    │  主侧断路器：I_gen 可能不够（DG 电流不经过它）→ 拒动！
    │  母线保护或 DG 逆功率保护应先动作

场景 C：DG 多电源辐射状
    │
    │  主电源 ─┬──── 故障点
    │           └──── DG1
    │  DG2 ────┘
    │
    │  故障点电流 = I_gen + I_DG1 + I_DG2（最大）
    │  多个断路器可能同时检测到过流，需要方向元件区分
```

## 3. 推导

### 3.1 配电网故障电流计算（含 DG）

故障点短路电流的通用公式：

$$\mathbf{I}_{\text{fault}} = \mathbf{Z}_{\text{total}}^{-1} \mathbf{U}_{\text{pre-fault}}$$

其中：
- $\mathbf{Z}_{\text{total}} = \mathbf{Z}_{\text{gen}} + \mathbf{Z}_{\text{DG,1}} + \cdots + \mathbf{Z}_{\text{DG,N}} + \mathbf{Z}_{\text{line}}$ 是各电源到故障点的等值阻抗并联
- $\mathbf{U}_{\text{pre-fault}}$ 是故障前各电源的端电压

**与传统配电网的核心差异**：$\mathbf{Z}_{\text{DG},i}$ 不可忽略（DG 容量可达主电源的 30~50%），必须纳入计算。

### 3.2 保护配置与整定

| 保护 | 传统整定 | ADN 整定修正 |
|---|---|---|
| **过流保护** | 按最大负荷 + 可靠系数整定 | 必须加**方向元件**（判别电流方向），且短路电流需考虑 DG 贡献 |
| **距离保护** | 配电网通常不用 | 现在需要：DG 贡献的短路电流会改变距离保护测量阻抗 |
| **逆功率保护** | 传统配电网无 | DG 接入后新增：检测功率反向（场景 B），先切断 DG |
| **母线保护** | 传统配电网通常不用 | DG 接入的母线段需要配置母线差动 |
| **孤岛检测** | 传统配电网无 | DG 必须配置反孤岛保护（见 TH-030） |

### 3.3 故障定位方法

#### 3.3.1 行波法（波头到达时间差）

故障产生的暂态行波沿线路传播：

$$t_i = t_0 + \frac{d_i}{v}$$

其中 $v \approx 200 \sim 300$ m/μs（电缆）或 $250 \sim 280$ m/μs（架空线）。

**双端行波**：两个测量点 $A, B$ 的波头到达时间差：

$$d_{\text{fault}} = \frac{L_{AB}}{2} - \frac{v \Delta t_{AB}}{2}$$

精度可达 ±10 m，适用于 ADN。

#### 3.3.2 阻抗法（传统但需修正）

基于故障稳态阻抗计算故障点：

$$Z_{\text{measured}} = Z_{\text{line}} \cdot d + Z_{\text{fault}}$$

**ADN 修正**：需要减去 DG 贡献的电流分量，用**对称分量法**分离：

$$I_{\text{gen}} = I_{\text{measured}} - \sum I_{\text{DG},j}$$

#### 3.3.3 多源融合定位（AI）

同时采集主电源和所有 DG 的电压电流，输入**神经网络/粒子滤波**模型，融合估计故障位置——在复杂配电网（含分支、DG 多源）下精度最高。

### 3.4 故障隔离与恢复策略

ADN 故障隔离策略（按优先级）：

```
1. 切断所有 DG（防孤岛保护自动动作，< 100 ms）
   │
2. 故障定位（行波法/多源融合，< 500 ms）
   │
3. 隔离故障段（跳开故障段两端开关）
   │
4. 网络重构（闭合联络开关，恢复非故障段供电）
   │   关键：DG 全部切断后，重构配电网回到辐射状
   │   然后逐个重新合闸 DG（需校验短路电流不越限）
   │
5. 恢复完成（< 5 min 非故障段，< 30 min 含 DG）
```

### 4.2 失效边界

| 边界条件 | 后果 | 工程速记 |
|---|---|---|
| DG 容量 > 馈线额定 50% 且无方向保护 | 故障时保护拒动/误动 | DG 比例 > 30% 必须配方向过流 |
| 反孤岛保护故障 | DG 继续向故障点供电 → 维修人员触电 | 孤岛检测必须双判据（被动 + 主动） |
| 故障定位误差 > 500 m | 隔离开关选错段 → 扩大停电范围 | 多源融合定位精度 < 100 m |

### 4.3 工程速记

> **ADN 保护三要点**：加方向、减 DG 贡献、先切 DG 再隔离。DG 接入比超过 30% 必须全面改造保护。
