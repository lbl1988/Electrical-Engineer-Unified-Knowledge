# SF₆ 气体分解产物诊断与环保替代

## 1. 定义

六氟化硫（SF₆）是目前高压电气设备（断路器、GIS、气体绝缘变压器）的**主流绝缘和灭弧介质**，具有极强的绝缘强度（约空气 2.5 倍）和优异的灭弧性能。但 SF₆ 有两个问题：

| 问题 | 数据 | 影响 |
|---|---|---|
| **温室效应（GWP）** | SF₆ 的 GWP = 22800（CO₂ 为 1） | 气候公约要求减排，2035 年前后面临禁限 |
| **分解产物毒性** | 放电/过热后产生 HF、SO₂、SOF₂、SO₂F₂、S₂F₁₀ 等 | 运行人员安全风险 + 设备内部故障诊断信号 |

SF₆ 分解产物的**定性定量分析**是设备内部故障诊断的关键技术——**分解产物的种类和浓度直接对应故障类型（局部放电/过热/电弧）**。

## 2. 物理图像

SF₆ 分解的三类反应与对应故障：

```
SF₆ 分解的三种触发机制
    │
    ├── 局部放电（PD，低能量）
    │   SF₆ + e⁻ → SFₓ（x=1~5）+ F·
    │   F· + H₂O → HF（氢氟酸，有毒）
    │   SF₂ + O₂ → SO₂F₂（二氟二氧化硫）
    │
    │   主要产物：SO₂F₂、SOF₂、HF、CF₄
    │   特征：SF₄/SO₂F₂ 比值 ≈ 0.5~2.0
    │   故障类型：绝缘体表面放电、针尖放电
    │
    ├── 过热（> 150°C，中能量）
    │   SF₆ + 金属（Cu/Al） → 金属氟化物 + S₂F₁₀
    │   S₂F₁₀ 在 > 300°C 分解为 SF₄ + SF₆
    │   SO₂ + F₂ → SOF₂、SO₂F₂
    │
    │   主要产物：SOF₂、SO₂、CO₂（来自绝缘纸）
    │   特征：SOF₂ >> SO₂F₂
    │   故障类型：接触不良过热、线圈匝间短路
    │
    └── 电弧（> 3000°C，高能量）
        SF₆ 直接电离为 SFₓ + F·，与电极材料（Cu/Al/W）反应
        W + 6F → WF₆（六氟化钨，剧毒，剧毒！）
        Cu + 2F → CuF₂
        C + 4F → CF₄
        O₂ + SF₄ → SO₂ + F₂
        │
        主要产物：SO₂、SOF₂、CO₂、CF₄、WF₆
        特征：SO₂ 浓度远高于 PD 场景
        故障类型：断路器开断、极间短路、触头熔焊
```

**关键诊断原则**：不同能量等级的故障产生的分解产物谱**有显著差异**，可通过色谱分析 + 比值法定位故障。

## 3. 推导

### 3.1 分解产物与故障类型的定量关系

| 故障类型 | 主导产物 | 特征比值 | 浓度阈值 |
|---|---|---|---|
| 局部放电（PD） | SO₂F₂, SOF₂, HF | $c(\mathrm{SO_2F_2})/c(\mathrm{SOF_2}) \approx 0.5\sim2$ | SO₂F₂ > 0.1 μL/L 告警 |
| 过热（150~300°C） | SOF₂, SO₂, CO₂ | $c(\mathrm{SOF_2})/c(\mathrm{SO_2}) > 10$ | SOF₂ > 1 μL/L 告警 |
| 电弧（> 3000°C） | SO₂, SOF₂, CO₂, WF₆ | $c(\mathrm{SO_2}) \gg c(\mathrm{SOF_2})$ | SO₂ > 5 μL/L 告警 |
| 固体绝缘分解 | CF₄, C₂F₆, CO | $c(\mathrm{CF_4}) > 1$ μL/L | 确认绝缘材料烧蚀 |

### 3.2 检测技术

| 方法 | 原理 | 检测下限 | 适用 |
|---|---|---|---|
| **气相色谱（GC）** | 气体组分分离保留时间 + FPD/ECD 检测器 | μL/L 级 | 实验室/车载检测 |
| **红外光谱（IR）** | 特征吸收峰（SO₂ = 4.0 μm，SO₂F₂ = 6.0 μm） | 数十 μL/L | 在线监测 |
| **光声光谱（PAS）** | 气体吸收光能→热膨胀→声波检测 | nL/L 级 | 高灵敏度在线 |
| **质谱（MS）** | 分子离子峰 | 超痕量 | 研究/疑难故障 |

### 3.3 环保绝缘气体替代

CIGRE 和 IEC 推动的 SF₆ 替代研究，主要候选：

| 气体 | 绝缘强度（相对 SF₆） | GWP | 状态 |
|---|---|---|---|
| **空气/CO₂ + 微正压** | 0.4~0.6 | ~1 | 已应用（中压） |
| **C₄F₇N + N₂（20%/80%）** | 0.85~0.95 | 约 2000 | 工程试点（ABB 36 kV 已商用） |
| **C₅F₁₀O + N₂** | 0.80~0.90 | < 1 | 中压已商用，高压试点 |
| **CF₃I** | 1.1 | < 5 | 灭弧好，毒性存疑 |
| **真空** | — | — | 真空断路器（中压已替代大部分 SF₆） |

**挑战**：替代气体绝缘强度低于 SF₆，需要**更高气压（1.2~1.6 MPa vs SF₆ 0.4~0.7 MPa）**，或**缩小间隙（电场优化）**，对设备设计提出新约束。

## 4. 与工程实践的联系

### 4.1 应用场景

| 应用 | 依赖条目 | 标准依据 |
|---|---|---|

| 环保气体替代设计 | TH-013（电弧/灭弧）、PR-DD-002（高压设备选型） | GB/T 18867-2012 |

### 4.2 失效边界

| 边界条件 | 后果 | 工程速记 |
|---|---|---|
| 分解产物浓度低但持续增长 | 慢性故障漏检 | 趋势比绝对值更重要，每周/每月跟踪 |
| SF₆ 气体泄漏导致气压降低 | 绝缘强度与气压近似线性下降，0.7 倍气压→0.85 倍绝缘强度 | GIS 配置气压在线监测，低于 90% 额定即补气 |
| 替代气体 C₄F₇N 水分含量高 | 水解产生 HF，腐蚀设备 | 水分含量 < 50 ppm（摩尔比） |

### 4.3 工程速记

> **分解产物看比值**：PD → SO₂F₂/SOF₂ ≈ 0.5~2；过热 → SOF₂/SO₂ > 10；电弧 → SO₂ >> SOF₂。在线监测 + 色谱定标 + 趋势跟踪。
