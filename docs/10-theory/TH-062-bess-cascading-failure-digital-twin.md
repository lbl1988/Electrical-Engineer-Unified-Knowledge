# 电化学储能系统级联故障数字孪生建模

## 1. 定义

储能系统级联故障数字孪生是**通过多物理场耦合模型（电-热-力-化学）实时映射电化学储能舱状态**，在单体热失控触发后**预测热蔓延传播路径与时间**，并**协同消防系统决策**的前沿技术。它是 [TH-055 级联故障与热蔓延动力学](TH-055-cascading-failure-and-thermal-propagation.md) 的工程化延伸：TH-055 给出**机理模型**，本条给出**数字孪生实现**。

| 模型层级 | 物理尺度 | 数学方法 | 计算实时性 | 应用场景 |
|---|---|---|---|---|
| **电芯级** | 单体（10~50 cm） | 等效电路 + SEI 分解动力学 | 毫秒级 | 单体热失控早期预警 |
| **模组级** | 模组（0.5~2 m） | 热网络 + CFD 简化 | 秒级 | 模组内蔓延预测 |
| **簇级** | 簇（2~10 m） | CFD + 辐射 + 气流 | 十秒级 | 簇间传播与消防决策 |
| **舱级** | 舱（10~30 m） | 多区域模型 + 风险评估 | 分钟级 | 全舱消防联动 |

**核心价值**：传统 BMS 只能告警已发生的热失控，**数字孪生能预测未来 5~30 分钟内的级联传播路径**，为消防介入提供决策窗口（详见 [TH-055](TH-055-cascading-failure-and-thermal-propagation.md)）。

## 2. 物理图像

数字孪生系统的"物理-数字-决策"三层闭环：

```
┌─────────────────────────────────────────────────────────┐
│  物理层（储能舱 + BMS + 消防系统）                      │
│  · 电芯温度 T_cell、电压 V、电流 I、SOC、压力 P         │
│  · 气体浓度（H₂、CO、VOCs）                            │
│  · 消防介质存量（七氟丙烷/全氟己酮/水喷雾）            │
└──────────┬──────────────────────────────────────────────┘
           │ 实时数据采集（BMS + 气体传感器 + 视觉）
           ↓
┌─────────────────────────────────────────────────────────┐
│  数字孪生层（多物理场耦合模型）                         │
│  ┌──────────────────────────────────────────────────┐   │
│  │ 电学模型：等效电路 + 极化电阻 R_pol(SOC,T)       │   │
│  │ 热学模型：C_thermal · dT/dt = Q_gen - Q_diss   │   │
│  │   Q_gen = I²R + Q_side_react (SEI 分解)          │   │
│  │ 力学模型：膨胀力 F = k_cell · ΔV (电芯膨胀)      │   │
│  │ 化学模型：r = A·exp(-E_a/RT) (Arrhenius, 副反应) │   │
│  └──────────────────────────────────────────────────┘   │
│  · 状态预测：未来 5~30 min 内的温度场与传播路径       │
│  · 参数辨识：基于实测数据递推更新模型参数              │
└──────────┬──────────────────────────────────────────────┘
           │ 预测结果 + 决策建议
           ↓
┌─────────────────────────────────────────────────────────┐
│  决策层（消防协同 + 运维建议）                          │
│  · 触发消防：七氟丙烷/全氟己酮/水喷雾（GB/T 42288 §5） │
│  · 隔离故障簇：断开簇级直流断路器                      │
│  · 启动排烟：防止可燃气体积聚爆燃                      │
│  · 告警调度：通知运维 + 消防部门                       │
└─────────────────────────────────────────────────────────┘
```

## 3. 推导

### 3.1 电芯热模型（基础，详见 TH-046/TH-055）

电芯能量平衡：

$$m \cdot c_p \cdot \frac{dT}{dt} = \underbrace{I^2 R_{int}}_{\text{焦耳热}} + \underbrace{Q_{side}(T, SOC)}_{\text{副反应热}} - \underbrace{h \cdot A \cdot (T - T_{amb})}_{\text{对流散热}}$$

其中 $Q_{side}$ 由 SEI 分解与正极析氧触发（详见 TH-046）：

$$Q_{side}(T) = m \cdot H_{rxn} \cdot A_0 \cdot \exp\left(-\frac{E_a}{R \cdot T}\right) \cdot (1 - \alpha)$$

| 参数 | 含义 | 典型值（三元锂电） |
|---|---|---|
| $m$ | 电芯质量 | 1.5 kg（50 Ah） |
| $c_p$ | 比热 | 1040 J/(kg·K) |
| $R_{int}$ | 内阻 | 1.5 mΩ |
| $H_{rxn}$ | 反应焓 | 3.5×10⁵ J/kg |
| $A_0$ | 指前因子 | 1×10¹⁵ 1/s |
| $E_a$ | 活化能 | 1.35×10⁵ J/mol |
| $R$ | 气体常数 | 8.314 J/(mol·K) |
| $\alpha$ | 反应转化率 | 0~1 |

**热失控触发判据**：$dT/dt > 1$ °C/min（不可逆）或 $T > 90$ °C（SEI 分解起始）。

### 3.2 多物理场耦合矩阵

数字孪生模型涉及四种物理场耦合：

| 耦合方向 | 物理机制 | 数学表达 | 影响尺度 |
|---|---|---|---|
| 电 → 热 | 焦耳热 + 极化热 | $Q_{Joule} = I^2 R_{int}(T, SOC)$ | 单体内部 |
| 热 → 化 | 副反应加速（Arrhenius） | $r_{side}(T) = A_0 \exp(-E_a/RT)$ | 单体内部 |
| 热 → 力 | 电芯膨胀（气体产压） | $\Delta V = \int (V_{gas}(T) - V_0) dP$ | 单体→模组 |
| 热 → 热 | 相邻电芯传导 + 对流 | $Q_{cond} = k_{sheet} \cdot A \cdot \Delta T / d$ | 模组→簇 |
| 化 → 化 | 可燃气体扩散 | $\partial C/\partial t = D \nabla^2 C - v \cdot \nabla C$ | 簇→舱 |

**关键耦合点**：电芯内部"热-化"正反馈（产热加速反应，反应加速产热）是热失控的核心机理（详见 TH-046）；电芯间"热-热"传导是级联传播的主导路径（详见 TH-055）。

### 3.3 状态预测模型（LSTM + 物理信息）

数字孪生需在线预测未来 $N$ 步的温度场，采用 **LSTM 时序网络 + 物理信息约束**（详见 [TH-043](TH-043-ai-foundations-in-electrical-engineering.md)）：

$$\hat{T}_{t+1}, \ldots, \hat{T}_{t+N} = f_{LSTM}(T_{t-K:t}, I_{t-K:t}, SOC_{t-K:t})$$

**损失函数**（PINN）：

$$L = \underbrace{\sum_{i=1}^{N} \|\hat{T}_{t+i} - T_{t+i}^{meas}\|^2}_{L_{data}} + \lambda \cdot \underbrace{\left\|m c_p \frac{d\hat{T}}{dt} - Q_{Joule} - Q_{side} + Q_{diss}\right\|^2}_{L_{phys}}$$

其中 $L_{phys}$ 是热平衡方程残差，保证 LSTM 预测不违反物理规律。

### 3.4 级联传播预测（图神经网络 GNN）

簇级传播路径预测采用 **图神经网络**：

- **节点**：每个电芯（状态：温度、SOC、健康度）
- **边**：热传导路径（相邻、铜排、气流）
- **边权重**：$w_{i,j} = k_{ij} \cdot A_{ij} / d_{ij}$（热导率 × 接触面积 / 距离）

**GNN 预测**：

$$h_i^{(l+1)} = \sigma\left(W^{(l)} h_i^{(l)} + \sum_{j \in \mathcal{N}(i)} \frac{w_{ij}}{\sum_k w_{ik}} \cdot h_j^{(l)}\right)$$

**输出**：每个电芯的"热失控触发概率"$P_i(T > T_{onset} | t < t_{max})$，识别传播关键路径。

### 3.5 消防决策优化

基于预测结果，求解最优消防策略：

$$\min_{u_t} \sum_{t=0}^{T} \left[\alpha \cdot \text{damage}(T_t) + \beta \cdot \text{cost}(u_t)\right]$$

约束：
- $\text{介质存量} \leq$ 额定容量
- $\text{响应时间} \leq t_{max}$（NFPA 855 §4.6 规定 5 min）
- $\text{隔离时间} \leq 2$ min（断开故障簇）

**决策空间**：$u_t = [$ 释放七氟丙烷浓度, 启动水喷雾, 隔离簇号 $]$

## 5. 工程算例

### 算例：5 MWh 储能舱级联故障预测与消防协同

#### 已知条件

| 参数 | 值 | 说明 |
|---|---|---|
| 储能舱 | 5 MWh，1500 V | 10 簇 × 357 单体/簇 |
| 触发电芯 | 簇 3 第 50 号 | $T_{init} = 200$ °C（已热失控） |
| 传感器 | BMS + 气体 + 视觉 | 1 Hz 采样 |
| 消防介质 | 七氟丙烷 + 水喷雾 | 双重系统 |
| 数字孪生模型 | LSTM + GNN + PINN | 离线训练，在线推理 |

#### 工况：触发后 30 s 开始预测

##### 1. LSTM 温度场预测

预测簇 3 内 50 号电芯未来 5 分钟温度：

| 时间 | 实测 T | 预测 T | 误差 |
|---|---|---|---|
| t = 30 s | 210 °C | 215 °C | +5 °C |
| t = 60 s | 280 °C | 275 °C | -5 °C |
| t = 120 s | 450 °C | 440 °C | -10 °C |

##### 2. GNN 级联传播预测

预测未来 10 分钟内的级联传播路径：

| 时间 | 簇 3 内传播 | 簇间传播 |
|---|---|---|
| t = 60 s | 50 → 51 → 52 号（同模组） | - |
| t = 180 s | 50~55 号（模组内蔓延） | - |
| t = 300 s | 簇 3 全部 6 模组（60 单体） | 簇 3 → 簇 4（辐射 + 气流） |
| t = 600 s | 簇 3 + 簇 4 全部失控 | 簇 4 → 簇 5 |

##### 3. 消防决策优化

最优策略求解结果：

| 决策 | 时间 | 动作 |
|---|---|---|
| t = 35 s | 立即隔离簇 3 | 断开簇 3 直流断路器（详见 [CALC-SC-005](../40-calc/CALC-SC-005-dc-system-short-circuit.md)） |
| t = 60 s | 释放七氟丙烷 | 簇 3 区域浓度 7% vol（NFPA 855） |
| t = 90 s | 启动水喷雾 | 簇 4 冷却防护 |
| t = 120 s | 启动排烟 | 防止可燃气体积聚爆燃 |

##### 4. 改善效果对比

| 指标 | 无数字孪生 | 数字孪生 + 协同 | 改善 |
|---|---|---|---|
| 级联触发到消防介入 | 8 min（人工告警） | 35 s（孪生预测） | -93% |
| 失控簇数 | 5 簇 | 1 簇（仅簇 3） | -80% |
| 经济损失 | 5 MWh 全损（500 万元） | 0.5 MWh（50 万元） | -90% |
| 消防介质用量 | 全舱释放 | 定向 1 簇 | -70% |

## 6. 工程注意点

| 要点 | 说明 |
|---|---|
| **传感器覆盖度** | 数字孪生精度强依赖传感器密度，电芯级温度传感器覆盖率应 ≥ 30%（GB/T 42288 §5） |
| **模型参数辨识** | 电芯副反应参数（$A_0, E_a, H_{rxn}$）随循环老化变化，必须周期性辨识更新 |
| **CFD 实时性** | 簇级 CFD 全仿真计算量大，工程上采用**降阶模型**（ROM）或简化多区域模型 |
| **GNN 训练数据** | 级联故障实测数据稀缺，主要依赖 PSCAD/COMSOL 仿真数据，存在"训练-实测 gap" |
| **消防介质兼容性** | 七氟丙烷遇高温分解产生 HF（剧毒），舱内人员撤离必须 ≤ 60 s（NFPA 855） |
| **隔离断路器配合** | 簇级直流断路器分断能力必须满足最恶劣短路工况（详见 CALC-SC-005） |
| **数据安全与合规** | 储能舱数据涉及国家安全，数字孪生平台必须满足等保 2.0 + GB/T 22239 |
| **模型验证** | 数字孪生模型必须定期与实测对比，偏差 > 15% 时应重新训练（DL/T 2547 §5） |
