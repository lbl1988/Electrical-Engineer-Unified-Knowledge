# 柔性直流多端 MTDC 故障穿越与恢复

## 1. 定义

柔性直流多端系统（MTDC）由 **3 个及以上 VSC-HVDC 换流站** 通过直流输电线路互联组成，可实现**多能互补、广域功率调度、跨区输电**。MTDC 的核心挑战在于**直流故障**（尤其是极间短路和极对地短路）的穿越与恢复。

| 故障类型 | 位置 | 特征 | 穿越难度 |
|---|---|---|---|
| **极对地短路** | 单极对站内或线路 | 直流电压跌落至半值，另一极电压升高 | 中（可通过 MM C 子模块旁路实现穿越） |
| **极间短路** | 双极之间 | 直流电压为零，过电流巨大（可达额定 10~20 倍） | 高（必须直流断路器 DCCB 或限流电抗器） |
| **换流阀内部短路** | MMC 换流阀 | 子模块 IGBT 击穿，直流偏磁风险 | 高（需换流站停运检修） |
| **交流侧故障** | 换流站交流母线 | 换相失败（LCC）/功率中断（VSC） | 低（VSC 具备 LVRT/HVRT 能力） |

**MMC 的优势**：模块化多电平换流器（MMC）每个桥臂由数十至数百个子模块（SM）串联，可通过**子模块旁路**快速切断故障电流，是 MTDC 穿越的首选拓扑。

## 2. 物理图像

极间短路故障的演进过程与抑制手段：

```
t=0     │ 极间短路发生（直流侧金属性故障）
        │
t=1ms   │ 直流电容放电，电流快速上升 di/dt ≈ 10~20 kA/ms
        │ 换流阀 IGBT 过流保护动作
        │
        ├── 方案 A：MMC 子模块旁路穿越
        │   t=5ms  全部子模块切换为旁路模式
        │           换流阀呈低阻抗，故障电流被抑制
        │           交流侧继续运行（不脱网）
        │   t=100ms 故障检测确认 + 直流线路隔离（DCCB 或故障段切离）
        │   t=500ms 子模块重新投入，恢复功率传输
        │
        └── 方案 B：直流断路器 + 限流电抗器
            t=5ms  限流电抗器感应电动势抑制 di/dt
            t=10ms DCCB 电流过零点附近分断
            t=100ms 故障段切离，非故障段恢复
```

## 3. 推导

### 3.1 直流故障电流数学模型

极间短路后，故障电流由三部分组成：

$$i_{\mathrm{fault}}(t) = \underbrace{\frac{U_{\mathrm{dc0}}}{R_{\mathrm{dc}}} \left(1 - e^{-tR_{\mathrm{dc}}/L_{\mathrm{dc}}}\right)}_{\text{电容放电分量}} + \underbrace{\frac{U_{\mathrm{sm}}}{Z_{\mathrm{ac}}} \sin(\omega t + \phi)}_{\text{交流侧馈入分量}} + \underbrace{i_{\mathrm{dc,pre}} e^{-t/\tau}}_{\text{预故障直流分量}}$$

其中：
- $U_{\mathrm{dc0}}$ = 故障前直流电压（典型 ±400~±800 kV）
- $R_{\mathrm{dc}}, L_{\mathrm{dc}}$ = 直流侧等效电阻和电感
- $U_{\mathrm{sm}}, Z_{\mathrm{ac}}$ = 交流侧电源幅值和等值阻抗
- $i_{\mathrm{dc,pre}}$ = 故障前直流电流

**初始电流上升率**（关键设计指标）：

$$\frac{di}{dt}\bigg|_{t=0} = \frac{U_{\mathrm{dc0}}}{L_{\mathrm{dc}} + L_{\mathrm{DCL}}}$$

其中 $L_{\mathrm{DCL}}$ = 限流电抗器电感（典型 100~300 mH），设计时需使初始 $di/dt$ 低于 DCCB 分断能力（< 10 kA/ms）。

### 3.2 MMC 子模块旁路穿越原理

MMC 桥臂由 $N$ 个子模块串联，每个子模块有两种工作状态：

| 状态 | 电路 | 电压贡献 |
|---|---|---|
| **插入（Inserted）** | IGBT 关断，电容接入 | $+U_c$ 或 $-U_c$ |
| **旁路（Bypassed）** | 旁路晶闸管导通 | 0 |

极间短路时的穿越策略：

1. **检测阶段**（< 1 ms）：通过**快速保护算法**（直流电压突变 + 电流突变量）定位故障
2. **旁路阶段**（1~10 ms）：同一桥臂所有子模块切换到**旁路模式**
   - 旁路晶闸管导通，形成短路桥臂
   - 故障电流由子模块旁路晶闸管 + 桥臂电抗器共同限制
   - **子模块 IGBT 不承受过电流**（安全）
3. **隔离阶段**（10~100 ms）：
   - DCCB 切断故障段
   - 或 MTDC 通过功率重分配转移潮流
4. **恢复阶段**（100~500 ms）：子模块逐步重新投入，恢复功率传输

**关键优势**：MMC 旁路穿越时间尺度为 ms 级，远快于传统火电黑启动（分钟级），**不会导致系统频率显著跌落**。

### 3.3 直流断路器（DCCB）选型

DCCB 是 MTDC 极间短路故障隔离的核心设备：

| 类型 | 原理 | 分断能力 | 分断时间 |
|---|---|---|---|
| **机械式** | 高速操动机构 + 电流过零点自然熄灭 | ~ 10 kA | 20~50 ms |
| **全固态**（IGBT 串联） | IGBT 强制关断 + 缓冲电路 | ~ 5~20 kA | 1~10 ms |
| **混合式**（机械 + 电力电子） | 机械开关先分断 → 转移到电子开关 → 强制灭弧 | ~ 20~50 kA | 10~30 ms |

选型约束：分断能力 ≥ 1.5 倍最严重故障电流；分断时间 < 50 ms（保证子模块电容不发生过充/过放）。

### 4.2 失效边界

| 边界条件 | 后果 | 工程速记 |
|---|---|---|
| 极间短路 + 无 DCCB 且无子模块穿越 | 换流阀 IGBT 雪崩击穿，换流站永久损坏 | MTDC 必须同时配 DCCB 和 MMC 穿越策略 |
| 限流电抗器取值过小 | di/dt 超 DCCB 分断能力，故障发展失控 | $L_{\mathrm{DCL}} \geq 150$ mH（±500 kV 系统） |
| MTDC 潮流重分配失败 | 非故障段过载保护动作，扩大停电范围 | 预先计算全部故障场景下的潮流可行域 |
| 旁路晶闸管故障 | 子模块无法旁路，故障电流直通过 IGBT | 晶闸管冗余设计（2 串或旁路保险） |

### 4.3 工程速记

> **直流故障三要素**：限流电抗器（压 di/dt）→ DCCB（切故障段）→ MMC 子模块旁路（穿越不脱网）。三者缺一不可。
