# 电力变压器励磁涌流机理与差动保护防涌流

## 1. 定义

**励磁涌流（Inrush Current）**指变压器空载合闸（或切除外部故障后电压恢复）时，因铁芯磁通暂态饱和引起的暂态励磁电流，峰值可达额定电流的 6~8 倍（甚至 10~12 倍），但衰减很快（0.1~1 s 内降至稳态空载电流）。涌流可能引起差动保护误动，须配置**防涌流判据**。

| 涌流特征 | 数值 | 与短路的区别 |
|---|---|---|
| 峰值 | $6\sim12\,I_N$ | 短路可达 $15\sim25\,I_N$ |
| 含有大量二次谐波 | $I_2/I_1>15\%$ | 短路电流接近正弦，$I_2/I_1<10\%$ |
| 有间断角 | $60^\circ\sim80^\circ$ | 短路电流连续，无间断角 |
| 衰减时间常数 | $0.1\sim1$ s | 短路被切除前不衰减 |
| 相对变压器侧 | 仅出现在合闸侧 | 两侧均有（穿越性） |

## 2. 物理图像

### 2.1 剩磁与合闸相位决定涌流

变压器铁芯磁通滞后电压 $90^\circ$。空载合闸时，铁芯中可能存在 **剩磁 $\Phi_r$**（上次断开时未完全消磁），叠加暂态磁通后总磁通可能远超饱和值 $\Phi_s$，使铁芯深度饱和。

```
最严重工况：电压过零合闸 + 最大正剩磁 Φ_r

  Φ ─→
       │         ┌─── 暂态磁通（含直流分量）
       │        ╱  ╲
  Φ_s ─┼─────╱────╲─→ 饱和值
       │   ╱       ╲
       │  ╱         ╲
  Φ_r ─┼─╱           ╲ 稳态交流分量
       │╱             ╲
  0 ───┴─────────────────→ t
```

磁通超过 $\Phi_s$ 的部分，铁芯进入饱和区（详见 [TH-014 磁路饱和](TH-014-magnetic-circuit-saturation.md)），励磁电流急剧增加——这就是涌流的物理根源。

### 2.2 涌流的偏置特性

涌流因含大量直流分量（暂态磁通的直流部分），波形严重**偏向时间轴一侧**——这一侧励磁电流大幅增加，另一侧几乎为零。差动保护两侧 CT 都测量，但由于涌流只在合闸侧，差流即等于涌流本身——这是差动保护可能误动的机理。

## 3. 推导

### 3.1 涌流峰值估算

最严重工况（电压过零合闸 + 剩磁 $\Phi_r$ 同向）下暂态磁通峰值：

$$
\Phi_{max} = 2\Phi_m + \Phi_r
$$

$\Phi_m$ 为稳态磁通幅值。若 $\Phi_r\approx 0.9\Phi_m$（铁镍合金可能更高），则 $\Phi_{max}\approx 2.9\Phi_m$。铁芯饱和后励磁电流：

$$
i_{inrush}\approx\frac{\Phi_{max}-\Phi_s}{\mu_0\,N\,A_{air}}\cdot N = \frac{\Phi_{max}-\Phi_s}{\mu_0\,A_{air}}
$$

$A_{air}$ 为铁芯饱和后的等效气隙面积（磁路主要压降在气隙）。典型 $i_{inrush}/I_N=6\sim12$。

### 3.2 二次谐波制动判据

涌流含大量偶次谐波（饱和非线性产生），其中二次谐波占比最高。差动保护制动方程：

$$
\text{若}\;\frac{I_{2nd}}{I_{1st}}\ge k_{2}\;\text{则制动（闭锁差动）}
$$

| 判据 | 典型 $k_2$ | 适用 |
|---|---|---|
| 二次谐波比 | $15\%\sim20\%$ | 传统判据，应用最广 |
| 交叉制动（三相或门） | 任意一相 $>k_2$ 即闭锁三相 | 防涌流不完全，Y/d 变换后分布改变 |
| 波形对称（间断角） | 间断角 $>60^\circ$ | 涌流有间断，短路无间断 |

### 3.3 CT 饱和引起的差流误判

涌流峰值大且含直流，合闸侧 CT 可能饱和 → 二次电流失真 → 差动保护测到的差流可能与涌流实际波形不符，二次谐波比可能低于 $15\%$ → 制动失效 → 误动。防范：

- 选用 **PR 类 TPY/TPZ 暂态 CT**（详见 [TH-026 开关电器](TH-026-switchgear-selection-and-breaking-capacity.md) §TRV 之外的暂态特性段）
- 增大 CT 变比（降低二次电流）
- 采用 **波形对称判据**（不受谐波比影响）

### 3.4 和应涌流（Sympathetic Inrush）

并列运行变压器中，一台合闸产生的涌流直流分量通过系统阻抗使另一台已运行变压器的中性点电位偏移 → 已运行变压器也产生涌流——**和应涌流**。和应涌流幅值较低（$1\sim3\,I_N$）但衰减慢（数秒），可能使运行变压器差动保护误动。防范须延长二次谐波制动时间或采用交叉制动。

- **支撑条目 2**：[TH-014 磁路饱和](TH-014-magnetic-circuit-saturation.md) 与 [TH-006 变压器漏抗](TH-006-transformer-leakage-impedance.md)——涌流机理根植于铁芯磁饱和，本条给出暂态磁通峰值与饱和后电流的定量关系。

- **失效边界**：① 二次谐波比判据在大型变压器（500 MVA 以上）饱和程度较低时 $I_2/I_1$ 可能 $<15\%$，须降至 $10\%\sim12\%$ 或改用波形对称判据；② 交叉制动可能使区内故障伴随涌流（如合闸于故障）时保护拒动，须设"涌流闭锁+故障开放"双重判据；③ Y/d 变压器两侧 CT 接线相位补偿会使涌流波形变换，二次谐波分布改变，须校验；④ 和应涌流在并列运行或长电缆+变压器组合中显著，须延长闭锁时间；⑤ 涌流对电网电压暂降的影响须评估（大型变压器空投可能使 PCC 电压跌落）。
