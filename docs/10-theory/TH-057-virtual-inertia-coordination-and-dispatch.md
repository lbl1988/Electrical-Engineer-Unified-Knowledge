# 新能源场站虚拟惯量协调控制与惯量调度

## 1. 定义

大规模新能源场站（数百 MW 级光伏/风电）的虚拟惯量协调控制，是指**在区域调度层面**统筹多个场站的 VSG/GFL 构网型 PCS 惯量参数，实现**惯量资源的跨场站共享**，使区域总等效惯量满足频率稳定要求，同时避免各场站惯量叠加引发的**低频集群振荡**。

与 TH-056 单场站 VSG 参数设计不同，本条关注**多场站惯量的协同策略**。

| 协调层级    | 控制器           | 时间尺度 | 目标             |
| ------- | ------------- | ---- | -------------- |
| 场站级     | VSG/GFM 局部控制器 | 毫秒级  | 单场站稳定          |
| 区域级（本条） | 区域惯量协调控制器     | 秒级   | 区域总惯量平衡、避免集群振荡 |
| 调度级     | AGC + 惯量调度中心  | 分钟级  | 全系统惯量优化配置      |

## 2. 物理图像

多新能源场站并联惯量协调的三种模式：

```
模式 A：独立控制（现状主流）
    │
    │  场站1 (VSG)  ←J₁, D₁→  │
    │  场站2 (VSG)  ←J₂, D₂→  │  电网
    │  场站3 (VSG)  ←J₃, D₃→  │
    │
    │  问题：参数独立整定 → 惯量/阻尼分布不均
    │       相邻场站间可能产生低频集群振荡
    │
模式 B：集中协调控制
    │
    │  ┌──────────────────┐
    │  │ 区域惯量调度器     │ ← 接收调度指令
    │  │  (Regional Inertia  │   J_total, D_total
    │  │   Coordinator)    │
    │  └────┬─────┬─────┬──┘
    │       │     │     │
    │       ▼     ▼     ▼
    │  场站1  场站2  场站3
    │  J₁*   J₂*   J₃*      ← 由调度器分配
    │  D₁*   D₂*   D₃*
    │
    │  优势：区域总惯量可控，避免集群振荡
    │  代价：需要场站间通信（低延迟）
    │
模式 C：去中心化协调（无通信）
    │
    │  各场站测量本地频率 f_i 和邻场站频率 f_j
    │  调整 J_i, D_i 使 |f_i - f_j| < ε
    │
    │  优势：无需场站间通信，抗通信故障
    │  代价：收敛时间较长（分钟级）
```

## 3. 推导

### 3.1 区域总等效惯量

N 个并联场站的区域总等效惯量：

$$J\_{\mathrm{total}} = \sum\_{i=1}^{N} J\_i \cdot \frac{S\_{N,i}}{S\_{N,\mathrm{total}}}$$

其中 $J\_i$ = 第 $i$ 个场站的虚拟惯量，$S\_{N,i}$ = 场站额定容量，$S\_{N,\mathrm{total}}$ = 区域总额定容量。

**调度约束**：$J\_{\mathrm{total}} \geq J\_{\mathrm{req}}$，其中 $J\_{\mathrm{req}}$ 由频率稳定要求确定（典型 $J\_{\mathrm{req}} \geq 0.5$ s 对应 RoCoF ≤ 0.1 Hz/s）。

### 3.2 惯量分配优化

在满足 $J\_{\mathrm{total}} \geq J\_{\mathrm{req}}$ 前提下，使**集群振荡风险最小**的惯量分配：

$$\min \quad \sum\_{i \neq j} w\_{ij} \cdot \left|\frac{J\_i}{J\_j} - 1\right|^2$$

约束：

- $\sum J\_i \geq J\_{\mathrm{req}}$

- $J\_i^{\min} \leq J\_i \leq J\_i^{\max}$（每个场站的物理约束）

- $w\_{ij}$ = 电气距离倒数（相邻场站权重更高）

**解**：相邻场站 $J\_i / J\_j$ 应尽量接近 1（参数一致性），远离场站可适当差异化。

### 3.3 集群振荡的抑制

多 VSG 并联的低频集群振荡（0.5\~2 Hz）源于**惯量耦合**：

特征值分析显示，当两个 VSG 的 $J\_1/J\_2 > 3$ 且电气距离小时，会出现一对共轭特征值靠近虚轴 → 集群振荡。

**抑制措施**：

1. **惯量比约束**：相邻场站 $J\_{\max}/J\_{\min} \leq 2$
2. **主动阻尼增强**：在 $D\_i$ 上附加与相邻场站频率差成比例的阻尼项
3. **去中心化协调**：各场站测量邻场站频率，自适应微调 $D\_i$

### 3.4 惯量调度与电力市场

惯量作为**虚拟服务**参与辅助服务市场：

| 服务                 | 定价方式                 | 典型价格          |
| ------------------ | -------------------- | ------------- |
| **惯量容量（MW·s）**     | 按 $J \times P\_N$ 报价 | 1\~5 元/MW·s   |
| **惯量响应（RoCoF 抑制）** | 按实际触发次数              | 10\~50 元/次    |
| **一次调频**           | 响应速度 + 响应量           | 50\~200 元/MWh |

### 4.2 失效边界

| 边界条件                                   | 后果                  | 工程速记                              |
| -------------------------------------- | ------------------- | --------------------------------- |
| 场站惯量比 > 5:1 且电气距离近                     | 稳定裕度 < 10%，易激发集群振荡  | 相邻场站 $J\_{\max}/J\_{\min} \leq 2$ |
| 区域总惯量不足（$J\_{\mathrm{total}} < 0.3$ s） | 频率跌落超 0.5 Hz，触发低频减载 | 惯量容量应冗余 20%                       |
| 惯量调度通信延迟 > 500 ms                      | 协调失效，退回独立控制模式       | 采用光纤通信或去中心化方案                     |

### 4.3 工程速记

> **惯量协调三原则**：总量要够（$J\_{\mathrm{total}} \geq J\_{\mathrm{req}}$）、相邻要一致（$J\_{\max}/J\_{\min} \leq 2$）、远场可差异化。
