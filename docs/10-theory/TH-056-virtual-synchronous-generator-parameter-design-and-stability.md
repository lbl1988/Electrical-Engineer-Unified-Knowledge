# 虚拟同步机（VSG）参数设计与稳定性

## 1. 定义

虚拟同步机（Virtual Synchronous Generator, VSG）是通过**电力电子控制算法使并网逆变器模拟同步发电机的外特性**，为高比例电力电子化电力系统提供**等效惯量和阻尼**的技术。VSG 是解决当前新能源并网后"系统无惯量、频率不稳定"问题的核心手段。

| 控制模式 | 是否有惯量 | 是否有阻尼 | 适用场景 |
|---|---|---|---|
| **跟网型（Grid-Following, GFL）** | ❌ | ❌（仅 PLL 引入弱阻尼） | 弱电网下不稳定 |
| **构网型（Grid-Forming, GFM）** | ✅（虚拟惯量 $J_v$） | ✅（虚拟阻尼 $D_v$） | 高比例新能源、弱电网、黑启动 |
| **VSG（广义 GFM）** | ✅ | ✅ | 模拟同步机完整外特性 |

**VSG 的核心思想**：让逆变器的输出频率不是由 PLL 锁相电网，而是由**虚拟转子的机械方程**自主决定——使逆变器具备同步发电机的"自组织"特性。

## 2. 物理图像

VSG 的控制结构与参数物理意义：

```
VSG 控制结构（简化）
    │
    ├── 电压外环 + 电流内环（与传统 PCS 相同）
    │
    ├── 功率环（新增）
    │   │
    │   ├── 有功功率 P 控制 → 虚拟机械方程
    │   │   J_v · dω/dt = P_ref - P_out - D_v · (ω - ω_grid)
    │   │   │
    │   │   J_v = 虚拟惯量（决定频率响应惯性）
    │   │   D_v = 虚拟阻尼（决定振荡衰减速度）
    │   │
    │   │   频率 ω 积分 → 相位 θ（输出电压的角度）
    │   │   └── 这是 VSG 的关键：相位由自身决定，不是 PLL
    │   │
    │   └── 无功功率 Q 控制 → 虚拟励磁方程
    │       K_v · dE/dt = Q_ref - Q_out - G_v · (E - V_grid)
    │       │
    │       E = 虚拟内电势（决定输出电压幅值）
    │       G_v = 下垂系数（决定 Q-V 下垂特性）
    │
    └── 下垂控制（可选增强）
        f - P 下垂：f = f_n - R_p · (P - P_ref)
        V - Q 下垂：V = V_n - R_q · (Q - Q_ref)
```

**关键优势**：VSG 不依赖 PLL 锁相电网，因此在**弱电网**下、**黑启动**时、**大扰动后**都能保持稳定——这恰好是跟网型 PCS 的薄弱环节。

## 3. 推导

### 3.1 虚拟机械方程的稳定性分析

VSG 的有功-频率外环可线性化后得到二阶系统：

$$J_v \cdot s \Delta\omega = -\Delta P - D_v \Delta\omega$$

其中 $\Delta P \approx K_p \Delta\delta$（同步功率系数），$\Delta\delta = \Delta\omega / s$。

特征方程：

$$J_v s^2 + D_v s + K_p = 0$$

**稳定条件**（两个特征根都在左半平面）：

$$J_v > 0, \quad D_v > 0, \quad K_p > 0$$

即三个参数都是正的就能稳定——比 PLL 耦合系统简单得多。

### 3.2 参数设计原则

| 参数 | 物理意义 | 设计原则 | 典型取值 |
|---|---|---|---|
| **虚拟惯量 $J_v$** | 决定频率响应惯性，防止频率快速跌落 | 使 RoCoF $\leq 0.1$ Hz/s（$\Delta P/P_N = 10\%$ 时） | $J_v \approx 0.5 \sim 2.0$ s |
| **虚拟阻尼 $D_v$** | 抑制有功-频率振荡 | 阻尼比 $\zeta \approx 0.7 \sim 1.0$（临界阻尼） | $D_v \approx 5 \sim 20$ pu |
| **同步功率系数 $K_p$** | 决定频率-功率耦合强度 | 与等效电网阻抗和 PCS 额定容量相关 | $K_p \approx 0.5 \sim 2.0$ pu |
| **无功下垂系数 $R_q$** | V-Q 下垂特性 | 与无功/电压调节需求匹配 | $R_q \approx 2 \sim 10\%$ |

**阻尼比 $\zeta$ 的计算**：

$$\zeta = \frac{D_v}{2\sqrt{J_v K_p}}$$

**设计目标**：$\zeta \approx 0.707$（最佳阻尼比，响应无超调）。

### 3.3 多 VSG 并联的稳定性

当多个 VSG 并联运行时，每个 VSG 的外环方程相互耦合：

$$J_i \cdot s \Delta\omega_i = -\sum_{j=1}^n K_{ij} (\Delta\delta_i - \Delta\delta_j) - D_i \Delta\omega_i$$

耦合系数 $K_{ij}$ 取决于**电网拓扑和各 VSG 连接位置的电气距离**。

**稳定判据**：所有 VSG 的同步功率矩阵 $\mathbf{K} = [K_{ij}]$ 为**正定矩阵**。这等价于**网络连接图是连通的**（所有 VSG 之间至少有一条电气路径）。

### 3.4 自适应参数整定

VSG 参数需要根据**运行方式和电网条件**动态调整：

| 条件 | $J_v$ | $D_v$ |
|---|---|---|
| 弱电网（低短路比 SCR < 3） | ↑ 增大 | ↑ 增大 |
| 高新能源占比（系统等效 $H$ 低） | ↑ 增大 | ↓ 减小（避免与其他 VSG 耦合振荡） |
| 孤网运行（无主网支撑） | ↑ 增大 2~3 倍 | ↑ 增大 |
| 黑启动（刚启动，空载） | 小 | 小（逐步增大） |

**简单自适应策略**：

$$J_v(t) = J_0 \cdot \frac{S_N(t)}{S_{N,\mathrm{rated}}}, \quad D_v(t) = D_0 \cdot \sqrt{\frac{S_N(t)}{S_{N,\mathrm{rated}}}}$$

即惯量与有功功率成线性关系，阻尼与平方根关系——保持阻尼比基本不变。

### 4.2 失效边界

| 边界条件 | 后果 | 工程速记 |
|---|---|---|
| $J_v$ 过大（阻尼比 < 0.3） | 有功-频率振荡（超调 > 50%） | 保证 $\zeta \geq 0.5$ |
| $D_v$ 过大（阻尼比 > 2.0） | 响应过慢，跟不上功率指令 | $\zeta$ 上限 ≤ 1.2 |
| 多 VSG 参数差异大（惯量比 > 5:1） | 机组间产生低频振荡（0.5~2 Hz） | 并联 VSG 的 $J_v/D_v$ 参数一致性 ±30% 以内 |
| VSG 与跟网型 PCS 混合系统 | 可能出现**模式混淆**（VSG 低频振荡 + GFL PLL 振荡耦合） | 用 Nyquist 判据校验整体稳定 |

### 4.3 工程速记

> **VSG 三参数**：惯量看频率响应（RoCoF ≤ 0.1 Hz/s），阻尼看响应速度（ζ = 0.7），下垂看功率分配（R_p = 1~5%）。弱电网下 $J_v$ 和 $D_v$ 都要加大。
