# 变压器铁芯直流偏磁与剩磁机理

## 1. 定义

直流偏磁（DC Magnetization）是指变压器铁芯中因**直流分量**存在而导致的**工作点偏移**现象。正常交流励磁下，铁芯工作在磁化曲线的线性区（$\pm B\_m$，峰值磁通密度 1.7\~1.8 T）；叠加直流后，工作点上移至磁化曲线**饱和段**，产生严重后果。

| 偏磁来源                  | 机理                           | 典型幅值                             | 出现场景            |
| --------------------- | ---------------------------- | -------------------------------- | --------------- |
| **HVDC 单极运行**         | 直流输电单极返回电流经变压器接地中性点流入        | 数 A \~ 数十 A                      | 南网/国网特高压直流工程    |
| **地磁暴（GIC）**          | 太阳活动引发地磁场突变，大地感应电场在电网中产生 GIC | 10\~100 A                        | 太阳活动高峰期（11 年周期） |
| **逆变器三次谐波**           | 非线性负荷（逆变器/整流器）产生直流偏置的磁通分量    | 小                                | 高比例电力电子系统       |
| **剩磁（Residual Flux）** | 断路器非同期合闸后铁芯残留的永久磁通           | $B\_r \approx 0.3 \sim 0.6 B\_m$ | 变压器空投、重合闸       |

**剩磁**是每次变压器合闸都存在的确定性现象，而直流偏磁的幅值取决于外部条件（HVDC 运行方式、地磁暴强度）。

## 2. 物理图像

直流偏磁对变压器磁化特性的影响：

```
正常交流励磁（无直流偏磁）
    │
    │  B(T)
    │   ↑  1.8 ─╮       ╭─ 饱和段
    │   1.7 ─┤       ┤
    │        ╰──╮ ╭──╯   ← 线性工作区
    │            ╰─╯
    │   0 ────────────────── H(A/m) →
    │            -H_c          H_c
    │
    │  工作点：B ∈ [-1.7, +1.7] T，H ∈ [-H_c, +H_c]

叠加直流偏磁 B_dc（单极性 +）
    │
    │  B(T)
    │   ↑  ~2.0 ─────────╭─ 深度饱和
    │        ╭───────╮
    │        │╰─╮    │    ← 工作点上移，上半周深度饱和
    │   0 ───┤   ╰───┤────  ← B_dc ≈ 0.3~0.8 T
    │        ╰───────╯
    │   -1.0 ────────────── ← 下半周仍在线性区
    │
    │  危害：
    │  1. 励磁电流畸变（严重时可达额定电流 5~10 倍）
    │  2. 谐波分量剧增（5/7/11 次尤为明显）
    │  3. 振动/噪声增大 10~30 dB
    │  4. 绕组附加损耗增加 → 局部过热
```

## 3. 推导

### 3.1 磁化曲线与偏磁工作点

变压器铁芯磁化的非线性关系：

$$B = \mu(H) \cdot H$$

典型硅钢片磁化曲线的分段近似：

| <br /> | <br />  | 区域 | H 范围        | $\mu$                            | 特性                          |
| :----- | :------ | -- | ----------- | -------------------------------- | --------------------------- |
| 线性区    | $       | H  | < H\_k$（拐点） | 高 $\mu\_r \approx 1000\sim 5000$ | $\mu$ 近似常数                  |
| 准饱和区   | $H\_k < | H  | < H\_s$     | 中                                | $\mu$ 快速下降                  |
| 深饱和区   | $       | H  | > H\_s$     | 低 $\mu\_r \approx 10\sim 100$    | $\mu \approx \mu\_0$（真空磁导率） |

直流偏磁的工作点偏移：

$$B(t) = B\_{\mathrm{dc}} + B\_{\mathrm{ac}}\sin(\omega t)$$

其中 $B\_{\mathrm{ac}} \approx 1.7$ T（额定峰值），$B\_{\mathrm{dc}}$ 取决于直流激磁电流 $I\_{\mathrm{dc}}$ 和励磁阻抗 $Z\_m$。

**关键公式**（忽略饱和时）：

$$B\_{\mathrm{dc}} = \frac{I\_{\mathrm{dc}} \cdot N\_1 \cdot \mu\_{\mathrm{core}} \cdot A\_{\mathrm{core}}}{l\_{\mathrm{core}}}$$

即 $B\_{\mathrm{dc}} \propto I\_{\mathrm{dc}}$，可近似估算直流偏磁的幅值。

### 3.2 剩磁的产生与衰减

断路器分闸瞬间（电流自然过零点之前或之后），铁芯磁通保留分闸时刻的值。若分闸瞬间励磁电流不为零：

$$B\_{\mathrm{residual}} = B\_{\mathrm{at\_trip}} \cdot \cos(\theta\_{\mathrm{trip}})$$

其中 $\theta\_{\mathrm{trip}}$ 是分闸瞬间的电角度。

**最大剩磁**：分闸在 $i=0$ 附近（自然过零点），此时 $B$ 接近峰值，剩磁最大 $B\_r \approx 0.5 \sim 0.8 B\_m$。

**衰减**：剩磁在铁芯中不会快速衰减（硅钢片是硬磁材料？——不，实际**软磁材料**的剩磁由磁畴壁的亚稳态决定，衰减时间常数为**小时级至天级**）。

### 3.3 剩磁对合闸涌流的放大

当变压器带剩磁 $B\_r$ 合闸时，首半周磁通：

$$B(t) = B\_{\mathrm{residual}} + B\_{\mathrm{steady}}(1 - e^{-t/\tau}) + B\_{\mathrm{steady}}\cos(\omega t)$$

稳态磁通 $B\_{\mathrm{steady}} \approx 1.7$ T。若合闸在电压峰值附近，暂态叠加后：

$$B\_{\mathrm{max}} = B\_r + 2 B\_{\mathrm{steady}}$$

**临界情况**：$B\_r = 0.7 B\_{\mathrm{steady}}$ 时，$B\_{\mathrm{max}} \approx 2.4 B\_{\mathrm{steady}}$，远超铁芯饱和磁通 → 励磁涌流可达额定电流的 **10\~20 倍**。

### 3.4 抑制措施

| 措施                | 适用场景        | 效果                        |
| ----------------- | ----------- | ------------------------- |
| **选相合闸装置（POW）**   | 剩磁抑制        | 在电压合适相位合闸，抵消剩磁，涌流抑制率 70%+ |
| **直流偏磁监测 + 抑制绕组** | HVDC/GIC 偏磁 | 注入反向直流，抵消偏磁               |
| **铁芯结构优化（气隙分段）**  | 设计阶段        | 降低偏磁敏感性，但会增加空载损耗          |
| **中性点电容/电感隔直**    | HVDC 偏磁     | 阻止直流流入变压器绕组               |

### 4.2 失效边界

| 边界条件              | 后果                             | 工程速记               |
| ----------------- | ------------------------------ | ------------------ |
| 直流偏磁 + 变压器差动保护    | 励磁涌流特征（二次谐波）可能缺失，差动保护误动        | 必须配置直流偏磁监测         |
| HVDC 单极运行 + 无偏磁抑制 | 多台 500 kV+ 变压器铁芯严重饱和，噪声 90+ dB | 特高压 HVDC 必须配偏磁抑制装置 |
| 选相合闸失败（剩磁未抵消）     | 涌流超 10 倍额定，母联断路器跳闸             | 选相合闸后必须监测首半周电流     |

### 4.3 工程速记

> **直流偏磁看 HVDC，剩磁看断路器**。选相合闸在"电压峰值 - 55°"附近合闸，可抵消 80% 剩磁。
