# 变压器电容式套管故障物理与绝缘诊断

## 1. 定义

变压器套管是**高压（≥66 kV）及以上**变压器的关键绝缘部件，实现高压引线从油箱内引出并承受系统对地电压。套管故障占变压器故障的 **8~12%**，其中**电容式套管**（Capacitive Bushing）因内置电容屏的制造、安装、运行老化问题，是故障高发类型。

| 套管类型 | 绝缘结构 | 电压等级 | 故障风险 |
|---|---|---|---|
| **纯瓷/油瓷** | 瓷套 + 油间隙 | ≤ 35 kV | 低 |
| **胶纸电容式（OIP）** | 纸/聚合物绝缘 + 电容分压屏 | 66~500 kV | 中（纸老化、浸油问题） |
| **油浸纸电容式** | 纸绝缘 + 电容屏 + 硅油 | 110~750 kV | 高（纸水树、屏短路） |
| **复合电容式（树脂）** | 环氧树脂电容屏 | 110~500 kV | 中（树脂脆化） |

套管故障机理的核心矛盾：**内置电容屏（均压作用）在绝缘劣化后反而成为局部放电的集中点**，加速击穿。

## 2. 物理图像

油浸纸电容式套管的结构与故障路径：

```
电容式套管结构（纵截面）
    │
    ├── 顶部引线端子（接绕组首端）
    ├── 电容屏串（N 层，每层电容 C_i ≈ 100~500 pF）
    │   │
    │   │  绝缘：纸（厚度 0.1~0.5 mm，层数 100~500）
    │   │         + 变压器油（浸渍）
    │   │         + 电容屏（铝箔/金属化纸，厚度 10~50 μm）
    │   │
    │   └── 故障区域 A：电容屏短路（金属箔搭接）
    │       → 分压比突变 → 电压重新分布 → 绝缘薄弱点击穿
    │
    │   └── 故障区域 B：绝缘纸劣化（水树、热老化）
    │       → 电容 C_i 变化（ΔC/C > 10%） → 介质损耗上升
    │
    │   └── 故障区域 C：末屏接地开路
    │       → 末屏悬浮 → 高电压 → 击穿
    │
    ├── 瓷套（外绝缘，承受操作/雷电冲击）
    ├── 法兰（接地，末屏引出）
    └── 油箱连接（油封）
```

故障演进时间：**年级**（纸/树脂缓慢老化）→ **月级**（缺陷发展为可测电容变化）→ **日级**（局部放电密集）→ **小时级**（击穿）。

## 3. 推导

### 3.1 电容式套管等效电路

正常状态下，套管可视为**电容分压器**：

$$C_{\mathrm{total}} = \frac{1}{\sum_{i=1}^{N} 1/C_i}$$

其中 $C_i = \frac{2\pi \varepsilon_0 \varepsilon_r h}{\ln(r_{i+1}/r_i)}$，$\varepsilon_r \approx 3.5$（变压器油浸纸）。

**末屏电压**（电容分压器原理）：

$$U_{\mathrm{end}} = U_{\mathrm{line}} \cdot \frac{C_{\mathrm{total}}}{C_{\mathrm{end}}}$$

正常 $U_{\mathrm{end}} \approx 0.5\sim 5$ kV，故障时可升至数十 kV。

### 3.2 电容屏短路的影响

当某层电容屏（第 $k$ 层）短路时：

$$C_{\mathrm{total,new}} = \frac{1}{\sum_{i \neq k}^{N} 1/C_i}$$

短路层被排除，等效电容**减小** $\Delta C = C_k / (C_{\mathrm{total}} + C_k)$。

**关键结论**：$\Delta C/C > 10\%$ 意味着至少一层电容屏失效，**必须停电检修**。

### 3.3 绝缘诊断方法

#### 3.3.1 电容/介损在线监测（最常用）

| 参数 | 正常值 | 告警阈值 | 含义 |
|---|---|---|---|
| 电容量 $C$ | 设计值 ±2% | ±3~5% | 电容屏短路/开路 |
| 介损 $\tan\delta$ | < 0.5% | > 0.8%（绝对值连续两周上升） | 绝缘纸/树脂劣化 |

#### 3.3.2 DGA 在线（油色谱分析）

套管故障的特征气体：

| 气体 | 来源 | 判据 |
|---|---|---|
| H₂ | 局部放电 + 绝缘油分解 | 持续增长 → 早期预警 |
| C₂H₄ | 电弧/过热（> 300°C） | 突增 → 故障演进中 |
| C₂H₂ | 电弧（> 1000°C） | **出现即危险** → 接近击穿 |
| CH₄, C₂H₆ | 热老化 | 缓慢增长 → 长期劣化 |

**罗杰斯比值法（IEC 60599）**：$C_2H_2/C_2H_4, CH_4/H_2, C_2H_4/C_2H_6$ 三个比值定位故障类型。

#### 3.3.3 局部放电（PD）检测

套管内部 PD 信号经电容屏耦合到末屏，可用**UHF 法（300 MHz~1.5 GHz）** 或**超声波法（40~200 kHz）** 检测。

**特征**：套管内部 PD 相位分布呈现典型**半波集中**（工频正或负半周），与外部电晕（整周均匀）可区分。

## 4. 与工程实践的联系

| 套管更换与故障分析 | TH-022（过电压）、TH-017（VFTO） | IEC 60599:2015 |

### 4.2 失效边界

| 边界条件 | 后果 | 工程速记 |
|---|---|---|
| 末屏接地松动（接触电阻 > 1Ω） | 末屏悬浮 → 高电压 → 放电 → 绝缘击穿 | 末屏必须直接接地，禁止串接保护装置 |
| 套管进水（油封失效） | 水树在纸层中快速发展（数月即击穿） | DGA 发现 H₂ 和 O₂ 同步升高即告警 |
| 电压等级 ≥ 500 kV 且 tanδ > 1.0% | 下次操作过电压即击穿 | 立即降额运行并安排检修 |

### 4.3 工程速记

> **套管三指标**：C（电容，±3%）、tanδ（介损，< 0.8%）、DGA 特征气体。C 突降或 C₂H₂ 出现，立即停电。
