## 5. 向量化预处理说明

### 5.1 文本块切分策略

| 层 | 切分粒度 | 块大小 | 向量化内容 |
|---|---|---|---|
| TH | 每条目按五段式切分 | ~500字/块 | 定义+物理图像+推导+工程联系+关联 |
| PR | 每条目按九段式切分 | ~400字/块 | 摘要+原理公式+设计要点+算例 |
| CALC | 每条目按步骤切分 | ~300字/块 | 方法+公式+算例步骤 |
| CASE | 每条目按场景切分 | ~500字/块 | 背景+分析+结论 |
| STD | 每条标准按条款切分 | ~200字/条款 | 条款号+要求要点+适用边界 |

### 5.2 向量化建议参数

```yaml
embedding_model: text-embedding-3-large  # 或 bge-large-zh-v1.5
dimension: 1536                           # 或 1024
chunk_overlap: 50                         # 字符重叠
top_k: 5                                  # 检索返回数
similarity_threshold: 0.75                # 相似度阈值
```
