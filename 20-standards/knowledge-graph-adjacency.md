# 知识图谱邻接表（条目间关系图）

> **用途**：知识图谱以邻接表形式存储条目间关系，支持图遍历（BFS/DFS）与最短路径查询，实现"从概念到工程到算例"的多跳检索。
> **关系类型**：`上游理论支撑`（TH→PR/CALC）、`同级关联`（TH↔TH）、`下游应用`（PR→CASE）、`标准溯源`（→STD）。
> **节点数**：142（TH×44 + PR×20 + CALC×17 + CASE×54 + STD×7）；**边数**：~400+

## 1. 图谱结构概览

```
STD 标准层（7 节点）
  ↑ 标准溯源
TH 理论层（44 节点）──同级关联──→ TH 理论层
  ↓ 上游理论支撑
PR 实践层（20 节点）──同级关联──→ PR 实践层
  ↓ 下游应用
CALC 计算库（17 节点）   CASE 案例库（54 节点）
```
