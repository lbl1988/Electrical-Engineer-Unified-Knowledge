# 低压断路器选型与级间选择性

## 1. 摘要

断路器选型＝**框架等级 → 分断/耐受校验 → 脱扣整定 → 选择性验证**四步。本条给出 ACB/MCCB/MCB 适用矩阵、$I_{cu}$/$I_{cs}$/$I_{cw}$/$I_{pk}$ 四参数的校验对象（全部对应 [CALC-SC-001](../40-calc/CALC-SC-001-低压三相短路电流计算.md) 的计算输出），以及四种选择性手段（电流/时间/能量/ZSI）的选用逻辑；算例引用 SC-001/PT-001 双条目数据形成完整选型闭环。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| $I_{cu}$ | 额定极限短路分断能力（O-CO 试验程序，分断后不要求继续承载） | GB/T 14048.2 |
| $I_{cs}$ | 额定运行短路分断能力（O-CO-CO，分断后可继续使用），取 25/50/75/100%$I_{cu}$ | 同上 |
| $I_{cw}$ | 额定短时耐受电流（0.5s/1s/3s），ACB 延时选型的关键量 | 同上 |
| $I_{pk}$ | 额定峰值耐受电流（= $n\times I_{cw}$，$n$ 按电流等级 2.1~2.2） | 同上 |
| 选择性 | 下级故障仅下级动作，上级不误动（全选择性/部分选择性） | GB 50054/IEC 60947-2 附录 |

## 3. 原理与公式（选型流程图）

```
第1步 框架等级：主进线/母联 → ACB（框架 630~6300A）
      干线/馈线 → MCCB（塑壳 63~1600A）
      终端/照明插座 → MCB（1~125A）
第2步 分断/耐受：
      Icu ≥ 安装处 Ik''；Ipk ≥ ip；
      进线/母联（靠上级、需短延时）加校 Icw ≥ 延时期间的短路电流
第3步 脱扣整定：→ CALC-PT-001 三段整定
第4步 选择性验证：
      ① 电流选择性：上级瞬时/下级瞬时带不重叠（级差≥1.3倍）
      ② 时间选择性：上级短延时 − 下级瞬时 ≈ 0.1~0.2s（ACB 间取 0.3s 级）
      ③ 能量选择性：限流型 MCCB/MCB（I²t 级差）
      ④ ZSI：区域选择联锁（下级检测到故障闭锁上级延时，最速切除）
```

**校验参数与计算输出对应表**：

| 断路器参数 | 对应计算量 | 来源条目 |
|---|---|---|
| $I_{cu}/I_{cs}$ | $I_k''$（安装处对称短路） | [CALC-SC-001](../40-calc/CALC-SC-001-低压三相短路电流计算.md) |
| $I_{pk}$（及母排动稳定） | $i_p=\kappa\sqrt2 I_k''$ | 同上 |
| $I_{cw}$（短延时期间） | 靠近变压器点的 $I_k''$ | 同上 |
| $I_r/I_{sd}/I_i$ | $I_B$、尖峰、末端最小短路 | [CALC-PT-001](../40-calc/CALC-PT-001-protection-setting.md) |

## 5. 设计/选型要点（校审清单）

- [ ] 主进线 ACB：$I_{cw}$（0.5s 或 1s）≥ 变压器出口短路电流（为短延时选择性与母线故障留窗口）；$I_{cs}$ 优先选 100%$I_{cu}$
- [ ] 末端 MCCB 按**馈线末端**短路降档选（[SC-001 §7.4](../40-calc/CALC-SC-001-低压三相短路电流计算.md)：21.5kA → 25kA 档即可，不必全线 50kA）
- [ ] 选择性组合逐级画**时间-电流曲线叠加图**（ACB 短延时与 MCCB 瞬时的带隙校验）
- [ ] 限流型断路器与电缆热稳定联动：$I^2t$ 限制值可放小电缆截面（利用限流后的实际 $I^2t$ 校验，制造商数据）
- [ ] 谐波场所（变频/UPS 下游）选脱扣器具备**谐波免疫**（RMS 检测）型
- [ ] 直流回路/光伏直流侧**严禁**直接用交流断路器（灭弧机理不同，选直流专用）

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 全线按变压器端子短路选 $I_{cu}$ | 末端成本虚高 | 按安装处 $I_k''$ 选，末端降档 | GB 50054 |
| 只校 $I_{cu}$ 不校 $I_{pk}$ | 峰值电流下触头斥开/母排变形 | $i_p$ 校 $I_{pk}$ 与成套动稳定 | GB/T 14048.2 |
| $I_{cs}$ 误解（以为=100%$I_{cu}$） | 重要回路分断后带病运行 | 明确订购 $I_{cs}$=100%$I_{cu}$ 档（进线/母联） | 同上 |
| 上级瞬时与下级瞬时带重叠 | 级联失选择，越级跳闸 | 上级改短延时或抬高瞬时带；重叠区间用 ZSI | 通行做法 |
| ACB 忽略 $I_{cw}$ 校验 | 短延时期间动热稳定不足 | 靠近变压器点 $I_{cw}\ge I_k''$（延时档对应时间） | GB/T 14048.2 |

## 7. 完整算例（引用 SC-001/PT-001 数据的选型闭环）

系统：1000kVA/Dyn11/uk6%（d1：$I_k''$=23.3kA、$i_p$=53.6kA；d2：21.5kA/46.5kA）。

| 位置 | 位置电流 | 校验 | 选型结果 |
|---|---|---|---|
| 主进线 ACB | $I_r^{ACB}$=1600A（≥$I_{30}$=1443A 变压器额定） | $I_{cu}\ge$23.3kA 且 $I_{cw}$(0.5s)$\ge$23.3kA、$I_{pk}\ge$53.6kA | 框架 2000A ACB，$I_{cu}$=$I_{cs}$=50kA，$I_{cw}$=50kA/1s，$I_{pk}$=105kA；整定见 [PT-001 §7.3](../40-calc/CALC-PT-001-protection-setting.md)（$I_{sd}$=12.8kA/0.3s） |
| 馈线 MCCB（→d2 动力箱） | $I_r$=125A ≥ $I_B$=114A | $I_{cu}\ge$21.5kA（**按末端**） | 160A 框架 MCCB，$I_{cu}$=25kA（$I_{cs}$=50%$I_{cu}$=12.5kA? —— 注意：$I_{cs}$ 须 ≥ 安装处预期短路的运行分断要求，本例取 $I_{cs}$=100% 档），三段整定见 PT-001 |
| 终端 MCB | C63 照明支路 | 灵敏度 250m 卡点工况见 PT-001 §7.6（B 型/放大截面） | C63 或 B63 按线路长度定 |

**选择性验证**：ACB $I_{sd}$=12.8kA/0.3s ↔ MCCB $I_{sd}$=750A/0.1s、$I_i$=1500A：电流级差 8.5 倍＋时间级差 0.2s → 全选择性 ✓；MCCB $I_i$=1500A ↔ 下级 C63 磁带上限 630A：2.4 倍级差，带隙不重叠 → 全选择性 ✓。
