# 电动汽车充电设施供配电与安全配置

## 1. 摘要

本条给出新建办公/住宅配套电动汽车充电设施的**容量估算、供配电系统、消防与安全防护**配置方法。接续 [CALC-LD-001](../40-calc/CALC-LD-001-demand-factor-method.md) 综合办公楼算例（$P_{30}=395.1$ kW），按 GB/T 50966-2024 与 GB 51348-2019 给出 30 慢充 + 6 快充配置方案，结论：**充电计算负荷 360kW（占建筑负荷 91%），须独立变压器 + 谐波治理，消防按防火分区 + 自动报警 + 剩余电流监测三位一体配置**。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 交流充电桩 | 通过车载充电机为动力电池充电的桩，功率 7kW/22kW（单/三相） | GB/T 18487.1-2023 |
| 直流充电桩 | 整流后直接输出直流到电池，功率 60~360 kW | 同上 |
| 充电模式 1~4 | 模式 2（家用便携）、模式 3（专用交流桩）、模式 4（直流快充） | GB/T 18487.1 §4 |
| 防火分区 | 建筑物内用防火墙分隔、限制火灾蔓延的区域 | GB 50016 §5.2 |
| 同时系数 $K_{\Sigma}$ | 多桩同时工作的折减系数，慢充常取 0.5~0.7，快充 0.8~0.9 | GB/T 50966 |

## 3. 原理与公式（配置决策树）

### 3.1 容量估算

总充电计算负荷：

$$P_{EV} = K_{\Sigma}\left(\sum P_{slow,i} + \sum P_{fast,j}\right)$$

分别按"同时系数"乘以慢充/快充总功率。配套供配电：

$$S_{EV} = \frac{P_{EV}}{\cos\varphi_{EV}},\qquad \cos\varphi_{EV}\approx 0.95\ (\text{含车载机功率因数校正})$$

| 符号 | 含义 | 单位 |
|---|---|---|
| $P_{slow,i}$ | 第 $i$ 个慢充桩额定功率（7~22 kW） | kW |
| $P_{fast,j}$ | 第 $j$ 个快充桩额定功率（60~360 kW） | kW |
| $K_{\Sigma}$ | 同时系数 | — |

### 3.2 谐波与剩余电流

车载充电机为整流负载，谐波电流 $I_h$ 须按 [GB/T 14549-1993](../20-standards/cn-01-强制性通用规范与主干标准.md) 校核（详见 [TH-008](../10-theory/TH-008-harmonic-generation.md)）。剩余电流保护须用 B 型 RCD（直流分量保护，详见 [PR-DD-001](PR-DD-001-lv-breaker-selection.md)）。

## 5. 设计/选型要点

- [ ] **容量估算决策树**：
  ```
  车位数 N、单桩功率 P_i、使用场景
    ├─ 车位数固定（住宅/办公配套）→ 按 1桩/1车位配，K_Σ=0.5~0.7（同时系数）
    ├─ 公共充电站 → 按快速补电需求，K_Σ=0.8~0.9
    └─ 高速快充站 → 按峰值流量，K_Σ=1.0
  ```

- [ ] **供配电系统**：
  - 大型站（> 500 kW）双电源 + 双变压器，按一级负荷（[PR-PS-001](PR-PS-001-load-classification.md)）
  - 中型站单电源 + 单变，变压器容量 $S_T\ge 1.15\, S_{EV}$（留 15% 裕度）
  - 独立变配电所，与建筑主变分开

- [ ] **保护配置**：每桩回路独立配电，三段保护（长延时 + 短延时 + 剩余电流 B 型）；总进线设剩余电流监测报警（非跳闸），区分故障与正常漏电流

- [ ] **消防**：
  - 车库内充电设施按防火分区单独配电
  - 充电站与建筑间距：室外独立站 ≥ 6m，贴邻建物设防火墙
  - 自动火灾报警（感烟 + 感温），与充电系统联动急停
  - 配置磷酸铵盐/水基灭火器（电气火灾）

- [ ] **接地**：采用 TN-S，PE 线与 N 线严格分开；等电位联结包含充电桩外壳

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 慢充按 $K_{\Sigma}=1$ 配变 | 变压器虚大、负载率失真 | 住宅 $K_{\Sigma}=0.4$、办公 0.6、公共 0.7 | GB/T 50966 |
| 按建筑主变容量"打擦边球"接入充电负荷 | 充电峰荷与建筑峰荷叠加 | 独立配电变，核算峰荷叠加（非同时系数直接相加） | GB 51348 §9.4 |
| 用 AC 型/型 RCD | 车载整流器产生脉动直流，AC 型拒动 | B 型 RCD，对脉动直流和平滑直流均可靠 | GB 51348 §9.4.6 |
| 谐波未治理 | 变压器发热、中线电流超标 | 装 APF 或加大变（K 因子法） | GB/T 14549 |
| 车库内未按防火分区单独配电 | 一区故障影响全库 | 每防火分区独立回路 + 总开关 | GB/T 51313 §4 |
| 充电桩与防雷接地未做等电位 | 雷电反击损坏桩 | 桩外壳纳入建筑 LEB | GB 50057/PR-GR-002 |

## 7. 完整算例

### 7.1 已知条件（接续 [CALC-LD-001](../40-calc/CALC-LD-001-demand-factor-method.md) 综合办公楼）

- 综合办公楼，地下车位 80 个
- 规划办公配套充电设施：慢充 30 个（7 kW，单相）/ 快充 6 个（120 kW，三相）
- 建筑主变 2×630 kVA，已带 $S_{30}=495.6$ kVA（负载率 78.7%）
- 与 cn-04 [GB/T 50966-2024](../20-standards/cn-04-新兴领域标准包.md) 一致

### 7.2 充电总功率与同时系数

慢充总功率 $=30\times 7=210$ kW；快充总功率 $=6\times 120=720$ kW；总功率 $=930$ kW。

按办公配套场景：$K_{\Sigma,slow}=0.6$、$K_{\Sigma,fast}=0.85$：

$$P_{EV} = 0.6\times 210 + 0.85\times 720 = 126 + 612 = 738\ \text{kW}$$

计入车载充电机 $\cos\varphi_{EV}=0.95$：

$$S_{EV} = \frac{738}{0.95} = 777\ \text{kVA}$$

### 7.3 变压器选择与校验

若并入建筑主变：$S_{total}=495.6+777=1272.6$ kVA，超 2×630 = 1260 kVA 上限 → **必须独立变压器**。

新增 1×1000 kVA 干变（Dyn11，$u_k=6\%$）专供充电站，负载率 $\beta=777/1000=77.7\%$ ✓。

谐波校核（[TH-008](../10-theory/TH-008-harmonic-generation.md) 法）：6 脉波整流，主要 5/7 次谐波。单台 120 kW 整流器 $I_N=120/(\sqrt3\times 0.4\times 0.95)=182$ A，5 次谐波 $I_5=I_N/5=36$ A。6 台叠加 $I_{5,total}=6\times 36\times 0.8$（同时系数）= 173 A。

短路容量 $S_{sc}=\sqrt3\times 0.4\times 23300=16.13$ MVA（同 [CALC-MS-001 §7.2](../40-calc/CALC-MS-001-motor-starting-voltage-drop.md)），5 次谐波电压畸变率：

$$V_5\% = \frac{\sqrt3\times h\, I_h\, U_n}{S_{sc}\times 10^3}\times 100\%$$

简化：$V_5\% = \frac{5\times 173}{23300}\times 100\%=3.71\%$（>4% THD 限值中单次 5 次的 4% 边界）。**临界，须装 APF 或加大变**。

按 K 因子法选变：$K=\sum I_h^2 h^2/(\sum I_h^2)$，6 脉波主要 5/7/11 次，$K\approx 4.5$，选 K=6 干变。

### 7.4 保护配置

- 进线：ACB 1600A，三段保护（长延时 1600A/0.1s、短延时 4800A/0.4s、瞬动 12.6kA 带 0.1s 延时躲励磁涌流）
- 慢充回路（30 个 7kW 桩，按 5 桩一组 6 回路）：每组 $I_N=5\times 32=160$ A，配 MCB 250A B 型 RCD（30mA 剩余电流）
- 快充回路（6 个 120kW 桩）：每桩 $I_N=182$ A，配 Moulded Case 250A B 型 RCD（30mA 剩余电流）
- 总进线剩余电流监测（剩余电流继电器 1A 报警不跳闸）

### 7.5 消防配置

- 充电站设于地下车库独立防火分区（GB/T 51313-2018），与建筑其他防火分区用 2h 防火墙分隔
- 自动火灾报警（感烟 + 感温），与充电系统急停联动
- 配置磷酸铵盐干粉灭火器（5kg × 8 具，按 4A 电气火灾）
- 充电桩外壳纳入建筑等电位联结（LEB，详见 [PR-GR-002](PR-GR-002-earthing-arrangement.md)）

### 7.6 接地与防雷

- 接地制式 TN-S，PE 线与 N 线在变压器中性点处一点接地后严格分开
- 充电桩外壳通过 PE 线接到变压器中性点接地（共用接地装置 $R\le 4$ Ω）
- 室外充电站设独立接闪杆，与桩距离 ≥ 3m

### 7.7 结论

- 独立 1×1000 kVA 变（K=6）专供，**不并入建筑主变**
- 谐波临界超标，须装 APF（120A 额定）或预留动态扩容
- 全部回路 B 型 RCD（30mA），总进线剩余电流监测报警
- 车库内按防火分区单独配电 + 自动火灾报警联动急停
