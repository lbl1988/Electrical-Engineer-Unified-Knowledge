# 分布式电源接入配电网设计（光伏/风电/微燃机）

## 1. 摘要

DG 接入＝**承载力评估 → 并网点与电压等级选择 → 逆变器选型 → 保护与控制配置 → 电能质量校核 → 孤岛防护**六步。本条给出光伏/风电/微燃机接入矩阵、承载力快速校核公式（衔接 [TH-041](../10-theory/TH-041-distribution-grid-high-penetration-dg-hosting-capacity.md)）、LVRT/HVRT 穿越要求、孤岛检测方案选择；算例为 2MW 光伏 10kV 并网完整设计。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 并网点 PCC | DG 与电网的产权分界点 | GB/T 33593 |
| 承载力 | 配电网接纳 DG 的最大容量 | GB/T 40567 |
| LVRT | 低电压穿越（故障期间不脱网） | GB/T 19964/19963 |
| HVRT | 高电压穿越（过压期间不脱网） | GB/T 19964-2024 新增 |
| 逆功率 | DG 倒送功率至上级电网 | GB/T 36121 |
| 孤岛 | 电网失电后 DG 继续供本地负荷的非计划运行 | GB/T 33593 |

## 3. 原理与公式

### 3.1 接入电压等级选择

| DG 容量 | 接入电压等级 | 接入方式 |
|---|---|---|
| $\le8$kW（单相） | 220/380V | 户用并网 |
| $8\sim400$kW | 380V | 三相并网 |
| $400\,\text{kW}\sim6$MW | 10kV | T 接或专线 |
| $6\sim50$MW | 35kV | 专线 |
| $>50$MW | 110kV 及以上 | 专线+独立升压站 |

### 3.2 承载力快速校核

**静态电压承载力**（见 [TH-041 §3.1](../10-theory/TH-041-distribution-grid-high-penetration-dg-hosting-capacity.md)）：

$$P_{DG,max}^U = \frac{(U_{max} - U_{i,0})\,U_N}{R_{i-source}}$$

**热稳定承载力**：

$$P_{DG,max}^{thermal} = \min(S_{line}, S_{trx}) - P_{load,min}$$

| 约束 | 10kV 馈线 8km | 承载力 |
|---|---|---|
| 电压（末端） | $R=0.5$Ω, $\Delta U=7\%$ | 1.4 MW |
| 热稳定（LGJ-185） | $S_{line}=8.7$MVA | 8.7 MW |
| 逆功率（不倒送） | $P_{load,min}=1$MW | 1.0 MW |

### 3.3 LVRT 要求（GB/T 19964-2024）

| 电压跌落 $U/U_N$ | 最低持续并网时间 |
|---|---|
| 0 | 0.15s |
| 0.2 | 0.65s |
| 0.5 | 1.5s |
| 0.9 | 5s |

无功支撑（故障期间）：

$$I_Q \ge 1.5\left(1-\frac{U}{U_N}\right)I_N$$

### 3.4 孤岛检测方案

| 方案 | 检测原理 | 响应时间 | 检测盲区（NDZ） |
|---|---|---|---|
| 被动（电压/频率） | 监测 U/f 越限 | 0.1~2s | 功率匹配时盲区大 |
| 主动频率偏移（AFD） | 注入畸变电流致频率偏移 | 0.5~1s | 小 |
| 主动移频移相（SMS） | 正反馈致频率不稳定 | 0.3~1s | 小 |
| 电网阻抗法 | 注入扰动测阻抗变化 | <0.5s | 几乎无 |

## 5. 设计/选型要点（校审清单）

- [ ] 接入电压等级：按容量选择（见 §3.1 矩阵）
- [ ] 承载力校核：电压/热稳定/逆功率三约束取最小值
- [ ] 逆变器选型：有功/无功控制、LVRT/HVRT 达标、型式试验认证
- [ ] 功率因数：$\cos\varphi=0.95$（超前）/0.98（滞后），可调无功支持
- [ ] 保护配置：并网点过流/欠压/过压/频率异常/孤岛检测
- [ ] 孤岛检测：被动+主动双重检测（大容量必须主动）
- [ ] 防孤岛保护：DG 侧与电网侧双重配置
- [ ] 逆功率保护：不允许倒送时配逆功率继电器
- [ ] 升压变选型：干式（室内）/油浸（室外），Dyn11 接线
- [ ] 电能质量：谐波注入 $\le$ GB/T 14549 限值，闪变 $\le$ GB/T 12326 限值
- [ ] 通信：RS485/光纤至调度（容量 $\ge250$kW 需远程监控）

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 容量超承载力 | 电压越限/设备过载 | 先做承载力评估 | GB/T 40567 |
| 逆变器 LVRT 不达标 | 故障脱网扩大事故 | 选 GB/T 19964-2024 认证产品 | GB/T 19964 |
| 孤岛检测失效 | 检修触电 | 被动+主动双重检测 | GB/T 33593 |
| 逆功率未配保护 | 倒送上级电网受罚 | 逆功率继电器+限功率运行 | GB/T 36121 |
| 保护无方向元件 | DG 侧故障误动主网侧 | 加方向元件 | TH-030 |
| 谐波注入超标 | 电能质量不合格 | 逆变器谐波认证+实测校核 | GB/T 14549 |
| 升压变接线不当（Yyn0） | 零序通路不对称、损耗 | Dyn11（零序低阻/防偏磁） | GB/T 6451 |

## 7. 完整算例（2MW 光伏 10kV 并网）

### 7.1 已知

光伏阵列 2MW，逆变器 2×1MW（三相），并网点 PCC 10kV 馈线 8km（LGJ-185），$R=0.5$Ω。末端最小负荷 1MW。最大负荷时电压 $U_{i,0}=9.8$kV。

### 7.2 承载力校核

**电压约束**：$P_{DG,max}^U = 0.07\times10000\times10000/0.5 = 1.4$MW

2MW > 1.4MW → **电压约束不满足**

解决方案：
- 配置 SVG 500kvar 无功支撑（升压效果）
- 部分负荷就地消纳（不外送）

**热稳定约束**：$P_{DG,max}^{thermal} = 8.7 - 1.0 = 7.7$MW ✓

**逆功率约束**：$P_{DG} \le P_{load,min} = 1$MW（不倒送）→ 配逆功率继电器限功率

### 7.3 逆变器选型

- 2 台 1MW 集中式逆变器，LVRT GB/T 19964-2024 达标
- 功率因数可调 $\pm0.95$，无功支撑 $I_Q\ge1.5(1-U/U_N)I_N$
- 孤岛检测：被动（U/f）+主动（AFD）双重

### 7.4 保护配置

- PCC 处：过流（1.3$I_N$）/欠压（0.7$U_N$, 2s）/过压（1.1$U_N$ 瞬时）/频率（49.5~50.2Hz）
- 孤岛：双重检测，检测时间 <2s
- 逆功率：1MW 限功率运行（不倒送）

### 7.5 升压变

2台 1250kVA，10kV/0.4kV，Dyn11，干式（室内）。
