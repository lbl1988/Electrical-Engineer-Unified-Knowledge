# 电能质量监测系统设计与治理评估

## 1. 摘要

电能质量监测＝**指标体系建立 → 监测点选择 → 设备选型 → 通信组网 → 评估与治理闭环**五步。本条给出 PQI 六项指标（频率/电压偏差/波动闪变/谐波/三相不平衡/暂态）的监测矩阵、A 级/B 级/S 级监测设备选择、PCC 监测点布局原则；算例为工业用户 PCC 处 A 级监测配置与超标评估流程，衔接 [PR-PQ-001](PR-PQ-001-pq-compensation-design.md) 治理设计。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| PQI | 电能质量指标（Power Quality Index） | GB/T 19862 |
| PCC | 公共连接点 | GB/T 14549 |
| THD | 总谐波畸变率（以基波为基准） | GB/T 14549 |
| $P_{st}/P_{lt}$ | 短期/长期闪变严重度（10min/2h） | GB/T 12326 |
| $\epsilon$（不平衡度） | 负序有效值与正序有效值之比 | GB/T 15543 |
| A/B/S 级 | 监测设备等级（A=合同/溯源, B=统计, S=专项） | GB/T 19862 |

## 3. 原理与公式

### 3.1 六项 PQI 限值与监测周期

| 指标 | 限值 | 测量周期 | 评估方法 |
|---|---|---|---|
| 频率偏差 | ±0.2 Hz（≤200MW）/ ±0.5 Hz | 10s | 95% 概率值 |
| 电压偏差 | 35kV +7%/-3%, 10kV ±7%, 380V ±7% | 10min | 95% 概率 |
| 谐波 THD | 10kV 4%, 380V 5%（查 GB/T 14549） | 3s（200ms 窗） | 95% 概率（取 10min 集合） |
| 闪变 $P_{st}$ | $P_{lt}\le1.0$（10kV/35kV），≤1.3（380V） | 10min（$P_{st}$）/ 2h（$P_{lt}$） | 长期 95% |
| 三相不平衡 $\epsilon$ | 10kV/35kV 2%, 380V 4% | 10min | 95% 概率 |
| 暂态（过电压/骤降） | 无固定限值（事件触发记录） | 半周波~1min | 事件记录 |

### 3.2 谐波评估

GB/T 14549 注入电流法（转述框架）：

$$I_{h,允许} = I_{h,基准}\left(\frac{S_i}{S_t}\right)^{1/\alpha}$$

$S_i$ 为用户协议容量，$S_t$ 为公共连接点供电总容量，$\alpha$ 为相位叠加系数（查表）。

### 3.3 不平衡度计算

负序电压不平衡度：

$$\epsilon_{U2} = \frac{U_2}{U_1}\times100\%$$

| 负荷特征 | 典型 $\epsilon$ | 治理需求 |
|---|---|---|
| 三相对称（集中电动机/照明） | <1% | 无 |
| 单相负荷均匀分配 | 1~2% | 无/轻 |
| 单相负荷集中（电焊/牵引） | 3~5% | 须平衡/SVG |
| 电弧炉/轧机 | 5~10% | 必须 SVG+平衡 |

### 3.4 监测设备等级

| 等级 | 用途 | 精度 | 通信 | 典型场景 |
|---|---|---|---|---|
| A 级 | 合同计量/仲裁 | 高（0.1%） | IEC 61850/MMS | PCC 变电所、争议点 |
| B 级 | 统计/趋势分析 | 中（0.5%） | Modbus/IEC 61850 | 用户侧、馈线 |
| S 级 | 专项测试/调试 | 高（0.1%） | 便携式/USB | 验收、故障诊断 |

## 5. 设计/选型要点（校审清单）

- [ ] PCC 监测点设置：用户产权分界处、主变低压侧、关键负荷馈线
- [ ] 监测等级：PCC 选 A 级；用户侧 B 级；验收/调试 S 级
- [ ] 监测指标全覆盖：六项 PQI + 事件录波（电压骤降/暂态过压）
- [ ] 通信：A 级 IEC 61850 MMS 上送主站；B 级 Modbus TCP
- [ ] 主站平台：PQ 专网/综合自动化平台，数据存档 $\ge$ 1 年
- [ ] 谐波超标评估：按 GB/T 14549 分配法校验用户注入
- [ ] 闪变评估：波动负荷（电焊机/轧机/电弧炉）按 $P_{st}/P_{lt}$ 校验
- [ ] 不平衡评估：单相负荷集中时按 $\epsilon$ 校验并做相序平衡/ SVG 分相补偿
- [ ] 事件触发录波：电压骤降（>10% $U_N$, 半周波以上）自动记录
- [ ] 治理闭环：超标 → 源头识别 → 治理方案（见 [PR-PQ-001](PR-PQ-001-pq-compensation-design.md)）→ 复测归档

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 只装 B 级做 PCC 合同计量 | 精度不够、争议难仲裁 | PCC 用 A 级设备 | GB/T 19862 |
| 谐波只测电压畸变 | 未校注入电流是否合规 | 电压畸变+注入电流双校 | GB/T 14549 |
| 闪变限值不分等级套用 | 小容量用户过严或大容量过松 | 按电压等级和短路容量查表 | GB/T 12326 |
| 单相负荷集中相分配不均 | 三相不平衡超标 | 设计阶段相序平衡+SVG 分相补偿 | GB/T 15543 |
| 监测数据无归档 | 趋势分析/争议举证失效 | 存档 ≥1 年+定期报告 | GB/T 19862 |
| 事件录波未配置 | 骤降/暂态无记录 | 配半周波事件触发录波 | GB/T 19862 |

## 7. 完整算例（工业用户 PCC 监测）

### 7.1 背景

某工厂 10kV 专线供电，协议容量 $S_i=8$MVA，PCC 短路容量 $S_{sc}=100$MVA。负荷含变频器群（6 脉冲）+电焊机+单相加热器。

### 7.2 监测配置

- PCC 变电所 10kV 母线：A 级监测设备 1 套（IEC 61850 通信）
- 变频器群馈线：B 级设备（谐波源头定位）
- 电焊机馈线：B 级设备（闪变/不平衡源头定位）

### 7.3 谐波评估

协议容量比 $S_i/S_t=8/100=8\%$，查 GB/T 14549 表（10kV，5 次谐波）基准值 $I_{5,基准}=20$A，叠加系数 $\alpha=1.4$：

$$I_{5,允许}=20\times\left(\frac{8}{100}\right)^{1/1.4}=20\times0.128=2.56\,\text{A}$$

实测 $I_5=3.2$A → 超标（1.25 倍）→ 治理方案：变频器群加 5 次调谐滤波器或 APF（→ [PR-PQ-001 §7.2](PR-PQ-001-pq-compensation-design.md)）。

### 7.4 不平衡评估

单相加热器 200kW 接于 AB 相，10kV 侧 $\epsilon$ 实测 3.2% > 2% 限值 → 需相序重新分配或加装分相 SVG。
