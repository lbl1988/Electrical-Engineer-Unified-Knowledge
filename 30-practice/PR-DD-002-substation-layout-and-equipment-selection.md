# 10/0.4kV 变配电所布置与设备选型

## 1. 摘要

变配电所设计＝**所址选择 → 变压器容量与台数 → 平面布置与安全净距 → 一次设备选型**四步。本条给出 10/0.4kV 室内变电所（2×630kVA）的完整布置方案：利用综合办公楼地下室一层，给出变压器室与高低压配电室分隔、安全净距校验、ACB/MCCB 母线选型与 [PR-DD-001](PR-DD-001-lv-breaker-selection.md) 断路器选型联动；算例引用 [LD-001](../40-calc/CALC-LD-001-demand-factor-method.md) 负荷数据、[SC-001](../40-calc/CALC-SC-001-低压三相短路电流计算.md) 短路数据和 [RC-001](../40-calc/CALC-RC-001-reactive-compensation.md) 无功补偿参数形成设计闭环。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 安全净距 | 不同电位裸带电体间、带电体与接地体间最小空气间距 | GB 50060 表 5.1.2（A1/A2/B1/B2/C/E 值） |
| 变压器室通风口 | 保证自然通风散热的最小进风口/出风口面积 | GB 50053 §4.6 |
| 母线 | 汇聚电能的主导体（硬母线铜/铝排） | DL/T 5222 第 6 章 |
| 配电装置分相布置 | 各相母线/设备按相序分列排列以减少相间短路概率 | GB 50060 §5.4 |

## 3. 原理与公式（设计决策树）

```
第1步 所址选择：
  ├─ 负荷中心附近，半径≤200m 经济供电范围
  ├─ 不设在厕所/浴室/厨房正下方（防渗漏）
  ├─ 不设于爆炸危险区域（GB 50058 §3.2）
  └─ 宜设于地下室一层或地上一层，避免积水

第2步 变压器容量与台数：
  ├─ S_rT ≥ S_30（计算负荷），并计及无功补偿后
  │    本工程 S_30=495.6kVA → 单台 S_rT=630kVA ✓
  ├─ 台数：2 台（互为备用，满足一二级负荷）
  ├─ 阻抗：uk=6%（1000kVA 以下标准值）
  └─ 联结组别：Dyn11（低压单相不平衡负荷适应性好）

第3步 平面布置（GB 50053/GB 50060）：
  ├─ 变压器室与高压室/低压室分室设置
  ├─ 安全净距校验（见 §7.1）
  ├─ 变压器至后墙/侧墙 ≥0.6m（干式）/ ≥0.8m（油浸）
  ├─ 通风：进风口面积 ≥ 变压器占地投影面积×0.3（以正式文本为准）
  └─ 油浸变压器设储油坑+挡油设施（≥20%油量）

第4步 一次设备选型：
  ├─ 高压开关柜：10kV KYN28 中置柜（真空断路器 VC）
  ├─ 变压器：SCB13 干式 630kVA（Dyn11, uk=6%）
  │    干式选型：建筑内禁止油浸（GB 50053 §3.3 + 防火要求）
  ├─ 低压主进线：ACB 框架 2000A, Icu=50kA
  │    详见 [PR-DD-001](PR-DD-001-lv-breaker-selection.md) §7 选型结果
  └─ 母线：TMY-3×(100×10)+1×(60×6) 铜排（校验见 §7.2）
```

## 5. 设计/选型要点（校审清单）

- [ ] 变压器室净距：前后操作通道 ≥1.0m（千式）/ ≥1.2m（油浸门向外开）
- [ ] 高压柜前操作通道 ≥柜宽（双列面对面布置 ≥双列柜宽＋0.6m）
- [ ] 安全净距：10kV 裸带电体至接地体 A1=125mm、至网状遮栏 B1=175mm
- [ ] 低压母线截面校验：$I_{cu}$ 母线额定峰值耐受 ≥ $i_p$（联动 [SC-001](../40-calc/CALC-SC-001-低压三相短路电流计算.md)）
- [ ] 干式变压器选 SCB13（损耗满足 GB 20052-2024 能效标准）——[交接报告 §7](../90-governance/HANDOVER-交接报告.md) 决策记录
- [ ] 接地：变压器中性点直接接地（TN-S 系统），见 [PR-GR-002](PR-GR-002-earthing-arrangement.md)
- [ ] 通风：夏季进风温度 ≤35°C，排风经独立竖井，不与其他空调回风混用
- [ ] 通道无遮挡物，检修门钥匙统一管理，安全标识完备

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 建筑内用油浸变压器 | 防火分区不符、储油坑占用大 | 干式 SCB13（损耗达标+无油） | GB 50053 §3.3 |
| 安全净距按 35kV 取值 | 10kV 装置取值过大浪费空间 | 按实际电压等级查 GB 50060 表 5.1.2 | GB 50060 |
| 母线只校载流量不校动热稳定 | 短路时母排变形/触头斥开 | $i_p$ 校峰值耐受（联动 [SC-001](../40-calc/CALC-SC-001-低压三相短路电流计算.md) $i_p$=53.6kA） | DL/T 5222 |
| 变压器室通风不足 | 绕组温升超限、寿命缩短 | 进风面积按 GB 50053 §4.5 核算，必要时加机械排风 | GB 50053 |
| 未考虑 GB 55024 特级负荷三独立电源 | 特级负荷供电可靠性不满足 | 设计前置检查负荷分级（联动 [PR-PS-001](PR-PS-001-load-classification.md)） | GB 55024 §4.1 |
| GB 20052-2024 能效未校核 | 选低效变压器不符现行能效标准 | SCB13 满足 GB 20052-2024（供配电考纲更新，见 [交接报告 §7](../90-governance/HANDOVER-交接报告.md)） | GB 20052-2024 |

## 7. 完整算例（综合办公楼 2×630kVA 变电所）

### 7.1 所址与平面布置

**建筑**：综合办公楼地下室一层（标高 -1.5m），净高 3.6m。

**变电所平面**（长×宽 = 12m × 8m = 96m²）：

| 区域 | 尺寸 (m) | 设备 |
|---|---|---|
| 高压配电室 | 5×4 | 10kV KYN28 中置柜×4（进线×2 + 计量 + PT/避雷器） |
| 变压器室×2 | 3.5×3 each | SCB13-630kVA 干式变压器 |
| 低压配电室 | 5×6 | LV 主配电柜 + 馈线柜 + 无功补偿柜 |

**安全净距校验**（GB 50060 表 5.1.2，10kV 等级）：

| 校验点 | 要求值 (mm) | 实际值 (mm) | 结果 |
|---|---|---|---|
| 带电体至接地体 (A1) | 125 | ≥150 | ✓ |
| 带电体至网状遮栏 (B1) | 175 | ≥200 | ✓ |
| 不同相带电体间 (A2) | 125 | ≥150 | ✓ |
| 带电体至板状遮栏 | 105 | ≥120 | ✓ |

**变压器室净距**（GB 50053 §4.2，630kVA 干式）：

| 校验点 | 要求值 (m) | 实际值 (m) | 结果 |
|---|---|---|---|
| 外廊至后墙/侧墙 | ≥0.6 | 0.8 | ✓ |
| 外廊至门 | ≥0.6 | 0.8 | ✓ |

### 7.2 低压母线选型

主进线母线 TMY-3×(100×10)+1×(60×6) 铜排（相排+N 排）：

| 参数 | 值 | 来源 |
|---|---|---|
| 额定载流量 | ~1800 A（35°C 空气） | 产品样本（以正式文本为准） |
| 负荷电流 $I_B$ | $I_{30} = \frac{S_{30}}{\sqrt{3} U_n} = \frac{495.6 \times 10^3}{\sqrt{3} \times 380} = 753$ A（单台变） | [LD-001](../40-calc/CALC-LD-001-demand-factor-method.md) |
| 载流量校验 | 1800 A ≥ 753 A ✓ 裕度 139% | — |
| 峰值耐受校验 | 母线 $I_{pk}$ ≥ $i_p = 53.6$ kA（联动 [SC-001](../40-calc/CALC-SC-001-低压三相短路电流计算.md) d1 点） | 选型时取母线 $I_{pk} = 65$ kA 档 ✓ |
| 短时耐受校验 | $I_{cw}$ (1s) ≥ $I_k'' = 23.3$ kA（同上） | 选 50 kA/1s 档 ✓ |

> 母线选型与 [PR-DD-001](PR-DD-001-lv-breaker-selection.md) ACB 选型联动：ACB 框架 2000A、$I_{cu} = 50$kA、$I_{cw} = 50$kA/1s、$I_{pk} = 105$kA，母线耐受值须 ≥ ACB 的耐受值。

### 7.3 无功补偿柜布置

[RC-001](../40-calc/CALC-RC-001-reactive-compensation.md) 确定补偿容量 $Q_C = 120$ kvar（6×20 kvar），布置在低压配电室：

- 补偿柜尺寸：800×600×2200mm（宽×深×高），2 台（每台 3×20kvar）
- 电容器选 480V 档（[RC-001](../40-calc/CALC-RC-001-reactive-compensation.md) §7 结论），串联 7% 电抗器防谐振
- 控制器采样 CT 装于变压器低压侧主进线，实现无功功率自动跟踪投切
