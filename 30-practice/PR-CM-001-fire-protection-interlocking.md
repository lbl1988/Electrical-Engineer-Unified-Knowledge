# 火灾自动报警与消防联动控制系统设计

## 1. 摘要

消防联动是火灾确认后自动启动应急照明、消防泵、防排烟、电梯迫降、防火卷帘、切除非消防电源、启动应急发电等动作的全流程。本条给出按 GB 50116-2013 与 GB 55037-2022 设计的**系统形式选择、联动逻辑表、时序配合、双回路+应急电源配置**，并对接 [PR-BE-001](PR-BE-001-emergency-lighting.md) 与 [CALC-DG-001](../40-calc/CALC-DG-001-diesel-generator-capacity.md) 给出综合办公楼联动方案。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 区域/集中/控制中心报警系统 | 三种报警系统形式，按建筑规模与功能选择 | GB 50116 §2 |
| 联动控制器 | 接收报警信号、按预设逻辑输出控制指令的设备 | GB 50116 §5 |
| 手动/自动状态 | 联动控制盘可切换，避免误动作 | GB 50116 §5.1 |
| 火灾确认 | 任一探测器报警 + 手动按钮，或两个独立探测器报警 | GB 50116 §4 |
| 强制停止非消防电源 | 火灾确认后切除非消防负荷，给消防设备让出容量 | GB 55037 强制 |

## 3. 原理与公式（联动决策树）

### 3.1 系统形式选择

| 建筑类型 | 系统形式 |
|---|---|
| 单层 ≤ 1500m² | 区域报警系统 |
| 多层公共建筑 ≤ 50000m² | 集中报警系统 |
| 高层/超高层/大型综合体 | 控制中心报警系统（含多个集中报警） |

### 3.2 联动动作逻辑表

```
火灾确认（两探测器或手报+探测器）
   │
   ├─→ 0~5s  ：应急照明强制点亮（[PR-BE-001] 5s 内进入点亮）
   │            疏散指示同步点亮、变向系统按预案切换
   │            非消防电梯迫降至首层
   │
   ├─→ 5~15s ：启动防排烟风机（防火分区对应）
   │            关闭空调系统、防火阀联动
   │            切除非消防电源（按防火分区联动）
   │
   ├─→ 15~30s：启动消防泵（如压力开关触发，[CALC-DG-001] 软启动器介入）
   │            启动应急发电机（双电源失电时）
   │
   └─→ 持续 ：防火卷帘分两步降下（首降至 1.8m 让疏散、二步全降）
              广播系统启动、消防电话接通
```

### 3.3 控制回路与供电

| 项 | 要求 |
|---|---|
| 联动控制线 | 单独布线、与电力线分管/槽分开，阻燃耐火 |
| 消防设备供电 | 双电源末端切换（[PR-PS-001](PR-PS-001-load-classification.md)），最末一级配电箱设 ATS |
| 应急电源 | 柴油发电机 + 蓄电池（双失电场景，详见 [CALC-DG-001](../40-calc/CALC-DG-001-diesel-generator-capacity.md)） |
| 线缆耐火 | 消防设备供电回路用 WDZN-YJY 或 NH-YJV，耐火时间 ≥ 90min |

## 5. 设计/选型要点

- [ ] 报警系统形式按建筑规模选定，超高层建筑设控制中心报警系统
- [ ] 联动逻辑表与消防预案、防火分区一致，可变向疏散指示按预案联动
- [ ] 切除非消防电源应**按防火分区**分步切除，避免一区故障影响全楼
- [ ] 消防泵、防排烟风机须双电源末端切换，且双电源来自不同变电所或柴发
- [ ] 电梯迫降、消防电梯专用：迫降至首层后消防电梯进入消防工作模式（含应急操作、专用钥匙）
- [ ] 防火卷帘控制：防火分区边界卷帘分两步降下；防火卷帘两侧设手动控制按钮
- [ ] 消防电话：消控室、消防泵房、变电所、电梯机房、各防火分区的电话插孔
- [ ] 消防广播：与正常广播切换；按建筑高度与功能选扬声器布置
- [ ] **校审高频问题**：只做报警不做联动、联动逻辑缺项、双电源切换点不在末端、消防线缆不阻燃耐火

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 集中报警系统未设联动控制器 | 仅报警不动作 | 集中及以上报警系统必含联动 | GB 50116 §5 |
| 联动逻辑与防火分区不一致 | 跨区误启动/漏启动 | 联动逻辑按防火分区逐区配置 | GB 50116 §5.2 |
| 非消防电源一刀切切除 | 大冲击负荷、影响疏散 | 按防火分区逐区切除，应急照明先点亮后切非消防 | GB 55037 |
| 应急电源切换点不在末端 | 配电线故障导致末端停电 | 消防设备末端配电箱设 ATS | GB 50016 §10 |
| 消防电梯迫降后未进入消防模式 | 疏散后无法应急使用 | 设置消防钥匙、迫降后切应急电源 | GB 50016 |
| 防火卷帘一步降到底 | 阻断疏散通道 | 疏散方向一步降至 1.8m + 延时二步全降 | GB 50116 |
| 消防电话与广播共线 | 应急时无法通讯 | 独立布线，泵房/电梯机房均设直通电话 | GB 50116 §6 |
| 联动控制盘未设手动/自动切换 | 误动作难阻止 | 设置明显手动/自动切换并加防护 | GB 50116 §5.1 |

## 7. 完整算例（综合办公楼消防联动方案）

### 7.1 建筑概况

- 综合办公楼，8 层，建筑高度 32m，建筑面积 8000m²，设消防控制室
- 按 GB 50116 选 **集中报警系统**（控制中心报警系统的简化形式）

### 7.2 火灾确认与 0~5s 动作

| 动作 | 设备 | 标准 |
|---|---|---|
| 应急照明强制点亮 | 全楼疏散照明、出口指示、方向标志 | GB 51309 §3 |
| 应急照明切换 | 集中电源/自带电源切换 | [PR-BE-001 §7.3](PR-BE-001-emergency-lighting.md) |
| 非消防电梯迫降 | 全楼普通电梯迫降至首层 | GB 50116 §5.4 |
| 防火卷帘一步降 | 防火分区边界卷帘降至 1.8m | GB 50116 §5.3 |

### 7.3 5~15s 动作

| 动作 | 设备 | 标准 |
|---|---|---|
| 启动防排烟风机 | 着火层及上下层的正压送风、排烟风机 | GB 50016 §9 |
| 关闭空调系统 | 切除空调、防火阀联动关闭 | GB 50116 §5.5 |
| 切除非消防电源 | 着火层及上下层非消防照明、动力 | GB 55037 |
| 广播启动 | 全楼应急广播切换 | GB 50116 §6 |

### 7.4 15~30s 动作

| 动作 | 设备 | 标准 |
|---|---|---|
| 消防泵启动 | 75kW 消防泵，配软启动器（[CALC-DG-001 §7.4](../40-calc/CALC-DG-001-diesel-generator-capacity.md)） | GB 50116 §5.7 |
| 应急发电机启动 | 市电失电时启动 312.5kW 机组 | GB 50052 §3 |
| 消防电梯进入应急模式 | 切应急电源、消防钥匙 | GB 50016 §8 |

### 7.5 30s 后持续动作

| 动作 | 设备 | 标准 |
|---|---|---|
| 防火卷帘二步降到底 | 延时 30~180s 后卷帘全降 | GB 50116 |
| 消防电话接通 | 消控室 ↔ 泵房、电梯机房、变电所 | GB 50116 §6 |

### 7.6 双回路+应急电源配置

```
10kV 进线（双路）─→ 10/0.4kV 主变（2×630kVA）
                       ├─→ 低压主母线 ─→ 非消防负荷
                       └─→ 消防专用母线（与主母线电气/物理隔离）
                               ├─→ 末端 ATS1（消防泵房）
                               │       ├─ 消防母线一路
                               │       └─ 柴发一路
                               ├─→ 末端 ATS2（电梯机房）
                               └─→ 末端 ATS3（消防控制室/应急照明）

柴发 312.5kW ─→ 应急母线 ─→ 各末端 ATS（双电源切换末端接入）
```

### 7.7 验收要点

- 火灾联动模拟试验：按预案预设火灾场景，逐动作核查时序
- 双电源末端切换试验：模拟一路市电失电，验证 ATS 切换 + 柴发启动 + 持续供电
- 双失电（市电+柴发同时停）试验：验证蓄电池持续（详见 [PR-BE-001 §7.3](PR-BE-001-emergency-lighting.md) 与 [CALC-BT-001](../40-calc/CALC-BT-001-battery-capacity.md)）
- 消防电话通话试验：消控室 ↔ 各点对讲通话
