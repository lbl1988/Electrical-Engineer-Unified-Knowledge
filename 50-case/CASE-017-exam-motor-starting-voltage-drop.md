# 2020供配电真题拆解：电动机启动压降校验与启动方式选择

## 1. 摘要

本案例拆解 2020 年注册电气工程师（供配电）执业资格考试"电动机启动压降校验"高频题型。某水厂 75kW 三相异步电动机直接接入 10/0.4kV、1000kVA（$u_k=6\%$）变电所低压母线，考四问：母线短路容量、直接启动压降校验、星-三角启动后压降复核、启动方式选择决策。教训：**电机启动压降是 GB 50055 强制校验项，须按"系统短路容量法"快速判定启动压降是否超限；启动方式按限值-转矩-经济性三步选优——直接启动不超限最优，超限首选降压启动（星-三角/软启动/变频），重载启动或转矩不足选变频软启动。**

## 2. 背景

### 2.1 真题题面摘要（2020 供配电，节选）

某水厂新建二级泵房，新增 1 台三相异步电动机（水泵负载，不频繁启动），数据如下：
- 电动机额定功率 $P_N$=75 kW，额定电压 380 V，$\cos\varphi_N$=0.85，$\eta_N$=0.92
- 启动电流倍数 $K_{st}$=6.5，启动转矩倍数 $T_{st}/T_N$=1.8
- 电动机接自变电所 0.4kV 低压母线（其他正常运行负荷 350kW，$\cos\varphi$=0.85）
- 变压器：10/0.4kV，$S_T$=1000kVA，$u_k$=6%，Dyn11
- 10kV 侧系统短路容量 $S_{s}$=200 MVA
- 启动压降限值按 GB 50055 不频繁启动 ≤15%

问题：（1）计算低压母线三相短路容量 $S_{sc}$；（2）校验直接启动时母线压降是否满足 GB 50055；（3）若改用星-三角启动，复核启动压降；（4）按 GB 50055 给出启动方式选择决策。

## 3. 方案（答题要点）

### 3.1 解题链路

```
电机额定容量 $S_M$ → 启动视在容量 $K_{st}S_M$
  → 母线短路容量 $S_{sc}$（系统+变压器阻抗串联）
  → 直接启动压降（系统短路容量法）
  → 星-三角启动压降（启动容量降至 1/3）
  → 启动方式决策（GB 50055 §2.3）
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $P_N$ | 电机额定功率 | 75 kW | 题给 |
| $\cos\varphi_N$ | 额定功率因数 | 0.85 | 题给 |
| $\eta_N$ | 额定效率 | 0.92 | 题给 |
| $K_{st}$ | 启动电流倍数 | 6.5 | 题给 |
| $S_T$ | 变压器额定容量 | 1000 kVA | 题给 |
| $u_k$ | 变压器阻抗电压 | 6% | 题给 |
| $S_s$ | 10kV 系统短路容量 | 200 MVA | 题给 |
| $\Delta U_{lim}$ | 启动压降限值 | 15% | GB 50055 §2.3 |

## 4. 计算

### 4.1 电机额定容量（引自 [TH-007](../10-theory/TH-007-induction-motor-starting.md) §3 启动容量推导）

电机额定输入视在容量：

$$S_M = \frac{P_N}{\cos\varphi_N\cdot\eta_N} = \frac{75}{0.85\times 0.92} = \frac{75}{0.782} = 95.9\ \text{kVA}$$

启动瞬间从系统抽取的视在容量（启动功率因数 $\cos\varphi_{st}\approx 0.3$，启动视在容量按启动电流倍数放大）：

$$S_{stM} = K_{st}\cdot S_M = 6.5\times 95.9 = 623.4\ \text{kVA}$$

### 4.2 低压母线短路容量 $S_{sc}$（引自 [CALC-MS-001](../40-calc/CALC-MS-001-motor-starting-voltage-drop.md) §3.3 母线短路容量推导）

系统侧与变压器侧短路容量串联叠加：

$$S_{sc} = \frac{1}{\dfrac{1}{S_s}+\dfrac{u_k\%}{100}\cdot\dfrac{1}{S_T}} = \frac{1}{\dfrac{1}{200}+\dfrac{6}{100}\cdot\dfrac{1}{1.0}} = \frac{1}{0.005+0.06} = \frac{1}{0.065} = 15.38\ \text{MVA}$$

| 符号 | 含义 | 取值 | 单位 |
|---|---|---|---|
| $S_s$ | 10kV 系统短路容量 | 200 | MVA |
| $S_T$ | 变压器容量 | 1.0 | MVA |
| $u_k\%$ | 阻抗电压百分数 | 6 | % |
| $S_{sc}$ | 0.4kV 母线短路容量 | 15.38 | MVA |

### 4.3 直接启动母线压降（系统短路容量法，引自 [CALC-MS-001](../40-calc/CALC-MS-001-motor-starting-voltage-drop.md) §3.1）

$$\Delta U_{st}\% = \frac{S_{stM}}{S_{sc}+S_{stM}}\times 100\% = \frac{623.4}{15380+623.4}\times 100\% = \frac{623.4}{16003.4}\times 100\% = 3.90\%$$

**校验**：$\Delta U_{st}\%$=3.90% < 15%（GB 50055 不频繁启动限值）✓ **直接启动满足标准要求**。

### 4.4 星-三角启动压降复核

星-三角启动将电机相电压降至 $1/\sqrt{3}$，启动电流降为 $1/3$，启动视在容量降至 $1/3$：

$$S_{stM,Y\Delta} = \frac{1}{3}\cdot S_{stM} = \frac{1}{3}\times 623.4 = 207.8\ \text{kVA}$$

$$\Delta U_{st,Y\Delta}\% = \frac{S_{stM,Y\Delta}}{S_{sc}+S_{stM,Y\Delta}}\times 100\% = \frac{207.8}{15380+207.8}\times 100\% = \frac{207.8}{15587.8}\times 100\% = 1.33\%$$

**校验**：$\Delta U_{st,Y\Delta}\%$=1.33% < 15% ✓，且启动转矩降至 $1/3\times 1.8T_N = 0.6T_N$，**水泵负载启动转矩须 > 静阻力矩**（一般水泵 0.3$T_N$），$0.6T_N$>0.3$T_N$ ✓，星-三角启动满足转矩要求。

### 4.5 启动方式决策（引自 [PR-DD-002](../30-practice/PR-DD-002-substation-layout-and-equipment-selection.md) §4 启动方式选型表）

按 GB 50055 §2.3 决策树：

| 校验项 | 直接启动 | 星-三角启动 |
|---|---|---|
| 启动压降 $\Delta U_{st}\%$ | 3.90% | 1.33% |
| 是否 ≤15% | ✓ | ✓ |
| 启动转矩（标幺） | 1.8 $T_N$ | 0.6 $T_N$ |
| 是否 > 启动静阻力矩 | ✓ | ✓ |
| 启动电流（额定电流倍数） | 6.5 | 2.17 |
| 接线/控制复杂性 | 低 | 中 |
| 经济性 | 最优 | 良 |

**决策**：直接启动压降仅 3.90%，远低于 GB 50055 不频繁启动 15% 限值，且启动转矩 1.8$T_N$ 富余，**首选直接启动**，无须采用降压启动。

### 4.6 同母线其他负荷电压跌落叠加校验（高频易错点）

题目给定同母线其他正常运行负荷 350kW、$\cos\varphi$=0.85，须叠加稳态压降（引自 [CALC-VL-001](../40-calc/CALC-VL-001-voltage-deviation-and-loss.md) §3.1 线路阻抗法）：

| 工况 | 容量 | 母线压降来源 | 叠加压降 |
|---|---|---|---|
| 稳态其他负荷 | 350kW（$\cos\varphi$=0.85） | 变压器内阻 | 约 2.3% |
| 电机启动尖峰 | +75kW×6.5=487.5kW | 启动容量冲击 | 3.9% |
| **叠加最大** | — | — | **6.2%** |

**校验**：6.2% < 15% ✓，且 < ±5%（GB 50052 一般用电设备端子偏差）→ **直接启动下母线设备端电压偏差不超标**，无须改降压启动。

## 5. 审查意见（命题陷阱与高频错误）

| 序号 | 命题陷阱 | 高频错误 | 正确做法 |
|---|---|---|---|
| 1 | 母线短路容量计算忽略系统侧阻抗 | $S_{sc}=S_T/u_k$ 直接得 16.67MVA（未扣系统阻抗） | 系统+变压器阻抗串联，$S_{sc}=\dfrac{1}{1/S_s+u_k\%/S_T}$ |
| 2 | 启动视在容量用 $K_{st}\times P_N$ | 95.9→487.5（误用 $P_N$ 不除效率功率因数） | $S_M=P_N/(\cos\varphi_N\eta_N)$，$S_{stM}=K_{st}S_M$ |
| 3 | 启动压降公式分母漏加 $S_{stM}$ | 直接 $\Delta U\%=S_{stM}/S_{sc}$ 得 4.05%（误差小） | 完整式 $\Delta U\%=S_{stM}/(S_{sc}+S_{stM})$ 得 3.90% |
| 4 | 星-三角启动容量降为 $1/\sqrt{3}$ 而非 $1/3$ | 压降算成 2.25%（错） | 电流降至 $1/\sqrt{3}$、相电压降至 $1/\sqrt{3}$，功率 $1/3$ |
| 5 | 启动转矩未校验 | 选了星-三角但转矩不足导致无法启动 | 须 $T_{st,Y\Delta}\ge$ 静阻力矩，水泵 0.3$T_N$ |
| 6 | 忽略启动方式选择 | 直接启动满足却选降压启动（过设计） | 满足限值+转矩，首选直接启动 |
| 7 | 稳态+启动压降未叠加 | 单看启动压降 3.9% 而忽略稳态 2.3% | 须叠加 GB 50052 ±5% 限值 |

## 6. 整改（典型解题规范）

### 6.1 解题规范

- 第（1）问必须用**系统+变压器阻抗串联**公式，标注单位统一（MVA）
- 第（2）问用**完整式** $\Delta U\%=\dfrac{S_{stM}}{S_{sc}+S_{stM}}\times100\%$，不用近似式
- 第（3）问星-三角启动容量降为 $1/3$，启动转矩同步降至 $1/3T_{st}$，**两步都要算**
- 第（4）问按 GB 50055 §2.3 决策树：限值-转矩-经济性三步，首选直接启动

### 6.2 答题模板

```
母线短路容量：$S_{sc}=\dfrac{1}{1/S_s+u_k\%/S_T}$=15.38MVA
启动视在容量：$S_{stM}=K_{st}\cdot S_M$=623.4kVA
直接启动压降：$\Delta U\%=\dfrac{S_{stM}}{S_{sc}+S_{stM}}$=3.90% < 15% ✓
星-三角启动：$S_{stM,Y\Delta}=S_{stM}/3$=207.8kVA，$\Delta U\%$=1.33% < 15% ✓，$T_{st,Y\Delta}$=0.6$T_N$>0.3$T_N$（水泵静阻） ✓
决策：直接启动满足 GB 50055，首选直接启动
```

## 7. 经验教训

- [ ] 母线短路容量须按系统+变压器阻抗**串联叠加**，单独用变压器 $S_T/u_k$ 会高估 8~10%
- [ ] 启动视在容量必须按 $S_M=P_N/(\cos\varphi_N\eta_N)\to K_{st}S_M$ 推导，**误用 $P_N$ 是高频错误**
- [ ] 启动压降完整式 $\Delta U\%=\dfrac{S_{stM}}{S_{sc}+S_{stM}}$ 分母含 $S_{stM}$，近似式仅当 $S_{stM}\ll S_{sc}$ 时用
- [ ] **星-三角启动容量降为 1/3**（不是 $1/\sqrt{3}$），电流、转矩均降至 1/3，启动转矩校验是隐藏考点
- [ ] **启动方式决策按 GB 50055 §2.3**：满足限值+转矩的首选直接启动，不超限不选降压；过设计也是错误
- [ ] **稳态压降+启动压降叠加**校验 GB 50052 ±5%，单看启动压降会漏判
