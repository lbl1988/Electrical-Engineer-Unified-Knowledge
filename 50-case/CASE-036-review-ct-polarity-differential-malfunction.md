# 校审驳回：变压器差动保护低压侧CT极性接反致空投误动

## 1. 摘要

某 35/10kV 变电所主变压器（SZ11-16000kVA）差动保护施工接线审查中发现：低压侧（10kV）A 相 CT 二次极性接反。正常负荷时差动电流 $I_{dA}=2I_{load,A}$ 远超整定 $I_{op}=0.4I_n$，空载投运时励磁涌流经反向 CT 叠加必然误动。校审驳回并要求整改：CT 极性试验 + 带负荷测差流 + 六角图验证。教训：**变压器差动保护投运前必须做 CT 极性试验（直流法/交流法）和带负荷六角图校验，任一相极性接反时 $I_d=2I_{load}$，正常负荷即满足跳闸条件。**

## 2. 背景

### 2.1 工程概况（脱敏）

某工业园 35/10kV 变电所（代号"某 SS 变"），主变压器 SZ11-16000kVA，35±3×2.5%/10.5kV，Dyn11，$u_k$=8%。配微机差动保护。

### 2.2 原接线审查发现

| 项 | 正确接线 | 原接线（错误） |
|---|---|---|
| 高压侧 CT | Y 型，P1 进 P2 出，S1 接保护正极 | 正确 |
| 低压侧 A 相 CT | Δ 型（或经软件补偿），P1 进 P2 出，S1 接保护正极 | **S2 接保护正极（极性反）** |
| 低压侧 B/C 相 CT | 同上 | 正确 |

### 2.3 保护整定

| 项 | 取值 | 说明 |
|---|---|---|
| 差动保护动作电流 $I_{op}$ | 0.4$I_n$=0.4×880=352A | 10kV 侧额定 $I_n$=880A |
| 二次谐波制动 | 15% | 防涌流误动 |
| CT 变比（高压） | 300/5 | 35kV 侧 |
| CT 变比（低压） | 1000/5 | 10kV 侧 |

### 2.4 后果

正常负荷 $I_{load}$=500A 时，A 相差动电流：

$$I_{dA}=I_{high,A}'+I_{low,A}'=500+500=1000\ \text{A}\gg 352\ \text{A}$$

差动保护在正常负荷时即满足动作条件，空载投运时涌流叠加更必误动。

## 3. 方案（校审复算要点）

### 3.1 审查链路

```
差动原理: Id = |I_high' - I_low'| (向量差)
  → 正常: Id ≈ 0 (仅不平衡电流 < 0.1In)
  → CT极性反: Id = |I_high' + I_low'| ≈ 2Iload
  → Id=1000A > Iop=352A → 正常负荷即跳闸
  → 空投涌流: 高压侧涌流经反向CT叠加 → 必然误动
  → 整改: CT极性试验+六角图
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $S_T$ | 变压器容量 | 16000 kVA | 铭牌 |
| $U_{n1}$ | 高压侧电压 | 35 kV | 铭牌 |
| $U_{n2}$ | 低压侧电压 | 10.5 kV | 铭牌 |
| $I_{n1}$ | 高压侧额定电流 | 264 A | $S/(\sqrt3 U)$ |
| $I_{n2}$ | 低压侧额定电流 | 880 A | $S/(\sqrt3 U)$ |
| $I_{op}$ | 差动动作电流 | 352 A | 0.4$I_{n2}$ |
| $I_{load}$ | 正常负荷电流 | 500 A | 设计 |
| $I_{inrush}$ | 励磁涌流 | 4~8$I_n$=3520~7040A | GB/T 14285 |

## 4. 计算

### 4.1 差动保护原理（引自 [TH-012](../10-theory/TH-012-protection-four-properties.md) §3 选择性 + GB/T 14285 §5.5）

正常运行时，归算至同一侧的高低压侧电流**大小相等、方向相反**：

$$\vec{I}_d = \vec{I}_{high}' + \vec{I}_{low}' = 0$$

（注：CT 接线使正常时 $\vec{I}_{high}' = -\vec{I}_{low}'$，和为零）

**不平衡电流**（正常范围）：

$$I_{unb}\leq(K_{er}+K_{st}+K_{tf})\times I_{load}=(0.10+0.05+0.05)\times 500=100\ \text{A}$$

$I_{unb}$=100A < $I_{op}$=352A → 正常不误动 ✓

### 4.2 CT 极性接反时的差动电流

A 相低压侧 CT 极性反 → $\vec{I}_{low,A}'$ 变号：

$$\vec{I}_{dA} = \vec{I}_{high,A}' + (-\vec{I}_{low,A}') = \vec{I}_{high,A}' + \vec{I}_{low,A}'$$

正常负荷（$I_{load}$=500A）：

$$I_{dA}=500+500=1000\ \text{A}$$

| 工况 | 正确接线 $I_d$ | 极性反 $I_d$ | 是否动作（$I_{op}$=352A） |
|---|---|---|---|
| 空载（$I_{load}$=0） | ≈0 | ≈0 | 否 |
| 25%负荷（220A） | 44A | 440A | **是** |
| 50%负荷（440A） | 88A | 880A | **是** |
| 100%负荷（880A） | 176A | 1760A | **是** |

**结论**：只要带负荷，极性反的相别差动电流即超标，保护误动。

### 4.3 空投涌流时的误动分析

变压器空载合闸，高压侧励磁涌流 $I_{inrush}$=5$I_n$=5×264=1320A（高压侧），归算至 10kV 侧：

$$I_{inrush,10}=1320\times\frac{35}{10.5}=4400\ \text{A}$$

极性反时，差动电流：

$$I_d=I_{inrush,10}+I_{inrush,10}\times K_{CT,error}$$

> 涌流仅在高压侧（低压侧空载无电流），但因极性反，涌流经差动回路时**不被抵消**，直接作为差动电流：

$$I_d=4400\ \text{A}\gg I_{op}=352\ \text{A}$$

**二次谐波制动**：涌流含 15~40% 二次谐波，若制动比 15% 且涌流二次谐波含量 30%，则制动力 $I_{res}$ 足够，可制动。但**极性反时涌流方向使差动电流增大**，二次谐波制动可能不足以完全制动，实际运行中多次发生空投误动。

| 涌流二次谐波含量 | 制动效果 | 是否误动 |
|---|---|---|
| 40% | 强制动 | 可能不误动 |
| 30% | 中等制动 | 临界 |
| 15% | 弱制动 | **必误动** |

### 4.4 整改：CT 极性校验方法（引自 GB 50150-2016 §7.1）

**方法一：直流法（干电池+指针表）**：

```
CT一次侧P1接电池正极、P2接负极
二次侧S1接直流表正极、S2接负极
接通瞬间指针正向偏转 → S1与P1同极性（正确）
接通瞬间指针反向偏转 → S1与P2同极性（接反）
```

**方法二：带负荷六角图（推荐，投运前必做）**：

通入负荷电流，测量各相差动电流的幅值和相位，绘制六角图：
- 正确接线：$I_d\approx 0$，各相电流相位差 120°
- 极性反：$I_d=2I_{load}$，故障相相位反 180°

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 低压侧 A 相 CT 二次极性接反 | GB 50150-2016 §7.1 | 正常负荷时差动电流 1000A > 整定 352A |
| 2 | 投运前未做 CT 极性试验 | GB 50150-2016 §7.1 | 极性错误未发现 |
| 3 | 未做带负荷六角图校验 | DL/T 587-2016 §6.2 | 差动回路接线错误无验证 |
| 4 | 仅做空载试验即投运 | 企业验收规程 | 空载时 $I_d$≈0，掩盖极性错误 |

## 6. 整改

### 6.1 接线整改

- 低压侧 A 相 CT 二次 S1/S2 对调，恢复正确极性
- 所有 CT 二次回路做绝缘测试（≥10MΩ）

### 6.2 试验补充

| 试验 | 标准 | 要求 |
|---|---|---|
| CT 极性试验（直流法） | GB 50150 §7.1 | 全部 CT 逐相测试 |
| 差动保护六角图 | DL/T 587 §6.2 | 带 ≥30% 负荷，$I_d$≤0.1$I_n$ |
| 差动保护整组试验 | GB 50150 §7.2 | 模拟内部/外部故障 |
| 涌流制动试验 | 厂商说明 | 空投 5 次不误动 |

### 6.3 验收规程强化

差动保护投运必须完成"三试验"：CT 极性试验 → 整组试验 → 带负荷六角图，缺一不可。

## 7. 经验教训

- [ ] **差动保护投运前必须做 CT 极性试验**（直流法逐相测试）
- [ ] **必须做带负荷六角图校验**，$I_d$≤0.1$I_n$ 才算合格；空载试验 $I_d$≈0 不能证明接线正确
- [ ] CT 极性反时 $I_d=2I_{load}$，正常负荷即满足跳闸条件
- [ ] 空投涌流时极性反会使涌流不被抵消，即使有二次谐波制动也可能误动
- [ ] 验收规程：极性试验 → 整组试验 → 六角图，三步缺一不可
