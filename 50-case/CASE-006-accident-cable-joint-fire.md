# 事故复盘：10kV电缆中间接头过热引发火灾

## 1. 摘要

本案例复盘某工业园区10kV电缆线路中间接头长期过热导致绝缘碳化、最终引燃电缆夹层可燃物的典型事故。直接原因为中间接头压接不良导致接触电阻随运行时间增大，接头温升超限后绝缘热击穿；间接原因为未配置电缆接头在线测温、继电保护仅配置三相过流未配零序/差动，故障切除滞后。教训：**电缆中间接头是电气-热耦合的薄弱节点，必须纳入红外测温周期巡检，单相接地保护应按 GB/T 14285 §4.0 配置零序保护实现选择性跳闸。**

## 2. 背景

某工业园区10kV专用供电线路，全长1.8 km，YJV22-8.7/15-3×240 mm² 交联聚乙烯电缆，线路中间设2处热缩式中间接头（投运3年）。线路所接负荷为某生产车间（一级负荷，双回路供电）。

事故经过（脱敏，引自调查报告）：
- T-30 d：电缆夹层烟感探测器偶发报警（误判为设备散热）
- T-7 d：值班员巡视发现配电柜有轻微焦糊味，未排查
- T 0：10kV开关柜速断保护动作跳闸，夹层电缆着火，消防喷淋启动灭火
- 事故损失：停电8小时，直接经济损失约120万元

## 3. 方案

### 3.1 原线路配置

| 项目 | 参数 |
|---|---|
| 电缆型号 | YJV22-8.7/15-3×240 mm² |
| 线路长度 | 1.8 km |
| 中间接头 | 2处热缩式接头（投运3年） |
| 保护配置 | 三相式电流速断 + 定时限过流 |
| 接地方式 | 中性点经消弧线圈接地 |
| 在线监测 | 无 |
| 巡检周期 | 外观巡视每季1次，无红外测温 |

### 3.2 事故现场勘查结论

- 着火点位于2号中间接头处，接头壳体已碳化，铜连接管压接面有电弧烧蚀痕迹
- 电缆夹层桥架防火封堵不完整（2处穿墙孔洞未封堵）
- 保护动作记录：先零序电压报警（3U0），后A相速断动作，时间间隔约18 s

## 4. 计算

### 4.1 接触电阻温升估算（引自 [TH-011](../10-theory/TH-011-switching-arc-physics.md) §3 接触电阻机理）

中间接头压接不良，接触电阻 $R_c$ 随运行时间因氧化/松动增大。稳态温升：

$$\Delta T = \frac{I^2 R_c}{\alpha\cdot A\cdot k}$$

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $I$ | 负荷电流（10kV侧） | 145 A | 运行记录 |
| $R_c$ | 接触电阻（事故前估算） | 0.015 Ω | 现场复测推算 |
| $\alpha$ | 综合散热系数 | 8 W/(m²·K) | 经验值 |
| $A$ | 接头等效散热面积 | 0.15 m² | 接头尺寸 |
| $k$ | 接触面积修正 | 1.0 | — |

$$\Delta T = \frac{145^2\times0.015}{8\times0.15\times1.0} = \frac{315.4}{1.2} = 262.8\ \text{K}$$

接头处稳态温升约263 K，**远超 XLPE 电缆长期允许工作温度90 ℃（环境40 ℃ + 温升50 K）**，铜连接管局部温度可达300 ℃以上，加速绝缘热老化。

### 4.2 单相接地故障电流（引自 [CALC-SC-002](../40-calc/CALC-SC-002-hv-short-circuit-iec60909.md) §5 单相接地）

中性点经消弧线圈接地系统，单相接地故障电流为残流：

$$I_{f} = \sqrt{(I_C - I_L)^2 + I_R^2}$$

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $I_C$ | 线路对地电容电流 | 18.6 A | 按电缆长度+截面计算 |
| $I_L$ | 消弧线圈补偿电感电流 | 17.2 A | 调档记录 |
| $I_R$ | 残流有功分量 | 4.5 A | 阻尼率估算 |

$$I_f = \sqrt{(18.6-17.2)^2 + 4.5^2} = \sqrt{1.96 + 20.25} = \sqrt{22.21} = 4.71\ \text{A}$$

单相接地故障电流仅4.71 A，**小于三相速断保护启动值**（按最大负荷1.2倍整定约174 A），故保护18 s后才由发展为相间短路时的A相速断动作。

### 4.3 保护配置校核（引自 [CALC-PT-001](../40-calc/CALC-PT-001-protection-setting.md) §4 零序保护整定）

按 GB/T 14285 §4.0，10 kV经消弧线圈接地系统应配置零序方向保护实现选择性跳闸，动作电流按躲过外部接地最大零序电流整定：

$$I_{0,set} = K_{rel}\times I_{0,max,external} = 1.2\times1.5 = 1.8\ \text{A}$$

灵敏度校验：$K_{sen}=I_f/I_{0,set}=4.71/1.8=2.6 > 1.5$ ✓，**应配置零序保护即可在故障初发阶段跳闸**，无需等待发展为相间短路。

## 5. 审查意见

| 序号 | 意见 / 结论 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 未配置电缆接头在线测温 | DL/T 1259 §3 | 接头过热长期未发现 |
| 2 | 未配置零序方向保护 | GB/T 14285 §4.0 | 单相接地故障18 s未切除 |
| 3 | 电缆夹层防火封堵不完整 | GB 50016 §10 / GB 51348 §7 | 火势沿桥架蔓延 |
| 4 | 红外测温未纳入巡检周期 | DL/T 1259 §5 | 接触电阻劣化未识别 |

## 6. 整改

### 6.1 电缆线路

- 2号中间接头更换为预制式中间接头（工厂预制，压接工艺受控）
- 1号接头同步更换（预防性维护）
- 加装电缆接头光纤测温系统，报警值65 ℃，跳闸值80 ℃

### 6.2 保护配置

- 三相式速断/过流保留，**新增零序方向保护**（动作值1.8 A，时限0.5 s）
- 配合消弧线圈自动调谐（自动跟踪电容电流）

### 6.3 防火

- 电缆夹层穿墙孔洞用防火堵料封堵（满足 GB 50016 §10 耐火极限1.0 h）
- 桥架涂刷电缆防火涂料（膨胀型），夹层设高灵敏感温电缆

### 6.4 运维

- 红外测温纳入季度巡检（重负荷/接头/连接处重点）
- 建立电缆接头档案（位置/型号/投运日/上次测温数据）

## 7. 经验教训

- [ ] 电缆中间接头是电气-热耦合薄弱节点，**必须纳入红外测温周期巡检**（DL/T 1259），重负荷与接头处为重点
- [ ] 经消弧线圈接地系统的10 kV线路**应配置零序方向保护**实现选择性跳闸（GB/T 14285 §4.0），三相速断不能覆盖单相接地故障
- [ ] 热缩式中间接头运行3年后接触电阻可能显著增大，预制式接头工艺受控、可靠性更高
- [ ] 电缆夹层防火封堵是火灾蔓延的最后一道防线（GB 50016 §10），穿墙孔洞必须完整封堵
- [ ] 烟感/焦糊味等早期征兆必须排查记录，不得误判为"设备散热"
