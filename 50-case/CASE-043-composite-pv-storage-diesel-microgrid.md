# 综合案例：光储柴微电网并离网切换多专业协同设计

## 1. 摘要

本案例以某海岛微电网（光伏 1MW/储能 2MWh/柴发 500kW×2/负荷 1.2MW）为载体，覆盖**并离网切换时序、储能 PCS 构网控制、柴发黑启动、光伏 LVRT、功率平衡与频率稳定、消防联动**六大专业接口。关键结论：离网切换须在 10ms 内由储能 PCS 接管（构网模式），柴发 15s 内启动接力；并网切换须先同频同相同幅再闭合 PCC 开关，冲击电流 ≤10%；光伏在离网模式下须切换为电压跟随。教训：**微电网并离网切换须电气-控制-消防联合设计，储能 PCS 须具备构网能力（Grid-Forming），切换过程中电压/频率波动须在 GB/T 12325 限值内（电压 ±7%、频率 ±0.2Hz）。**

## 2. 背景

### 2.1 工程概况（脱敏）

某海岛综合微电网（代号"某 ISL 微网"），保障岛上 2000 居民及通讯基站供电。

| 电源 | 容量 | 类型 |
|---|---|---|
| 光伏 | 1 MWp | 并网逆变器 |
| 储能 | 2 MWh (1MW/2h) | LFP 电池 + 构网型 PCS |
| 柴发 | 500kW × 2 | 柴油发电机组 |
| 负荷 | 1.2 MW（峰值） | 居民+商业+基站 |

### 2.2 运行模式

| 模式 | 条件 | 主电源 | 次电源 |
|---|---|---|---|
| 并网 | 市电正常 | 市电 | 光伏+储能+柴发备用 |
| 离网 | 市电失电 | 储能PCS(构网) | 柴发+光伏 |
| 黑启动 | 全停 | 储能PCS | 柴发→光伏 |

### 2.3 多专业接口图

```
电气专业                  控制专业              消防专业
  │ PCC开关/PCS选型      │ 并离网切换逻辑       │ 储能消防
  │ 短路电流/保护        │ 构网vs跟网          │ 气体灭火联动
  │ 柴发容量             │ 频率/电压控制        │ 切柴发
  ├───────────────────────┼────────────────────┤
  │ 结构专业              │ 通信专业            │ 暖通专业
  │ 储能舱布置            │ SCADA/通信延迟      │ 电池温控
  │ 柴发降噪             │ 切换指令传输         │ 柴发通风
```

## 3. 方案

### 3.1 系统拓扑

```
市电 ── PCC ── 10kV母线 ── 变压器(10/0.4) ── 0.4kV母线
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
    光伏1MW              储能1MW              柴发500kW×2
    (跟网逆变器)      (构网型PCS)           (黑启动电源)
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $P_{PV}$ | 光伏功率 | 1 MW | 设计 |
| $E_{BESS}$ | 储能容量 | 2 MWh | 设计 |
| $P_{BESS}$ | 储能功率 | 1 MW | 设计 |
| $P_{DG}$ | 柴发单台功率 | 500 kW | 设计 |
| $P_{load,peak}$ | 峰荷 | 1.2 MW | 设计 |
| $T_{switch}$ | 离网切换时间 | ≤10 ms | 设计 |
| $T_{DG,start}$ | 柴发启动时间 | ≤15 s | 厂家 |
| $U_{dev}$ | 电压偏差 | ≤±7% | GB/T 12325 |
| $f_{dev}$ | 频率偏差 | ≤±0.2Hz | GB/T 15945 |

## 4. 计算

### 4.1 离网切换功率平衡（引自 GB/T 36547-2024 §8 + [CALC-LD-001](../40-calc/CALC-LD-001-demand-factor-method.md)）

市电失电瞬间（$t=0$），光伏出力 $P_{PV}$=0.8MW，负荷 $P_{load}$=0.6MW：

**储能 PCS 须立即接管功率差额**：

$$P_{BESS}=P_{load}-P_{PV}=0.6-0.8=-0.2\ \text{MW}$$

负号表示储能充电。此时光伏 > 负荷，储能充电，**无需柴发启动**。

最严重工况（夜间，$P_{PV}$=0，$P_{load}$=1.0MW）：

$$P_{BESS}=P_{load}=1.0\ \text{MW}$$

储能满功率放电，同时发出柴发启动指令。

**储能续航时间**（1MW/2MWh）：

$$t_{BESS}=\frac{E}{P}=\frac{2}{1}=2\ \text{h}$$

> 远大于柴发启动时间 15s，柴发接力充裕。

### 4.2 并离网切换时序（引自 NB/T 10988-2022 §7 + GB/T 36547-2024 §8）

**离网切换时序**：

| 时间 | 动作 | 电压/频率 |
|---|---|---|
| $t=0$ | 检测市电失电（<0.5s） | 电压跌落 |
| $t=0.5$s | PCC 分闸 | 储能 PCS 切换构网模式 |
| $t=0.5\sim 0.51$s | PCS 建立电压 | $U=0.93\sim 1.07$ p.u. |
| $t=0.51$s | 光伏切换为电压跟随 | 锁相 PCS 输出 |
| $t=1$s | 柴发启动指令 | — |
| $t=15$s | 柴发建压合闸 | 并联运行 |
| $t=16$s | 功率分配（柴发 60%，储能 40%） | 稳定 |

**切换时间 10ms**（PCS 构网建压时间），满足 GB/T 36547 ≤100ms 要求。

### 4.3 并网切换（同期合闸）（引自 GB/T 29319-2012 + [TH-002](../10-theory/TH-002-phasor-analysis.md)）

市电恢复后，PCS 输出须与市电同期：

$$\Delta U\leq 10\%,\quad \Delta f\leq 0.2\text{Hz},\quad \Delta\delta\leq 10°$$

合闸冲击电流：

$$I_{sh}=\frac{\Delta U}{Z_{sys}+Z_{PCS}}$$

设 $\Delta U$=5%，$Z_{sys}=0.04$Ω，$Z_{PCS}=0.05$Ω：

$$I_{sh}=\frac{0.05\times 400}{0.04+0.05}=\frac{20}{0.09}=222\ \text{A}$$

额定电流 $I_n=1.2\times 10^3/(\sqrt3\times 0.4)=1732$A。

$$\frac{I_{sh}}{I_n}=\frac{222}{1732}=12.8\%$$

> 12.8% < 15%（限值），合格。若用选相合闸装置可降至 <5%。

### 4.4 构网型 PCS 控制（引自 GB/T 36547-2024 §6.3 + [TH-011](../10-theory/TH-011-synchronous-machine-subtransient-reactance.md)）

跟网型（Grid-Following）：依赖电网电压锁相，离网时无法独立运行。

构网型（Grid-Forming）：内置电压源，可独立建立电压/频率：

$$U_{PCS}=U_{ref},\quad f_{PCS}=f_{ref}$$

**虚拟同步机（VSG）控制**：

$$J\frac{d\omega}{dt}=P_m-P_e-D_p(\omega-\omega_0)$$

| 参数 | 取值 | 说明 |
|---|---|---|
| 虚拟惯量 $J$ | 15 kg·m² | 模拟同步机惯量 |
| 阻尼系数 $D_p$ | 500 N·m·s/rad | 抑制频率振荡 |
| 频率响应 | ≤2 Hz/s | 满足 GB/T 19963 |

### 4.5 柴发黑启动（引自 [CALC-DG-001](../40-calc/CALC-DG-001-diesel-generator-capacity.md)）

黑启动路径：储能 PCS 建立 0.4kV 母线 → 柴发启动电机由储能供电 → 柴发建压 → 并网 → 光伏启动。

柴发启动功率（启动电机 + 辅助）约 30kW，储能容量 1MW 完全满足。

### 4.6 消防联动（引自 GB 50016-2014 §10 + [PR-CM-001](../30-practice/PR-CM-001-fire-protection-interlocking.md)）

| 联动项 | 动作 | 时间 |
|---|---|---|
| 储能舱火灾报警 | 切 PCS 直流侧+交流侧断路器 | <1s |
| 七氟丙烷喷放 | 切全部电源 | 延时 30s |
| 柴发房火警 | 切柴发燃油阀+断输出 | <1s |
| 光伏火警 | 切直流汇流箱+逆变器 | <1s |

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 储能 PCS 选型为跟网型，无构网能力 | GB/T 36547-2024 §6.3 | 离网无法独立供电 |
| 2 | 未设离网切换时序与同期校验 | NB/T 10988-2022 §7 | 并网冲击电流超标 |
| 3 | 柴发黑启动电源未取自储能 | GB/T 51048-2025 §10 | 黑启动失败 |
| 4 | 储能舱消防未联动切 PCS | GB 50016 §10 | 火情时 PCS 持续放电 |

## 6. 整改

### 6.1 PCS 改为构网型

储能 PCS 更换为构网型（支持 VSG 控制），具备并离网无缝切换（≤10ms）。

### 6.2 切换控制

- 加装同期装置（自动检测 $\Delta U/\Delta f/\Delta\delta$）
- 离网切换：PCS 检测到 PCC 分闸后 <10ms 接管
- 并网切换：同期满足后闭合 PCC，冲击电流 <10%

### 6.3 黑启动

- 柴发启动电源由储能直流侧经 DC/DC 供电
- 配置黑启动按钮与 SCADA 自动流程

### 6.4 消防

- 储能舱：七氟丙烷 + 切 PCS 联动
- 柴发房：气体灭火 + 切燃油阀
- 联动试验纳入验收

## 7. 经验教训

- [ ] **微电网储能 PCS 必须用构网型**（Grid-Forming），跟网型无法离网运行
- [ ] **并离网切换 ≤10ms**，储能 PCS 构网建压
- [ ] **并网须同期校验**：$\Delta U\leq10\%$、$\Delta f\leq0.2$Hz、$\Delta\delta\leq10°$
- [ ] **柴发黑启动电源须取自储能**，否则黑启动失败
- [ ] 储能舱消防必须联动切 PCS 交直流侧
