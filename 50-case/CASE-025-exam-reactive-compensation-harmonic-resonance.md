# 2023供配电真题拆解：并联电容器无功补偿与谐波谐振校验

## 1. 摘要

本案例拆解 2023 年注册电气工程师（供配电）执业资格考试"10kV 工厂并联电容器无功补偿与谐波谐振校验"题型。某工厂 10kV 母线 P=1000kW、cosφ=0.80，要求补偿至 0.95，10kV 侧短路容量 25MVA，含大量变频驱动（VFD）产生 5 次/7 次谐波。考三问：补偿容量、谐振频率与放大倍数校验、串联电抗器选型。教训：**电容器组接入前必须校验并联谐振频率 $n_r=\sqrt{S_{cc}/Q_c}$，当 $n_r$ 接近特征谐波次数时须配串联电抗器将谐振点下移至 3.5~4.5 次以下，否则谐波放大数十倍致电压畸变超标。**

## 2. 背景

### 2.1 真题题面摘要（2023 供配电，节选）

某 10kV 工厂变电所，主要负荷为生产设备（含变频驱动），参数：
- 计算有功功率 $P_c$=1000 kW，补偿前 $\cos\varphi_1$=0.80
- 要求补偿后 $\cos\varphi_2$≥0.95
- 10kV 母线短路容量 $S_{cc}$=25 MVA
- VFD 约占总负荷 20%（200kW），6 脉冲整流，产生 5 次/7 次/11 次/13 次谐波电流

问题：（1）计算并联电容器补偿容量 $Q_c$；（2）校验电容器组接入后是否发生谐波谐振及放大倍数；（3）选择串联电抗器参数并说明理由。

## 3. 方案（答题要点）

### 3.1 解题链路

```
负荷功率+功率因数 → 补偿容量 Qc = P(tanφ1 - tanφ2)
  → 谐振频率 fr = fs·√(Scc/Qc) → 谐波次数 nr = fr/fs
  → 判断 nr 是否接近特征谐波（5/7/11/13）
  → 放大倍数 Kh = 1/|1-(h/nr)²|
  → 不达标 → 选串联电抗器 p% → nr' = 1/√p → 校验 nr' < 3.5
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $P_c$ | 计算有功功率 | 1000 kW | 题给 |
| $\cos\varphi_1$ | 补偿前功率因数 | 0.80 | 题给 |
| $\cos\varphi_2$ | 补偿后目标功率因数 | 0.95 | 题给 |
| $S_{cc}$ | 10kV 母线短路容量 | 25 MVA | 题给 |
| $f_s$ | 系统基波频率 | 50 Hz | 系统 |
| $h$ | 特征谐波次数 | 5/7/11/13 | VFD 整流 |

## 4. 计算

### 4.1 补偿容量计算（引自 [CALC-RC-001](../40-calc/CALC-RC-001-reactive-compensation.md) §3 功率因数法）

$$Q_c = P_c\,(\tan\varphi_1 - \tan\varphi_2)$$

$$\cos\varphi_1=0.80 \Rightarrow \tan\varphi_1=\frac{\sqrt{1-0.80^2}}{0.80}=\frac{0.60}{0.80}=0.750$$

$$\cos\varphi_2=0.95 \Rightarrow \tan\varphi_2=\frac{\sqrt{1-0.95^2}}{0.95}=\frac{0.312}{0.95}=0.329$$

$$Q_c = 1000\times(0.750-0.329)=1000\times 0.421=421\ \text{kvar}$$

按 GB 50227-2017 §3.2 选标准容量，取 **$Q_c$=500 kvar**（向上取整至标准规格，GB/T 11024.1 序列），实际补偿后 $\cos\varphi_2$≈0.96。

### 4.2 谐振频率与谐波次数校验（引自 [TH-008](../10-theory/TH-008-harmonic-generation.md) §3.3 谐波谐振 + [CALC-HM-001](../40-calc/CALC-HM-001-harmonic-power-flow.md) §2 并联谐振）

**并联谐振频率**（电容器组与系统电感并联）：

$$f_r = f_s\sqrt{\frac{S_{cc}}{Q_c}}$$

$$n_r = \frac{f_r}{f_s} = \sqrt{\frac{S_{cc}}{Q_c}} = \sqrt{\frac{25}{0.5}} = \sqrt{50} = 7.07$$

$$f_r = 50 \times 7.07 = 353.6\ \text{Hz}$$

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $S_{cc}$ | 10kV 母线短路容量 | 25 MVA | 题给 |
| $Q_c$ | 电容器组容量 | 0.5 Mvar | §4.1 |
| $n_r$ | 谐振谐波次数 | 7.07 | GB/T 14549 附录C |
| $f_r$ | 谐振频率 | 353.6 Hz | $f_s\times n_r$ |

**判据**（GB/T 14549-1993 附录 C）：$n_r$=7.07，**接近 7 次特征谐波**（$|n_r-7|=0.07<0.5$），存在严重谐波放大风险。

### 4.3 谐波放大倍数计算

**7 次谐波放大倍数**（无串联电抗器，引自 GB/T 14549-1993 附录 C 式 C-5）：

$$K_7 = \frac{1}{\left|1 - \left(\frac{h}{n_r}\right)^2\right|} = \frac{1}{\left|1 - \left(\frac{7}{7.07}\right)^2\right|}$$

$$= \frac{1}{|1 - 0.980|} = \frac{1}{0.020} = 50$$

**7 次谐波电压畸变估算**：

VFD 注入 10kV 母线 7 次谐波电流 $I_7$：

$$I_1 = \frac{P_{VFD}}{\sqrt{3}\cdot U_n} = \frac{200}{\sqrt{3}\times 10} = 11.55\ \text{A}$$

$$I_7 \approx 14\%\times I_1 = 0.14 \times 11.55 = 1.62\ \text{A}$$

系统 7 次谐波阻抗（纯电感性）：

$$Z_{s,7} = 7 \times \frac{U_n^2}{S_{cc}} = 7 \times \frac{10^2}{25} = 7 \times 4 = 28\ \Omega$$

$$V_7 = K_7 \times I_7 \times Z_{s,7} = 50 \times 1.62 \times 28 = 2268\ \text{V}$$

$$\frac{V_7}{U_{n,phase}} = \frac{2268}{10000/\sqrt{3}} = \frac{2268}{5774} = 0.393 = 39.3\%$$

| 项 | GB/T 14549 限值（10kV） | 实际（无电抗器） | 是否达标 |
|---|---|---|---|
| 7 次谐波电压含有率 | ≤3.2% | **39.3%** | ✗ |
| 电压总畸变 THD | ≤4.0% | >40% | ✗ |

**结论**：无电抗器时 7 次谐波放大 50 倍，电压畸变远超 GB/T 14549 限值，**必须加装串联电抗器**。

### 4.4 串联电抗器选型（引自 GB 50227-2017 §5.6 + [PR-PQ-001](../30-practice/PR-PQ-001-pq-compensation-design.md) §5 串联电抗器）

串联电抗率 $p=X_L/X_C$ 将谐振频率下移：

$$n_r' = \frac{1}{\sqrt{p}}$$

| 电抗率 $p$ | 偏调谐频率 $n_r'$ | 适用场景 |
|---|---|---|
| 4.5% | 4.71 | 仅限制 5 次以上，但偏调不够深 |
| 5% | 4.47 | 限制 5 次以上，GB 50227 推荐 |
| 6% | 4.08 | 限制 5 次以上，部分场景 |
| 7% | 3.78 | 限制 3 次以上，**含 7 次谐波单独补偿** |
| 12%~14% | 2.67~2.89 | 限制 3 次谐波（电弧炉等） |

本案例含显著 7 次谐波，选 **$p$=7%**：

$$n_r' = \frac{1}{\sqrt{0.07}} = 3.78$$

$$f_r' = 50 \times 3.78 = 189\ \text{Hz}$$

偏调谐点 3.78 次，**低于 5 次**，7 次谐波处电容器-电抗器支路呈**感性**，不再参与并联谐振，放大倍数 $K_7'$→1（无放大）。

**电抗器额定参数**：

| 参数 | 计算值 | 说明 |
|---|---|---|
| 额定电压 | 10 kV | 与母线一致 |
| 额定电流 | $500/(\sqrt{3}\times 10)=28.9$ A | 电容器组额定电流 |
| 额定电抗 | $X_L=p\times X_C=0.07\times \frac{10^2}{0.5}=0.07\times 200=14\ \Omega$ | $X_C=U^2/Q_c$ |
| 额定容量 | $Q_L=p\times Q_c=0.07\times 500=35\ \text{kvar}$ | 串联电抗器容量 |

## 5. 审查意见（命题陷阱与高频错误）

| 序号 | 命题陷阱 | 高频错误 | 正确做法 |
|---|---|---|---|
| 1 | 补偿容量不取标准值 | 算出 421 kvar 直接用 | 按 GB/T 11024.1 向上取 500 kvar |
| 2 | 谐振校验漏算 $n_r$ | 只算 $f_r$ 不除以 $f_s$ | $n_r=\sqrt{S_{cc}/Q_c}$ 直接得谐波次数 |
| 3 | $n_r$ 接近判据不清 | $n_r$=7.07 认为不接近 7 次 | $|n_r - h| < 0.5$ 即视为接近（GB/T 14549 附录C） |
| 4 | 放大倍数公式用错 | $K_h=1/(1-h^2/n_r^2)$ 不取绝对值 | 取绝对值 $|1-(h/n_r)^2|$ |
| 5 | 电抗率选 5% 或 6% | 只看 5 次谐波，忽略 7 次 | 含 7 次谐波应选 7%，使偏调点 < 5 次 |
| 6 | 电抗器容量漏算 | $Q_L$=电抗率×电容器容量 | $Q_L = p \times Q_c$，不是 $p \times$ 额定电压电流 |

## 6. 整改（典型解题规范）

### 6.1 解题步骤

1. 补偿容量：$Q_c=P(\tan\varphi_1-\tan\varphi_2)$ → 取标准值 500 kvar
2. 谐振次数：$n_r=\sqrt{S_{cc}/Q_c}=\sqrt{25/0.5}=7.07$
3. 接近判据：$|7.07-7|=0.07<0.5$ → 7 次谐波谐振风险
4. 放大倍数：$K_7=1/|1-(7/7.07)^2|=1/0.02=50$
5. 电抗器选型：$p$=7% → $n_r'$=3.78 < 5 → 消除 7 次谐振

### 6.2 答题模板

```
Qc = 1000×(0.750-0.329) = 421 kvar → 取 500 kvar
nr = √(25/0.5) = √50 = 7.07，接近 7 次
K7 = 1/|1-(7/7.07)²| = 1/0.02 = 50 → 严重放大
选 7% 电抗器：nr' = 1/√0.07 = 3.78 < 5 → 消除谐振
电抗器容量：QL = 0.07×500 = 35 kvar
```

## 7. 经验教训

- [ ] **补偿容量须取标准规格**（GB/T 11024.1 序列），不得直接用计算值 421 kvar
- [ ] **谐振校验核心公式 $n_r=\sqrt{S_{cc}/Q_c}$**，先判次数再判频率，$|n_r-h|<0.5$ 即接近
- [ ] **放大倍数 $K_h=1/|1-(h/n_r)^2|$**，取绝对值；$n_r$ 恰等于 $h$ 时 $K_h→∞$（完全谐振）
- [ ] **含 7 次谐波选 7% 电抗率**，使偏调点 $n_r'$=3.78 低于 5 次；仅含 5 次可选 5%
- [ ] 电抗器容量 $Q_L=p\times Q_c$，不是 $p\times U_n\times I_n$
- [ ] GB/T 14549 限值：10kV 电压 THD ≤4%、单项谐波 ≤3.2%
