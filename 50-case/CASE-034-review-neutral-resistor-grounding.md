# 校审驳回：10kV系统中性点经小电阻接地电阻器选型不当

## 1. 摘要

某 10kV 配电系统由不接地改为经小电阻接地，设计选型 $R_N$=40Ω 接地电阻器。校审驳回两项问题：（1）电阻过大，单相接地故障电流仅 144A，远低于接地保护最小动作电流 300A，**接地保护灵敏度不满足**；（2）电阻器短时通流容量按 10s 选 200A，而接地后备保护动作时间 2s，通流裕度不足。整改：$R_N$=10Ω（$I_d$=577A），短时通流容量 600A/10s。教训：**小电阻接地 $R_N=U_n/(\sqrt{3}\cdot I_d)$，$I_d$ 须满足接地保护灵敏度（$K_{sen}\geq 1.5$）且不超过设备耐受，10kV 系统典型 $R_N$=10Ω、$I_d$=500~600A。**

## 2. 背景

### 2.1 工程概况（脱敏）

某城市配电网（代号"某 NG 电网"）10kV 系统因电缆比例达 85%，电容电流 $I_C$=180A，原不接地系统单相接地时电弧无法自熄，频发相间短路。改为经小电阻接地。

### 2.2 原设计参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 系统电压 | 10 kV | 线电压 |
| 接地方式 | 中性点经小电阻接地 | 经接地变压器 |
| 接地电阻 $R_N$ | **40 Ω** | 原设计选型 |
| 接地变压器 | ZN 型，100kVA | 引出中性点 |
| 接地保护 | 零序过流，$I_{set}$=300A, $t$=0.5s | 主保护 |
| 后备保护 | 零序过流，$I_{set}$=200A, $t$=2s | 后备 |
| 电阻器通流容量 | 200A / 10s | 厂家参数 |

### 2.3 问题暴露

模拟单相接地试验：故障电流 144A，接地保护（$I_{set}$=300A）不动作，后备（$I_{set}$=200A）也不动作，故障持续 10s 后上级电源跳闸。

## 3. 方案（校审复算要点）

### 3.1 审查链路

```
GB/T 50065 §3.2 小电阻接地 Id 取 400~1000A
  → RN = Un/(√3·Id)
  → 原设计 RN=40Ω → Id=10000/(√3×40)=144A < 300A(保护定值)
  → Ksen = 144/300 = 0.48 < 1.5 → 灵敏度不足
  → 整改: RN=10Ω → Id=577A → Ksen=577/300=1.92 ✓
  → 电阻器通流容量 ≥ Id×√(top/10)
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $U_n$ | 系统线电压 | 10 kV | 系统 |
| $I_d$ | 单相接地故障电流 | 设计目标 | GB/T 50065 |
| $R_N$ | 中性点接地电阻 | 选型 | 设计 |
| $I_{set}$ | 接地保护整定电流 | 300 A | 设计 |
| $t_{op}$ | 保护动作时间 | 0.5 s | 主保护 |
| $t_{backup}$ | 后备动作时间 | 2 s | 后备 |
| $K_{sen}$ | 灵敏度要求 | ≥1.5 | GB/T 14285 |

## 4. 计算

### 4.1 单相接地故障电流计算（引自 GB/T 50065-2011 §3.2 + IEEE C62.92.2）

经小电阻接地系统，单相接地故障电流（忽略系统阻抗，电阻接地为主）：

$$I_d=\frac{U_n}{\sqrt{3}\cdot R_N}$$

**原设计 $R_N$=40Ω**：

$$I_d=\frac{10}{\sqrt{3}\times 40}=\frac{10}{69.28}=0.144\ \text{kA}=144\ \text{A}$$

**整改 $R_N$=10Ω**：

$$I_d=\frac{10}{\sqrt{3}\times 10}=\frac{10}{17.32}=0.577\ \text{kA}=577\ \text{A}$$

### 4.2 接地保护灵敏度校验（引自 GB/T 14285-2023 §5.6 + [TH-012](../10-theory/TH-012-protection-four-properties.md) §3.1 灵敏系数）

$$K_{sen}=\frac{I_{d,min}}{I_{set}}$$

**原设计**：

$$K_{sen}=\frac{144}{300}=0.48$$

$K_{sen}$=0.48 < 1.5 → **不满足**。

**整改**：

$$K_{sen}=\frac{577}{300}=1.92$$

$K_{sen}$=1.92 ≥ 1.5 → **满足**。

| 方案 | $R_N$ | $I_d$ | $K_{sen}$ | 判定 |
|---|---|---|---|---|
| 原设计 | 40Ω | 144A | 0.48 | ✗ |
| 整改 | 10Ω | 577A | 1.92 | ✓ |

### 4.3 电阻器通流容量校核（引自 DL/T 5222-2021 §18.3）

电阻器短时通流容量按 $I_{rated}\times\sqrt{t_{rated}}$ 等效，须满足最大接地电流持续至后备保护跳闸：

$$I_{thermal}\geq I_d\times\sqrt{\frac{t_{backup}}{t_{rated}}}$$

**原设计**（200A/10s）：

$$I_{thermal,allow}=200\times\sqrt{\frac{10}{10}}=200\ \text{A}$$

$$I_d=144\ \text{A} < 200\ \text{A}$$

原设计通流容量看似满足（144<200），但这是因为 $R_N$ 过大导致 $I_d$ 过小——**不是通流容量够，而是故障电流太小保护不动作**。

**整改**（$R_N$=10Ω, $I_d$=577A, $t_{backup}$=2s）：

$$I_{thermal}\geq 577\times\sqrt{\frac{2}{10}}=577\times 0.447=258\ \text{A}$$

选 **600A/10s** 接地电阻器（通流容量 600A，裕度 $600/258=2.3$）。

| 项 | 原设计 | 整改 |
|---|---|---|
| $R_N$ | 40Ω | 10Ω |
| $I_d$ | 144A | 577A |
| 通流容量 | 200A/10s | 600A/10s |
| 裕度 | — | 2.3 |

### 4.4 接地变压器容量校核（引自 DL/T 5222-2021 §18.2）

接地变压器须持续承载 $I_d$ 直到保护跳闸（$t_{op}$=0.5s 主保护，$t_{backup}$=2s 后备）。

短时容量（按 $I^2 t$ 等效）：

$$S_{Z,\Delta}=\sqrt{3}\cdot U_n\cdot I_d\cdot\sqrt{\frac{t_{backup}}{10}}$$

$$=\sqrt{3}\times 10\times 0.577\times\sqrt{\frac{2}{10}}=10\times 0.577\times 0.447=2.58\ \text{MVA}$$

> 注：接地变压器按短时过载能力选择，持续容量按 10s 等效。原 100kVA 接地变压器**严重不足**（2.58MVA 需求 vs 0.1MVA 容量）。

**整改**：选 **1000kVA 接地变压器**（短时过载能力 2.5 倍，持续 10s 等效 2.5MVA，满足 2.58MVA 需求）。

### 4.5 跨步电压校核（引自 [TH-005](../10-theory/TH-005-touch-step-voltage.md) §3 + [CALC-GR-001](../40-calc/CALC-GR-001-grounding-grid-design.md) §3）

接地故障电流经接地网入地，跨步电压：

$$E_{step}=K_{step}\times I_d\times R_g$$

设 $R_g$=0.5Ω, $K_{step}$=0.15（10kV 变电所接地网，GB/T 50065）：

$$E_{step}=0.15\times 577\times 0.5=43.3\ \text{V}$$

| 项 | GB/T 50065 限值 | 计算值 | 判定 |
|---|---|---|---|
| 跨步电压 | ≤50V（10kV 变电所） | 43.3V | ✓ |
| 接触电压 | ≤70V | 需校验 | — |

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | $R_N$=40Ω 过大，$I_d$=144A < $I_{set}$=300A | GB/T 50065-2011 §3.2 | 接地保护拒动，故障扩大 |
| 2 | 接地保护灵敏度 $K_{sen}$=0.48 < 1.5 | GB/T 14285-2023 §5.6 | 接地故障无法切除 |
| 3 | 接地变压器 100kVA 远小于短时需求 2.58MVA | DL/T 5222-2021 §18.2 | 接地变压器烧毁 |
| 4 | 电阻器通流容量 200A 裕度不足（无故障电流放大空间） | DL/T 5222-2021 §18.3 | 电阻器烧毁 |

## 6. 整改

### 6.1 接地电阻器

| 项 | 原设计 | 整改 |
|---|---|---|
| 阻值 | 40Ω | **10Ω** |
| 通流容量 | 200A/10s | **600A/10s** |
| 故障电流 | 144A | 577A |
| 灵敏度 | 0.48 | 1.92 |

### 6.2 接地变压器

| 项 | 原设计 | 整改 |
|---|---|---|
| 容量 | 100kVA | **1000kVA**（短时过载 2.5 倍/10s） |
| 型式 | ZN 型 | ZN 型（曲折接线） |

### 6.3 保护整定配合

| 保护 | 原整定 | 整改整定 |
|---|---|---|
| 接地主保护 | $I_{set}$=300A, $t$=0.5s | $I_{set}$=250A, $t$=0.3s |
| 接地后备 | $I_{set}$=200A, $t$=2s | $I_{set}$=150A, $t$=1.0s |
| 灵敏度 | 0.48 | 2.31（主保护） |

## 7. 经验教训

- [ ] **小电阻接地 $R_N=U_n/(\sqrt{3}\cdot I_d)$**，$I_d$ 须 ≥ 保护定值 × 1.5（灵敏度要求）
- [ ] **10kV 系统典型 $R_N$=10Ω、$I_d$=500~600A**（GB/T 50065 推荐 400~1000A）
- [ ] **电阻过大的危害**：故障电流太小，接地保护拒动——比故障电流大更危险（大电流至少保护能动作）
- [ ] **接地变压器短时容量须按 $I^2 t$ 校核**，不能用持续容量直接套
- [ ] **电阻器通流容量须留裕度**（≥2 倍后备动作时间需求）
- [ ] 跨步电压须校核（$E_{step}=K_{step}\cdot I_d\cdot R_g$），确保 ≤50V
