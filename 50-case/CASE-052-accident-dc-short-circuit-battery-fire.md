# 事故复盘：变电站直流系统正极电缆短路致阀控铅酸蓄电池起火

## 1. 摘要

某 220kV 变电站直流系统：220V 阀控铅酸蓄电池组（108 只，2V/300Ah），正极馈电电缆在端子箱处因绝缘老化对地短路。蓄电池组内阻极低（约 0.05Ω/只×108=5.4Ω），短路电流 $I_{sc}=220/5.4\approx 40.7$A，直流断路器因**短路电流未达到瞬时脱扣值**（100A），熔断器（63A）在 3 秒后熔断，但短路电弧点燃端子箱内积尘与电缆绝缘层，火势蔓延至蓄电池室，烧毁蓄电池组 36 只，直流系统瘫痪 8 小时。教训：**直流系统短路电流虽小但持续时间长（秒级），能量 $W=I^2Rt$ 巨大，必须配置快速直流保护（短路瞬动 ≤50ms），端子箱须密封防尘，蓄电池室设气体灭火与排风。**

## 2. 背景

### 2.1 系统配置（脱敏）

| 参数 | 数值 |
|---|---|
| 直流电压 | 220V DC |
| 蓄电池组 | 108 只 × 2V/300Ah（阀控铅酸） |
| 蓄电池内阻 | 0.5 mΩ/只（10h 率） |
| 正极馈电电缆 | ZR-YJV-1×95mm²，长 50m |
| 直流断路器 | In=63A，瞬时脱扣 10In=630A |
| 熔断器（端子箱） | 63A |
| 充电装置 | 2 套 50A 高频开关 |

### 2.2 事故时间线

| 时间 | 事件 |
|---|---|
| T+0s | 端子箱正极电缆绝缘击穿，对地短路 |
| T+0.5s | 直流监控告警：绝缘电阻 <10kΩ |
| T+1.0s | 短路电流稳定在 ~40A（断路器未瞬动） |
| T+2.0s | 端子箱冒烟，绝缘层燃烧 |
| T+3.0s | 63A 熔断器熔断（$I^2t$ 熔断），但火势已起 |
| T+10s | 火焰蔓延至蓄电池室通风口 |
| T+120s | 蓄电池室 12 只电池外壳融化，析出氢气 |
| T+300s | 气体灭火系统启动，但已烧毁 36 只 |
| T+480min | 更换临时蓄电池，直流恢复 |

## 3. 方案（事故调查链路）

```
绝缘老化 → 正极对地短路
  → 蓄电池组内阻极低(5.4Ω), Isc≈40.7A
  → 直流断路器瞬时脱扣值过大(630A), 未动作
  → 熔断器63A按I²t特性约3s熔断
  → 短路持续3s, 能量 W=I²Rt=40.7²×5.4×3=26.9kJ
  → 电缆绝缘层+端子箱积尘点燃
  → 蔓延至蓄电池室, 电池外壳融化析氢
  → 直流系统瘫痪
```

## 4. 计算

### 4.1 直流短路电流计算（引自 [CALC-BT-001](../40-calc/CALC-BT-001-battery-capacity.md) + DL/T 5044-2012）

蓄电池组内阻：

$$R_b=n\times r=108\times 0.05\ \Omega=5.4\ \Omega$$

电缆电阻（95mm²，50m，铜 $\rho$=0.0184Ω·mm²/m）：

$$R_c=\rho\frac{L}{S}=0.0184\times\frac{50}{95}=0.0097\ \Omega$$

短路电流（忽略充电装置内阻）：

$$I_{sc}=\frac{U_n}{R_b+R_c}=\frac{220}{5.4+0.0097}\approx 40.7\ \text{A}$$

### 4.2 保护动作分析

| 保护 | 整定值 | 实际短路电流 | 动作时间 | 是否动作 |
|---|---|---|---|---|
| 直流断路器瞬动 | 630A（10In） | 40.7A | — | 否 |
| 断路器长延时 | 63A（1.05In→反时限） | 40.7A | 反时限约 10s | 否（未到） |
| 熔断器 63A | $I^2t$ 特性 | 40.7A | ~3s | 是（但太慢） |

**核心问题**：直流断路器**瞬时脱扣值设得过大**（10In=630A），而蓄电池短路电流仅 40.7A，远低于瞬动值，靠熔断器 $I^2t$ 熔断需 3 秒。

### 4.3 短路能量计算

$$W=I_{sc}^2\times R_{total}\times t=40.7^2\times 5.4\times 3=40.7^2\times 16.2=1656\times 16.2\approx 26800\ \text{J}=26.8\ \text{kJ}$$

26.8 kJ 能量集中在端子箱狭小空间，足以点燃 PVC 绝缘层（燃点 ~250°C）和积尘。

### 4.4 正确的直流保护整定（引自 DL/T 5044-2012 §7.3）

直流断路器瞬时脱扣应按**蓄电池出口短路电流**整定：

$$I_{op0}\leq K_{rel}\times I_{sc,max}$$

取可靠系数 $K_{rel}$=0.8：

$$I_{op0}\leq 0.8\times 40.7=32.6\ \text{A}$$

应选瞬动值 32A 的直流专用断路器（直流脱扣特性不同于交流，需选 D 型或直流专用型）。

### 4.5 熔断器配合校验

熔断器额定电流应大于最大负荷电流且 $I^2t$ 配合：

$$I_{fuse}\geq 1.1\times I_{load,max}=1.1\times 50=55\ \text{A}\to 63\ \text{A}$$

熔断器 $I^2t$ 熔断值 < 断路器 $I^2t$（选择性）：

- 熔断器 63A：$I^2t\approx 3\times 10^4$ A²·s（40A 时 3s）
- 断路器瞬动 32A：$I^2t\approx 40.7^2\times 0.05=83$ A²·s（50ms）

断路器先动作 ✓

### 4.6 蓄电池室消防校核（引自 GB 50171-2012）

- 蓄电池室须设**气体灭火系统**（七氟丙烷）
- 通风量 ≥ 6 次/小时（排氢）
- 氢气浓度 < 1% LEL（1%）

事故中通风系统正常，但灭火系统启动延迟 300s（手动确认），期间已烧毁 36 只。

## 5. 原因分析

| 类别 | 直接原因 | 根本原因 |
|---|---|---|
| 一次设备 | 电缆绝缘老化击穿 | 电缆超期服役、定期绝缘检测缺失 |
| 二次保护 | 断路器瞬动值过大 | 按交流断路器选型，未按直流短路电流整定 |
| 运维管理 | 端子箱积尘未清理 | 运维周期过长 |
| 消防 | 灭火启动慢 | 人工确认延时 |

## 6. 整改

### 6.1 立即整改

1. 更换直流断路器为**直流专用型**，瞬动值 32A
2. 端子箱全部更换为 IP54 密封型
3. 蓄电池室气体灭火改**自动启动**（2 级报警联动）
4. 全所直流电缆红外测温，超期电缆更换

### 6.2 长期整改

1. 直流系统加装**直流电弧故障保护**（AFDD）
2. 蓄电池组在线内阻监测（内阻突增 → 预警）
3. 直流短路电流定期校核（电池老化内阻变化）

## 7. 经验教训

- [ ] **直流短路电流小但持续时间长**，能量 $W=I^2Rt$ 可致命
- [ ] **直流断路器瞬动值须按蓄电池短路电流整定**（≤0.8$I_{sc}$）
- [ ] **交流断路器不可用于直流回路**（灭弧特性不同）
- [ ] 端子箱须 IP54 密封防尘
- [ ] 蓄电池室气体灭火应自动启动（2 级联动）
- [ ] 直流电缆定期红外测温与绝缘检测
