# 综合案例：A级数据中心冷却系统电气-暖通-消防多专业协同设计

## 1. 摘要

本案例以某 A 级数据中心机房区（IT 负载 800kW，热密度 8kW/m²，机房面积 100m²）为载体，覆盖**冷却负荷计算、精密空调 N+1 配置、电气供配电（UPS 供冷+柴发保障）、消防联动（气体灭火+空调停机+防火阀）、气流组织（冷热通道封闭）**五大专业接口。关键结论：制冷量 1.3×IT 功率=1040kW，配 3 台 520kW 精密空调（N+1）；冷却负荷属二级（A级数据中心按一级），由 2N UPS 供电；气体灭火联动须切断空调电源+关闭防火阀+启动排烟。教训：**数据中心冷却须电气-暖通-消防三专业联合设计，空调电源须与消防联动（灭火时切电+关阀），冷热通道封闭+架空地板送风是高热密度机房标配。**

## 2. 背景

### 2.1 工程概况（脱敏）

某金融机构 A 级数据中心（代号"某 DC 中心"），机房区 100m²，IT 负载 800kW（200 个机柜，单机柜平均 4kW，最高 8kW）。

### 2.2 多专业接口图

```
电气专业                暖通专业              消防专业
  │ 冷却负荷分级        │ 制冷量计算          │ 气体灭火
  │ UPS供冷+柴发        │ 精密空调N+1         │ 联动切电
  │ 空调配电            │ 冷热通道封闭        │ 防火阀联动
  ├─────────────────────┼────────────────────┤
  │ 自动化专业          │ 结构专业            │ 弱电专业
  │ 温湿度监控          │ 架空地板承重        │ 漏水检测
  │ 空调群控            │ 管线综合            │ 环境监测
```

## 3. 方案

### 3.1 系统拓扑

```
市电 → 2N UPS → 精密空调（N+1）→ 冷热通道封闭机柜
                                    ↓
              气体灭火 → 联动切空调+关防火阀+排烟
```

### 3.2 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $P_{IT}$ | IT 负载 | 800 kW | 设计 |
| $A_{room}$ | 机房面积 | 100 m² | 设计 |
| $\rho_{heat}$ | 热密度 | 8 kW/m² | $P_{IT}/A$ |
| $P_{cool}$ | 制冷量 | 1040 kW | 1.3×$P_{IT}$ |
| $COP$ | 精密空调能效比 | 3.5 | 厂家 |
| $P_{AC,elec}$ | 空调用电功率 | 297 kW | $P_{cool}/COP$ |
| $T_{supply}$ | 送风温度 | 18°C | GB 50174 |
| $T_{return}$ | 回风温度 | 38°C | 设计 |
| $RH$ | 相对湿度 | 40~60% | GB 50174 |

## 4. 计算

### 4.1 冷却负荷计算（引自 GB 50174-2017 §9.1 + GB 50019-2015 §7.5）

**总冷负荷** = IT 设备散热 + 建筑围护结构 + 照明 + 人员 + 新风

| 负荷项 | 计算 | 取值 |
|---|---|---|
| IT 设备 | $P_{IT}\times 0.98$（电能→热） | 784 kW |
| 围护结构 | $A\times K\times \Delta T$=100×0.8×10 | 8 kW |
| 照明 | 10 W/m² × 100 | 10 kW |
| 人员 | 5人 × 120W | 0.6 kW |
| 新风负荷 | 1000m³/h × 0.32 | 3 kW |
| **合计** | | **806 kW** |

**设计冷量**（含 30% 裕度，GB 50174 §9.2.1）：

$$P_{cool}=1.3\times 806=1048\ \text{kW}$$

取 **1040 kW**。

### 4.2 精密空调配置（引自 GB 50174-2017 §9.3 + GB 50019-2015）

**N+1 冗余配置**：

$$N=\frac{P_{cool}}{P_{unit}}=\frac{1040}{520}=2$$

选 **3 台 520kW 精密空调**（N=2, 1 台备用），任一台故障时剩余 2 台仍满足 100% 冷量。

| 项 | 计算 | 取值 |
|---|---|---|
| 单台制冷量 | — | 520 kW |
| 配置数量 | N+1 | 3 台 |
| 单台用电功率 | $520/3.5$ | 148.5 kW |
| 总用电功率 | $3\times 148.5$ | 445.5 kW |
| 运行台数 | N | 2 台 |
| 运行用电 | $2\times 148.5$ | 297 kW |

### 4.3 电气供配电（引自 GB 51348-2019 §25 + [CALC-LD-001](../40-calc/CALC-LD-001-demand-factor-method.md)）

**冷却负荷分级**：A级数据中心空调属一级负荷（GB 50174 §8.1.1），由 2N UPS 供电。

**UPS 容量核算**（含 IT+空调）：

$$P_{UPS,total}=P_{IT}+P_{AC,elec}=800+297=1097\ \text{kW}$$

选 **2N UPS：4 台 600kVA（3 用 1 备，或 2+2 冗余）**，每台负载率 60%。

**柴发容量**（引自 [CALC-DG-001](../40-calc/CALC-DG-001-diesel-generator-capacity.md)）：

柴发须承担 IT+空调+应急照明+消防设备：

$$P_{DG}=P_{IT}+P_{AC}+P_{fire}=800+297+50=1147\ \text{kW}$$

选 **1500kW 柴油发电机组**（持续功率，余量 30%）。

### 4.4 气流组织（引自 GB 50174-2017 §9.4 + ASHRAE TC 9.9）

**冷热通道封闭**：

- 架空地板高度 600mm（静压箱送风）
- 冷通道宽度 1200mm，封闭门+顶板
- 热通道回风至空调
- 送风温度 18°C，回风 38°C（ΔT=20K）

**风量计算**：

$$Q=\frac{P_{cool}}{c_p\cdot\rho\cdot\Delta T}=\frac{1040}{1.005\times 1.2\times 20}=\frac{1040}{24.12}=43.1\ \text{m}^3\text{/s}=155000\ \text{m}^3\text{/h}$$

每台空调风量 $155000/2=77500$ m³/h。

**架空地板开孔率**：

地板开孔总面积 ≥ 送风量/出口风速（3m/s）：

$$A_{open}=\frac{Q}{v}=\frac{43.1}{3}=14.4\ \text{m}^2$$

开孔率 $=14.4/100=14.4\%$（高密度机柜区取 30%~50%）。

### 4.5 消防联动（引自 GB 50116-2013 §4.4 + GB 50016-2014 §8.5）

气体灭火（七氟丙烷/IG541）联动逻辑：

```
烟感+温感双报警 → 延时 30s → 启动气体灭火
  → 联动1: 切断精密空调电源（防止灭火剂被吹散）
  → 联动2: 关闭新风/回风防火阀
  → 联动3: 关闭排风
  → 联动4: 启动事故排烟（灭火后）
```

| 联动项 | 动作 | 时间 |
|---|---|---|
| 空调切电 | 分断空调总开关 | <1s |
| 防火阀关闭 | 70°C/280°C 防火阀熔断+电信号 | <5s |
| 气体喷放 | 七氟丙烷/IG541 | 延时 30s |
| 排烟启动 | 灭火后确认 | 手动/自动 |

**关键**：灭火前必须切断空调电源，否则空调气流将灭火剂吹散，灭火失败。

### 4.6 漏水检测与电气保护

机房设漏水检测绳（沿精密空调水管、地板下水管敷设），报警联动：

- 一级报警：显示漏水位置
- 二级报警：切断对应区域空调电源+关闭水阀

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 精密空调未做 N+1 冗余 | GB 50174-2017 §9.3.2 | 单台故障机房过热宕机 |
| 2 | 空调电源未接 UPS（市电直供） | GB 50174-2017 §8.1.1 | 市电中断冷却停止，IT 过热 |
| 3 | 气体灭火未联动切空调电源 | GB 50116-2013 §4.4 | 灭火剂被吹散，灭火失败 |
| 4 | 架空地板高度仅 300mm | GB 50174-2017 §9.4.2 | 送风静压不足，局部过热 |
| 5 | 冷通道未封闭 | ASHRAE | 冷热气流短路，制冷效率降 30% |

## 6. 整改

### 6.1 空调冗余与供电

- 精密空调改为 N+1（3 台 520kW）
- 空调电源改由 2N UPS 供电
- 每台空调配独立 UPS 馈线（双路）

### 6.2 消防联动

- 增加空调切电继电器，气体灭火动作时切除空调电源
- 防火阀接入消防联动
- 排烟系统接入灭火确认信号

### 6.3 气流组织

- 架空地板抬高至 600mm
- 冷热通道封闭（门+顶板）
- 高密度区地板开孔率提高至 40%

## 7. 经验教训

- [ ] **A级数据中心空调属一级负荷，须由 UPS 供电**，不可市电直供
- [ ] **精密空调须 N+1 冗余**，单台故障不影响冷却
- [ ] **气体灭火必须联动切断空调电源**——空调气流会吹散灭火剂
- [ ] **冷热通道封闭**可提高制冷效率 20~30%，高热密度机房标配
- [ ] 架空地板高度 ≥600mm（静压箱送风），高密度区地板开孔率 ≥30%
- [ ] 冷却总负荷 = IT 功率 × 1.3（含围护、照明、新风等）
