# 2017供配电真题拆解：应急照明蓄电池容量与持续时间校验

## 1. 摘要

2017 年供配电专业案例题：某一类高层公共建筑，应急照明集中电源（蓄电池组）供电，应急照明负荷 5kW，要求持续供电时间 90min。已知蓄电池为阀控铅酸（VRLA），标称电压 220V，放电终止电压 1.85V/单体，电池效率 0.95。要求选择蓄电池容量并校验是否满足。结论：蓄电池容量 $C_{10}=\frac{P\times t}{U_n\times \eta\times K_{c}}$，取 $K_c$=0.75（90min 放电容量系数），$C_{10}=\frac{5000\times 1.5}{220\times 0.95\times 0.75}=47.8$Ah，选 50Ah。教训：**应急照明蓄电池容量须用容量系数法核算，不同放电时间对应不同 $K_c$（30min→0.5, 60min→0.65, 90min→0.75, 120min→0.85），持续时间按建筑性质取 30~180min。**

## 2. 背景

### 2.1 真题题干（脱敏重构）

某一类高层公共建筑（建筑高度 80m），设集中电源集中控制型应急照明系统。

| 参数 | 数值 | 说明 |
|---|---|---|
| 应急照明总功率 $P$ | 5 kW | 含疏散指示+备用照明 |
| 持续供电时间 $t$ | 90 min | 一类高层（≥1h，按90min） |
| 蓄电池标称电压 $U_n$ | 220 V | 104节×2V |
| 单体终止电压 | 1.85 V | VRLA |
| 放电容量系数 $K_c$ | 0.75 | 90min放电，VRLA |
| 电池效率 $\eta$ | 0.95 | — |
| 温度系数 | 1.0 | 25°C |

**问题**：选择蓄电池容量（$C_{10}$）。

### 2.2 关键考点

1. 应急照明持续时间取值（按建筑性质）
2. 蓄电池容量计算（容量系数法）
3. 放电终止电压与单体数量
4. 容量系数 $K_c$ 的选取

## 3. 方案（解题链路）

```
1. 确定持续时间 t: 一类高层 → 90min
2. 计算放电功率 P=5kW
3. 容量系数法: C10 = P×t / (Un×η×Kc)
4. Kc 取值: 90min → 0.75 (VRLA)
5. 计算 C10 并取标准容量
6. 校验: 实际放电时间 ≥ 90min
```

## 4. 计算

### 4.1 应急照明持续时间（引自 GB 51309-2018 §3.2 + GB 55037-2022 §16.2）

| 建筑类型 | 持续时间 |
|---|---|
| 高度＞100m 民用建筑 | ≥90min |
| 医疗建筑、老年人照料设施、总建面＞10万m²公共建筑 | ≥60min |
| 其他建筑 | ≥30min |
| 避难层/间 | ≥60min |

本题为一类高层（80m，≤100m），按 GB 55037 取 ≥60min，但题目给定 90min（设计留裕度）。

### 4.2 蓄电池容量计算（引自 [CALC-BT-001](../40-calc/CALC-BT-001-battery-capacity.md) + DL/T 5044-2014 附录B）

**容量系数法**：

$$C_{10}=\frac{P\times t}{U_n\times \eta\times K_c\times K_t}$$

| 符号 | 含义 | 取值 |
|---|---|---|
| $P$ | 放电功率 | 5000 W |
| $t$ | 放电时间 | 1.5 h |
| $U_n$ | 蓄电池标称电压 | 220 V |
| $\eta$ | 蓄电池效率 | 0.95 |
| $K_c$ | 容量系数 | 0.75（90min，VRLA） |
| $K_t$ | 温度系数 | 1.0（25°C） |

$$C_{10}=\frac{5000\times 1.5}{220\times 0.95\times 0.75\times 1.0}=\frac{7500}{156.75}=47.8\ \text{Ah}$$

**选标准容量 50Ah**（向上取整到标准系列）。

### 4.3 放电容量系数表（引自 DL/T 5044-2014 附录B 表B.1）

VRLA 蓄电池容量系数 $K_c$：

| 放电时间 | $K_c$（VRLA，25°C） |
|---|---|
| 30 min | 0.50 |
| 60 min | 0.65 |
| 90 min | 0.75 |
| 120 min | 0.85 |
| 180 min | 0.92 |
| 600 min | 1.00 |

### 4.4 单体数量与终止电压（引自 [CALC-BT-001](../40-calc/CALC-BT-001-battery-capacity.md)）

标称 2V/单体，220V 系统：

$$n=\frac{U_n}{U_{cell,nominal}}=\frac{220}{2}=110\ \text{节}$$

终止电压 1.85V/单体：

$$U_{min}=110\times 1.85=203.5\ \text{V}$$

> 203.5V 为放电末期电压，仍满足应急照明灯具工作电压范围（一般 0.85~1.1$U_n$）。

### 4.5 实际放电时间校验

选 50Ah 后，实际放电电流：

$$I_d=\frac{P}{U_n}=\frac{5000}{220}=22.7\ \text{A}$$

放电率：$I_d/C_{10}=22.7/50=0.455C_{10}$

90min 放电时实际容量系数（0.455$C_{10}$ 放电率）约 0.78，实际可放电量：

$$C_{act}=50\times 0.78=39\ \text{Ah}$$

实际放电时间：

$$t_{act}=\frac{C_{act}}{I_d}=\frac{39}{22.7}=1.72\ \text{h}=103\ \text{min}>90\ \text{min ✓}$$

### 4.6 另一种算法：恒流法（对照）

$$C_{10}=\frac{I_d\times t}{K_c\times \eta}=\frac{22.7\times 1.5}{0.75\times 0.95}=\frac{34.1}{0.7125}=47.9\ \text{Ah}$$

与功率法结果 47.8Ah 一致 ✓

## 5. 审查意见（真题考点陷阱）

| 序号 | 常见错误 | 正确做法 |
|---|---|---|
| 1 | $K_c$ 取 1.0（不考虑放电率） | 按放电时间查 $K_c$ 表 |
| 2 | 持续时间取 30min（所有建筑） | 按建筑性质取 30~180min |
| 3 | 不计电池效率 $\eta$ | $\eta$=0.95（VRLA） |
| 4 | 用 $C_{10}$ 直接 = $I\times t$ | 须除以 $K_c$ 和 $\eta$ |

## 6. 整改

### 6.1 容量选择原则

$$C_{10}\geq \frac{P\times t}{U_n\times \eta\times K_c}$$

向上取标准容量系列（25/30/40/50/60/80/100/120...Ah）。

### 6.2 持续时间选择

严格按 GB 51309/GB 55037 表 3.2.4 取值，一类高层（≤100m）取 60min，超 100m 取 90min。

## 7. 经验教训

- [ ] **蓄电池容量用容量系数法**：$C_{10}=P\times t/(U_n\times \eta\times K_c)$
- [ ] **容量系数 $K_c$ 按放电时间查表**，不可取 1.0
- [ ] **持续时间按建筑性质**：超100m→90min，医疗/老人/大商业→60min，其他→30min
- [ ] VRLA 单体终止电压 1.85V，电池效率 0.95
- [ ] 选标准容量向上取整，再校验实际放电时间
