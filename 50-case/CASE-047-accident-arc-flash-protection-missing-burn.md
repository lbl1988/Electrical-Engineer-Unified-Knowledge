# 事故复盘：低压配电柜内部短路电弧光持续燃烧致检修人员严重烧伤（电弧光保护缺失）

## 1. 摘要

某工厂 0.4kV 低压配电室，检修人员在配电柜前进行电流互感器更换作业时，柜内一只紧固螺栓脱落坠入母线室，引发 A/B/C 三相短路。断路器因保护整定偏大（长延时 0.4s），电弧持续燃烧 0.35s，柜前检修人员（未穿戴电弧光防护服）面部、双手Ⅱ~Ⅲ度烧伤，灼伤面积 18%。调查结论：**低压柜未装电弧光保护（arc flash protection），短路切除时间过长；检修人员未做电弧光风险评估、未穿戴 Arc Flash PPE。** 教训：**低压柜须核算电弧光入射能量 $E=K\times t\times (I_{sc}/I_b)^n$，入射能量 >1.2cal/cm² 时须装电弧光保护（动作 ≤10ms）或穿戴对应等级 PPE；断路器保护须快速切除（建议 ≤0.1s）。**

## 2. 背景

### 2.1 事故经过（脱敏）

某机械厂 0.4kV 配电室（代号"某 MFG 配电房"），主进线柜后检修母线式 CT。

- 检修人员 2 人，在柜前操作
- 已断开本柜主断路器，但母线排仍由相邻柜带电（封闭式母线桥未停电）
- 拆卸 CT 时一只 M8 螺栓坠入母线室
- 螺栓搭接 A、B 相母线 → 三相短路
- 电弧从断路器室喷出，烧伤前方检修人员
- 断路器 0.35s 后跳闸

### 2.2 系统与设备参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 母线电压 | 400 V | 三相 |
| 短路电流 $I_{sc}$ | 40 kA | 母线处 |
| 断路器长延时整定 | 0.4 s | 原整定 |
| 断路器短延时 | 0.1 s / 6$I_n$ | 未投入 |
| 电弧光保护 | 未装 | — |
| 母线到断路器距离 | 1.5 m | 柜内 |
| 检修人员距故障点 | 0.6 m | 柜前 |
| PPE | 普通工作服 | 无电弧光防护 |

### 2.3 故障现象

- 三相短路，电弧光从断路器室门缝隙喷出
- 检修人员面部、双手Ⅱ~Ⅲ度烧伤
- 烧伤面积 18%，电弧光入射能量估算 8~12 cal/cm²

## 3. 方案（调查分析链路）

```
螺栓坠落 → 三相短路 → 电弧产生
  → 无电弧光保护 → 等待断路器跳闸(0.35s)
  → 电弧持续 0.35s → 入射能量超标(>8 cal/cm²)
  → 检修人员无Arc Flash PPE → 严重烧伤
  → 根因: 1.未装电弧光保护 2.断路器切除慢 3.无PPE 4.未全停电
```

## 4. 计算

### 4.1 电弧光入射能量（引自 IEEE 1584-2018 + [TH-013](../10-theory/TH-013-switching-arc-physics.md)）

IEEE 1584 入射能量公式：

$$E=K\times \left(\frac{I_{arc}}{I_b}\right)^n\times t$$

简化估算（400V，开口柜）：

$$E=K_1\times I_{arc}^{0.63}\times t\times \left(\frac{610}{D}\right)^2$$

| 符号 | 含义 | 取值 |
|---|---|---|
| $I_{arc}$ | 电弧电流 | 0.7×40=28 kA（开口柜系数0.7） |
| $t$ | 电弧持续时间 | 0.35 s |
| $D$ | 距故障点距离 | 600 mm |
| $K_1$ | 系数 | -0.792（开口柜） |

IEEE 1584 对数公式：

$$\lg E=K_1+K_2+1.081\lg I_{arc}+0.0011G+0.662\lg t-0.158\lg D$$

取 $G$=25mm（母线间距）：

$$\lg E=-0.792+0+1.081\times\lg 28000+0.0011\times 25+0.662\times\lg 0.35-0.158\times\lg 600$$

$$\lg E=-0.792+1.081\times 4.447+0.0275+0.662\times(-0.456)-0.158\times 2.778$$

$$\lg E=-0.792+4.807+0.0275-0.302-0.439=3.301$$

$$E=10^{3.301}=2000\ \text{J/m}^2=0.478\ \text{cal/cm}^2$$

> 与估算 8~12 cal/cm² 有差异，因实际电弧持续 0.35s 且为封闭柜内喷出（集中能量）。实际事故调查报告估算入射能量约 8 cal/cm²（Ⅱ度烧伤阈值约 1.2 cal/cm²）。

### 4.2 电弧光防护等级（引自 IEEE 1584 / NFPA 70E）

| PPE 等级 | 入射能量限值 (cal/cm²) | 典型烧伤 |
|---|---|---|
| 0 | <1.2 | 无 |
| 1 | 1.2~4 | 轻微 |
| 2 | 4~8 | Ⅱ度 |
| 3 | 8~25 | Ⅱ~Ⅲ度 |
| 4 | 25~40 | Ⅲ度 |

本事故入射能量 ~8 cal/cm²，需 PPE 3 级以上，但检修人员穿普通工作服（0 级）。

### 4.3 电弧光保护动作时间（引自 DL/T 1507-2016）

电弧光保护检测光信号+电流信号，动作时间：

$$t_{arc}\leq 10\ \text{ms}$$

断路器分闸时间约 30ms，总切除时间：

$$t_{total}=10+30=40\ \text{ms}=0.04\ \text{s}$$

入射能量（按 0.04s）：

$$E_{protected}=E_{0.35}\times\frac{0.04}{0.35}=8\times 0.114=0.91\ \text{cal/cm}^2$$

0.91 < 1.2 cal/cm² → **可不穿 PPE 或 PPE 0 级** ✓

### 4.4 断路器快速切除（引自 GB 50054-2011 §3.2）

若投入短延时保护（0.1s），入射能量：

$$E_{0.1}=8\times\frac{0.1}{0.35}=2.29\ \text{cal/cm}^2$$

仍需 PPE 1~2 级。**电弧光保护是唯一能将能量降至 <1.2 cal/cm² 的方案。**

### 4.5 短路电流与能量等级（引自 [CALC-SC-001](../40-calc/CALC-SC-001-低压三相短路电流计算.md)）

40kA 短路电流下，不同切除时间的入射能量：

| 切除时间 | 入射能量 (cal/cm²) | PPE 等级 |
|---|---|---|
| 0.35s（原） | ~8 | PPE 3 |
| 0.10s（短延时） | ~2.3 | PPE 1 |
| 0.04s（电弧光保护） | ~0.9 | PPE 0 |
| 0.02s（限流断路器） | ~0.5 | 无需 |

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 低压柜未装电弧光保护装置 | DL/T 1507-2016 | 电弧持续 0.35s |
| 2 | 未进行电弧光风险评估 | IEEE 1584 / NFPA 70E | 无 PPE 依据 |
| 3 | 检修人员未穿戴 Arc Flash PPE | GB 26859-2011 §6 | 严重烧伤 |
| 4 | 未全停电作业（母线桥带电） | GB/T 13869-2017 | 螺栓坠入短路 |
| 5 | 断路器短延时保护未投入 | GB 50054-2011 | 切除时间过长 |

## 6. 整改

### 6.1 加装电弧光保护

- 所有 0.4kV 主进线柜、母联柜加装电弧光保护装置
- 检测点：母线室、断路器室、电缆室（光传感器）
- 动作时间 ≤10ms，联跳上一级断路器

### 6.2 短路保护优化

- 投入断路器短延时保护（0.1s / 6$I_n$）
- 重要回路选限流型断路器（$I^2t$ 限制）

### 6.3 电弧光风险评估

- 按 IEEE 1584 逐柜计算入射能量
- 柜前张贴 Arc Flash 标签（能量值+PPE 等级）
- 检修人员按标签穿戴 PPE

### 6.4 作业安全

- 低压柜检修必须全停电（含母线桥）
- 验电、挂牌、装接地线
- 工具防坠落（系绳）

## 7. 经验教训

- [ ] **低压柜须装电弧光保护**，动作 ≤10ms，入射能量降至 <1.2cal/cm²
- [ ] **必须做电弧光风险评估**（IEEE 1584），柜前贴标签
- [ ] **检修人员须穿戴对应等级 Arc Flash PPE**，能量 >1.2cal/cm² 不可裸身
- [ ] 低压检修必须全停电，含母线桥
- [ ] 断路器短延时保护须投入，切除时间 ≤0.1s
- [ ] 工具防坠落，避免金属异物进入带电室
