# 综合案例：新能源汇集站光伏+风电并网保护与电能质量多专业协同

## 1. 摘要

本案例以某 110kV 新能源汇集站（光伏 80MW+风电 60MW，汇集至 110kV 母线送出）为载体，覆盖**并网保护配置（防孤岛/低电压穿越/逆功率/频率保护）、电能质量治理（谐波/间谐波/电压波动）、继电保护配合（汇集线/主变/送出线路）、调度通信**四大专业接口。关键结论：汇集站须配置防孤岛保护（主动+被动）、LVRT（0.2p.u./625ms）、逆功率保护（1.0$P_n$/0.5s）；光伏逆变器谐波 $THD_u$≤3%，风电 $THD_i$≤5%，须装 SVG 动态补偿。教训：**新能源并网须保护-电能质量-调度联合设计，逆变器具备 LVRT/FRT 能力是硬性指标，谐波电流须按逆变器台数叠加核算。**

## 2. 背景

### 2.1 工程概况（脱敏）

某 110kV 新能源汇集站（代号"某 RE 汇集站"）：

| 电源 | 容量 | 台数 | 并网电压 |
|---|---|---|---|
| 光伏 | 80 MW | 160台500kW逆变器 | 35kV |
| 风电 | 60 MW | 30台2MW风机 | 35kV |
| 合计 | 140 MW | — | 110kV送出 |

### 2.2 系统拓扑

```
光伏80MW ── 35kV母线 ── 主变(150MVA) ── 110kV母线 ── 送出线路 ── 电网
风电60MW ── 35kV母线 ──  110/35kV
                    │
                    ├── SVG(±20Mvar)
                    └── 接地变压器(消弧线圈)
```

### 2.3 多专业接口图

```
电气专业                保护专业              电能质量专业
  │ 主变/汇集线选型      │ 并网保护配置         │ 谐波核算
  │ 短路电流             │ LVRT/防孤岛          │ SVG选型
  │ 接地方式             │ 逆功率/频率          │ 间谐波
  ├───────────────────────┼────────────────────┤
  │ 通信专业              │ 结构专业            │ 消防专业
  │ 调度数据/PMU         │ 主变基础/风机吊装   │ SVG消防
  │ 并网协议             │ 接地网              │ 油浸主变消防
```

## 3. 方案

### 3.1 关键参数表

| 符号 | 含义 | 取值 | 来源 |
|---|---|---|---|
| $P_{PV}$ | 光伏容量 | 80 MW | 设计 |
| $P_{WT}$ | 风电容量 | 60 MW | 设计 |
| $S_T$ | 主变容量 | 150 MVA | 设计 |
| $U_{grid}$ | 送出电压 | 110 kV | 系统 |

| $I_{sc,110}$ | 110kV短路电流 | 40 kA | 计算 |
| $LVRT$ | 低电压穿越 | 0.2p.u./625ms | GB/T 19964 |
| $P_{reverse}$ | 逆功率 | 1.0$P_n$/0.5s | GB/T 14285 |

## 4. 计算

### 4.1 并网保护配置（引自 GB/T 19964-2024 §6 + GB/T 14285-2023）

| 保护类型 | 整定值 | 说明 |
|---|---|---|
| 防孤岛保护 | 主动+被动，<2s | 防止孤岛运行 |
| 低电压穿越 LVRT | 0.2p.u./625ms不脱网 | 电压跌落时支撑电网 |
| 高电压穿越 HVRT | 1.3p.u./500ms | 过电压时不脱网 |
| 频率保护 | 48~50.5Hz | 低频/高频切机 |
| 逆功率保护 | 1.0$P_n$/0.5s | 防止向电网倒送（按需） |
| 过电流保护 | 1.3$I_n$/0.5s | 汇集线短路 |
| 差动保护 | 35kV汇集线+主变差动 | 内部故障 |

### 4.2 低电压穿越 LVRT（引自 GB/T 19964-2024 §6.2 + [TH-011](../10-theory/TH-011-synchronous-machine-subtransient-reactance.md)）

LVRT 曲线：

| 电压跌落 | 持续时间 | 要求 |
|---|---|---|
| 0.2 p.u. | 625 ms | 不脱网 |
| 0.5 p.u. | 1000 ms | 不脱网 |
| 0.9 p.u. | 连续 | 不脱网 |

跌落期间须提供无功支撑：

$$Q_{support}=\frac{0.9-U}{0.5}\times I_{n,max}\times U_n$$

当 $U$=0.2p.u.：

$$Q_{support}=\frac{0.9-0.2}{0.5}\times 1.5I_n\times U_n=2.1\times S_n$$

> 逆变器须具备 1.5 倍额定电流的短时过载能力。

### 4.3 谐波核算（引自 GB/T 14549-1993 + [TH-008](../10-theory/TH-008-harmonic-generation.md)）

**光伏逆变器谐波电流**（单台 500kW）：

| 次数 | $I_h/I_1$ (%) |
|---|---|
| 5 | 2.0 |
| 7 | 1.5 |
| 11 | 0.8 |
| 13 | 0.6 |

160 台并联，因相位分散，叠加系数 $\sqrt{n}$：

$$I_{5,total}=160\times 500\times 0.02/\sqrt3\times\frac{1}{\sqrt{160}}\times\frac{1}{35}=??$$

简化：单台 5 次电流 $I_5$=0.02×$I_1$=0.02×(500/(\sqrt3×0.35))=0.02×825=16.5A

160 台叠加（相位不完全同相，取 $\sqrt{n}$ 系数）：

$$I_{5,total}=16.5\times\sqrt{160}=16.5\times 12.65=209\ \text{A}$$

35kV 母线 5 次谐波电压：

$$U_5=I_{5,total}\times Z_5$$

系统 5 次阻抗 $Z_5=5Z_1=5\times(35^2/1500)=5\times 0.817=4.08\Omega$（$S_{sc}$=1500MVA）

$$U_5=209\times 4.08=853\ \text{V}=0.024\times U_\phi$$

$U_5/U_1$=2.4% < GB/T 14549 限值 3% ✓（35kV）

**间谐波**（风电双馈风机特有）：0~2 倍基波，限值 0.16%（GB/T 24337）。

### 4.4 SVG 容量（引自 [CALC-RC-001](../40-calc/CALC-RC-001-reactive-compensation.md) + [PR-PQ-001](../30-practice/PR-PQ-001-pq-compensation-design.md)）

光伏无功需求（逆变器功率因数 0.95~1）：

$$Q_{PV}=P_{PV}\times\tan(\arccos 0.95)=80\times 0.329=26.3\ \text{Mvar}$$

风电无功需求：

$$Q_{WT}=P_{WT}\times 0.48=60\times 0.48=28.8\ \text{Mvar}$$

总无功波动（含电压波动补偿）：

$$Q_{SVG}\geq Q_{PV}+Q_{WT}=26.3+28.8=55.1\ \text{Mvar}$$

选 **±30Mvar SVG**（两台 ±15Mvar），可分相调节。

### 4.5 继电保护配合（引自 GB/T 14285-2023 + [CALC-PT-001](../40-calc/CALC-PT-001-protection-setting.md)）

| 保护 | 整定 | 动作时间 |
|---|---|---|
| 110kV送出线路差动 | 两侧差动 | <40ms |
| 110kV送出线路距离 | Ⅰ段80% / Ⅱ段120% | 0s/0.5s |
| 主变差动 | 比率制动 | <40ms |
| 35kV汇集线过流 | 1.3$I_n$ | 0.5s |
| 逆变器防孤岛 | 主动+被动 | <2s |

**保护配合关键点**：汇集线过流 0.5s 须与逆变器 LVRT（625ms）配合，避免电网故障时汇集线先切导致逆变器脱网。

### 4.6 调度通信（引自 GB/T 19964-2024 §8）

- AGC/AVC 接入调度
- PMU 同步相量测量（100帧/s）
- 有功/无功/电压/频率远方调节
- 并网点电能质量在线监测

## 5. 审查意见

| 序号 | 意见 | 不符条款 | 后果 |
|---|---|---|---|
| 1 | 逆变器 LVRT 能力未明确 | GB/T 19964-2024 §6.2 | 电网故障时大规模脱网 |
| 2 | 未核算间谐波（风电双馈） | GB/T 24337-2009 | 间谐波超标 |
| 3 | SVG 容量仅按光伏算 | 设计遗漏 | 无功补偿不足 |
| 4 | 汇集线过流 0.3s 与 LVRT 625ms 不配合 | GB/T 14285 | 故障时逆变器脱网 |

## 6. 整改

### 6.1 逆变器 LVRT

明确逆变器 LVRT/HVRT 参数写入合同，到货后做型式试验验证。

### 6.2 间谐波治理

风电双馈风机间谐波主要由 PWM 开关频率产生，选开关频率 >10kHz 的变流器，叠加后间谐波含量降低。

### 6.3 SVG 扩容

SVG 由 ±20Mvar 增至 ±30Mvar（含无功储备）。

### 6.4 保护配合

汇集线过流整定 0.5s，与 LVRT 625ms 配合，确保电网故障时逆变器不脱网。

## 7. 经验教训

- [ ] **新能源并网须核 LVRT/HVRT**，写入合同并做型式试验
- [ ] **谐波须按逆变器台数叠加**（$\sqrt{n}$ 系数），风电须算间谐波
- [ ] **SVG 容量须覆盖光伏+风电无功需求**
- [ ] **继电保护须与 LVRT 配合**，汇集线保护不能先于 LVRT 动作
- [ ] 新能源并网须保护-电能质量-调度联合设计
