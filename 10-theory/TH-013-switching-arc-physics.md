# 开关电弧物理与交流电流零点熄弧

## 1. 定义

高压断路器开断短路电流时，触头分离瞬间介质被击穿形成电弧——本质是**高温等离子体通道**，电导由热电离维持。交流电弧每半周电流自然过零一次（50Hz 系统每 10ms 一次），若电流过零后弧隙介质强度恢复速率高于恢复电压上升速率，电弧熄灭、电路被切断；反之重燃。

| 物理量                  | 定义                                         | 工程意义                 |
| -------------------- | ------------------------------------------ | -------------------- |
| 电弧电压 $u\_a$          | 弧柱两端压降（典型 20\~30V/短弧、数百 V/长弧）              | 决定电弧功率 $P\_a=u\_a,i$ |
| 介质恢复强度 $U\_{rec}(t)$ | 电流过零后弧隙可承受的工频/冲击电压                         | 须 > TRV              |
| 瞬态恢复电压 TRV           | 电流过零后断口两端电压的瞬态振荡                           | 开断成功的关键考核量           |
| RRRV                 | TRV 上升速率（Rate of Rise of Recovery Voltage） | IEC 62271-100 标准化特征量 |

## 2. 物理图像

电弧稳定燃烧需三个条件：**热电离（高温 > 4000K 维持电导）+ 阴极斑点（电子发射）+ 弧柱电中性（等离子体准中性）**。电流过零瞬间：

```
电流过零前（10ms 半周期）：
  ├─ 弧柱高温 → 气体分子电离 → 电荷载流子密度高 → 电导维持
  └─ 触头分离、弧拉长 → 电弧电压升高 → 电源向电弧输入能量

电流过零瞬间（i=0）：
  ├─ 弧柱能量输入骤停（P_a = u_a·i ≈ 0）
  └─ 弧柱开始冷却去电离 → 电导下降

电流过零后（关键几 μs）：
  ├─ 系统向断口施加 TRV（LC 振荡，上升率 RRRV = 几 kV/μs）
  ├─ 弧隙介质强度 U_rec(t) 恢复（冷却速率决定）
  └─ 比较 U_rec(t) vs TRV(t)：
       U_rec > TRV → 电弧熄灭、开断成功
       U_rec < TRV → 介质击穿、电弧重燃 → 开断失败
```

**交流电弧"自动过零"特性是高压断路器能够开断的根本原因**。直流电弧无过零点，必须另设灭弧手段（磁场吹弧、气吹、人工电流过零），开关技术复杂度高得多。

## 3. 推导

### 3.1 弧隙介质恢复特性（Mayr 模型简化）

电流过零后弧隙电导 $g(t)$ 的衰减：

$$\frac{dg}{dt} = \frac{1}{\tau}\left(\frac{P\_a}{P\_0}-1\right)g$$

其中 $P\_a$ 为电弧功率、$P\_0$ 为冷却功率（灭弧介质决定）、$\tau$ 为电弧时间常数（SF6 \~ 0.1\~1 μs、空气 \~ 数 μs）。当 $P\_a\<P\_0$ 时 $g$ 指数衰减，电弧趋于熄灭。

### 3.2 TRV 与介质恢复的赛跑

系统侧 TRV 近似为 LC 振荡：

$$u\_{TRV}(t) = U\_p\left(1-\cos\omega\_n t\right)+\frac{di}{dt}\bigg|\_0\cdot L\_s\cdot\sin\omega\_n t$$

| 符号           | 含义             | 单位    |
| ------------ | -------------- | ----- |
| $U\_p$       | TRV 峰值（工频恢复分量） | kV    |
| $\omega\_n$  | 系统自然振荡角频率      | rad/s |
| $L\_s$       | 系统等效电感         | mH    |
| $di/dt\|\_0$ | 电流过零变化率        | A/μs  |

**开断成功判据**：$U\_{rec}(t) \geq TRV(t)$ 对全部 $t>0$。

### 3.3 近区故障的特殊挑战

故障点距断路器 0.5~~5km 时，线路行波叠加到 TRV 上，RRRV 显著抬高（可达标准值的 3~~5 倍），是高压断路器最严苛的开断工况之一（IEC 62271-100 §4.105）。

## 4. 与工程实践的联系

- **支撑条目 1**：[CALC-SC-002 高压短路计算](../40-calc/CALC-SC-002-hv-short-circuit-iec60909.md) §7 校验断路器开断容量 $I\_{bk}\geq I\_k''$ 的根据——$I\_k''$ 决定 $di/dt|\_0$ 与 TRV 幅值，本理论给出物理原因。

- **支撑条目 2**：[PR-PE-001 继电保护配置](../30-practice/PR-PE-001-relay-protection-config.md) §7.8 CT 准确限值校验的关联——近端短路时 $I\_k''$ 大、$di/dt$ 大、TRV 严苛，断路器与保护须协同校验。

- **失效边界**：① **直流系统**——无过零点，传统交流断路器原理失效，须用磁吹/气吹/人工过零装置；② **超导失超**——超导限流器失超瞬间等效电阻快速增大，迫使电流进入零点，是新型灭弧思路；③ **SF6 替代气体**（环保型真空、干燥空气、g3 等）的 $\tau$ 与 $P\_0$ 不同，介质恢复速率可能慢于 SF6，TRV 校验须重做；④ **逆变器故障电流**——电力电子无机械触头，靠关断器件"自熄弧"，但器件反向恢复电流与 dv/dt 耐量是新型等效约束（构网型变流器见 GB/T 47968-2026）。
