# 同步电机暂态与次暂态电抗

## 1. 定义

同步电机在机端突然三相短路时，定子电流经历**次暂态 → 暂态 → 稳态**三段衰减，分别对应三种直轴电抗：

| 符号 | 名称 | 物理量 | 典型值（p.u.） |
|---|---|---|---|
| $X_d''$ | 直轴次暂态电抗 | 最小；含阻尼绕组闭路效应 | 0.15~0.30（隐极）；0.20~0.40（凸极） |
| $X_d'$ | 直轴暂态电抗 | 阻尼衰减后、励磁绕组闭路效应仍存 | 0.25~0.45 |
| $X_d$ | 直轴同步电抗 | 稳态；仅定子电枢反应 | 1.2~2.5（隐极）；1.0~1.8（凸极） |

对应的时间常数：

| 符号 | 含义 | 典型范围 |
|---|---|---|
| $T_d''$ | 次暂态时间常数 | 0.02~0.10 s（2~6 周波） |
| $T_d'$ | 暂态时间常数 | 0.5~3.0 s |
| $T_a$ | 非周期分量衰减时间常数 | 0.05~0.30 s |

## 2. 物理图像

同步电机正常运行时，转子励磁磁链 $\Psi_f$ 恒定（恒励励磁通）。机端突然短路瞬间，定子电流骤增、电枢反应磁通骤变。根据**磁链守恒定律**（超导闭合绕组磁链不能突变），三个闭合绕组——阻尼绕组、励磁绕组、定子绕组——各自产生感应电流抵抗磁通变化：

```
t=0 突然短路
  ├─ 阻尼绕组（低漏抗闭合）→ 感应电流最大 → 磁通被挤到气隙→定子漏磁路径
  │   → 电抗最小 = Xd″（次暂态）
  │
  ├─ Td″ 后阻尼电流衰减完毕
  │   → 励磁绕组仍闭路反抗 → 磁通经励磁漏磁路径
  │   → 电抗增大 = Xd'（暂态）
  │
  └─ Td' 后励磁暂态电流衰减完毕
      → 仅剩定子电枢反应主路径
      → 电抗最大 = Xd（稳态）
```

**直角理解**：电抗大小由磁通路径的磁阻决定。短路瞬间磁通被"挤"进高磁阻路径（漏磁路），故电抗最小；随各绕组感应电流衰减，磁通逐步"夺回"低磁阻主磁路，电抗逐步增大。

## 3. 推导

### 3.1 次暂态电抗 $X_d''$ 的表达式

基于双反应理论，d 轴等效电路（三绕组耦合：定子 d 轴 / 励磁绕组 f / 阻尼绕组 D）：

$$X_d'' = X_{ls} + \frac{1}{\frac{1}{X_{ad}} + \frac{1}{X_{lf}} + \frac{1}{X_{lD}}}$$

其中：

| 符号 | 含义 | 单位 |
|---|---|---|
| $X_{ls}$ | 定子漏抗 | p.u. |
| $X_{ad}$ | d 轴电枢反应电抗（互感） | p.u. |
| $X_{lf}$ | 励磁绕组漏抗 | p.u. |
| $X_{lD}$ | 阻尼绕组漏抗 | p.u. |

物理含义：三个漏抗经互感 $X_{ad}$ 并联后与定子漏抗串联——即磁通被挤入定子漏磁 + 励磁漏磁 + 阻尼漏磁三条并联高磁阻路径。

### 3.2 暂态电抗 $X_d'$

阻尼绕组衰减完毕后（阻尼绕组"开路"），仅剩定子与励磁绕组耦合：

$$X_d' = X_{ls} + \frac{1}{\frac{1}{X_{ad}} + \frac{1}{X_{lf}}} = X_{ls} + \frac{X_{ad} \cdot X_{lf}}{X_{ad} + X_{lf}}$$

### 3.3 短路电流衰减全表达式

机端三相突然短路，交流分量有效值：

$$I_k(t) = \underbrace{\frac{E_f}{X_d}}_{\text{稳态}} + \underbrace{\left(\frac{E_f}{X_d'} - \frac{E_f}{X_d}\right) e^{-t/T_d'}}_{\text{暂态分量}} + \underbrace{\left(\frac{E_f}{X_d''} - \frac{E_f}{X_d'}\right) e^{-t/T_d''}}_{\text{次暂态分量}}$$

其中 $E_f$ 为励磁电势。短路瞬间 $t=0$ 时：

$$I_k''(0) = \frac{E_f}{X_d''}$$

这就是 IEC 60909 / GB/T 15544.1 计算初始对称短路电流 $I_k''$ 时取 $X_d''$ 的根据。

### 3.4 交轴次暂态电抗 $X_q''$

凸极电机 q 轴无励磁绕组，仅有阻尼绕组：

$$X_q'' = X_{ls} + \frac{1}{\frac{1}{X_{aq}} + \frac{1}{X_{lQ}}}$$

$X_q'' \geq X_d''$（q 轴阻尼效应通常弱于 d 轴），不对称短路分析中用于求 $I_{k2}''$（两相短路）。

## 4. 与工程实践的联系

- **支撑条目 1**：[CALC-SC-002 高压短路电流计算](../40-calc/CALC-SC-002-hv-short-circuit-iec60909.md)——发电机端或近端短路时，$I_k'' = c \cdot U_n / (\sqrt{3} \cdot X_d'')$，发电机作为等效电压源内阻抗取次暂态电抗。
- **支撑条目 2**：CALC-SC-001 §7.4 电动机反馈电流——异步电动机在短路瞬间也贡献次暂态电流，等效电抗 $X_M'' \approx 1/I_{st}^*$（启动电流倍数倒数），本理论给出"感应电流反抗磁通突变"的共同物理本质。
- **失效边界**：① 磁路饱和——$X_d''$ 随短路电流增大而降低（饱和效应），大型电机须取饱和值；② 调节器动作——自动励磁调节器（AVR）在 $T_d'$ 量级介入，可能改变暂态段衰减速率；③ 不对称工况——单相/两相短路须用对称分量法（见 [TH-003](TH-003-symmetrical-components.md)）引入 $X_2$（负序）和 $X_0$（零序），三者均为次暂态量级但机理不同。
