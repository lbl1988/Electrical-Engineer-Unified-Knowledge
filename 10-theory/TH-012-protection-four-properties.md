# 继电保护四性（可靠性/选择性/灵敏性/速动性）

## 1. 定义

继电保护在电力系统故障或异常运行时的**四项基本性能要求**，源自 GB/T 14285-2006 §3.1 与长期工程经验：

| 性能 | 定义 | 量化指标方向 |
|---|---|---|
| **可靠性** (Reliability) | 该动时**必动**（依赖性/不拒动），不该动时**不动**（安全性/不误动） | 拒动率/误动率；MTBF |
| **选择性** (Selectivity) | 只切除故障元件，停电范围最小；近后备/远后备配合 | 配合级差 Δt=0.3~0.5s |
| **灵敏性** (Sensitivity) | 对保护范围内最小运行方式下的故障能可靠反应 | 灵敏系数 $K_{sen}$ |
| **速动性** (Speed) | 尽快切除故障，限制设备损坏与系统稳定破坏 | 切除时间 $t$ |

## 2. 物理图像

电力系统短路本质是绝缘破坏形成低阻抗通道，故障电流骤增至数倍~数十倍额定。保护装置感知这一电气量突变（电流增大/电压降低/阻抗下降），按预设逻辑跳闸。**四性是同一动作行为的四个评价维度**，彼此**互相制约**：

```
        可靠性（不拒动）↔ 不误动
              ↑ 矛盾
        速动性（快）  ↔ 选择性（只跳该跳的）
              ↑ 矛盾
        灵敏性（敏）  ↔ 速动性（动作量门槛低→易误动）
```

典型权衡：为提高**速动性**把瞬时动作门槛 $I_{set}$ 调低 → 末端故障也能瞬动 → 但下游近端故障时本保护可能越级跳闸，**选择性**被破坏；为提高**灵敏性**降低最小动作值 → 启动元件易受涌流/负荷波动干扰 → **可靠性（不误动）**下降。

## 3. 推导

### 3.1 灵敏系数 $K_{sen}$

对**过量保护**（电流/电压升高型）：

$$K_{sen} = \frac{\text{保护范围内最小运行方式下的故障量}}{\text{保护动作整定值}}$$

对**欠量保护**（距离/电压降低型）：

$$K_{sen} = \frac{\text{保护动作整定值}}{\text{保护范围内最小运行方式下的故障量}}$$

**GB/T 14285-2006 §3.0.5 给出常用下限**：

| 保护类型 | 灵敏系数 $K_{sen}$ 要求 |
|---|---|
| 电流/电压速断（主保护） | $\geq 1.5$（个别 1.25） |
| 带时限电流/电压保护（主） | $\geq 1.3\sim 1.5$ |
| 远后备保护 | $\geq 1.2$ |
| 零序电流后背 | $\geq 1.2\sim 1.3$ |

### 3.2 选择性级差 $\Delta t$

$$\Delta t = t_{upstream} - t_{downstream} = t_{op,down} + t_{GF,down} + t_{err} + t_{margin}$$

| 组成 | 含义 | 典型值 |
|---|---|---|
| $t_{op,down}$ | 下游断路器分闸时间 | 30~60 ms |
| $t_{GF,down}$ | 下游保护继电器返回时间 | 20~50 ms |
| $t_{err}$ | 上下级保护时间误差累计（同型 ±5%） | 50~100 ms |
| $t_{margin}$ | 裕度 | 50~100 ms |
| **合计** | — | **0.3~0.5 s** |

微机型保护时间精度提高，**$\Delta t=0.3\sim 0.4$ s 已成主流**（电磁式时代 0.5 s）。

### 3.3 速动性与系统稳定的关系

故障切除时间 $t_c$ 影响同步发电机**等面积准则**中的减速面积。对于近端三相短路，**极限切除时间** $t_{c,\lim}$ 与故障期间发电机转差 $\delta$ 增量正相关：

$$t_{c,\lim} \propto \sqrt{\frac{2H(\delta_c-\delta_0)}{\omega_0 P_m}}$$

其中 $H$ 为惯性常数、$\delta_c$ 为临界清除角。$t_c > t_{c,\lim}$ 即失稳。这就是 220kV 及以上系统主保护要求 $\leq 0.1$ s 的根据。

| 符号 | 含义 | 单位 |
|---|---|---|
| $K_{sen}$ | 灵敏系数 | — |
| $I_{set}$ | 动作电流整定值 | A |
| $\Delta t$ | 上下级时间级差 | s |
| $t_c$ | 故障切除时间 | s |
| $H$ | 发电机惯性常数 | s |

## 4. 与工程实践的联系

- **支撑条目 1**：[PR-PE-001 继电保护配置与整定配合](../30-practice/PR-PE-001-relay-protection-config.md)——本理论给出整定配合的"为什么"：动作值/时间级差/灵敏系数校验全部源自四性约束，工程整定流程是把四性量化为可校验参数。
- **支撑条目 2**：[CALC-PT-001 低压保护整定](../40-calc/CALC-PT-001-protection-setting.md)——低压断路器级间选择性配合（$\Delta t=0.1\sim 0.2$ s、长延时/短延时/瞬动三段）是四性在低压侧的具体化，与高压侧主后备保护同源。
- **失效边界**：① **弱馈与最小运行方式**——系统容量小、电源远离故障点时，故障电流可能低于最小动作值，导致 $K_{sen}<1.2$，须增设方向/距离/差动保护；② **新型电源（逆变器并网）**——逆变器故障电流受电流环限幅，幅值仅为额定 1.1~1.5 倍且相位可控，传统过流保护**灵敏性与选择性同时退化**，构网型变流器（GB/T 47968-2026、GB/T 47655-2026）通过故障穿越与电流注入策略部分恢复；③ **直流系统**——无过零点，传统交流保护原理失效，须用行波/微分保护；④ **涌流与 CT 饱和**——变压器空投励磁涌流可达 8~10 倍额定，2/3 次谐波闭锁是防止误动的关键，CT 严重饱和会畸变二次电流波形，影响采样保护判据。
