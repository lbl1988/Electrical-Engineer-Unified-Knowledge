**三条铁律**（README §1，不可违反）：

1. **上层引用下层，禁止反向依赖**（实践条目可引理论，理论条目不得引实践结论）；

## 5. 治理机制（接手即生效）

- **版本信息只认白名单 8 源**，公众号/网盘转录只能作线索，须双独立来源交叉验证后才可入库（历史上靠此方法修正过 OCR 噪声，如"CD-55020-2022"→GB 55029-2022）；

- **换版响应**：新版本实施 → 按 05 模板写 CHG → 在 changelog 表格登记"对本库影响"→ 逐条修正受影响条目的 standards 数组与正文引用 → git commit。

## 6. 质量方法论（已验证的写作纪律，务必延续）

1. **算例数字全部手工复算**：写作前先在草稿中复算每个中间值（如 Ae=[1800+13194+16890]×10⁻⁶=0.0319km²），不自洽不落盘；
2. **方法严谨优先于数字吻合**：CALC-SC-001 曾遇预告值 ip≈42.8kA 与精确复算 53.6kA 不符，处置是改为双短路点设计（d1 精确法＋d2 演示 κ=1.3 简化法对照），而非凑数；
3. **不确定值显式标注**：照度档位、GB 51309 具体条文号、Kc 曲线精确值等一律写"以正式文本/曲线为准"；
4. **典型易错点固化为"常见错误"表**：如 c 系数双重计入（X_Q 应=Un²/SscQ，避免 c 双重计入）、GB 51309 与 DL/T 5044 双体系公式不混用、10/350μs 与 8/20μs 波形不可互换；
5. **条目交叉引用成网**：TH→CALC→PR 三层链（如 TH-003 对称分量→CALC-PT-001 两相灵敏度→PR-DD-001 选型闭环），每条至少一个上游引用＋一个下游应用。
