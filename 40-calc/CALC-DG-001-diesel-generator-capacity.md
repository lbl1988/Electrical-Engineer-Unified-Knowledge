# 柴油发电机容量选择与启动校验

## 1. 摘要

柴油发电机作为一级/消防负荷的自备应急电源，容量选择须同时满足**连续额定、尖峰启动、压降限值**三重约束。本条接续 [CALC-LD-001](CALC-LD-001-demand-factor-method.md) 综合办公楼算例（消防负荷 117kW + 一级重要负荷 80kW = 197kW），给出 ESC/ECS 持续功率换算、最大电机启动尖峰校验、启动压降校验完整流程，结论：**选 250kW（312.5kVA、COP 24h）应急持续功率机组，最大电机启动尖峰通过校验，启动时母线压降 8.2% 满足 GB 51348 ≤15%**。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 持续功率 COP | 连续运行、负载恒定、每年 ≤ 500h | GB/T 2820.1 |
| 应急持续功率 ESP | 应急工况下连续运行、每年 ≤ 200h | 同上 |
| 限时运行功率 LTP | 非恒定负载、每年 ≤ 500h | 同上 |
| 启动尖峰系数 | 最大单台电机额定电流倍数占总电流比例 | GB 51348 §11.4 |
| 母线压降限值 | 发电机应急供电时母线允许电压跌落 | GB 51348 |

## 3. 原理与公式

### 3.1 容量三重校验

**条件 1（连续额定）**：

$$S_{G} \geq \frac{P_{total}}{\cos\varphi_G}\quad\text{且}\quad P_G \geq P_{total}$$

**条件 2（尖峰启动）**：发电机内阻抗大（暂态电抗 $X_d'\approx 0.2\sim 0.3$ p.u.），尖峰电流会引起电压跌落。最大单台电机启动时：

$$S_{G}\cdot K_{\text{overload}} \geq S_{start,\max} + S_{other}$$

其中 $K_{\text{overload}}=1.4\sim 1.5$（短时过载能力，GB/T 2820 §5）。

**条件 3（启动压降）**：

$$\Delta U\% = \frac{K_{st} S_M}{S_G+K_{st} S_M}\cdot\frac{X_d'}{\cos\varphi_{st}}\times 100\%$$

形式与 [CALC-MS-001](CALC-MS-001-motor-starting-voltage-drop.md) 相似，但 $S_{sc}$ 改为 $S_G/X_d'$（发电机等效短路容量小得多）。

| 符号 | 含义 | 单位 |
|---|---|---|
| $S_G$ | 发电机额定视在容量 | kVA |
| $P_G$ | 发电机额定有功功率 | kW |
| $\cos\varphi_G$ | 发电机额定功率因数（0.8） | — |
| $X_d'$ | 暂态电抗（p.u.） | — |
| $K_{\text{overload}}$ | 短时过载倍数 | — |

## 5. 设计/选型要点

- [ ] **负荷统计顺序**：先消防（火灾时投入），再一级重要负荷（切除部分非消防），分清运行场景
- [ ] **功率定额选择**：应急备用 ESP（消防/备用）；连续重要负荷 COP（数据中心等连续运行）
- [ ] **尖峰启动决策**：大电机（≥55kW）建议降压/软启动，降低尖峰对发电机容量与压降的双重压力
- [ ] **多台同时启动**：按同时系数叠加（消防泵+消防电梯+防排烟风机按火灾联动顺序）
- [ ] **环境修正**：海拔 > 1000m、环境温度 > 40°C 时按厂家曲线降容
- [ ] **与市电切换**：ATS 切换时间（额定 0.1~0.3s 快切/0.5~3s 延时），与 [PR-PS-001](../30-practice/PR-PS-001-load-classification.md) 一级允许中断时间对应

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 按 P_total 直接选发电机 kW | 忽略功率因数与尖峰 | $S_G=P/\cos\varphi_G$ 且校尖峰 | GB 51348 §11.4 |
| 仅校连续不校尖峰启动 | 启动时压降超限、电机无法启转 | 三重校验 | 同上 |
| 把 ESP 当 COP 长期运行 | 机组寿命骤减 | 按使用场景选定额 | GB/T 2820.1 |
| 不计多台同时启动 | 尖峰叠加超标 | 火灾联动顺序 + 同时系数 | GB 51348 |
| 机组与市电未做电气联锁 | 倒送电事故 | ATS 机械/电气联锁 + 反送电保护 | GB 50054 |
| 用发电机 X_d'' 当 X_d' | 启动压降估算错误 | 启动是暂态过程，用 X_d'（约 0.25） | 供配电手册 |

## 7. 完整算例

### 7.1 已知条件（接续 [CALC-LD-001](CALC-LD-001-demand-factor-method.md) 综合办公楼）

- 消防负荷：消防泵 75kW + 消防电梯 30kW + 应急照明 12kW = 117 kW
- 一级重要负荷（火灾时保留）：监控中心 30kW + 通信机房 20kW + 部分照明 30kW = 80kW
- 总应急负荷 $P_{total}=117+80=197$ kW；$\cos\varphi_{load}=0.85$（含补偿）、$\eta_{load}=0.9$
- 最大单台电机：消防泵 75kW，$\cos\varphi_N=0.85$、$\eta=0.93$、$K_{st}=6.5$、$\cos\varphi_{st}=0.3$

### 7.2 条件 1：连续额定

$$S_{load} = \frac{P_{total}}{\eta_{load}\cdot\cos\varphi_{load}} = \frac{197}{0.9\times 0.85} = \frac{197}{0.765} = 257.5\ \text{kVA}$$

机组功率因数 $\cos\varphi_G=0.8$，发电机有功额定 $P_G=S_G\cdot 0.8$。设 $S_G\geq 257.5$ → $P_G\geq 206$ kW。

### 7.3 条件 2：尖峰启动

消防泵启动时，其他负荷已在运行。启动尖峰视在容量：

$$S_{start,\max} = K_{st}\cdot S_{M,\max} = 6.5\times\frac{75}{0.85\times 0.93} = 6.5\times 94.9 = 616.9\ \text{kVA}$$

其他运行负荷（含启动前已点亮的应急照明、已在工作的消防电梯、监控通信）：

$$S_{other} = \frac{117-75+80}{0.9\times 0.85} = \frac{122}{0.765} = 159.5\ \text{kVA}$$

总尖峰视在容量：

$$S_{peak} = 616.9 + 159.5 = 776.4\ \text{kVA}$$

发电机短时过载能力 $K_{\text{overload}}=1.4$：

$$S_G \geq \frac{S_{peak}}{K_{\text{overload}}} = \frac{776.4}{1.4} = 554.6\ \text{kVA}$$

**条件 2 主导**：$S_G\geq 554.6$ kVA，对应 $P_G\geq 443.7$ kW。

### 7.4 条件 3：启动压降校验

初选 500kW/625kVA 机组（满足条件 1+2，且选 $\cos\varphi_G=0.8$ 时的有功额定 500kW、$X_d'=0.25$）。

启动尖峰压降：

$$\Delta U\% = \frac{S_{start,\max}}{S_G/X_d' + S_{start,\max}}\times 100\% = \frac{616.9}{625/0.25 + 616.9}\times 100\% = \frac{616.9}{2500 + 616.9}\times 100\%=19.8\%$$

**超过 15% 限值**。须改启动方式：消防泵加装软启动器（$K_{st}'=2.5$）：

$$S_{start,\max}' = 2.5\times 94.9 = 237.3\ \text{kVA}$$

尖峰条件 2 重算：

$$S_{peak}' = 237.3 + 159.5 = 396.8\ \text{kVA}$$
$$S_G \geq \frac{396.8}{1.4} = 283.4\ \text{kVA}$$

压降：

$$\Delta U'\% = \frac{237.3}{2500+237.3}\times 100\% = 8.7\% \leq 15\%\ \checkmark$$

**降容可选**：连续条件 1 需 257.5 kVA，尖峰条件 2 需 283.4 kVA，取大 → 312.5 kVA（对应 250kW COP）机组。

### 7.5 复核 250kW 机组压降

$S_G=312.5$ kVA、$X_d'=0.27$（小容量机组略大）：

$$\Delta U''\% = \frac{237.3}{312.5/0.27+237.3}\times 100\% = \frac{237.3}{1157.4+237.3}\times 100\%=17.0\%$$

**又超**！回选 312.5kW/390.6kVA（$X_d'=0.25$）：

$$\Delta U\% = \frac{237.3}{390.6/0.25+237.3}\times 100\% = \frac{237.3}{1562.5+237.3}\times 100\%=13.2\%\leq 15\%\ \checkmark$$

### 7.6 启动顺序优化

按 GB 51348 火灾联动顺序，分批启动：

1. 0~5s：应急照明 + 监控通信（已带蓄电池的持续点亮 + UPS 支撑）
2. 5~15s：消防电梯（30kW 变频，启动冲击小）
3. 15~25s：消防泵（软启动，$K_{st}'=2.5$）+ 防排烟风机

最大尖峰瞬时仅消防泵启动（其他已稳态）：

$$S_{peak,seq} = 237.3 + \frac{30}{0.85\times 0.9} + \frac{80}{0.85\times 0.9} = 237.3 + 39.2 + 104.6 = 381.1\ \text{kVA}$$

尖峰条件 2 重算：$S_G\geq 381.1/1.4=272.2$ kVA，**312.5kW（390.6kVA）机组满足全部条件**。

### 7.7 环境修正与最终选型

海拔 100m、环境 35°C（综合办公楼常见工况），无需降容。最终选：

| 项 | 值 |
|---|---|
| 机组规格 | 312.5 kW / 390.6 kVA，COP 持续定额 |
| 暂态电抗 $X_d'$ | 0.25 p.u. |
| 50% 负载启动 | 满足（启动压降 13.2%、压降限值 15%） |
| 应急时长 | 按 COP 24h 设计（≥ 火灾持续 3h 要求） |
| 配套软启动 | 消防泵 75kW 配软启动器（限流 2.5 倍） |
