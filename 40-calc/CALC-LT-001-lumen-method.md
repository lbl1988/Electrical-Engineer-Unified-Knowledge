# 利用系数法照度计算（LED 时代校准）

## 1. 摘要

利用系数法是室内一般照明**灯具数量与照度**互算的标准方法：$N=\dfrac{E\,A\,MF}{\Phi\,UF}$。本条算例：普通办公室 12m×6m、层高 3.3m，目标 300lx（GB/T 50034-2024），36W/3600lm LED 面板灯，$RI$=1.57、$UF$=0.60、$MF$=0.80 → **8 套、间距 3m 双排布置，LPD=4.0 W/m²**（大幅优于现行值）。LED 时代三个校准点：光通量按初始值×维持假设、$UF$ 表须用 LED 灯具分布光度数据、维护系数按 2024 版周期取值。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 利用系数 $UF$ | 投射到工作面上的光通量与灯具总光通量之比 | 照明设计手册（第三版） |
| 维护系数 $MF$ | 设备老化与污染后的照度与初始照度之比（清洁环境通常 0.80） | GB/T 50034-2024 |
| 室形指数 $RI$ | 房间几何特征量 $RI=LW/[h_m(L+W)]$ | 同上/手册 |
| 维持平均照度 | 维护周期内须始终保证的平均照度（标准值即维持值） | GB/T 50034-2024 |
| LPD | 照明功率密度（W/m²），含驱动电源 | 同上 |

## 3. 原理与公式

$$\boxed{N=\frac{E\,A\,MF}{\Phi\,UF}}\qquad\text{或校验}\qquad E=\frac{N\,\Phi\,UF}{A\,MF}$$

$$RI=\frac{L\times W}{h_m\,(L+W)},\qquad h_m=H-0.75\ \text{（坐姿工作面，站姿 0.85~0.9m）}$$

| 符号 | 含义 | 单位 |
|---|---|---|
| $E$ | 维持平均照度标准值 | lx |
| $A=L\times W$ | 房间面积 | m² |
| $\Phi$ | 单灯具**额定**光通量（LED 按初始值） | lm |
| $UF$ | 利用系数（查表：反射比组合 × $RI$） | — |
| $MF$ | 维护系数 | — |

**适用边界**：① 一般照明均匀布灯；② 体育场馆、道路、投光照明用专门的利用系数/亮度法体系；③ 局部照明/重点照明用逐点计算法（点光源平方反比＋余弦），软件（DIALux 类）验证；④ LED 灯具 $UF$ 表必须由该灯具 C-γ 分布光度数据生成，旧灯具（格栅荧光）表格不可沿用。

## 5. 设计/选型要点（校审清单）

- [ ] 照度标准值取**维持值**口径（GB/T 50034-2024），作业面高度按实际（坐姿 0.75m）
- [ ] $UF$ 用**本项目灯具**的分布光度数据表；灯具色温/显色（Ra≥80，视看需求 Ra≥90）另列
- [ ] $MF$ 按环境洁净等级与擦拭周期；户外/工业多尘取 0.65~0.70
- [ ] 布灯后校验**距高比 $SHD$** ≤灯具允许值（防照度谷）；靠墙距离 ≤ 间距/2
- [ ] LPD 复核 ≤ 现行值；绿色建筑目标可按目标值申报
- [ ] 频闪（波动深度）、眩光（UGR）与蓝光危害（RG 分级）单列校验（GB/T 50034-2024 新体系，→ [CHG-001](../20-standards/changelog/CHG-001-GBT50034-2024.md)）

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| LED 沿用荧光灯 $UF$ 表 | 灯具数偏差 ±15% | 用 LED 灯具光度数据重建 $UF$ 表 | 手册＋灯具样本 |
| $MF$ 统一取 0.8 | 多尘工业/户外照度不足 | 按环境分级取 0.65~0.80 | GB/T 50034-2024 |
| 混淆"初始照度"与"维持照度" | 交验时照度"虚高" | 标准值=维持值；初始照度≈$E/MF$ | 同上 |
| 用灯具"输入功率×光效"反推光通量 | 漏驱动损耗 | $\Phi$ 取额定光通量（样本实测） | 样本 |
| LPD 只算灯珠功率 | LPD 虚低 | LPD 含驱动电源全部输入功率 | GB/T 50034-2024 |

## 7. 完整算例

### 7.1 已知条件（普通办公室）

| 参数 | 数值 | 来源 |
|---|---|---|
| 房间 | L=12m，W=6m，H=3.3m，吸顶安装 | 建筑 |
| 反射比 | 顶棚 0.70 / 墙 0.50 / 地面 0.20 | 手册推荐 |
| 灯具 | LED 面板灯 36W，$\Phi$=3600lm，允许 $SHD$≈1.3 | 样本 |
| 目标照度 | 300lx（维持平均，工作面 0.75m） | GB/T 50034-2024 |
| 维护系数 | 0.80（清洁环境） | 同上 |

### 7.2 室形指数与利用系数

$$h_m=3.3-0.75=2.55\ \text{m},\qquad RI=\frac{12\times6}{2.55\times(12+6)}=\frac{72}{45.9}=1.57$$

查该灯具 $UF$ 表（0.70/0.50/0.20 反射比组合）：$RI$=1.5 行 → **$UF$=0.60**。

### 7.3 灯具数量与布灯

$$N=\frac{300\times72\times0.80}{3600\times0.60}=\frac{17\,280}{2160}=8.0\ \Rightarrow\ \textbf{8 套}$$

布置：2 列×4 行，间距 3.0m×3.0m（靠墙 1.5m）。距高比校验：$3.0/2.55=1.18<1.3$ ✓。

### 7.4 反算与 LPD 复核

$$E=\frac{8\times3600\times0.60}{72\times0.80}=300\ \text{lx}\ \checkmark,\qquad LPD=\frac{8\times36}{72}=4.0\ \text{W/m}^2$$

LPD 4.0 W/m² 大幅低于 GB/T 50034-2024 普通办公室现行值（LED 基准，具体数值以标准 LPD 表为准），满足节能审查并为绿色建筑留出空间。
