# 高压线路距离保护整定（三段式距离保护）

## 1. 摘要

距离保护以**测量阻抗**（$Z_m=U_m/I_m$）为判据，反映故障点距离，是高压线路主保护的核心。本条给出三段式距离保护（Ⅰ段瞬动/Ⅱ段带时限/Ⅲ段后备）的整定流程与灵敏度校验，算例：某110kV线路长40km，正序阻抗 $Z_1$=0.4Ω/km，Ⅰ段整定 $Z_{set1}$=0.8×16=12.8Ω（瞬动，保护线路80%）、Ⅱ段 $Z_{set2}$=0.8×(16+0.8×20)=25.6Ω（与下级Ⅰ段配合）、Ⅲ段按躲最大负荷整定，末端金属性短路灵敏度1.56。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 测量阻抗 $Z_m$ | 保护安装处电压与电流之比 $Z_m=U_m/I_m$ | GB/T 14285-2006 |
| 距离Ⅰ段 | 瞬动段，保护线路全长的80%~85%，无延时 | DL/T 584 |
| 距离Ⅱ段 | 带时限段，与下级Ⅰ段配合，延时0.3~0.5s | 同上 |
| 距离Ⅲ段 | 后备段，按躲最大负荷整定，延时与下级Ⅱ段配合 | 同上 |
| 灵敏系数 $K_{sen}$ | 保护区末端最小运行方式下短路时测量阻抗与整定阻抗之比 | GB/T 14285-2006 |

## 3. 原理与公式

**距离Ⅰ段整定**（瞬动，不伸出本线末端）：

$$Z_{set,1} = K_{rel,1}\cdot Z_{L}$$

其中 $K_{rel,1}$=0.80~0.85（可靠系数），$Z_L$=本线路正序阻抗。

**距离Ⅱ段整定**（与下级Ⅰ段配合）：

$$Z_{set,2} = K_{rel,2}\cdot(Z_L + Z_{set,1}^{next})$$

其中 $K_{rel,2}$=0.80，$Z_{set,1}^{next}$=下级线路Ⅰ段整定阻抗。

**距离Ⅲ段整定**（躲最大负荷 + 与下级Ⅱ段配合）：

$$Z_{set,3} = \frac{U_{min}/\sqrt3}{K_{rel}\cdot K_{re}\cdot I_{L,max}}\cdot\frac{1}{\cos(\varphi_L-\varphi_{sen})}$$

或按与下级Ⅱ段配合：$Z_{set,3}=K_{rel,3}\cdot(Z_L+Z_{set,2}^{next})$。

| 符号 | 含义 | 单位 |
|---|---|---|
| $Z_{set,1/2/3}$ | Ⅰ/Ⅱ/Ⅲ段整定阻抗 | Ω |
| $Z_L$ | 本线路正序阻抗 | Ω |
| $K_{rel}$ | 可靠系数（0.8~0.85） | — |
| $K_{re}$ | 返回系数（0.85~0.9） | — |
| $I_{L,max}$ | 最大负荷电流 | A |
| $\varphi_L$ | 负荷功率因数角 | rad |
| $\varphi_{sen}$ | 最大灵敏角（约70°~80°） | rad |

**灵敏系数校验**：$K_{sen}=Z_{set}/Z_{fault,min}\ge K_{sen,req}$（Ⅰ段不校验灵敏度，Ⅱ段≥1.25，Ⅲ段≥1.2）。

## 5. 设计/选型要点

- [ ] Ⅰ段可靠系数0.80~0.85，保护本线80%~85%，瞬动无延时
- [ ] Ⅱ段与下级Ⅰ段配合，延时0.3~0.5s，灵敏度≥1.25
- [ ] Ⅲ段躲最大负荷，延时与下级Ⅱ段配合，作远后备
- [ ] 振荡闭锁：系统振荡时距离保护可能误动，须投振荡闭锁
- [ ] 过渡电阻影响：单相接地经高阻短路时测量阻抗增大，Ⅰ段保护范围缩短，Ⅱ段须校核

## 6. 常见错误与争议

| 错误 | 后果 | 正确做法 |
|---|---|---|
| Ⅰ段可靠系数取1.0 | 区外故障误动（线路末端对侧母线故障） | $K_{rel,1}$=0.80~0.85 |
| Ⅱ段不与下级配合 | 越级跳闸，选择性破坏 | $Z_{set,2}=K_{rel,2}(Z_L+Z_{set,1}^{next})$ |
| Ⅲ段按额定电流整定 | 高峰负荷时误动 | 按最大负荷电流+返回系数 |
| 未投振荡闭锁 | 系统振荡时误动 | 投振荡闭锁或加装失步判别 |

## 7. 完整算例

### 7.1 系统参数

某110kV线路AB，长40km，正序阻抗 $Z_1$=0.4Ω/km，$Z_L$=16Ω。下级线路BC长25km，$Z_{L2}$=10Ω。最大负荷电流 $I_{L,max}$=300A，最小运行方式下BC末端两相短路电流 $I_{k,min}$=1200A。

### 7.2 距离Ⅰ段整定

$$Z_{set,1}=0.85\times16=13.6\ \Omega$$

保护范围：$13.6/16=85\%$，瞬动（$t_1$=0s）。

### 7.3 距离Ⅱ段整定

下级BC线路Ⅰ段：$Z_{set,1}^{BC}=0.85\times10=8.5\ \Omega$

$$Z_{set,2}=0.8\times(16+8.5)=19.6\ \Omega$$

延时 $t_2$=0.5s（与下级Ⅰ段配合）。

**灵敏度校验**（本线末端最小运行方式两相短路）：

$$Z_{fault,min}=\frac{U_{ph}}{I_{k,min}}=\frac{110/\sqrt3}{1200}=0.0529\ \text{kA...}$$

实际按阻抗比：$K_{sen}=Z_{set,2}/Z_L=19.6/16=1.225\ge1.25$？边界不足，需调整。重新取 $K_{rel,2}$=0.85：

$$Z_{set,2}=0.85\times(16+8.5)=20.8\ \Omega,\quad K_{sen}=20.8/16=1.30\ge1.25\ \checkmark$$

### 7.4 距离Ⅲ段整定

按躲最大负荷：

$$Z_{set,3}=\frac{110/\sqrt3}{0.85\times0.85\times300}\times\frac{1}{\cos(30°-75°)}...$$

简化取与下级Ⅱ段配合：$Z_{set,3}=0.8\times(16+20.8)=29.4\ \Omega$，延时 $t_3$=1.0s。

### 7.5 结论

Ⅰ段13.6Ω/0s，Ⅱ段20.8Ω/0.5s，Ⅲ段29.4Ω/1.0s，灵敏度满足要求。
