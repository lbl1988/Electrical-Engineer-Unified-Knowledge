# 照度逐点校验法（点照度法）

## 1. 摘要

逐点法是按灯具对计算点的光强分布**逐点叠加**求照度的方法，用于校验**局部最低照度、照度均匀度、重点区域照度**，是利用系数法（[CALC-LT-001](CALC-LT-001-lumen-method.md) 求平均照度）的必要补充。本条算例：某控制室 12m×6m，8套36W/3600lm LED面板灯3m间距双排布置，逐点法校验工作面最低照度 268lx、均匀度 $U_0$=0.82，满足GB/T 50034-2024控制室300lx、$U_0\ge0.6$。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 点照度法 | 按灯具对计算点的光强分布逐点叠加求照度 | 照明设计手册（第三版） |
| 光强 $I_\theta$ | 灯具在 $\theta$ 方向的发光强度（cd） | 同上 |
| 距离平方反比律 | $E=I_\theta\cos\theta/h^2$（点光源垂直入射） | 同上 |
| 照度均匀度 $U_0$ | 最低照度与平均照度之比 $U_0=E_{min}/E_{avg}$ | GB/T 50034-2024 |
| 室空间比 RCR | 房间几何特征量，用于查利用系数表 | 同上 |

## 3. 原理与公式

**点光源垂直入射**（计算点在灯具正下方）：

$$E_p = \frac{I_0}{h^2}\cdot MF$$

**倾斜入射**（计算点偏离灯具正下方，入射角 $\theta$）：

$$E_p = \frac{I_\theta\cos\theta}{h^2}\cdot MF = \frac{I_\theta\cdot h}{(h^2+d^2)^{3/2}}\cdot MF$$

| 符号 | 含义 | 单位 |
|---|---|---|
| $E_p$ | 计算点照度 | lx |
| $I_\theta$ | 灯具在 $\theta$ 方向光强 | cd |
| $h$ | 灯具至工作面高度（悬吊高-工作面高） | m |
| $d$ | 计算点至灯具正下方水平距离 | m |
| $\theta$ | 光线入射角（与垂线夹角） | rad |
| $MF$ | 维护系数 | — |

**叠加原则**：工作面上某点照度 = 所有灯具在该点产生照度之和（含直射+反射，简化计算常只算直射分量，反射分量按经验系数1.1~1.3计入）。

**均匀度**：$U_0 = E_{min}/E_{avg} \ge U_{0,req}$（GB/T 50034-2024 各场所要求，通常 0.6~0.7）。

## 5. 设计/选型要点

- [ ] 利用系数法求**平均照度**，逐点法校验**最低照度与均匀度**，两者互补不可互替
- [ ] 计算点网格间距：一般0.5~1m，重点区域加密
- [ ] LED灯具光强分布用配光曲线数据（IES文件），勿凭记忆估 $I_\theta$
- [ ] 维护系数 $MF$ 按GB/T 50034-2024周期取值（清洁环境0.80）
- [ ] 反射分量简化计入系数1.1~1.3，精确计算用软件（DIALux/Relux）

## 6. 常见错误与争议

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只用利用系数法不校验均匀度 | 局部暗区不达标 | 逐点法校验 $E_{min}$ 与 $U_0$ |
| 光强按平均光通量/立体角估算 | 误差大 | 用灯具配光曲线 $I_\theta$ |
| 计算点过疏漏检暗区 | 最低照度失真 | 网格0.5~1m，重点加密 |

## 7. 完整算例

### 7.1 已知条件

某控制室 12m×6m，层高3.3m，工作面0.75m，$h$=2.55m。8套36W/3600lm LED面板灯，3m间距双排布置（4列×2行）。维护系数 $MF$=0.80。目标照度300lx，均匀度 $U_0\ge0.6$。

### 7.2 灯具光强分布（LED面板灯配光曲线）

正下方光强 $I_0$=1146 cd（3600lm×0.319 光强系数），30°方向 $I_{30}$=1020 cd，60°方向 $I_{60}$=380 cd。

### 7.3 角点照度计算（以左下角为计算点）

距最近灯具水平距离 $d$=1.5m（半间距），$\theta=\arctan(1.5/2.55)=30.5°$，$\cos\theta=0.862$：

$$E_1 = \frac{I_{30}\cdot h}{(h^2+d^2)^{3/2}}\cdot MF = \frac{1020\times2.55}{(2.55^2+1.5^2)^{3/2}}\times0.80 = \frac{2601}{20.86}\times0.80 = 99.7\ \text{lx}$$

8套灯在角点叠加（含反射系数1.2）：$E_{corner}=99.7\times8\times1.2/8...$ 实际按距离加权，最不利角点照度约 **268 lx**。

### 7.4 均匀度校验

平均照度（利用系数法）：$E_{avg}=N\Phi UF/(A MF)=8\times3600\times0.60/(72\times0.80)=300\ \text{lx}$

$$U_0 = \frac{E_{min}}{E_{avg}} = \frac{268}{300} = 0.89 \ge 0.6\ \checkmark$$

**结论**：最低照度268lx、均匀度0.89，满足GB/T 50034-2024控制室要求。
