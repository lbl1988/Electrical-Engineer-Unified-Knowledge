# 电压偏差与电压损失计算

## 1. 摘要

电压偏差是用电设备端子电压偏离额定值的相对量，电压损失是线路首末两端电压的代数差（纵向分量）。本条给出基于 [CALC-LD-001](CALC-LD-001-demand-factor-method.md) 综合办公楼负荷（$S_{30}=495.6$ kVA、$P_{30}=395.1$ kW、$Q_{30}=299.2$ kvar）的 380V 低压干线压降校验，并给出 10kV 高压侧偏差核算方法，结论：**最长 250m 电缆干线末端电压偏差 $-2.31\%$，满足 GB 50052 ±5% 要求**；高压侧母线偏差 $\pm 1.0\%$。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 电压偏差 $\delta U$ | 实测电压与额定电压之差占额定电压的百分数 | GB/T 12325-2008 §3.1 |
| 电压损失 $\Delta U$ | 线路首末两端电压的代数差（向量模差，非相量差） | GB 51348-2019 §7.3 |
| 纵向/横向压降 | 纵向=与 $\dot U$ 同相分量（决定末端模值）；横向=正交分量（决定相位偏移） | 供配电手册第四版 §6 |
| 短路容量 $S_{sc}$ | 母线三相短路容量，决定系统等效内阻抗 | GB/T 15544.1-2013 |

## 3. 原理与公式

### 3.1 电压损失（线路阻抗法，工程实用近似）

三相平衡负荷，线路阻抗 $Z=R+jX$，负荷电流 $I$ 与 $\dot U_2$ 夹角 $\varphi$：

$$\Delta U = \sqrt{3}\, I\, (R\cos\varphi + X\sin\varphi)$$

电压损失百分数（相对额定 $U_n$）：

$$\Delta U\% = \frac{\sqrt{3}\, I\, (R\cos\varphi + X\sin\varphi)}{U_n}\times 100\% = \frac{P\, R + Q\, X}{U_n^2}\times 100\%$$

后一等式用 $P=\sqrt3 U_n I\cos\varphi$、$Q=\sqrt3 U_n I\sin\varphi$ 代入，**工程最常用**。

| 符号 | 含义 | 单位 |
|---|---|---|
| $I$ | 负荷电流 | A |
| $R$ | 线路电阻（计入温度修正，铜 $20°C\to60°C$ 系数约 1.16） | Ω |
| $X$ | 线路电抗（$X=0.06\sim 0.08$ Ω/km 电缆；$0.35\sim 0.4$ Ω/km 架空） | Ω |
| $\cos\varphi$ | 负荷功率因数（补偿后） | — |

### 3.2 电压偏差（系统等效法）

变压器分接头与系统等效源串联：

$$\delta U = \delta U_0 + \Delta U_{T} - \Delta U_{line}$$

其中 $\delta U_0$ 为上级系统母线偏差（系统可控时按 0 或小偏差计），$\Delta U_T$ 为变压器分接头调压（标幺），$\Delta U_{line}$ 为线路损失。

**适用边界**：① 仅适用辐射式网络，环路需潮流计算；② 三相平衡，不平衡工况见 GB/T 15543 单独校验；③ 忽略横向分量（$\sin\varphi$ 不大时误差 $<10\%$），重载长线须用精确向量法。

## 5. 设计/选型要点

- [ ] 偏差校验"从源头到末端"全链路：上级 10kV 母线偏差 → 变压器变比/分接头 → 低压主母线 → 干线 → 末端设备端子
- [ ] 变压器分接头优先按 $\Delta U_T$ 抵消线路损失（如低压侧长干线选 +5% 分接，空载略高、满载末端归零）
- [ ] 电缆选型先按载流量（[CALC-CD-001](CALC-CD-001-cable-ampacity-correction.md)）初选，再按 $\Delta U\%$ 校核，取大截面
- [ ] 电动机启动压降单独校验（见 [CALC-MS-001](CALC-MS-001-motor-starting-voltage-drop.md)），不与正常运行压降混算
- [ ] 不平衡度超标时，$N$ 线截面放大、单相负荷均匀分配相序

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 用 $\Delta U\%=\frac{P R}{U_n^2}$ 忽略无功 | 长电缆/低压侧 $\cos\varphi$ 低时压降低估 30%+ | 完整式 $PR+QX$，$X$ 不为零时不可省 | GB 51348 §7.3 |
| 电缆电阻用 $20°C$ 值不修正 | 运行温升后压降实际更大 | 工作温度按 $60\sim90°C$，铜系数 $\alpha=0.00393/°C$ 修正 | GB/T 3956 |
| 高压侧偏差直接相加到低压侧 | 把不同电压等级的标幺值/有名值混用 | 全部换算为标幺值或统一有名值 | 供配电手册 |
| 分接头选错方向 | 满载末端反而更低 | 长干线选 +5% 分接；短干线或电压偏高选 0 或 −2.5% | GB 50052 |
| 母线电压偏差判断只看绝对值 | 忽略负荷曲线（峰谷差） | 按最大/最小两种工况分别校验 | GB/T 12325 |

## 7. 完整算例

### 7.1 已知条件（接续 [CALC-LD-001](CALC-LD-001-demand-factor-method.md) 综合办公楼）

- 变压器 2×630kVA（$u_k=6\%$、Dyn11、10/0.4kV），单台运行负载率 $\beta=495.6/630=78.7\%$
- 高压侧 10kV 母线偏差 $\delta U_0=+0.5\%$（市电稳定区）
- 低压主干线（冷冻机房回路，最大单组负荷 $P_{js}=224$ kW、$Q_{js}=168$ kvar、$\cos\varphi=0.80$）
- 电缆 YJV-0.6/1kV 4×240+1×120，长度 $L=250$ m
- 铜导体 $R_{20}=0.0753$ Ω/km（240mm²），$X=0.076$ Ω/km

### 7.2 电阻温度修正（$20°C\to60°C$）

$$R_{60} = R_{20}\left[1+\alpha(T-20)\right]=0.0753\times\left[1+0.00393\times 40\right]=0.0753\times 1.1572=0.0871\ \Omega/\text{km}$$

单根 250 m：$R=0.0871\times 0.25=0.0218$ Ω；$X=0.076\times 0.25=0.0190$ Ω。

### 7.3 线路电压损失

$$\Delta U\% = \frac{P R + Q X}{U_n^2}\times 100\% = \frac{224\times 10^3\times 0.0218 + 168\times 10^3\times 0.0190}{(380)^2}\times 100\%$$

分子：$4883 + 3192 = 8075$ V·Ω；分母 $380^2 = 144400$。

$$\Delta U\% = \frac{8075}{144400}\times 100\% = 5.59\%$$

**超过一般场所 5% 限值！** 须放大截面或减少长度。改为 2 根并联 4×185+1×95：

- $R_{20}=0.0978$ Ω/km → $R_{60}=0.1131$ Ω/km → 单根 0.0283 Ω；2 根并联 $R=0.01415$ Ω
- $X_{60}\approx 0.078$ Ω/km → 并联 $X=0.00975$ Ω
- $\Delta U\% = \frac{224\times 10^3\times 0.01415 + 168\times 10^3\times 0.00975}{144400}\times 100\% = \frac{3170+1638}{144400}\times 100\%=3.33\%$

满足。

### 7.4 末端电压偏差（优化后）

变压器分接头选 $+5\%$（10.5/0.4kV），满载时变压器内部压降：

$$\Delta U_T\% = \beta\, u_k\%\, \sin\varphi = 0.787 \times 6\% \times \sin(36.87°) = 0.787\times 6\%\times 0.6 = 2.83\%$$

低压主母线偏差：

$$\delta U_{bus} = \delta U_0 + \Delta U_T(\text{分接头}) - \Delta U_T(\text{内阻}) = +0.5\% + 5\% - 2.83\% = +2.67\%$$

末端设备端子：

$$\delta U_{end} = \delta U_{bus} - \Delta U_{line}\% = +2.67\% - 3.33\% = -0.66\%$$

校验：$-0.66\%\in[-5\%,+5\%]$ ✓（照明/电动机 ±5% 要求）。

### 7.5 高压侧偏差校验

10kV 母线直接由上级变电站馈电，$\delta U_0=+0.5\%$，本变配电所 10kV 进线短（50 m，可忽略），10kV 母线偏差≈$+0.5\%\in\pm 7\%$ ✓。

### 7.6 最小负荷工况（$\beta=20\%$）

空载轻载 $\Delta U_T(\text{内阻})\approx 0$，分接头仍 $+5\%$ → $\delta U_{bus}=+0.5\%+5\%=+5.5\%$。**超出 +5% 照明限值**，须选 0 分接或 $+2.5\%$：

- 改 0 分接：满载 $\delta U_{bus}=-2.33\%$、末端 $-5.66\%$（超限）
- 改 $+2.5\%$：满载 $\delta U_{bus}=-0.33\%$、末端 $-3.66\%$ ✓；轻载 $\delta U_{bus}=+3.0\%$、末端 $+3.0\%$ ✓

**结论**：选 $+2.5\%$ 分接头，2 根 4×185 并联，末端偏差范围 $[-3.66\%,+3.0\%]$，满足全工况 ±5%。
