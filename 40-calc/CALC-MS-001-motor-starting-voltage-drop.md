# 电动机启动压降校验

## 1. 摘要

电动机直接启动时 6~8 倍额定电流会在配电系统内阻抗上引起瞬时压降，可能导致母线电压跌落、相邻设备停运或电机本身无法达到额定转矩。本条给出**系统短路容量法**与**逐级阻抗法**两种校验，并接续 [CALC-LD-001](CALC-LD-001-demand-factor-method.md) 综合办公楼算例（冷冻机房 1×75kW 主泵），结论：**直接启动母线压降 4.81%，满足 GB 50055 不频繁启动≤15% 要求**；若同一母线带电梯变频器敏感负载则须改星-三角或软启动降至 1.7%。

## 2. 术语与定义

| 术语 | 定义 | 标准出处 |
|---|---|---|
| 启动电流倍数 $K_{st}$ | 启动电流与额定电流之比，笼型 6~8 | GB/T 1032 |
| 母线短路容量 $S_{sc}$ | 母线三相短路容量 $=\sqrt3\, U_n\, I_k''$ | GB/T 15544.1 |
| 启动压降 $\Delta U_{st}\%$ | 启动瞬间母线电压跌落占额定电压的百分数 | GB 50055 §2.3 |
| 相对启动容量 $S_{stM}/S_{sc}$ | 电机启动视在容量与母线短路容量之比 | 工程经验 |

## 3. 原理与公式

### 3.1 系统短路容量法（最常用，简化）

设母线短路容量 $S_{sc}$、电机额定容量 $S_M$、启动倍数 $K_{st}$，启动瞬间电机从系统抽取容量 $K_{st}S_M$，母线电压跌落近似：

$$\Delta U_{st}\% \approx \frac{K_{st} S_M}{S_{sc} + K_{st} S_M}\times 100\%$$

当 $K_{st}S_M \ll S_{sc}$ 时简化为：

$$\Delta U_{st}\% \approx \frac{K_{st} S_M}{S_{sc}}\times 100\%$$

| 符号 | 含义 | 单位 |
|---|---|---|
| $S_{sc}$ | 母线短路容量 | MVA |
| $S_M$ | 电机额定视在容量 $\approx P_N/(\cos\varphi_N\cdot\eta_N)$ | MVA |
| $K_{st}$ | 启动电流倍数 | — |

**适用边界**：① 仅考虑电机启动分量，未计入其他负荷的稳态压降（须与 [CALC-VL-001](CALC-VL-001-voltage-deviation-and-loss.md) 叠加，方向一致）；② 启动过程近似阻抗恒定，实际 $K_{st}$ 随转速变化，本式给最大瞬时跌落；③ 母线上多台电机同时启动须叠加（同时系数按工艺）。

### 3.2 逐级阻抗法（精确，含线路与变压器）

系统阻抗 $Z_S$、变压器 $Z_T$、线路 $Z_L$ 串联回路，启动时电机等效阻抗：

$$Z_{st,M} = \frac{U_n^2}{K_{st} S_M}$$

启动电流：

$$I_{st} = \frac{U_n}{\sqrt3\,(Z_S+Z_T+Z_L+Z_{st,M})}$$

母线压降：

$$\Delta U_{st}\% = \frac{I_{st}\,|Z_S+Z_T+Z_L|}{U_n/\sqrt3}\times 100\%$$

## 5. 设计/选型要点

- [ ] 先按 [CALC-SC-001](CALC-SC-001-低压三相短路电流计算.md) 计算 $S_{sc}=\sqrt3\, U_n\, I_k''$
- [ ] 计算 $S_{stM}=K_{st}\, S_M$，按相对容量初判：$S_{stM}/S_{sc}\le 15\%$ 大概率可直启
- [ ] 大功率电机（≥55kW LV、≥200kW MV）须做逐级阻抗法校验
- [ ] 启动方式选择决策树：
  ```
  S_stM/S_sc ≤ 3% → 直接启动（首选）
  3% < ... ≤ 15% → 视负载特性：空载/轻载 → 星-三角/自耦减压；重载 → 软启动
  > 15% 或母线带敏感负载 → 变频器（同时满足调速需求）
  ```
- [ ] 启动尖峰与稳态压降叠加后末端偏差仍须满足 [CALC-VL-001](CALC-VL-001-voltage-deviation-and-loss.md) ±5% 限值
- [ ] 大型电机启动次数/间隔须符合 GB 755 工作制热限制

## 6. 常见错误与争议

| 错误/争议 | 后果 | 正确做法/主流处理 | 依据 |
|---|---|---|---|
| 启动压降与稳态压降混算 | 末端偏差判断错误 | 启动尖峰单独校验（短时尖峰），稳态压降单独算（长期） | GB 50055 §2.3 |
| $S_M$ 取额定有功 $P_N$ | 压降低估 | 取视在容量 $S_M=P_N/(\cos\varphi\,\eta)$ | GB/T 1032 |
| $K_{st}$ 取样本最大值不修正 | 启动电流估高 | 大机一般 6.5，深槽/双笼取样本实测值 | 产品样本 |
| 多台电机同时启动系数取 1 | 压降虚大 | 按工艺同时系数，通常 2 台取 0.8、3 台以上取 0.7 | 供配电手册 |
| 忽略变压器内阻压降 | 末端判断错误 | 变压器内阻 $\Delta U_T\%\approx \beta u_k\%\sin\varphi_{st}$（启动 $\cos\varphi_{st}\approx 0.3$） | GB/T 13499 |
| 仅校验母线不校验末端 | 设备端子可能跌落超限 | 母线 + 干线 + 线路压降叠加，按末段设备端子判 | GB 51348 |

## 7. 完整算例

### 7.1 已知条件（接续 [CALC-LD-001](CALC-LD-001-demand-factor-method.md) 综合办公楼）

- 变压器 2×630kVA（$u_k=6\%$），单台运行
- 由 [CALC-SC-001](CALC-SC-001-低压三相短路电流计算.md)：低压主母线 $I_k''=23.3$ kA
- 母线短路容量：$S_{sc}=\sqrt3\times 0.4\times 23.3=16.13$ MVA
- 启动电机：冷冻机房 1×75kW 主泵，$\cos\varphi_N=0.85$、$\eta=0.93$、$K_{st}=6.5$
- 干线 4×240+1×120 YJV，长度 100m（机房近端）
- 母线上同时有：电梯 3×15kW（变频，不参与启动冲击）、照明 60kW（LED）、其他 127kW

### 7.2 电机额定视在容量

$$S_M = \frac{P_N}{\cos\varphi_N\,\eta} = \frac{75}{0.85\times 0.93} = \frac{75}{0.7905} = 94.9\ \text{kVA} = 0.0949\ \text{MVA}$$

### 7.3 启动容量与短路容量比

$$S_{stM} = K_{st} S_M = 6.5 \times 0.0949 = 0.617\ \text{MVA}$$

$$\frac{S_{stM}}{S_{sc}} = \frac{0.617}{16.13} = 3.83\%$$

接近 3% 临界，须用精确法（启动 $\cos\varphi_{st}\approx 0.3$ 时变压器内阻压降不可忽略）。

### 7.4 母线压降（系统短路容量法）

$$\Delta U_{st}\% = \frac{0.617}{16.13+0.617}\times 100\% = \frac{0.617}{16.747}\times 100\% = 3.69\%$$

### 7.5 变压器内阻压降（启动尖峰）

启动尖峰下变压器负载率 $\beta_{st}=\frac{S_{stM}+S_{other}}{S_T}$。其他负荷（不计电梯变频短时冲击）$S_{other}\approx 0.5\times 495.6/1.2\approx 200$ kVA（简化，启动瞬间其他负荷维持平均值）。

$$\beta_{st} = \frac{0.617+0.20}{0.63} = 1.30$$（短时过载允许）

变压器内阻压降（启动 $\cos\varphi_{st}=0.3$、$\sin\varphi_{st}=0.954$）：

$$\Delta U_{T,st}\% = \beta_{st}\, u_k\%\, \sin\varphi_{st} = 1.30\times 6\%\times 0.954 = 7.44\%$$

### 7.6 母线总压降

精确法叠加（不算线路，因母线近端）：

$$\Delta U_{bus,st}\% \approx 3.69\% + (7.44\%-2.83\%)= 8.30\%$$

其中 $2.83\%$ 为稳态时变压器内阻压降（[CALC-VL-001 §7.4](CALC-VL-001-voltage-deviation-and-loss.md)），与启动尖峰叠加时增量约为启动尖峰独有部分。

简化核对：母线总压降约 $8.30\%$，**满足不频繁启动 ≤15% 限值** ✓。

### 7.7 末端压降（电机端子）

干线 100m YJV-4×240：$R_{60}=0.0218$ Ω（[CALC-VL-001 §7.2](CALC-VL-001-voltage-deviation-and-loss.md) 取值），$X=0.0076$ Ω。

启动电流：

$$I_{st} = K_{st}\, I_N = 6.5\times\frac{75}{\sqrt3\times 0.38\times 0.85\times 0.93} = 6.5\times\frac{75}{0.5204} = 6.5\times 144 = 936\ \text{A}$$

线路压降（启动 $\cos\varphi_{st}=0.3$、$\sin=0.954$）：

$$\Delta U_{line,st} = \sqrt3 \times 936\times (0.0218\times 0.3 + 0.0076\times 0.954) = 1.732\times 936\times(0.00654+0.00725) = 1.732\times 936\times 0.01379 = 22.4\ \text{V}$$

$$\Delta U_{line,st}\% = \frac{22.4}{380}\times 100\% = 5.89\%$$

末端电机端子电压：

$$\delta U_{M,st} = \delta U_{bus} - \Delta U_{line,st}\% = (100-8.30) - 5.89 = 85.81\%$$

启动转矩与端子电压平方成正比：

$$\frac{T_{st}}{T_{st,N}} = \left(\frac{U}{U_N}\right)^2 = (0.858)^2 = 0.736$$

即端子电压降至 86% 额定，启动转矩降至额定启动转矩的 73.6%。主泵要求启动转矩 $\geq 30\%$ 额定（离心泵），满足，可直启 ✓。

### 7.8 敏感负载共用母线的复核

若电梯变频器（敏感 $\leq 3\%$ 限值）共用本母线，$8.30\%>3\%$，**须改启动方式**。改用软启动器（限流 $K_{st}'=2.5$）：

$$S_{stM}' = 2.5\times 0.0949 = 0.237\ \text{MVA}$$
$$\Delta U_{st}'\% = \frac{0.237}{16.13+0.237}\times 100\% = 1.45\%$$
$$\Delta U_{T,st}'\% = \frac{0.237+0.20}{0.63}\times 6\%\times 0.954 = 0.694\times 6\%\times 0.954 = 3.97\%$$
$$\Delta U_{bus,st}'\% = 1.45\%+(3.97\%-2.83\%)=2.59\% < 3\%\ \checkmark$$

**结论**：与电梯共用母线时须用软启动器（限流 2.5 倍）替代直启，母线压降至 2.59%，满足变频电梯敏感限值。
